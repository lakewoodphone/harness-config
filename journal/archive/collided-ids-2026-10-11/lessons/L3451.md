**L3451 · No ports is not no route: dead USB, no Wi-Fi and no Bluetooth still leaves the SD reader - copy keyboard-only with one robocopy**

**The situation (Weitman, 2026-10-08).** A Lenovo IdeaPad Slim 1-14AST-05 (`81VS0001US`, S/N
`R90WH06Z`) whose owner needed her files copied off before retiring it. On this one machine every
obvious route was gone:

- **USB ports dead** — `WO26082712634`, closed `unfixable` 2026-09-14.
- **No Bluetooth** — so the shop's own workaround, which it had already offered her (rent her a
 Bluetooth mouse for a deposit minus 20), could not have worked.
- **No Wi-Fi** — this model carries Wi-Fi and Bluetooth on **one combo module**, so when her TAG
 filter removed the internet it took both. That kills every network copy route: email, OneDrive,
 SMB, "send it to herself".
- **Touchpad disputed/dead**, so Windows itself was hard to drive.

**The route that was there the whole time: the SD card reader, and the keyboard.**

1. SD card in.
2. `Win`+`R` → `cmd` → `Enter` — no pointing device is touched at any point.
3. `robocopy "C:\Users" "D:\Weitman-backup" /E /R:0 /W:0 /XD AppData "All Users" Default "Default User" Public`
 `/R:0 /W:0` skips a locked file instead of retrying it forever; `AppData` is excluded because
 Windows holds files open inside it.

**Why this is a lesson and not a note.** The previous session spent **three phone calls over two
days** hunting a pointing device and ended at *"either working really hard to get the data or
hiring someone to work really hard to get the data."* The transfer was never a pointing-device
problem. **The touchpad is a comfort problem; the port inventory is the blocker.** Ask "which ports
still work" before asking "how will they click."

**Check the combo module before blaming a driver.** On filtered (TAG / Techlo) devices the WLAN+BT
card is sometimes physically removed, which removes Wi-Fi and Bluetooth together and cannot be
restored by any driver method. Do not offer a Bluetooth accessory before confirming Bluetooth
exists — the shop made that offer in writing and had to walk it back the same day.

**Price it honestly when the port inventory is thin.** An SD reader on this class of machine runs at
SD speeds: tens of gigabytes is on the order of an hour, with a handful of files skipped because
Windows holds them. **Bench time, not expert time, and no data-recovery lab** — that distinction is
the difference between a courtesy and a quote.
