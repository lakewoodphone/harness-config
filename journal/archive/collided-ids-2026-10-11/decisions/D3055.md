**D3055 · 2026-10-11 · 2026-10-11 - the authority is secratary-cloud; the office box is a shadow rollback; every agent bridge points at the cloud.**

**DECIDED 2026-10-11 (ZABZ-TECH, dev decision -- not the owner's).**

1. **`secratary-cloud` is the authority.** Cloudflare CNAME `api.abletelsolutions.com` ->
 tunnel `3e62916c-04ac-421b-b4a4-9af0852d8024`; API `company-api.service` on loopback :8002; repo
 `/opt/company`; store `/root/authority.db`. The office `secratary` is a SHADOW: it keeps
 `cloudflared` for `dialer.abletelsolutions.com` (:8899) and `secretary-ssh.abletelsolutions.com`
 (:22), and everything else it runs is a rollback copy, not a source of truth.

2. **Every agent bridge points at the cloud.** ssh alias `secratary-cloud` (tailnet IP
 100.73.176.126, root, `~/.ssh/id_ed25519_hetzner`); `presets/zabz` and `presets/yocheved`
 retargeted to `/opt/company`; live `profiles/web/cordis.patch.yml` on both ZABZ-TECH and the
 authority corrected. Commits `bb73261` and `e51de44` on `origin/main`.

3. **`ps_mcp_server.py` must never hardcode a store path again.** It resolves `SECRETARY_DB`, then a
 sqlite `DATABASE_URL`, then the historical `ROOT/data/secretary.db`, and the API base is
 `SECRETARY_API_BASE` with `http://localhost:8002` as the fallback. Same reasoning as the
 models-resolve-at-runtime rule: a path is a deployment fact, and a deployment that moves turns a
 hardcoded one into a confident lie.

4. **Do not stop the office Dialpad pipeline yet.** `lpt-dialpad-apply.sh` is office-only and is the
 only path carrying Dialpad-derived notes into the shop's operational Postgres. It moves first;
 the harvesters stop second. A one-writer end state does not justify a customer-facing gap.

5. **Do not start a second wake dispatcher.** The office `wake-fanout` runs every minute; the cloud's
 has no cron and its last run failed on prompt transfer. Two dispatchers double-wake. This is one
 switch, made when the transfer is proven.
