**L3763 · Apple ID sign-out blocked by 'restrictions' is a Screen Time restriction; the shop had no SOP for it**

## What I learned

**"Sign out is not available due to restrictions" is Apple's own error string, and Apple names the cause:
a Screen Time passcode / Screen Time restriction.** Not Find My, not iCloud, not a forgotten Apple ID
password. Source read live 2026-10-13: <https://support.apple.com/en-us/101973> (published 2026-09-15).

The two and only two mechanisms:
1. **Screen Time** on with a passcode, and Content & Privacy Restrictions blocking **Accounts** (older iOS
 "Account Changes") under **Allow Changes to Settings**. The same list holds **Passcode** / "Passcode
 Changes" — which is why the *same* restriction also blocks removing the lock-screen passcode. One
 restriction, two symptoms.
2. **A configuration profile** (MDM / school / carrier / refurbisher) with `allowAccountModification=false`
 → Settings ▸ General ▸ VPN & Device Management.

**Screen Time passcode recovery is the path when the passcode is unknown** — Settings ▸ Screen Time ▸
Manage Screen Time ▸ Change Screen Time Passcode ▸ *again* → it asks for the **Apple Account and password
used to set up Screen Time Passcode Recovery**, which is frequently a **different** account from the one
signed in on the phone (and for a child, it must be done on the family organizer's device).
<https://support.apple.com/en-us/102677>. If there is no recovery account, Apple documents no reset path.

**The order that matters: clear the restriction → Find My off → sign out → only then, if still needed,
erase.** Erasing before sign-out leaves Activation Lock and produces a phone nobody can activate.
