## Traps paid for in this session

1. **`lpt sql` goes through PowerShell, which mangles the statement.** Embedded double quotes are **stripped**,
 so `o."customerId"` arrives as `o.customerId` and Postgres folds it to lowercase:
 `column o.customerid does not exist`. Use `to_jsonb(orders)->>'customerId'` instead — never a quoted
 camelCase identifier. And **a multiline statement is truncated at the first newline** ("syntax error at end
 of input"): keep the SQL on one line.
2. **A per-column sweep must be chunked.** 238 UNION ALL arms is ~40 KB of command line; Windows refuses it
 with `The filename or extension is too long`. ~20 arms per call works.
3. **`lpt sql --json` emits ONE pretty-printed JSON object, not JSONL.** Join every output line before
 `ConvertFrom-Json` and read `.rows`.
4. `lpt --json sql` on 238 columns took **26 s** — use `--json` once to learn the schema, then query narrowly.
