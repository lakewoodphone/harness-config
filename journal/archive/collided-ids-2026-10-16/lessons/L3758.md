**L3758 · Parts-price research: Cloudflare/blocks playbook (laptopscreen, mobilesentrix, DVW, eBay) + A3401 display price floor**

Parts-price research (MacBook Pro 14 M4 Pro, A3401/A3112/A3185 display assembly), read 2026-10-13.

BLOCKERS AND THE WAY THROUGH THEM (reusable, cost me most of the session):
1. laptopscreen.com returns HTTP 200 with a 0-BYTE body to this estate's egress IP (71.104.140.242) for EVERY path - home page, model pages, all of it - to both plain HTTP and the playwright browser. It is NOT a Cloudflare interstitial you can wait out, and it is NOT a 404. Do not conclude "not available" from it. r.jina.ai renders the site perfectly: prepend https://r.jina.ai/ to the URL and fetch that. The plain web_fetch tool worked on jina; the MCP fetch server got 403 from jina (rate limit) - retry later or use web_fetch.
2. laptopscreen.com model-page URL form uses TILDES, not spaces: /English/model/Apple/MACBOOK~PRO~14~M4~PRO~A3401~(LATE~2024)/ . The space-encoded form 404s with a real "No items found" page. Get exact names from the series index: /English/series/Apple/MACBOOK%20PRO%2014/ .
3. laptopscreen.com's own /English/search/?q=... returns only boilerplate through a proxy - not usable. Use the series index or web_search.
4. To tell "no products" from "extraction failed", fetch a control model the site definitely stocks. The 2021 14" A2442 page renders "2 items found" with prices and grades; the 2024 A3112/A3401/A3185 pages render ONLY the grading legend and no item cards. The control is what makes the negative real.
5. mobilesentrix.com and dvwarehouse.com return Cloudflare 403 ("Just a moment..." / "Attention Required") to this egress, in the browser too. Both render fine through r.jina.ai. mobilesentrix.co.uk was NOT blocked and loaded directly in the browser.
6. eBay serves 403 / "Pardon Our Interruption..." after a handful of searches from one session. The FIRST search returned the full item list with prices and URLs; the used-condition-filtered follow-up was blocked. Get everything in one pass, and extract hrefs (a[href*="/itm/"]) in the same call as the text.
7. A playwright browser session is a SINGLE lock file (C:\Users\ezabz\AppData\Local\ms-playwright-mcp\mcp-chrome-*). A parallel subagent that also wants the browser fails with "Browser is already in use ... use --isolated". If you fan out, give browser work to exactly one agent; others must use a different browser path (firecrawl worked).
8. Our egress geolocation is not reliably US - a mesh subagent got a "we noticed you are in Turkey" storefront switch, and genuineparts.mobilesentrix.com rendered MDL, not USD. Pin the storefront and confirm which currency actually rendered before believing a number.

PRICE FLOOR OBSERVED (2026-10-13, all reproduced first-hand): used/OEM-pull complete lid assembly $369.95 (Maya Cellular Parts, IN STOCK); genuinely NEW Apple 661-41792 $595.00 (DV Warehouse, Available) vs Apple Self Service Repair $659.12 ($571.12 net after an $88 core-return credit); MobileSentrix US used OEM-pull Grade A $521.87 and Genuine OEM 661-41792 $644.45. Apple publishes NO flat out-of-warranty display price for the 14" M4 Pro - its pricing widget shows only "Battery service $249" and "Other damage* -". AppleCare+ screen/enclosure accidental-damage fee for all Macs except MacBook Neo is $99.
