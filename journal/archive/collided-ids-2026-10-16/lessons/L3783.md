**L3783 · Round 2 tags tool-failure on 66% of his sessions against round 1's 10% - one is wrong, and the test says which is only half-answerable**

THE DISCREPANCY. Round-2 mesh readers tag tool-failure on 65.9% of sessions (162 of 246 clean, as of 19 shards). Round 1 tagged 10.2% over a LARGER set. That gap is too big to be noise, so I treated it as a suspected artefact of my own doing: each session block in shards2/*.md carries a header line I put there - 'failure classes: exit_nonzero x17, overloaded x3, ...' - and a reader shown '17 failures' in the header of every session is being invited to tag one. A tag induced by the prompt is not a measurement. THE TEST, needing no re-reading. The corpus holds a deterministic per-session count of failure signals in sessions-index.tsv (column 7, 'fails'), computed from isError flags and failure regexes rather than from any agent's judgement. If the tag is real, tagged sessions should carry materially more recorded failures. RESULT, 417 records, all matched to an index row: sessions TAGGED tool-failure (273) have mean 32.2 recorded failures, median 17, and **0.0% have zero**; sessions NOT tagged (144) have mean 14.9, median 5, and **32.6% have zero**. So no session was tagged without a recorded failure -- the tag is grounded and is not noise. MY OWN ERROR, CAUGHT AND CORRECTED IN THE SAME RUN: the first version of the validator read column 8, which is 'events', not 'fails', and produced a mean of 886 -- an implausible failure count that is what exposed it. An implausible number is a gift; the second run used column 7. THE HONEST CONCLUSION, which is not the same as 'the number is right'. The tag means 'this session CONTAINS tool failures'; it does not mean 'tool failure is why the session went wrong'. The digest primes readers toward the first reading, so 65.9% is an upper bound on real tool-failure friction and round 1's 10.2% is a lower bound, because round 1 read 256 KB heads and 220-char turns and simply could not see the failures its successors can. THE NUMBERS ARE NOT COMPARABLE ACROSS ROUNDS, and any document that puts them side by side without saying so is lying by juxtaposition. The durable rule: when a measurement layer changes, the metric it produced changes too, and a metric is only comparable to another taken the same way.
