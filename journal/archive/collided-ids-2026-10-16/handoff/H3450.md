## FIXED

1. **The mesh, in the right place.** Restarted `mesh-broker` on the OFFICE box - the one host that can
 actually read the node surfaces - and **enabled** it (it was `disabled`, so a reboot would have
 killed it again). Its own report now: `nodes 5, reads 5, failures 1, SUMMARY ok=4` with 23 free

 lease released. Note the pressure line was itself information: the local node was at 92.2% commit

 **The broker running on a frozen box is a deliberate, documented exception** (it reads node health

2. **The money monitor that lied.** `financial_alert_sweep` reported `success: true` **2,859 times**

 `quickbooks_service._open_local_ledger()` called `_repo_path(settings)` FIRST, which raises when
 `QB_AGENT_REPO_PATH` names a repo that never came over from the office box - so it returned None
 BEFORE resolving the ledger path, while the real 22 MB ledger sat at
 `/root/accounting-data/live/accounting.db` (migrated and verified by this seat earlier today). The
 repo is only where a `.env` with overrides lives; the DATABASE is not in it. The ledger is now
 resolved first, with a documented fallback path, and the repo used only for overrides. **Proved:**
 the resolver connects and reads **8,490 transactions**, and `get_local_ledger_snapshot` returns
 `ok: True, error: None`. **STAGED, NOT DEPLOYED:** the running API still holds the old module, and
 this unit was OOM-killed at 05:47Z with no `MemoryMax`, so the reload waits for a supervised
 restart rather than being taken unattended.
3. **The anchor is being given a second home.** It exists on ONE consumer SSD in a 2013 desktop with
 no UPS, and there is **no provider snapshot for that host** (it is a physical machine - measured;
 `lpt-survivor-01` is the Hetzner standby, a different machine). Every other copy of that state has

 backup. Nowhere on the estate has room for a 23.6 GB copy except object storage (authority ~20 GB

 `scripts/mesh/anchor-to-r2.py` streams it gzip -> 64 MiB multipart upload, with **zero local

 Its `--verify` mode is explicit that it proves the sidecar and the object size AGREE and does NOT
