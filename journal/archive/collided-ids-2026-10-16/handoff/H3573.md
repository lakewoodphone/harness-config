2. OUR OWN DIALPAD LINE IS NOT A CUSTOMER'S SECOND PHONE NUMBER. Filtering `communications` on
 last-10 "7326552355" matches EVERY outbound SMS the shop ever sent, because that is
 +17326552355, DIALPAD_SMS_FROM_NUMBER. A query that included phoneNumberFrom/phoneNumberTo for

3. ffprobe CANNOT DECODE A PDF and says so as "Invalid data found when processing input". My first

 no validator - PDFs now get a header+%%EOF check, images get magic bytes, and only av goes to
 ffprobe.

 control (126,460 rows here) so a vacuous zero cannot pass as health.
