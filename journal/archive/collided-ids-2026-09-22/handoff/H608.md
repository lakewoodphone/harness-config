jsonb** (created by that 2026-09-16 migration, per D173). So the fix is not "invent a source", it is

instead of adding an eighth hand-written string. That keeps it consistent with the rule that made
Mon/Tue/Thu 10:30-17:30 true everywhere in the first place.
