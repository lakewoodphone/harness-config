**What that means.** The dead-instruction defect was one contributing mechanism. The dominant

`work_sessions` by outcome **and** by marker before anyone calls this fixed. If
`[STALLED_REPEATING_OUTPUT]` disappears but `[STEP_BUDGET_EXHAUSTED]` does not, the fix worked
and the real problem is elsewhere — which is the more likely outcome.

The methodological point worth keeping: **a fix that is verified against the mechanism it
