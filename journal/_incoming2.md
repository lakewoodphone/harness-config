### Lesson worth keeping

A tool can be wired into the loop, run on schedule, exit 0, and print a healthy line while being
pointed at a path that does not exist. `0 integration item(s) filed` was indistinguishable from
"nothing to integrate" for 27 runs. Every source that can skip a subject must SAY it skipped, and the
line it prints must distinguish "nothing to do" from "I could not look". Same shape as the pain rule:
a refusal is not a negative.

Second lesson: two branches implementing the same item merge without conflict when their code sits far
apart, and the result is dead code that still counts in a route inventory. `/readyz` did it twice in
one day. A guard test on "defined exactly once" is cheaper than finding it through a security audit.
