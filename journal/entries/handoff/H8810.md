## One thing still wrong, named rather than hidden

Those documents are counted in `host_pushes` under **"local"** — the authority's own row — so `/health`'s
"has this host pushed recently" line is empty for the mini. Two causes were found and fixed
(`_local_host()` trusted a `HOSTNAME` environment variable that held the literal string "local"; the
spool never passed a host at all), and **the mislabelling survived both**, so the derivation on the
receiving side differs from the sender's. The documents themselves are attributed correctly, which is
what search uses; the counter is not. Recorded in the commit as OPEN.
