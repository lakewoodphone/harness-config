## The trap for the Ullman machine specifically

The doc scopes this flow to **refurbished PCs being resold**. The Ullman laptop is a customer's data-bearing machine with an **intermittent input path**. Two reasons not to run it there before the power path is fixed:

1. **It does not answer the question the case is waiting on.** It answers RAM / disk / CPU health. The open question is a fractured jack or cracked input solder joint against a `BQ24780S` protection latch.
2. **The surface scan reads the whole drive and takes hours** (`badblocks`, no mode flag — read-only, so a power loss cannot lose data, which is the 2026-10-14 correction), on a machine that cuts out under flex. It will not finish, and the result will be nothing.

The case's own bench plan also says: **read the drive's encryption state before anything else touches the SSD.**
