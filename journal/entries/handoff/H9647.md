## 2026-10-19 18:40 UTC - ZABZ-YOGA - kosher-filter-ai discipline rounds 1-2: the estate had no value checker at all, and now it has two

Owner opened a new session on HANDOFF-REPO-DISCIPLINE-2026-10-18 and said the previous session did the checklist but "there is so much more to do", and that this is a paying production app: every number, feature, script, test and document must have one owner, nothing may contradict, and any question must be answerable in one hop. Asked for 50+ rounds.

Baseline before touching anything: branch agent/kf-counter-install-nonwipe at fbc31e4, working tree clean, `python scripts/docs_check.py` -> 7 of 7 pass. So the estate was GREEN and still wrong. That is the finding that shaped both rounds: every checker this repository had was about LINKS and STRUCTURE. Not one compared a VALUE.

ROUND 1 - D-20261019-02, the fact register. Measured the estate first with a one-pass scan: three different "tests passed" totals published at once (1632, 1651, 1667) and five different route counts (137, 304, 338, 364, 443), each in a file that looked authoritative, with every link resolving. New mechanism: scripts/facts/<id>.py owns exactly one number (ID, QUESTION, MODE, VALUE, CITE regex, EVIDENCE, MEASURED, NOTE, compute()); scripts/check_facts.py recomputes every `command` fact and then compares every citation of every fact in every live/generated/draft/pointer document, failing with path and line; docs/FACTS.md is generated; docs/runbooks/add-a-fact.md is the procedure. 11 facts live. Wired into docs_check as #8.

 KEY DESIGN DECISION worth not re-litigating: documents MAY restate a number, and the restatement is VERIFIED. "Documents must link and never restate" is unimplementable across 295 documents and would be evaded in a week. One owner per fact is preserved because the register owns the value and the document is a checked citation.
 KEY DESIGN DECISION 2: a dated record declares itself with `facts-as-of: YYYY-MM-DD` and is exempt from comparison. Audits, handoffs and research notes are records; correcting their numbers would destroy the record. It must be a declaration, never inferred from a filename.
 TWO FACTS DELIBERATELY NOT CREATED: the document count and the decision count. Both churn on every legitimate commit and both are already owned by generated pages (INDEX.md, REGISTER.md). A fact register that must be edited whenever anyone writes a document is a second index.

ROUND 2 - D-less, the generated-document contract. docs/API_REFERENCE.md was 7,294 lines with `generated-by: unrecorded`, so it could not be current and nobody could know: it said 331 paths / 355 operations / 30 tags against a live app serving 337 / 365 / 0. Built scripts/gen_api_reference.py (deterministic, --check, --diff, and now lists query parameters the old one omitted). Built scripts/check_generated_docs.py: a generated document must name the command that WRITES it, and the check is "run it and see whether it changes any bytes" - a file it does not touch is current, a file it rewrites was out of date. It restores the original bytes and reports; `docs_check.py --write` is the fix. GEN-UNRECORDED / GEN-DEAD / GEN-UNSAFE / GEN-STALE / GEN-FAILED, all proved by --selftest. Writers run 4 at a time: nine in series cost 201 s of the gate, four at a time 147 s. Wired into docs_check as #9.
 ARCHITECTURE_DIAGRAMS.md was the same defect in a different shape and was NOT fixed by generating it: it declared itself generated, named no generator, and carried a snapshot table + router inventory + package roots that REACHABILITY.md and FACTS.md already own - which is why a mermaid label still said "26 routers / 304 HTTP+Endpoints". It is now `live`, keeps the four hand-drawn diagrams, points at the pages that own the numbers.
 Also superseded (registered contradictions are not resolved ones): IMPLEMENTATION_BACKLOG.md, which carried a "CONTRADICTION REGISTERED" banner and still said LIVE at the top; and QUESTIONS_AND_CLARIFICATIONS.md, which decision D-20261019-01 had already ordered archived on 2026-10-19 and never was.

METHOD THAT FOUND EVERYTHING: compare a claim against the SYSTEM (grep the code, import the app, count the files), never against another document. Two consecutive rounds of this produced more real defects than reading the 295 documents would have.
