## The six traps this session paid for

1. `git stash pop` with no index pops **another session's WIP** (L4769). Always `stash pop stash@{N}`.
2. `install -o "$(stat -c %U …)"` fails with `invalid user: 'UNKNOWN'` **and the script continues to
 restart the service anyway**. Write in place (`cat NEW > LIVE`) and compare shas before touching a
 service.
3. A control must isolate the **code**, not the code and its tests.
4. A `find /` count is not the count of the thing: 201 profile copies was really **11** live ones.
5. **md5 is not sha256.** I raised a false alarm that a deployed file had changed by comparing an md5
 from the deploy script against a sha256 from the check. Compare like with like.
6. `/opt/company` is the live company-api working tree. Copy single files in, back them up, restart
 deliberately, never run `git` verbs in it.
