## 2026-10-18 01:54 UTC · ZABZ-YOGA · Waze Device sign v12 redesigned and print-proved; W2 next

Reading `_waze-fleet-sync/HANDOFF-2026-10-16.md` §5.1 and doing it. The sign was the one item the owner
had explicitly asked for and the one thing left between the business model and a first customer.

**What changed, and only in graphics — the copy is untouched, character for character.**

1. **One icon family.** v11 had four glyphs on a 32-unit grid at three different drawn weights, each
 inside its own circle at 20% opacity. v12: every glyph on ONE 24-unit grid, ONE stroke width (2.2),
 round caps and joins, no fill on any glyph, solid khaki disc behind, navy glyph. The family rules live
 in exactly one CSS rule (`.row svg .g`), so they cannot drift glyph by glyph. Four icons, one per row
 (CarPlay = display screen; network = wifi arcs + dot; countries = globe; cap = arrow rising to a
 ceiling). Glyphs sized at 30px, lead row 34px, so the disc reads at 10 feet.
2. **The embedded font is gone.** `@font-face` with the Inter variable font as base64 was 64,344 of the
 80,850 bytes. Removed; system stack only (`-apple-system, BlinkMacSystemFont, "Segoe UI", ...`).
 File is now 16,264 chars / 16,537 bytes. Verified on the record copy: `grep -c @font-face` = **0**.
3. **The stale header comment is corrected.** v11's comment still documented 900c/250 MB/1800c per GB
 while the sheet had already been re-lettered to 8 a month / 150 MB / two cents. A comment that
 contradicts the sheet is worse than none; v12's header now names the source of every number on it.

**The drift bug worth remembering.** The built `waze-device-sign-letter.html` had been hand-edited on
2026-10-17 to the new plan copy (9/250 MB -> 8/150 MB/two cents) and the edit **never went back into
`templates/v11.tpl.html`**, which still said `$9` / "250 MB included". Anything that rebuilt from the
template would have silently restored the wrong price. Confirmed by diffing template vs output with the
font stripped: two copies of the same text, one right and one wrong. Fix: the template is now named
`templates/waze-device-sign-letter.tpl.html`, so it emits exactly the path the owner opens, and
`tools/build.mjs` was taught to copy a token-less template straight through (it used to `SKIP` anything
without the font token, which is precisely what let the output and the source part company).

**Print is proved, not assumed.**
`node tools/print.mjs waze-device-sign-letter.html shots/waze-device-sign-letter.pdf` ->
`pdfPages: 1`, `mediaBox: /MediaBox [0 0 612 792]` (= 8.5 x 11 in exactly), `fitsHeight: true`,
`fitsWidth: true`, sheet 816x1056 CSS px = 8.5 x 11 in. Then rendered under `emulateMedia({media:'print'})`
and looked at it: the teal background prints, nothing is clipped, the fine print ends line 1 at
"work again." with "14-day returns." alone on line 2 (a `·` separator was stranded at the head of that
line before the fix). Also rendered at 4/10/20 ft with `tools/distance.mjs` and looked: the four discs
read as a khaki column down the left at 10 ft while the headline and the two prices still dominate.
