### What landed

`POST /rules/pending/report` — phone-authenticated, household-scoped, and deliberately a **notification,
not an authority**. The device applies the change itself through the same writer a rules sync uses; this
records that it happened in the audit trail that already exists (`log_admin_action`), which is why it
needed **no new table, no migration and no parity work**.

**The scoping is the security of it.** A phone may report only for the household it belongs to, and a
mismatch and an unknown phone return the **same 403 wording** so a caller cannot enumerate households by
watching which refusals differ. One of the seven tests asserts a refused report leaves **no audit row** —
a 403 that still recorded something would read in the trail as though the decision had been accepted.

### Two mistakes of mine, both worth not repeating

1. **`_require_async_callback` is synchronous in this module and async in `frames.py`.** I copied the
 `await` from the other file and every test failed with *"object function can't be used in 'await'
 expression"*. Same name, different module, different shape.
2. **A new route needs THREE registrations**, not two: `RouteSecurityRule`, `HttpHardeningRule`, **and** an
 entry in `KNOWN_HTTP_ROUTES` — otherwise `test_route_security_audit` fires on the count while the
 classification itself is correct. I had done two of three and CI found the third.

### The recurring CI trap, now three times in three rounds

`docs/audits/dead-citations-2026-10-19.md` was stale **on the merge ref only**: it is generated from what
the tree cites, and main had changed citations. Same root cause as the counter drift in round 22 — **PR
checks run on the merge ref, so a generated document that is correct for the branch can be wrong for the
merge.** The routine is now: merge main, `--write`, commit, push.

### Still owed

*"Applied on this phone. The server has not been told yet."* — which is now the honest statement of an
unfinished wire rather than of a missing route. Wiring it is an HTTP call from the Activity plus a real
report-state display.
