### Three subagent findings worth keeping
1. **The manifest cache is permanent.** `MlModelProvisioner` returns the cached catalogue first with no
 version, ETag, TTL or timestamp, so a broker-side model swap reaches **no installed phone** — the
 feature's entire purpose. Also: model *file names* are still hardcoded in three classifiers and the
 load path never re-verifies the digest (`GantManNsfwClassifier.kt:131`, `NudeNetClassifier.kt:156`,
 `PoseLandmarkerWrapper.kt:182`).
2. **`docs/CLIENT-CONTRACT.md` was the only date-stamped generated page** (`check_client_contract.py:223`
 `updated: __DATE__`, `:252` `date.today()`). The earlier nine-writer fix touched the document, not the
 writer, which had landed ten hours earlier. Guard added, 12 selftest cases, falsified on the real tree.
3. **The device ladder has no level to run on.** `classify(..., ladderLevel: Int? = null)` and
 `ContentProfile` carries thresholds, not a level, so the rung policy is built and unreachable.
 Filed as ledger **1096**.
