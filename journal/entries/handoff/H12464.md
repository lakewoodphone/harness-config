**What a future me should not re-learn:**
1. A lane's green unit tests never start the application lifespan. `python -c "from app.main import app;
 ... audit_http_route_security(app).raise_for_failures()"` is the check that would have caught it.
2. Mount a router **once**, in `router_registry.py`. Mounting it in `main.py` too makes every test-built
 app miss it (audit: "missing reviewed routes") and then serves each path twice (391 served vs 389
 known).
3. Merge conflicts in the same file from two lanes are best resolved by assembling the file from both
 sides programmatically, then checking it **parses** — a hand-kept conflict left git markers in
 `BrokerHeartbeatService.kt` and the Kotlin build failed twice before `check_conflict_markers.py`
 caught it.
4. Bulk `git add -- android/` is how that marker got committed. Stage explicit files.
5. Fetching the `.apk` from this laptop returns a broker-shaped 404 while the host gets 200 — verify
 downloads from the host.
