WHAT THE APP DOES: hides com.google.android.googlequicksearchbox (the Google app), Google Go,
Gemini, Assistant via DevicePolicyManager.setApplicationHidden; adds DISALLOW_FACTORY_RESET,
DISALLOW_SAFE_BOOT, DISALLOW_INSTALL_UNKNOWN_SOURCES, DISALLOW_UNINSTALL_APPS,
DISALLOW_APPS_CONTROL. Boot receiver re-applies every boot. One screen prints per-package
HIDDEN / NOT HIDDEN so the result is read off the device.

HOW TO INSTALL (both routes documented in tools/device-owner/README.md)
1. Non-wipe first: `adb install -r`, then IF `adb shell dumpsys account` shows NO accounts -
 settings put global device_provisioned 0 / secure user_setup_complete 0,
 `adb shell dpm set-device-owner com.lpt.searchlock/.AdminReceiver`, then restore both flags.
 This is the "dirty provisioning" workaround from kyocera-lockdown-1-device-owner-setup.md:80.
2. If it returns "already provisioned": factory reset, provision before the setup wizard
 finishes. AOSP requires it; not a limitation of this app.
Removal also needs a factory reset. That is exactly what makes it tamper-resistant.
