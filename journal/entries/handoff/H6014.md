## Method notes worth keeping

- The `lines` key on the stdin JSON path renders `! `-prefixed lines as bold headlines and word-wraps
 the rest; 306 px wide (29 mm) is the tape width the anchor renders at.
- PowerShell cannot do `< file` redirection for a native command the way bash can. `scp` the JSON to
 the anchor and let the remote shell do the `<` — do not pipe from PowerShell.
- **Never write `2>/dev/null` in a PowerShell command**: PowerShell reads the `/dev/null` as a Windows
 path and fails with `Could not find a part of the path 'C:\dev\null'`.
