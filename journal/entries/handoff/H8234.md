### A mistake worth recording

`python prune-local.py --apply` took `--apply` as the *database path* and silently created a 0-byte
file named `--apply` in the working tree. Caught immediately, file removed, argument parsing made
order-independent. The lesson is the same shape as `L8702`: a script that accepts "the next argument"
as a path will accept a flag as a path, and the failure is silent because sqlite happily creates the
file.
