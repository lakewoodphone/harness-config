## Transferable lessons from this session

- **A fresh `git worktree` has no `node_modules`.** Run `pnpm run worktree:setup` (the repo's own script;
 exit 0) first. Before that, `prettier`, `eslint`, `vitest` and `turbo` are "not recognized" and **every
 check exits 1** — an environmental failure that reads exactly like a code failure.
- **`prettier --write` in a CRLF worktree rewrites the entire file** (the diff went 22/14 → 219/205 lines).
 `git stash push -- <paths>`, restore the real content, keep the small diff. A whole-file EOL churn in a PR
 is unreviewable.
- **The LPT deploy path:** `.github/workflows/deploy-env.yml` — push to `test` deploys the test env, push to
 `main` deploys production behind the `production` GitHub Environment's required reviewer. The runner is
 `secratary-lpt` (a host that is **not** in `settings/machines/host-posture.tsv`) with labels
 self-hosted/Linux/X64/`lpt-deploy`. Slug is **`lakewoodphone/phone-and-tech-full`**, not the org name.
- **Never build a remote command with nested quotes.** pwsh → ssh → cmd → PowerShell mangles parentheses and
 quotes (it cost two failed attempts here). Put the work in a `.ps1`, `scp` it, run it.
- **The price was 299 in the code, 285 in the owner's own 2026-10-05 plan, and "case included" on the site —
 because queue row 255 was resolved with no answer text** and `PRICING-AUTHORITY` defended the code default
 with a citation to `D3039`, which is not a pricing decision. Ask what writes the field, and check the row
 holds his words, not just a status.
