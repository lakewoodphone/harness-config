# H (2026-10-20, round 2) - the gate was red only where it mattered, and the registry's DoD got a reader

## What round 2 produced, all verified by command
1. **CI found what this host could not.** PR #64's docs job failed on the Linux runner with **256 FM-STALE**
 findings while the same commit was green on every workstation. Cause: `actions/checkout@v4` fetches one
 commit, so `git_last_change_map()` reports the tip commit's date as the last change for every file and every
 document with `updated: 2026-10-19` looks stale. Fixed both halves: `fetch-depth: 0` in
 `.github/workflows/docs-check.yml`, and `check_docs_index.py` now detects a shallow clone
 (`git rev-parse --is-shallow-repository`) and reports ONE finding, `FM-SHALLOW`, naming the remedy, instead of
 256 that look like defects. Proven on a real depth-1 clone: `docs checked: 318, findings: 1, FM-SHALLOW`.
 Added to `--selftest` (18 codes).
2. **The registry's `definition_of_done` existed and nothing read it.** A running shift added it to the
 `kosher-ai-filter` row at 16:10:17Z (67,089 -> 67,931 B). `grep -rn definition_of_done /root/bin --include=*.py`
 -> no reader. Wired one: `project-keepalive.py` renders it into the shift prompt above the generic paragraph.
 Proved by rendering: `standing_contract()` on the live row gives 17,956 chars containing the block; on
 `lpt-website`, which lacks the field, it does not.
3. **Ledger 667 and 644 are both `done`**, and AUTONOMY.md still called 667 "the enforcement point today". The
 page now carries the measurement instead.
4. **harness-config import (item 794)** by a worker: before `1 identical of 37`, after `37 identical of 37`. Two
 real divergences found: `_flag.py` (the repo has a saturation guard from commit 08f85e75 that NEVER reached
 the authority; live has October fixes the repo lacked) and `run-wake-sources.sh` (2,979 B in the repo against
 21,713 B live - the cron entry point itself, not imported because it sits outside `sources/`).
 Branch `chore/wake-sources-import` at `4a8168f6`, cut from harness-config's LOCAL main `1bd92a99`, which is
 18 ahead / 91 behind `origin/main` - so it must be cherry-picked onto origin/main, not merged.

## Lessons
- **CI is a different observer, not a formality.** 256 false findings were produced by a checkout depth, and no
 workstation could have seen it. When a check compares a field to git history, ask what the history looks like
 where the check runs.
- **A field added by another agent five minutes before you look is still decoration until something reads it.**
 The registry is live state that shifts mutate; re-read it before quoting it.
- Adding a checker invalidates `docs-checker-count` (FACT-STALE, 17 -> 18), and `--write` does NOT fix it - it
 rewrites the page, not the owning module. The FACT-STALE message said "run --write"; it now names the file, the
 value and the MEASURED bump. Fifth time this estate has lost time to a remedy that does not remedy.
