## 2026-09-28 20:03 UTC - ZABZ-TECH - Round 23: one command that says what the system is doing, and the current bottleneck named honestly

BUILT: `autonomy-status` - one read-only command that answers, in one call, everything I have been
writing a throwaway probe script for all evening (roughly ninety of them). It prints releases vs the
backstop, failures, spend vs the ceiling, caps in force, wake states, ledger states, todo by priority,
proofs (settled attempts carrying one, out of settled, with how many are still in progress), in-flight
dispatcher processes, BOTH heartbeat ages, per-project todo/running/done, the last few releases, an
explicit PROBLEMS list, and an IDLE line that says WHY nothing is running - and says "healthy" when the
reason is a guard doing its job, so nobody "fixes" a working system.

Read-only by construction (no claim, no finish, no flag, no merge, no cron edit, no write to either
store), safe to run by anyone at any time, exit always 0, and `--json` for a machine. Verified live:
`PROBLEMS: none`, both heartbeats under 3 minutes, and the IDLE line naming the exact reason.

It corrected two of my own numbers while being built: the proof ratio now counts SETTLED attempts only (a
claim still in progress carries no proof by definition, so the old ratio understated it - it is 12 of 13,
not 11 of 13), and a disabled test project no longer prints a row of zeros.
