VALIDATE, and a trap worth remembering. `pnpm validate` in the worktree: frontend **747 files / 10,459 tests passed**; backend test and typecheck FAILED. The failures were **NOT real**: the generated Prisma client predated `model ComputerRequest`, so four `Property 'computerRequest' does not exist` errors appeared. After `npx prisma generate`, backend typecheck exits 0 and the endpoint suite is 21/21. **`pnpm validate` in a fresh worktree needs `prisma generate` first, or it reports the newest model as broken.** CI does this for you; a local run does not.
