**And the general lesson those two make, which belongs in every future fleet brief: a pinned baseline measured on a branch is not the baseline of what ships.** Both the route count and the SQL call count are *global* numbers, so two branches that each bump them cannot both be right, and neither branch can discover the other's delta. The manager must recompute both on the merged tree — which is why "never merge a generated file from a branch" is not tidiness, it is the only way the numbers can come out true.
