## The sixth missing import, and it is a pattern now

D4's first run failed with `NameError: name 'timedelta' is not defined`. The module imported
`date, datetime, timezone` and not `timedelta`. Same shape as `import sys` in `charge_msg` and
`timezone` in `charge_msg` — **three missing-import defects in a single day, in code I wrote and
re-read each time.**

That is no longer a coincidence worth noting each time; it is a defect class. It has one
characteristic: the failure lands inside a `try/except` that reports a plausible result, so the
missing name surfaces as "no data", "no cache", or "check failed with a reason" rather than as a
crash at import. The remedy that has worked six times out of six today is the same — make the
exception audible — and the structural remedy is **import the module, not the names**:
`import datetime as _dt` cannot be half-right.
