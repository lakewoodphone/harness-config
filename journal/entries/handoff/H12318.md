### Still the highest-value open item: FRP is never armed on the adb seal route

Unchanged from round 2 and now recorded as **P9872**. `ResetProtectionAnchorStore.arm` is called only inside `onProfileProvisioningComplete` (`AdminReceiver.kt:97`); the shop seals with `dpm set-device-owner`, which does not deliver that broadcast, and neither `ACTION_DEVICE_OWNER_CHANGED` nor `onEnabled` arms it. `strings.xml:735` is empty, so `PolicyApplier` sets no FRP policy and logs the refusal. **A factory-reset phone sealed today can be set up again by anyone.** The fix needs one input from the owner: whose Google account is the anchor (owner-queue row **#806**).

### What the audit lane proved about method, and it applies to every future sweep

The obvious grep is not enough. `git grep 'VERSION_CODES\.|SDK_INT'` misses `AntiEvasionPolicyManager.kt:273`, which compares the `sdkInt` parameter to the literal `35`. The working pattern is `SDK_INT|VERSION_CODES\.|sdkInt\s*[<>]=?`. Re-measured after `notify` merged: **44 matching lines, 37 real guards**, in `VersionGuardInventoryTest`.

### Integration lessons, each of which cost time once

1. **Sync every lane with `origin/main` before merging.** All five branched at `37aa6bac`; an unsynced merge shows the newer `docs/` files as deletions and would have reverted them.
2. **The audit tests are supposed to fail at merge time.** `PermissionInventoryTest` failed the moment `notify` fixed the permission it recorded as missing, and `VersionGuardInventoryTest` failed when `notify` added seven guard lines. That is the design working; the merge is not "green" until the record is updated to the measurement.
3. **Resolving a conflict by stripping markers left two `VALUE =` lines in a fact owner and the second silently won.** Always re-read the resolved file, never just the diff.
4. **A `--write` on Windows and the Linux CI can disagree with an identical byte count** (`GEN-STALE`, same size, different sha). Re-running the writer on the branch and committing the result is the fix; confirm idempotence by hashing twice.
5. **`gh pr create` mangles a body containing backticks in a PowerShell double-quoted string** — write the body to a file and pass `--body-file`.
6. **`git worktree` does not inherit gitignored `android/local.properties`**; write it before a lane's first Gradle call.
7. **`adb kill-server` before starting an emulator wedges the run.** The instrumented lane's recipe — start the emulator, then `adb wait-for-device`, then poll `sys.boot_completed` — works; mine did not.
8. **`connectedDebugAndroidTest` targets attached physical phones unless `ANDROID_SERIAL` is set**, and two are attached to ZABZ-TECH. Always set it.
