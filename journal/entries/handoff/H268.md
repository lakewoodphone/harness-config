**The repository is behind production on six auth fixes.** Production is safe; the repo is not.

 `terminal.js` holds **13 managerProcedure** guards.

 `a2pAutoReply.ts` with 0 guards. Per the PART-120 audit, the terminal router minted a
 **live `pst_live_…` Stripe Terminal connection token** unauthenticated from the internet,

 committed state would silently reintroduce all six.**

 **never merged into `test`**. `test` and the audit branch have diverged.
