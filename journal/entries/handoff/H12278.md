### Traps paid for here

- A PowerShell here-string with `\$var` escapes mangles remote scripts into silent argument errors. Write
 the script to a file, `scp` it, strip CR (`tr -d '\r'`), then `bash` it.
- A ParserError in PowerShell rejects the **whole** invocation — no `scp` in that block ran, and the next
 command then failed on a missing file. Verify a transfer landed before depending on it.
- `work.py add --from-json -` reads stdin because "text never passes a shell". Use it, and loop one JSON
 object per line.
- `check_roadmap.py --ledger` passing does **not** mean the bridge is current: the snapshot is dated, so a
 row filed after it is invisible. Refresh the snapshot before trusting a green result.
- `work.py edit` takes the item id as a positional **before** the flags; `work.py edit --priority 1 907`
 parses the flag as the id.
