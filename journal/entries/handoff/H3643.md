## What I learned that I did not know at the start

- **A session run "from the phone" is not indexed by the node list.** `sessions nodes` shows local / secratary / zabz-tech-linux / mac-mini / zabz-yoga — **`secratary-cloud` is not among them**, so the 609 sessions on the authority were invisible to `list --since 2d --sub` until I passed `--host secratary-cloud`. The phone work lands in `--home-zabz-phone--` on the authority (cwd `/home/zabz/phone`).
- **"Synced" in this estate can mean a file copy, not git.** The build session's own handoff says "Synced and verified on ZABZ-TECH … (57/57 markdown files)" — that was a `tar`, and the destination had no `.git`, so nothing could ever tell whether the copy had drifted. That is the defect class to ask about: *how* was it synced, not *whether*.
