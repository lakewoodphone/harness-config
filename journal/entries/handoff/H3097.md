- `ec13f62` **provider**: an empty/unreadable transport host is now UNPROVEN (warn, keep the
 child's message) instead of a discarded run; a present-but-contradicting host still fails but

BROKEN / NOT DONE
- **Child↔parent conversation is NOT fixed and cannot be by configuration.** Measured:
 `prepareContinuable` receives only `{ seed? }` — the continuation manager composes the child
 itself and owns a live in-process `AgentHandle`, so a remote child can never be a continuable
 child in this contract. `README.md:170` names the gap ("remote providers need an Activation
 ownership contract"). Adding `prepareContinuable() { return {} }` would pass both gates and
 silently run the child LOCALLY while the parent believed the mesh placed it — worse than the
 honest failure. A real fix is a message relay over the transport, not a provider flag.
- **Broker per-node concurrency cap and an explicit reroute field: not written.** The broker
 already has `task.exclude` (soft, caller), the hard operator `excluded: true`, and refuses to
 rank unreachable nodes as fitting; what is missing is a cap on concurrent children per node
 and `excludeNodes` on `/place`.

 anything (the very bug `97c9c34` fixes).
