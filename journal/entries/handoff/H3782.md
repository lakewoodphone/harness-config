## THE SOLUTIONS, IN ONE PLACE
1. **Voice input** — done on the six units. `allowDictation=true` + `Enable Dictation` by hand.
2. **Model download with no per-device step** — allow `/mobileassets/` and refuse `/patches/` + `/fullrestores/` on
 Apple's three CDN hosts, at the PAC (a DNS allowlist structurally cannot see paths).
 **The measurement that makes it safe: 0 of 2,532 over-the-air OS-update assets use a `/mobileassets/` path, and
 the dictation model does.** Verified by fetching Apple's own catalogues for
 `com_apple_MobileAsset_EmbeddedSpeech` (80 entries) and `com_apple_MobileAsset_SoftwareUpdate` (2,532 entries).
3. **No self-updating** — the same path rule today; a real update policy once declarations exist.
4. **Surviving future iOS** — **KMFDDM sidecar beside NanoMDM**: one container (`ghcr.io/jessepeterson/kmfddm:v0.8.3`,
 `filekv` storage), `NANOMDM_DM` pointing at it, **no device re-enrolment**, no Caddy change for the device path.
 It unlocks `softwareupdate.settings` (turn off unattended download/install, 90-day deferral), `keyboard.settings`
 and `siri.settings` (both iOS 26.4+, so usable on 26.5.2) and status subscriptions. Roughly half a day to prove on
 one device. `app.settings` (the app-gating replacement) needs iOS 27, so the legacy app keys remain the only
 mechanism on 26.5.2.

## THE FIRM NEGATIVES, so they are not re-researched
- **No Apple mechanism turns Enable Dictation ON.** Every key only disables; the MDM `Settings` command has no
 keyboard or dictation item; `cfgutil` has no such verb; Configurator Prepare has no keyboard option; no MDM vendor
 exposes an enable. The tap stays — or a supervised golden-backup clone removes it (documented for "anything you can
 set in Settings", **untested for this key**; the 300 MB model does not travel in a backup).
- **An update does not remove the profile** and **does not make new apps appear** — the allow-list "only shows or can
 launch apps with bundle IDs in the array"; Settings and Phone are the only exemptions.
- **No downgrade path exists** for an iOS device; Apple stops signing the old version by design.
