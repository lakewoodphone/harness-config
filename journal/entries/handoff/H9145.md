## Two things that were wrong before they were right

1. **The extractor assumed JSONL and a `v` wrapper.** The real object is ONE pretty-printed JSON
 document with `requests` at the top level. The first run reported *15 sessions written* and every one
 was empty — the shape of a silent no-op, and only looking at the count of EMPTY ones caught it.
2. **`v` is a LIST in some exports**, which crashed the first full run with `'list' object has no
 attribute 'get'`.

And one process mistake worth keeping: I edited the script on the laptop with a PowerShell string
replace that silently did not match, shipped it, re-ran it, and read a **stale log** that still showed
the old traceback. Two of those three minutes were spent believing a log instead of checking the file.

## The scope wiring

The backfilled documents sit in the estate index, so `scope=chats` — which queries the company's vscode
tables — could never return them. It now also searches `source_prefix='chat:copilot-'`. Verified:
"audit grand supervisor" returns the archived prompt conversation in 3.98 s.

That 3.98 s is the known expensive corner (a source-filtered search of 673,000 documents to reach 52),
and it sits just inside the 4 s deadline. Worth stating plainly rather than leaving as a surprise.
