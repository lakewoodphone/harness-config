## 2026-10-14 01:06 UTC · ZABZ-YOGA · Window blank-session sharing: cause found, fixed in the engine client bundle, verified on 2 and 3 windows

Owner's complaint: with two or three DSH windows open that have no session yet, typing in one turns
all of them into that session with the same words.

CAUSE (read, then measured). `@deepseek-ai/dsh-client-ui-workspace/lib/client.js`
`UiWorkspaceService.reuseOrCreateBlank()` scanned the WHOLE session catalog for any row with
`blank: true` in the target workspace and reused it. A blank session is a host-side catalog row
(`blank` = `session.seq === 0`, flipped only by `turn/start`, dsh-api-session-controller/lib/index.js:1808),
so the first empty window created it and the next empty window adopted it — every window then
rendered the same conversation. The window-per-origin trick (one loopback port per slot) isolates
`localStorage["dsh.sessions.current"]` but not the catalog, which is shared by every window.

FIX. `window-blank-isolation`, three changes in that one bundle: a per-origin record of the blank
this window created (`localStorage["dsh.sessions.ownedBlank"]`); reuse only that blank, else create
fresh; and never restore/adopt a blank this window does not own (which also detaches an already
blank-doubled window on reload). Applied with
`node ~/code/harness-config/multi-window/tools/patch-window-blank-isolation.mjs --apply`.

VERIFIED, both before and after, with `multi-window/tools/verify-window-session-isolation.mjs`:
* before — 2 isolated browser contexts on the live engine: both persisted the SAME session
 pointer `session-8c62e107-…` → verdict SHARED (the complaint, reproduced);
* after — 3 contexts: three distinct ids, each equal to its own `ownedBlank` → verdict ISOLATED,
 and a reload kept its own id (`sameAsBeforeReload: true`);
* after, on the owner's real path — two slot origins 3215/3216 through dshw-proxy.mjs → ISOLATED.
Engine pid 10668 was NEVER restarted: the client bundle is served per request keyed on mtime, so a
window reload is enough. The six test blanks were archived (`workspace/archiveSession`), census 0
blanks before, 6 created and archived after.

WHAT IS LEFT. (1) A window already doubling keeps restoring the shared session until *New session*
is clicked in it, or until a reload while that session is still blank. (2) Orphan blanks are no
longer recycled by anyone, so a blank abandoned by a closed window stays until the archival pass.
(3) NOT verified by execution: a live turn typed in one window with a second window watched — that
needs a real agent turn.

RECORD. `docs/multi-window/WINDOW-BLANK-ISOLATION.md` (cause, patch, evidence, limits);
`multi-window/tools/patch-window-blank-isolation.mjs` (--check exit 0 applied / 4 absent / 5
unverifiable); a `PATCH-NOTICE-window-blank-isolation.md` sits in the engine root because an engine
update will silently drop this patch and `dsh-update` cannot see it (pain filed).
