## THE LIE IN MY OWN DIGEST

The corpus line read:

```
✅ none — every hub record has a production order
```

**That is not what the number measures.** It sits on `push_would_create`, which is *how many records the
sync tool would CREATE*. Zero means **nothing needs creating** — not that every record has an order.
**Seven records have no production order** and are held for recorded reasons, and the held line
immediately below the claim contradicted it.

Corrected to *"✅ nothing would be created — no record needs a production order"*.

**Why this is more than a wording nit:** the digest is the ONE surface the owner reads. A claim it cannot
support is worse than a missing line, because it asserts work is complete that was never checked. Same
class as the stale "held, and why" note corrected in round 15: **a page that describes a state instead of
measuring it will eventually describe a state that no longer exists.**
