## Four attempts, and the reason each failed

Worth writing down because all four are ordinary and only one was a code error:

1. `$U` and `$u` are **the same variable** in PowerShell. The loop variable overwrote the repository
 path, and every write went to a path built from a unit name.
2. `Set-Content -NoNewline` concatenated the ssh output, so both shell scripts landed as **one 2 KB
 line** — in the directory whose whole purpose is being runnable.
3. The files arrived CRLF; git stores LF, so the working copy was the only thing wrong.
4. A `sed` and a heredoc mangled a header comment and left a literal `\n`.

The final version is checked with `bash -n` and a live run (`exit=0`) on the box before it was committed.
