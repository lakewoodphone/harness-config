## 2026-10-22 18:16 UTC · ZABZ-TECH · personality-system round 2: the 502 fixed by splitting, pause/resume proven for both cases, and the option-id bug that hid every job direction for 13 answers

End of round 2. Production runs 6e5751a (deployed 18:15:45Z, health green, both hosts 26/26). Ten deploys today.

## Landed this round, each deployed
1. SPLIT SYNTHESIS - the real 502 fix. The report is now FIVE small generations (opening / narrative-core /
 narrative-close / directions-primary / directions-secondary), four concurrent, split on OUTPUT size because an
 experiment proved max_tokens does not drive wall time. Measured: four part-sized calls (19 KB prompt) returned in
 2/2/3/3 s at ~130 output tokens, vs 10-31 s at 857-1375 tokens for the single call. One part failing withholds
 that part, not the report. src/lib/assessment/report-synthesis.ts.
2. FLAT-PROFILE REPORT - a midpoint profile used to withhold 4 Part-1 sections and list 10 things it left out,
 because two individually-correct gate rules are jointly impossible at the midpoint (a direction word is false on
 both sides when the value is exactly at it) and rule 4 refused the profile code. Now every row is printed with its
 value and side, no direction words, composed text re-validated by the same gate, and a refused paragraph is
 REPLACED not withheld. src/lib/assessment/report-sections.ts.
3. THE BIGGEST CORRECTNESS BUG FOUND TODAY - scoring.ts:843 compared a stored option ID against the list of option
 VALUES (question-bank stores `six-months` for `within-6-months`). 13 context questions have id != value, including
 C03 `degree`, so choosing one of those made the app think the person had not answered, which withheld the whole
 ranking and printed "modules are not complete yet" - false. Anyone picking one of those 13 answers saw zero job
 directions. Fixed: id->value resolution, readiness separates "module unmeasured" from "unanswered", one scoring
 body for both the normal and least-worst paths, and a demoted role is labelled least-worst rather than dropped.
4. SAVE WINDOW + COPY - a departing page flushes the one unconfirmed answer exactly once (visibilitychange-hidden +
 pagehide, same single-flight queue, refuses when signed out or when a conflict holds writes); the box the
 not-saved copy points at now renders the state; the drafts list no longer says "on this device" when the account
 is what it read. Residual, recorded: a flush queued behind an in-flight save is lost on a hard close.
5. P2 SWEEP - owner's feedback view shows the question not `question P07`, cursor paging + CSV export, and eight
 accessibility defects (named inputs, ARIA selection, 16px controls, real dialog with Escape + focus return,
 spelled-out interest areas).
