## 2026-09-14 14:41 UTC · ZABZ-YOGA · Is Netlify the best option for us? No: it prices deploys, we deploy constantly, and our DNS is already Cloudflare

The owner asked whether Netlify is the best option for us. Answer: no, and the exhaustion is
arithmetic rather than bad luck. Measured this session.

WHAT NETLIFY CHARGES, AND WHAT WE USE

Netlify's credit card (their changelog, 2025-09-05): production deploy 15 credits, bandwidth
10 credits/GB, web requests 3 credits/10,000, preview/branch deploys free. Free plan = 300
credits/month. So 300 / 15 = **20 production deploys per month, full stop** (independently
corroborated: netli.fyi/blog/netlify-free-plan-limits-2026 reads "300 Credits = ~15 GB or 20
Deploys").

Our real usage, read from the Netlify API:
- lakewood-phone-test, last 100 deploys: 16 ready, 84 error, spanning 2026-09-02..09-14 (13
 days). About 37 successful production deploys/month = about 555 credits. The free plan is
 exhausted roughly eight times over.
- Bandwidth is irrelevant: 484,475,886 bytes used since 2026-09-07, so about 2 GB/month, about
 20 credits. Requests trivial.
- So about 97% of our credit burn is the ACT of deploying, and Netlify prices deployments at
 roughly 0.30 to 0.375 USD each on its paid tiers. Our workflow is many small deploys, which
 is exactly the shape that model punishes.
- 84 of 100 test deploys are errors (the webhook "Unrecognized Git contributor" builds). They
 are free, but they make the dashboard show about 10 deploys/day when about 1.6 land, and they
 are the likely source of the hundreds of GitHub "Run failed" emails.

THE DECISIVE FACT FOR MIGRATION COST

lakewoodphoneandtech.com and abletelsolutions.com are ALREADY on Cloudflare nameservers
(aron/patryk.ns.cloudflare.com), and both frontend hosts already resolve to Cloudflare anycast
IPs (104.21.10.50, 172.67.189.242). Netlify is only the ORIGIN behind Cloudflare's proxy. So
moving to Cloudflare is not a DNS migration, it is swapping an origin, and rolling back is
pointing the origin back.

WHAT WE ACTUALLY DEPEND ON (from netlify.toml)

A prebuilt frontend/dist uploaded with --no-build; a generated _redirects (10 rules, including
the SPA catch-all); a [[headers]] block (X-Frame-Options, nosniff, Referrer-Policy); per-context
VITE_* environment values; a custom domain with TLS. No Netlify Functions, no Forms, no
Identity found. Cloudflare takes _redirects and _headers with the same file-based syntax we
already generate, so the artefacts port rather than being rewritten.

THE OPTIONS

1. Netlify Personal, 9 USD/month = 1,000 credits, about 66 deploys. Works, still metered; a
 heavy day is 12 deploys (2026-09-10) = 180 credits.
2. Netlify Pro, 20 USD/member/month = 5,000 credits. Comfortable, metered, 4x the cost.
3. Cloudflare Workers Static Assets. Cloudflare's own docs (billing-and-limitations, updated
 2026-04-23): "Requests to static assets are free and unlimited", no storage cost. Direct
 upload via wrangler means no CI build and no deploy metering at all. Same _redirects and
 _headers files. Already our DNS and CDN. Note Cloudflare's Pages docs now carry a "Migrate to
 Workers" link, so build on Workers rather than Pages and skip a second migration. (Pages
 free tier would also work: 500 builds/month.)
4. Self-host the frontend on the Hetzner lpt-apps box behind Cloudflare. Zero marginal cost, but
 we would build atomic deploys and rollback ourselves, and the site's availability would
 become the API box's availability.
5. Excluded: GitHub Pages (private repo needs a paid plan, no SPA fallback, cannot proxy), and
 Vercel (Hobby meters everything, 100 GB transfer guideline, and its plan terms reportedly
 restrict commercial use; I did not confirm that clause from a primary source this session).

BLOCKER ON EXECUTING, AND IT IS SMALL

I hold no Cloudflare API credential: no CLOUDFLARE_API_TOKEN on this machine or on secratary,
only a cloudflared tunnel cert. So the migration needs either an API token from the owner or
one project created in his dashboard, after which the deploys are mine to run.

RECOMMENDATION

Cloudflare Workers Static Assets for both frontend sites, test first and proven before
production is touched. It is 0 USD/year against 108 to 240 USD/year, and it removes the metering
that caused this stall instead of paying to postpone it.
