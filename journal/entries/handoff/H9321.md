### What was wrong with my own handling

I filed the merge/deploy/sign decision to the owner queue as #812 and asked him to choose. He asked why
it needed him. **It did not.** Two of the three options were engineering; nothing was irreversible; and
"his name is on the document" is not the same as "the decision is his". This is the measured failure the
queue exists to prevent — it is an admission that I could not, and I could. Row resolved as mine.

### The work, and the two defects underneath it

- The contact block the owner supplied on 2026-10-18 was merged into `parent-notice-2026-09-14.md`
 §Contact and `terms-of-service-2026-09-14.md` §10, and into both rendered template copies, so the
 drift test still holds.
- **`web/server/app/pages_public.py:132` hardcoded `DRAFT_PLACEHOLDER_LABELS = ("the shop's address,
 telephone number and email",)`.** That label feeds the page banner unconditionally, so no amount of
 filling in the documents could ever clear it. A hardcoded "still missing" is the exact inverse of the
 placeholder it replaced: the placeholder hid an unfinished document behind an empty bracket; this hid
 a finished one behind a stale warning. It now names only the owner's signature, which no document
 edit can supply.
- The same file substituted *"Ask at the shop for the address and the telephone number"* for the
 placeholder **at render time**, so a page whose source was unfinished read as finished copy. That is
 why nobody looked for months. The guard moved to where it can work — a test on the **source
 documents** — because a page-level assertion cannot see a placeholder the renderer has already
 replaced.
- Footer pointed at `/legal` for contact details; it now points at the notice, where they are.
- Three new tests in `web/server/tests/test_public_pages.py`; web suite **305 passed**.

### Deployment, done the careful way

The deploy doc says `scp -r web/ lpt-apps:/opt/filter-site/`, which would replace a live tree with a
branch. Instead: the deployed templates were fetched and **diffed against HEAD first** (identical
modulo line endings), then only the five changed files were copied, each backed up to
`/opt/filter-site/backups/<timestamp>/`, and the image rebuilt in place with `docker compose up -d
--build`.

Verified from outside the host: `https://filterapp.lakewoodphoneandtech.com/parent-notice` → HTTP 200,
prints the address, telephone number and email, banner reads *"This page is still waiting on the
owner's signature."*; `/terms` carries the same block; container `Up (healthy)`, `/healthz` 200.

### The one thing that is his

**The signature.** The page now says so in exactly those words. No engineering action can supply it.
