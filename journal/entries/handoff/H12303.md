### 1065 is not "the cheapest unclaimed win" — it is two jobs wearing one title

Read before building, and the reading changed the answer:

- **The model half needs an evaluation set that does not exist.** An int8 post-training quantisation of a
 child-safety classifier can lose recall, and there is no labelled calibration set, no evaluation harness
 and no baseline accuracy measurement in this repo. Shipping one would trade a 96 MB download for an
 **unverified loss of the filter's core promise**. That is a worse trade than the download.
- **"From our own storage" has no storage.** No S3/R2/boto3 configuration in the repo, no rclone remote on
 the authority, no quantize or tflite tooling anywhere in `scripts/` or `server/scripts/`.
- **p50/p95 on a named handset** — the owner's device, so that clause cannot be met from here at all.

**The useful part is the split I recorded on the item.** Most of the win is available *without touching the
model*: every handset currently pulls a **100.6 MB zip to obtain one 17.36 MB file**, because the catalogue
URL is the release zip while `size_bytes` and `sha256` describe the extracted tflite (consistent — the
provisioner unzips, then verifies). Serving the extracted file from the broker itself is an **83% cut with
zero accuracy risk**, needing no quantisation, no calibration set and no external bucket. That now sits in
the item as Job A, ahead of Job B.

### 1134 traced to where the fix actually goes

The phrase `Integrate origin/` appears in `/root/bin/sources/roadmap-supply.py` **only** in a docstring and
a selftest, as a title-prefix exemption — so **no script creates those items; a shift does, from its
brief**. And the per-project brief is *not* in the kosher repo; it lives on the authority
(`/root/wake-seed/kosher-advance`).

So 1134 is a change to the **shift brief**, which governs ~130 ticks a day. That is a deliberate, testable
change to the autonomy system, not a code edit, and doing it blind at the end of a round is exactly the
kind of move that breaks a working loop. Recorded with the trace so the next session starts from the right
file instead of re-deriving it.

### Why this round is still worth having

A shift that read 1065's one-line premise would have downloaded a model, quantised it with no eval set, and
shipped a safety filter whose recall nobody had measured — and it would have closed the item as done. The
item's own `why` called it "the cheapest unclaimed win"; it is not cheap, and the expensive part is not the
compute.

**Both remaining failures this session have the same shape**: an item that describes a change and says
nothing about what would make that change *safe*. That is the thing to fix in the supply, not in the items.
