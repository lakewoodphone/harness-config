THE UNLOCKS (all measured, none inferred)
1. **The workflow endpoint exists and nobody had tried the spelling**: `GET /api/scriptedivr` (path B,
 internal headers) returns both workflows — `workflow_WF101048590-1268826451` "Main line" and
 `workflow_WF101048590-4155869469` "Closed hours", both deployed, type voice. Found by reading
 `REQUEST_URL + "scriptedivr"` out of the **Chrome profile's HTTP cache**, which held the authenticated
 app bundle. Earlier sweeps failed because they tried `scripted_ivr` with an underscore, 26 times.
2. **The audio library is enumerable and writable**: `GET /api/v2/customivrs?target_type=…&target_id=…`
 returns 26 office files in 7 groups with `selected` flags; `POST /customivrs` (base64 MP3) and
 `PATCH /customivrs/{id}` are documented. **This is the fix path for the spoken hours — no browser
 needed.** `target_type=company` is rejected; use office/user/department.
3. **The public API is much wider than assumed**: 244 operations (104 GET, 140 write), official spec at
 `https://dialpad.com/static/openapi/platform-v1.0.json`. Office hours ARE publicly writable
 (`PATCH /api/v2/offices/{id}`, exactly 8 fields). Personal Working Hours are NOT public but ARE
 readable internally at `GET /api/user/{key}?extended=1` — the base form hides the ranges.
4. **`GET /api/changelog` is not a changelog** — it is a 50-event admin audit log with before→after values
 and the actor. That is how we can ever prove who changed a live setting.
5. **Both responses on path B are zstd.** A 200 that will not parse is compressed, not broken.

TWO LIVE DEFECTS FOUND, NEITHER MINE, BOTH CUSTOMER-FACING
- **Every Dialpad webhook is rejected 401.** `GET /webhooks` exposes a 10-char signing secret; our `.env`
 holds a different 64-char `DIALPAD_WEBHOOK_SECRET`. Proven live against our own handler. Hidden because
 the polling path writes the same table the webhook would.
- **Every customer SMS is delivered twice** — two enabled SMS subscriptions on the same office, one to us
 and one to `api.lakewoodphoneandtech.com`.
