## CHANGED — shipped to production (lakewoodphoneandtech.com), verified in a real browser
Branch `deploy/lpt-site-truthful-20260916`, two commits, built locally and uploaded to the Cloudflare Pages
project `lakewood-phone-prod` from `ZABZ-YOGA` with the token the owner supplied (stored at
`secratary:~/.secrets/cloudflare-api-token`, mode 600).

1. **The homepage no longer publishes a fabricated address.** `useFaqs` called
 `faq.getPublished.query()` with no argument against a non-optional Zod object, so it always failed and the
 catch returned mock FAQs containing an invented "123 Main Street / Highway 99 / blue storefront".
 Mock set deleted; failure now logged, re-thrown and surfaced.
2. **The FAQ list actually loads for the first time.** The same hook called `.query()` on the HOOKS client
 (`createTRPCReact`), which has no such method, so the request never reached the network - in any build.
 Switched to `vanillaTrpcClient`. Live proof: `GET api.../faq.getPublished?batch=1&input={"0":{"json":{}}}`
 now fires from the page, returns 27 records, and the rendered FAQ block shows **28 questions with zero
 console errors** (was 22 fallback questions with 4 TypeErrors).
3. **Business hours are true on every surface.** JSON-LD was "Sunday-Thursday 18:00-23:00" with Friday
 omitted; it is now [Monday,Tuesday]+[Thursday] 10:30-17:30 and [Friday] 10:30-13:00, Wed/Sat unlisted,
 Sunday by appointment. `business-hours.ts` has Wednesday closed. The rendered line reads
 "Mon, Tue & Thu 10:30 AM-5:30 PM * Fri 10:30 AM-1:00 PM". A guard test scans every hours surface and was
 proved to bite by reintroducing the old phrasing.
4. **The Google sign-in link is absolute** via a new `buildApiUrl()`; it was root-relative and 404'd on the
 frontend host.

Deploy provenance, corrected: prod deployment `f8c7ac198b8b`, `environment=production`, aliased to
`lakewoodphoneandtech.com` + `www`. Bundle `index-oE0RNlUr.js`.
