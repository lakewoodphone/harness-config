BROKEN / ROOT CAUSE
- UNIFIED ROOT CAUSE, evidence-backed: **UEFI NVRAM writes are not persisting across boots** on this
 machine. Consequence 1: the firmware never sees the staged-capsule marker, so no firmware can ever
 apply (CM_PROB_NEED_RESTART forever, capsule re-staged every boot). Consequence 2: the VSM key blob
 Windows writes is never found intact next boot (`BlobFromUefiVariableSize: 0`,
 `UefiBlobIsCorrupt: 1` on EVERY boot since 2026-09-17), so VSM mints a new key every boot and the
 VSM-protected Windows Hello container is undecryptable every boot -> UserOOBEBroker deletes it ->
 PIN must be re-created every boot. Consequence 3: the firmware retrying a staged capsule each POST
 is why the shutdown->bootmgr window went 178 -> 232 -> 251 s.
- Measured, so it stays ruled out: BitLocker (PCR 7,11) unseals fine every boot, so PCRs are stable
 and "DBX changed the PCRs" is NOT the cause. RTC/CMOS accurate. Disk 153 GB free.
- Relevant BIOS settings read from Lenovo_BiosSetting (root\wmi, 255 entries, no BIOS passwords set):
 WindowsUEFIFirmwareUpdate=Enabled, RequireSVPwhenFlashing=No, SecureRollBackPrevention=Yes,
 SecurityChip=Enabled, PhysicalPresenceforClear=Disabled, FastBoot=Enabled,
 BIOSSelfHealing=Enabled, BlockSIDAuthentication=Enabled, AbsolutePersistenceModule=Enabled.
