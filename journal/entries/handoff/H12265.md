LESSONS THAT COST TIME TONIGHT
- A python heredoc through ssh: non-ASCII (a curly apostrophe) can terminate the shell string. Write
 the file locally, base64 it in, decode remote. That is now the standard path for anything non-trivial.
- `ssh ... | tail` swallows the real exit code; capture to a file, echo $? before tailing.
- Variable shadowing on the token object in a nested function silently returns the Request object.
- Deezer /artist/{id}/top has no isrc; /track/{id} does.
- Spotify /audio-features is 403 for this app; tempo must be learned from behaviour.
