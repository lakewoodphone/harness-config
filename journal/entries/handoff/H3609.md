## WHAT CHANGED

The objective asks for a walkthrough of **both sites, once a day**. The standing daily item said "test
and production" but never said **how** - so a woken shift had to work it out, and the obvious way is
wrong:

**Test** (all four personas): `pnpm personas:walk && pnpm personas:walk:report`

**Production, public pages only, read-only:**
```
$env:E2E_BASE_URL="https://lakewoodphoneandtech.com"
npx playwright test --config=e2e/personas/personas.config.ts visitor.spec.ts --no-deps
```

**`--no-deps` IS LOAD-BEARING.** Every viewport project in `personas.config.ts` declares
`dependencies: ['persona-auth']`, so without the flag Playwright runs the **staff login first, against
production.** That is the difference between a safe read-only walk and a credential sent at the live
site, and it is now written beside the command instead of being left to be discovered.

And it is **proven, not assumed**: `visitor.spec.ts` against production ran on 2026-10-13 - **12
journeys, 21.4s, 36 findings** - and confirmed the sub-24px phone number is on the live customer site.
