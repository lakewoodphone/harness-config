## WHAT THIS DOES NOT FIX — state it plainly

The call still is not ONE voice, and cannot cheaply be. `nova` is OpenAI's and `<Say>` is Amazon
Polly's. The composed confirm sentence contains the **device name**, which is arbitrary customer
text, so it can never be a recording. Recorded fragments would fix the ticket and the amount but
leave the device name in TTS — which is MORE switches, not fewer. The only true fix is per-order
`nova` generation at draft time, which needs storage, serving and an unguessable URL because the
audio would speak the customer's device and balance. **Do not half-build that.** The owner should
listen first: the change is now female-to-female.
