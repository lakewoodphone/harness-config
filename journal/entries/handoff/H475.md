## BUILT (not yet on main)

`tools/customer/surfaces.py` — read-only adapters for production Postgres and the authority
SQLite, so a verifier and a repair tool share one implementation. Enforces, in code: every
connection is asserted read-only before a query (`SHOW transaction_read_only` must be `on`;
`PRAGMA query_only` must take), an unreachable store raises `Unreachable` rather than returning
zero rows, and every reading carries `Provenance(store, locator, read_at)`.

**It took four wrong transports to get right, and each failure is now in the module's docstring
because each cost a cycle**: (1) a `python3 - <<'EOF'` heredoc whose stdin collided with the
script ssh was already delivering on stdin; (2) the program interpolated into `python3 -c '...'`,
where the escape-free one-line `exec(compile(...))` stub I wrote to avoid `'\''` was itself
invalid Python and produced *no output at all*; (3) `cd X || { echo ...; }` missing its
terminating `;`; (4) `export NAME=$payload` unquoted — base64 can begin with `$`, so the shell
expanded the value away and the bug looked intermittent. The working form: **the program on fd 3,
base64, single-quoted env vars.**
