## 2026-10-19 17:54 UTC · ZABZ-YOGA · Owner text round 11: the turn dedupe only matched OPEN turns, so 19 of 20 reply turns were doubled - an orphan turn row is a channel that will not open

## Addendum 10 to H9513 (round 11) — one text opened two turns, and the orphan kept the channel shut

### The finding, from the labelled set

The 151-turn closure (round 10) showed **29 turns share a sid with another row, and 19 of the 20
`owner_sms_reply` turns are doubled**. Chasing it found a guard that was right about the principle
and wrong about its scope.

`app/owner_text.record_outbound` already carried the correct comment — *"One message, one turn.
Measured 2026-10-02: a single reminder opened rows #39 and #40 with the SAME sid … so the owner's
reply would have closed one row and re-shut the channel."* — but it only looked at turns that were
still **open**:

```sql
SELECT id FROM owner_text_turn WHERE answered_at IS NULL AND sid = ?
```

So `record the send → he answers, the row closes → the same send is recorded again` found nothing
and inserted a **second** row for the same sid. Two rows for one text means his single reply closes
one of them, and the other keeps the channel shut — the exact failure the guard exists to prevent,
surviving in the half of the state space it did not look at.

**A turn is a lock.** An orphan turn row is a channel that will not open, which is why this matters
more here than the same double-write did in `sms_log`.

### The fix and the proof

A sid identifies a text; "has he answered it" is not part of a text's identity. The sid branch now
matches regardless of state. The **body** branch keeps the open-only scope on purpose, because the
same body is legitimately sent again later and must be able to open a new turn.

Proven on a throwaway database against the real function:

| case | result |
|---|---|
| first record | `id=1 rows=1` |
| same sid, turn **open** | `id=1 rows=1` |
| same sid, turn **closed** | `id=1 rows=1` ← the case that used to double |
| same body, **no sid** | `id=2 rows=2` ← still free to open a new turn, correctly |
