### The three mistakes this stretch produced, all mine

- **An exemption list keyed on work kinds, called with agent ids** - present, documented, tested, and inert in
 the only path that ran it. Caught only because a prediction was written down before the event (`L10305`).
- **A duplicate module constant.** I added a second `_QUALITY_RANK` with different values without checking the
 module had one; Python took the later definition and silently re-ranked every other user of that map. Caught
 by a port script's `already patched` guard (`L10366`).
- **A timestamp written from memory** rather than from the clock, corrected in its own commit. A wrong stamp
 is worse than none, because the next reader cannot tell which of the others were also guessed.

### The habit that is working

Ship it **inert by default**, prove it on the box with the box's own interpreter, then flip one environment
variable - and flip it back when a rehearsal contradicts the design. That sequence is why the exemption bug
cost minutes instead of a night: `SCHEDULE_MODE` went on, off, and on again in ten minutes without touching
code. **The reason to ship with an off switch is not caution; it is that you will need it, fast.**
