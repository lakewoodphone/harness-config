 key. This is the shape of bug that looks fixed and is not.

### THE RULES, WHICH ARE NOW THE SAME IN TWO LANGUAGES

`lpt_ops/redact.py` (Python, for what is already stored) and `card-scrub.ts` (TypeScript, for what
arrives) share one definition: a card is four groups of four or an unbroken run of 16-19 digits;
**fifteen digits is an IMEI, not a card**; a run preceded by `dialpad`/`call_id`/`message id`/
`ticket`/`imei`/`serial`/`stripe` is an identifier; a security code is masked **only behind its own
word**; a bare three-digit number and an expiry are never touched.
