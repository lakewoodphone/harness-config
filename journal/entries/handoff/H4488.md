## 2026-10-15 01:43 UTC · SECRATARY-CLOUD · Onboarding sets roaming and verifies acks; the data-bearer monitor is live and scheduled; profile schema audit running on the mesh

**CHANGED — two live faults closed, one monitor built**
- **Onboarding now sets Data Roaming, and stops treating "enqueued" as done.** Commit
 `23da0239b` (branch `fix/lpt-waze-onboarding-roaming-and-ack`). `onboard.py` gained step 5b
 (`POST /fleet/devices/{drn}/data-roaming`, on by default, `--no-roaming` as a loud opt-out), and
 BOTH the APN install and the roaming command now wait for the device's own `command_results` row
 and fail the run unless it says `Acknowledged`. The APN step used to print a ✓ after an `ok:true`
 — i.e. it looked like verification while the fleet had no data. New `wait_for_ack()` returns
 `unreadable: ...` on a DB failure rather than an empty string, because "we could not read the
 answer" and "the device did not answer" are different facts. scripts/waze suite: 157 passed.
- **The missing measurement now exists** (P3929). Commit `e0f21deb9`:
 `deploy/waze-mdm/operator-tools/data-bearer-check.{sql,sh}`, deployed to `waze-mdm-01`, crontab
 backed up (`/tmp/crontab.bak-20261015T005349Z`) and scheduled **every 6 hours**, logging to
 `/var/log/waze-data-bearer.log` and writing de-duplicated `fleet_alerts` rows. Pure SQL over
 tables that already existed (`waze_usage_ledger` + `fleet_device_health_history`) — no new
 collection, no schema change, no container rebuild. Wrapper exit codes are distinct on purpose:
 0 clean, 1 flagged, **2 the check failed to run** — a check that cannot read its data must never
 report a pass.
 - **Reproduced on the live fleet before scheduling**: flags DRN 2005, 2006, 2007, 2008 (alive,
 26h window, under 0.1 MB each); passes 2002 (112.12 MB) and 2004 (1.22 MB).
 - **What it refuses to claim**: an idle device and a broken one look identical, so a flag is a
 PROMPT TO VERIFY and both the alert text and the SQL say so. The value is the other direction —
 a device that is alive and has moved nothing is a device nobody has verified.
