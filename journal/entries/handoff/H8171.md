## 2026-10-18 · ZABZ-YOGA + secratary-cloud · Estate search round 8: freshness was being measured wrong, and the authority was ssh-ing to itself

Continues **H8170**. Commit `71e5e36`.

### The two defects that mattered

**1. `/health` judged freshness by the newest row in the whole store.** Measured: every source on the
authority was **267 minutes old** — comms and mail four and a half hours behind a three-hour
requirement — while `/health` reported `ok=true`, because a workstation's push had written something
newer that morning. A store is not fresh because *something* in it is fresh. Each corpus is now judged
against its own ceiling, by its own means:

| source kind | judged by | example |
|---|---|---|
| produced on this host (`host: authority`) | its own ingest row | `comms:authority` 4 min |
| arrives by push | the newest document it delivered | `chat:vscode` 281 min |
| a workstation's corpus (`host: local`) | reported, not failed here | `files:local` |

**2. The authority had no clock because it ssh'd to itself.** `sync.py --host authority` dispatched
to the remote path for any `--host` that was not literally `local`, without asking `host_is_local` —
so it ran `ssh root@secratary-cloud` from `secratary-cloud` and died with
`Permission denied (publickey)`. A host has no key for itself. This is why the authority's own
corpora had never been on a schedule. Fixed, and then run: **6/6 sources ok, 181,006 documents, comms
and mail 4 minutes old.**

New unit: **`esearch-local-sync.timer`**, hourly at `:40`, runs `sync.py --host authority`. The
authority's own corpora now have the same clock the workstations have.

### The mistake I made and caught

An edit removed a newline between `def disk_health(...)` and its body, fusing two statements into
`def disk_health(path: str) -> dict: try:`. **The parse check caught it and the deploy went ahead
anyway**, because the check and the `scp` were in the same command — so the service was restarted on
a file that could not import. Caught within a minute by the health read that followed, repaired, and
redeployed. The lesson is in the journal as **L…**: a parse check and a deploy in one command are not
a gate.
