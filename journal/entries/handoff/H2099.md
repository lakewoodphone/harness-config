THE ANSWER (verified against Google primary sources, not inferred)
- Family Link cannot block Google search on a Galaxy BY DESIGN: Google documents that system apps
 cannot have app limits, and com.google.android.googlequicksearchbox is a system app - so it never
 appears in App limits. What the "Google Search" screen offers is SafeSearch, i.e. content
 filtering, not an off switch.
- Working route: `adb shell pm suspend --user 0 com.google.android.googlequicksearchbox`, then
 close browser / Assistant / Circle-to-Search / Google Go surfaces, then VERIFY BY REBOOTING.
 adb 36.0.0 is present on ZABZ-TECH.
- Our prior art does NOT cover it: Techloq is Windows-only (707-line SOP, nothing Android);
 Livigent is Android but we hold only an incident about it failing, not an install procedure.
 Flip fleet = Livigent, Windows fleet = Techloq, Galaxy = unowned gap.
