## Two costs worth remembering
1. **A dynamic import of a module that defines dataclasses must register it in `sys.modules` before
 `exec_module`**, or `dataclasses` looks up `cls.__module__` and finds `None`:
 `AttributeError: 'NoneType' object has no attribute '__dict__'`. Not a design problem, a Python gotcha.
2. **The selftest's temporary roots have no `scripts/docs_check.py`**, so the ownership check is applied only
 where a runner exists. A check that cannot read the registry must say nothing rather than fail every fixture
 for the wrong reason - and the guard has to be visible in the code, not inferred.
