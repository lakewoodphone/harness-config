## METHOD NOTE - why the callsite work is safe to have shipped
`vanillaTrpcClient` and `trpcClient` are built from the SAME links: same `buildTrpcUrl()`, same bearer header
from `getAuthToken()`, same `credentials: 'include'`, same 401 handler. So the swap for imperative calls keeps
identical auth and cookie behaviour; it is not a different transport. Read in `lib/trpc.ts:403` and `:462`.
