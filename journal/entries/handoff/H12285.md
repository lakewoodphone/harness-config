## 2026-10-22 00:20 UTC · ZABZ-TECH · Kosher filter: three E2EE phone routes had no hardening classification at all; main's red gate cut from 8 to 1 (PR #106 open, blocked)

`origin/main` = **c469416**. PR **#106** is **open and blocked**, not merged. Ledger 1095 back to `todo`.

### The find that mattered

`origin/main` was red on 8 server tests, measured on a clean worktree. Seven of those eight were symptoms of
one real defect:

**Three phone-or-admin-ingress routes landed with a `RouteSecurityRule` but NO `HttpHardeningRule`** —
`POST /api/frames/e2ee`, `POST /api/frames/e2ee/key`, `DELETE /api/frames/e2ee/key`. With no hardening
classification their `required_controls` were empty, so the runtime review reported
*"missing hardening classification"* and phone mTLS sat at **48/51**.

Fixed by adding `e2ee_retention_requires_mtls` requiring `PHONE_MTLS` on those paths. **51/51.**

**The shortcut was available and refused**: refreshing the security snapshot would have recorded three
routes as reviewed while their required controls were empty. A route with no hardening classification cannot
be *verified*, so it must not be treated as verified — that is precisely what the audit was saying.

The other three: router baseline 35 → 37 (`models_manifest` 934 / `e2ee_frames` 1005, both landed without
bumping it — the test's own comment already records this exact lesson); and `test_verify_script_min_sizes`
**rewritten, not deleted**, to assert the sha256 manifest that ledger 934 deliberately put in place of the
`minBytes` size guard.

### Traps paid for here

- **`pytest tests/<file>.py::<node_id>` trips the Windows suite guard.** It wants a bare filename:
 `"Refusing to run the unqualified server suite on Windows ... name the test files"`. Drop the `::`.
- **A single CI test failing while the whole file passes locally is a flakiness signal, not a verdict.**
 Run the file, not the node id, before attributing it to your change.
- **Scope a "main is red" item by job, not by the files you happened to run.** There are four CI jobs and
 they fail independently; measuring one and calling it "main is red" undercounts.
