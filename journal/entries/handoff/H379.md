## The foundation bug that broke three workstreams, now closed
Every adapter names its entry point `sync.py`, and every test module put its own adapter directory
on `sys.path` and wrote `import sync`. The moment two adapters existed in one suite, each test
imported whichever directory won the race and failed with `module 'sync' has no attribute ...`.
It broke the journal tests, then the chats tests, then localdb. `tests/adapter_loader.py` loads an
adapter by explicit file path under a unique module name; the sys.path hacks are gone.

## Second schema defect, found by the secretary agent
A statement separator inside a SQL **comment** in `SCHEMA` truncated `executescript`'s statement
split, so `migrate()` aborted with the misleading `no such column: source` on any database created
by an earlier version -- taking the migration path out of service on exactly the databases that hold
data, while a fresh file worked perfectly, which is why every test passed. Fixed, and a test now
fails if any comment line in SCHEMA contains a separator. It caught my own explanatory comment twice.

## Two core APIs two adapters had to work around
* `delete_documents(con, source, external_ids)` -- the files adapter was issuing raw SQL to prune one

* `_rollback()` -- a rollback no longer hides the error that caused it. Lock contention used to
 surface as "cannot rollback - no transaction is active" and read like a logic bug.

## The lock, and what it blocks

`BEGIN IMMEDIATE` was still waiting after 13 s. That is correct behaviour, not a bug, but it is the
reason the **chat corpus is still not in the index** -- the largest unindexed corpus left, 285 VS
Code session files / 3.76 GB plus Copilot CLI events and zstd DSH transcripts, roughly nine months of
the owner's own reasoning.

half is being done now (`--out ~/.usearch/chats.jsonl`, state at `~/.usearch/state/chats.json`,
progress in `~/.usearch/logs/chats-parse.log`). At 200/285 files it had produced 184 sessions and
18.6 MB of text, and the remaining files are the very large ones. Then, when the writer yields:
