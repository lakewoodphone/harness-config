The shift's tree and branch were provably untouched afterwards (`git rev-parse --abbrev-ref HEAD` still the shift branch).
- **`git show <ref>:<path> | Set-Content -Encoding utf8` is not a copy.** It rewrites LF to CRLF: the extracted file hashes `fb1fb235…` against the blob's `b3810c59…`. Edit case files **on the host**; never round-trip them through PowerShell and copy them back.
- **Anchor-and-assert is the safe way to edit a 31 KB customer dossier over ssh.** Every substitution asserts it matched exactly once and the run aborts on a miss, so a changed anchor writes nothing. The dry-run diff is the review, and it is cheap.
