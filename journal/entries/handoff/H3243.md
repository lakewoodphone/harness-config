## I WAS WRONG, AND IT IS RECORDED

I told the owner the blocklist was **empty** and had never worked. It held 474,178 domains. The
measurement was `docker exec … python -c "len(blocklist._domains)"` — a **fresh process**, whose
module-level singleton never ran a refresh, so it cannot report anything but zero. The instrument
manufactured the conclusion. Full entry: **`L3335`**, which corrects `H3242`. The transferable rule:
when a value lives in a long-running process, read it from that process — never by importing the
module in a new one.

**The same class of error happened again in the same round, from the other end:** I ran the speed
lane's suite with `--basetemp` **inside the repo** and got 24 failures against the lane's claimed 5.
Nineteen were mine — `test_pilot_capture.py` has its own guard, "refusing to capture frames into the
repository", which my temp path tripped. With the temp dir outside the repo that file is **38
passed**. Two different instruments, two wrong readings, one round. See `L3336`.
