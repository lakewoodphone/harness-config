## THE ANSWERS, so they are not re-derived
- **A software update does not remove a configuration profile** — Apple's removal list is wipe, unenrolment, the
 management service, a Configurator host, the user. A software update is not on it.
- **The app allow-list HIDES, it does not merely block**: "the system only shows or can launch apps with bundle IDs
 in the array". A new app from a future iOS should therefore not appear. The only exemption Apple names is
 **Settings and Phone** — which is exactly why the kiosk folders them on page 2.
- **The real danger is the deprecation clock** (L3937): `allowListedAppBundleIDs`, `blockedAppBundleIDs` and
 `com.apple.dnsSettings.managed` are all deprecated at iOS 27.0, and Apple's own precedent removed the
 software-update keys one release after deprecating them.
- **Untested and highest-value**: what iOS does with a profile containing a *removed* key — ignored, or payload
 rejected. The same payload carries the allow-list.
- **The upgrade window is where kiosks actually break** — a documented iOS 26.2 incident left supervised devices on
 the Hello screen; iOS 27 adds two setup panes. Pre-empt with `com.apple.SetupAssistant.managed` BEFORE upgrading.
- **No way back**: Apple stops signing the old version by design; no MDM downgrade path.
- **DECISIVE**: NanoMDM cannot serve declarative configurations (verified: its README has no DDM, and the Caddyfile
 routes no declaration path), so the fleet cannot turn off automatic download/install, cannot defer beyond the
 deprecated legacy key, and after one upgrade to 27 would have **no update control at all**.

## RECOMMENDATION (changed by the last finding)
Keep OS updates out and let assets through, **at the PAC**: allow `^/\d{4}/mobileassets/…/com_apple_MobileAsset_EmbeddedSpeech/`
and refuse `/patches/` and `/fullrestores/`. Gets the dictation model down unattended, keeps the fleet on a tested
iOS, and needs no new MDM capability. Traps: never match the string `MobileAsset` (an OTA update IS a MobileAsset);
Apple publishes no path contract for this CDN, so it needs a check after each release.
