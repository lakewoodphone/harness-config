## THE FINDING, AND IT IS A CORRECTION TO MY OWN WORK

Earlier in this program I wrote onto production notes, and told the owner, that a
`payment_transactions` row **could not be created by us** — that the figure would have to be typed into
the website's counter page by a person. **`bin/lpt-record-payment` has existed since 2026-10-12** and
does exactly that, guarded, from a proven charge. Its docstring quotes the owner — *"you are always the
someone, never wait for someone else"* — and names the very failure I was writing into the record as
unavoidable:

> the order read CAPTURED while `collected` read **0.00** ... **That is the failure this tool removes.**

**Why it was missed:** `docs/` was searched and `bin/` was not. The tool has no doc of its own and is
not on `install.ps1`'s launcher list (correctly — it is authority-side), so it was invisible from both
directions. **"Is there a tool for this?" is answered by listing `bin/`, not by searching `docs/`.**
That rule is now `L3822`, and `README.md` carries a Tools index so the next session does not have to
rediscover the inventory.

## WHAT WAS FIXED WITH IT

Three orders had a **proven** Stripe charge while `collected` read 0.00 — the order claiming money its
own ledger showed none:

| order | charge id | amount | `payment_transactions` |
|---|---|---|---|
| `WO26082712685` | `ch_3U8NzmLnlgYj1gmT0O0GfS9D` | 309.21 | 3319 |
| `WO2609040001` | `ch_3UBzHiLnlgYj1gmT1omeKAN3` | 309.21 | 3320 |
| `WO2609030001` | `ch_3UBcRPLnlgYj1gmT1phxUJr2` | 159.94 | 3321 |

Each read back `collected <amount> across 1 SUCCEEDED row(s)`, verified live afterwards. Each is
followed by a **corrective note**, because the earlier note on that order said the opposite and a record
that contradicts itself is worse than either half alone. The correction states the attribution **and its
limit** — `WO26082712685` is name-matched (the charge's staff note names the customer and the job), the
other two are amount-and-timing matches and say so.

**The original instruction was not wrong about the danger** — a row invented from a prose claim IS the
defect this area keeps producing. It was **too broad**: it forbade the evidenced thing along with the
unevidenced one. *"Do not fabricate" must not become "do not record."*
