**Defect worth knowing, documented but still sharp:** `lpt-write status set --reason` puts the
reason in the audit ledger only. The row it writes into `order_status_history` carries the app's
hardcoded `Auto-updated by secretary reconciliation (confidence: 0.95)` no matter what you pass
(`lpt_ops/write_helper.py:1120`, noted in `docs/writes.md`). So these three deliberate,
owner-sourced corrections appear in the history as machine guesses. The note above each one says
otherwise; a future session reading only the history line will misread it.
