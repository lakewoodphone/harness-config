## THE DECISION ON "CREATING ONE WHERE MISSING"
The objective says create a case file so no customer exists only in a call log. Taken
literally that means 154 files, mostly empty, for numbers that rang once. That would bury 260
real cases under noise. The rule applied instead: a case file is created where there is
substance - a voicemail, a text longer than a greeting, or three or more rings from a number
we already know. A single zero-second ring from a stranger is traffic. This is recorded as a
judgement, not an omission.
