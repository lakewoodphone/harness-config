### The authority is now a mesh worker (the owner's real ask)
Half of the box was idle: 87-94 % CPU idle, 26.3 GiB available of 30.6, and the estate had excluded
it on purpose since it was a 4-core/15 GB machine with 11 OOM kills in a day. What changed is
containment, not the risk:
* `/opt/dsh-mesh-runtime` — a **pinned** dsh 0.2.0-rc.2 (`npm ci` from the authority's own lockfile),
 deliberately NOT `/opt/dsh-phone`, which is the phone product's promotion target.
* `/root/.dsh-worker` — its own DSH_HOME. `phone-engine` owns `/root/.dsh` and two engines on one home
 is the state `docs/mesh/71` forbids. Proven: after the first turn the worker home gained 1 session
 while `/root/.dsh/sessions` stayed at **6**.
* `/usr/local/bin/dsh-mesh` **refuses** any DSH_HOME but `/root/.dsh-worker`, and every turn runs in
 `dsh-mesh.slice` (`MemoryMax=6G`, `MemorySwapMax=1G`, `CPUQuota=400%`) so a runaway child dies in
 its own cgroup instead of being saved by `company-api`'s cap.
* Roster row `maxChildren: 2` (the node's own CPU-bound governor value), and a `phone-gate` drop-in so
 the gate stops publishing 12 (it computed that from RAM alone).
* Proof, all four measurements: `dsh-mesh …` → `MESH-HOST: secratary-cloud` exit 0; the same over ssh
 from a dispatcher, exit 0; `GET /nodes?fresh=1` → `state=ok`; `POST /place` with the other five
 nodes excluded → **position 0, tier=fits**, lease released.
* **The 403 that nearly made this a false negative:** the broker reads a node at
 `<baseUrl>/mesh/capacity`, and this node's gate answered **403 "This node does not sign in this
 device"** over its own tailnet name, because `phone-gate-allow.txt` lists every peer except the
 authority itself. Rather than add the authority to a list that hands out 30-day engine cookies on
 the database host, the row uses **loopback** `http://127.0.0.1:3086` — the broker runs there.
* Also fixed: `broker-client.js:163` still defaulted to **`secratary-ts`**, the frozen office box,
 which runs its own broker with a roster that has no `secratary-cloud` row. Third and last of three
 places that had to name the authority.
