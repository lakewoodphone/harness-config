## THREE CORRECTIONS TO GET ONE RE-CUT RIGHT, EACH WORTH RECORDING

**1. The docs half was not a simple cherry-pick.** Taking the branch's `AGENTS.md` whole would have
**deleted** `pnpm worktree:setup` and the "Build commands that report the truth" table - the branch's
file is based on an older commit and `origin/test` has gained those since. My first re-cut did exactly
that. Replaced with an insertion into test's current file.

**2. `git diff` at three dots measures the CHANGE, not the FILE.** I first concluded from
`git show branch:AGENTS.md` that the docs change was a 48/48 rewrite. The three-dot numstat says
`49 0` - a pure addition. The whole-file difference included test's independent gains and I read it as
the branch's edit. **Whole-file comparisons and change-comparisons are different questions.**

**3. LINE ENDINGS TURNED 49 LINES INTO 212.** Python's `write_text` on Windows translates LF to CRLF;
the repo is LF. The commit read **212 insertions / 163 deletions** - a whole-file rewrite, the kind of
diff a reviewer skips - for a 49-line addition. Normalising to LF collapsed it to **49 / 0**
immediately.
