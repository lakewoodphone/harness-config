THE FINDING THAT MATTERED MOST

`/opt/lpt-test/src` had **`backend/src/lib/jwt.ts` modified in the working tree, uncommitted**: it gave every refresh token a `jti` nonce. Without it two refresh tokens for the same user in the same second are byte-identical (a JWT's `iat` is whole-second), rotation cannot insert the replacement into a UNIQUE column after the revoke succeeded, the session dies, and the next attempt reads as token REUSE and revokes the whole session family. Live as "Unique constraint failed on the fields: (`token`)". The fix was already running in BOTH the test and production containers, installed by hand, and was in NO git ref — so the next deploy would have reverted it. It is now committed (`0a39daf61`), pinned by two tests in `jwt.test.ts`, and the box's copy was stashed (`git stash` on `lpt-apps`, message `jti-patch-now-committed-upstream-20261006`).

A phone that holds a session all day is exactly the workload that would have found this the hard way.
