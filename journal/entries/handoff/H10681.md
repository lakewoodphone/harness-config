 path is a repository directory — no basename at all — so it covered 80-100 % of the words in
 "customer asked about water damage" and led it. The band now requires a basename with an extension
 and a file-like kind; a commit message is not a name.

 than two.

 `session/title`; the surface now resolves it for the sessions it returns and treats it as a name.
