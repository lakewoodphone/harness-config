## THE REAL CAUSE, AND IT IS A FIX THAT WAS MADE ONCE ALREADY AND WENT STALE

`e2e/personas/lib/journeys.ts:135` `openFirstWorkOrder()` — its FIRST candidate is:

```js
page.locator('a[href^="/work-orders/"]').filter({ hasNotText: /new|create|express/i }),
```

and the comment immediately above it records **this exact false blocker being fixed before**:

> *"FIRST, and viewport-independent: every hub row is now a real anchor (`/work-orders/:id`), and
> BELOW the table breakpoint the hub renders cards, where there is no `table tbody tr` at all.
> Looking only inside a table made the run of 2026-09-25 report a BLOCKER on an iPhone 15 - "no work
> order could be opened" - while 14 valid work-order links sat on the same page. That was the
> harness's locator, not the product."*

**So the harness was fixed in September to click the hub's real anchors — and the Counter's rows are
no longer anchors.** Measured today from the live DOM:

```html
<ul data-testid="staff-open-rows" data-row-count="25">
 <li><button data-testid="staff-open-case-1427" data-kind="case" data-status="NEW"
 class="min-h-20 w-full touch-manipulation rounded-xl …"> <!-- a BUTTON -->
```

There is no `a[href^="/work-orders/"]` on the page because the row is a `<button>` with a click
handler. The harness is correct; **the markup changed under it.**

## THE FINDING THAT IS ACTUALLY WORTH KEEPING

**The hub's rows stopped being links.** That is a real difference, not a harness artefact, and it is
in the owner's own territory ("not easy to use"):

- an `<a href="/work-orders/1427">` can be **middle-clicked, opened in a new tab, right-click-copied,
 and it shows its URL** — a `<button>` cannot do any of those;
- browser back/forward and "open in new tab" semantics are lost;
- and the harness's own September comment called the anchor *"the honest thing to click"*.

**Whether that change was deliberate is not known and is not claimed.** What is known: the rows are
buttons today, the September fix expected anchors, and the difference is worth a decision rather than
a harness patch — either the rows go back to being anchors, or the harness is updated and the
accessibility cost is accepted on purpose.

**This is exactly the class of thing the daily loop exists to catch, and it caught it — twice, five
months apart, because nothing was watching in between.**
