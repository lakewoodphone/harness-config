## THE CONCLUSION IN `13`, IN ONE PARAGRAPH
The switch is on and correctly installed; what has never happened is the **one-time dictation consent**. Tapping the
keyboard mic with dictation permitted-but-unconsented raises an **"Enable Dictation?"** alert, and on a kiosk whose
only permitted app is Waze — which holds an audio session for navigation voice — that alert is **torn down in ~0.5 s
before anyone can tap it**. Three independent public reports of exactly this, one of them on iOS 26
(firefox-ios issue #30537, 2025-11-11) and one naming an app holding `AVAudioEngine` as the cause (StackOverflow
62597911). Consent never lands ⇒ dictation never enables (toggle looks ON, no **Dictation Languages** row) ⇒ the
~330 MB model never downloads either, and `forceOnDeviceOnlyDictation=true` means no fallback.

## WHAT WAS ELIMINATED OR DOWNGRADED (do not re-derive these)
- **iOS 26.4 deprecation is NOT the cause.** Apple keeps `deprecated` and `removed` as separate fields; all four
 dictation/Siri keys are `deprecated: '26.4'` with **no `removed`** in the 27.0 *and* 27.2 branches. Precedent:
 software-update keys deprecated 26.0, dead only at `removed: 27.0`. And decisively: the fleet sets the key **true**,
 so an ignored permissive key leaves dictation at its default — also true. ~80-85 % the key still works.
- **Screen Time / MDM restriction**: ruled out (`allowScreenTime=false`; the kiosk permits dictation).
- **A platform-wide 26.5 regression**: one was real (26.5 beta 2, third-party-app dictation activation) and was fixed
 in 26.5 beta 4. No dated report anywhere matches our symptom cluster on 26.4-26.6.
- **The DNS filter does not block dictation itself** (0 `guzzoni` requests in 3 h; on-device-only is forced; a shop
 device on this estate dictates fine). It may block the *model download*: `updates.cdn-apple.com`, `mesu.apple.com`
 and `appldnld.apple.com` are allowed but all three **CNAME to `*.g.aaplimg.com`, which the blocklist answers
 NXDOMAIN** — measured with raw wire answers; the device asks for the refused target 22× in 45 min.
- **The phase-1 profile is not the landmine it was described as**: iOS itself refuses it —
 `MCInstallationErrorDomain 4027 "Remove the profile "DRN Waze Layered Kiosk" before installing this profile."`
- **DRN 2002's shop history gave it no model** — it fails exactly like 2004.
