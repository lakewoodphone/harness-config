The comparison now normalises CRLF on both sides; the restore still writes the original bytes back untouched. A check whose verdict depends on `core.autocrlf` is not a check.

The register's own citation count was 3,178 here and 3,151 in a clean checkout - the number in a generated document depended on what I had left in tmp/. The skip set is now directory names matched against path parts, and `archive` is skipped uniformly with the status rule.
