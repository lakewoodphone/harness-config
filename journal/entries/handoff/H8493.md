## The test that found it: asking a question I did not know the answer to

Every earlier acceptance question was chosen by me, and I know where those answers live — which is
exactly why they passed. This round asked **"kyocera e4610 deployment steps"** with no idea what the
answer was. The result:

 rank 1 master-index.json <- a generated catalogue of lpt-hub documents
 rank 2 6PYW.json <- VS Code undo-history snapshot
 rank 3 7W4y.json <- another undo-history snapshot

**Not one real document.** Two species of noise, both structural:

- **Catalogue files.** A generated index of documents contains every title, so it outranks the
 documents it indexes for any query phrased as a title. Fixing `lpt-hub/index/` by directory simply
 moved the winner one directory over — `research/index/master-index.json` — so the rule now names
 the FILE (`/master-index.json`, `/entries.tsv`) wherever it lives.
- **Undo-history.** `Code/User/History/` holds every saved revision of every file: a copy store, and
 a copy always outranks the original. That root is gone from `files:local`.

**7,638 documents removed** from the centre (673,569 left). The same query now returns, in **31 ms**:

1. `lpt-flip-phone/docs/README.md` — the project's docs index
2. `lpt-hub/legacy/kyocera-escalator-value/README.md` — legacy notes
3. `lpt-flip-phone/docs/LAUNCHER_ARCHITECTURE_CHANGE_2025-12-14.md` — **with the actual steps**
 (`adb shell pm enable jp.kyocera.kyocerahome`)

**The lesson, and it is the strongest one this program has produced:** a test set chosen by the author
measures the author, not the system. Every acceptance run until now was mine to choose; the first
question I could not answer myself is the one that found a defect nothing else had.

## Also recorded

Passing a body containing backticks through PowerShell corrupts it silently — the escape characters
become control characters, and the journal's own `check` caught the result as a sha mismatch, which is
how a corrupted entry gets noticed instead of being trusted. Write the body to a file and use
`--body-file`.
