WHY THIS SHAPE
- Hyper-V 'Default Switch' is type Internal but NATs to the host's real network, so a guest on it CAN reach secratary (Tailscale 100.84.72.88, LAN 192.168.50.77). Measured. It is not a boundary.
- Windows Sandbox takes the host network stack with no isolation control at all.
- So: purpose-built internal switch with NO uplink, plus firewall blocking the subnet both ways as belt-and-braces.

KEY UNLOCK - POWERSHELL DIRECT
