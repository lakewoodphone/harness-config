```
laptop: python scripts/wake-flag.py --subject selftest-crossmachine --prompt "Reply with exactly
 CROSSMACHINE_FLAG_OK and nothing else." --source selftest --priority high -> filed
```

## WHAT I FIXED AS INTEGRATOR (invisible to any single stream)

1. **`WAKE_SESSION` was never set.** The store refuses flags from inside a woken session — the
 recursion guard — but nothing armed it for the actual session. `runner.ps1` now sets it in the
 child's environment. Without this the guard was theoretical and the runaway was one confused
 session away.
2. **The new dispatcher wrote no liveness heartbeat.** Deployed as-is it would have made the owner
 digest report a healthy dispatcher as **DEAD after 20 minutes**. A false alarm is its own harm.
 It now writes `~/.sms-inbox/wake-heartbeat` on every run before any early exit.
