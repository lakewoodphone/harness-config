### A p1 was filed about my own test, and it was right

Ledger **1150**: *"A test asserted a route is mounted and was cited as proof that an HTTP path works."*
My round-32 test scanned `app.routes` for a matching entry, made no request, and I reported the release
path as "a shipped surface". Behind that green test, two defects were live:

1. **500 on every admin reset-protection route.** The shared marker called the callback with `request`
 only, while `main.py:_require_admin_or_phone_read_auth` declares `phone_id` **keyword-only with no
 default**. TypeError as soon as an operator authenticated.
2. **501 on all six routes, on the backend the shop runs.** `ResetProtectionStore.__init__` demanded
 `isinstance(conn, sqlite3.Connection)`, but the SQLite backend hands out `_ThreadLocalConnectionProxy`
 — one connection per anyio worker thread, which exists *because* a shared connection leaked descriptors
 and killed the SOCKS listener for 56 hours. The guard rejected the real connection and reported
 "SQLite backend only" while running on SQLite.

Both fixed: the marker passes `phone_id` through all three call sites, and the guard now tests the **API**
rather than the type (`_speaks_sqlite`: a real `sqlite3.Connection`, or anything exposing both `execute`
and `executescript`). `executescript` is what keeps the original intent — psycopg has `execute` but not
`executescript`, so Postgres is still refused.

**The mounted-only test is removed**, with a note recording why, replaced by four tests that issue
requests and drive the real proxy.

One of my assertions was wrong and corrected: `complete_release` calls `ensure_release_allowed` **before**
it looks for an open request, so a freshly sealed policy reports the floor, not the missing request.

### The lesson this round cost

**A test that proves a declaration is not a test that proves behaviour, and citing it as one is how two
HTTP defects stayed invisible through a green suite.** That is the same shape as the four false claims —
the artefact said one thing and did another — one level up, in the tests themselves.
