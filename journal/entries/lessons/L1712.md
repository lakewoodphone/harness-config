**L1712 · DSH money is only in the console export, never in local session logs**

Measured 2026-09-16: for 2026-09-15 the local store (~/.dsh/sessions on ZABZ-YOGA) captured 11,033,065 cache-miss / 1,457,682,944 cache-hit / 5,679,582 output tokens, while the DeepSeek console export's 'deepseek harness' key for the same day recorded 21,975,657 / 1,919,397,888 / 9,846,477 - 50% of misses and 76% of hits. Same on 09-14 (33.2M vs 61.6M miss). The store holds one cwd and has day-gaps while the ledger charges those days. RULE: local session sums are a sample of MECHANISM, never a dollar source. For DSH money cite api_key_name from the console usage export (https://platform.deepseek.com usage -> download CSV, columns amount-*.csv = user_id,start_time_iso,end_time_iso,model,api_key_name,api_key,type,price,amount). This is the same provenance failure as reading a stale DB copy: a partial local view reported as the whole truth.
