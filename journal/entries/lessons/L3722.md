**L3722 · Dell power-LED blink codes are POST codes: an Inspiron 15 3520's 2 amber / 4 white is memory, and no blink is a charger code**

**Case that produced this: WO26100812737, Schreiber, Dell Inspiron 15 3520 (tag DCGF854), 2026-10-12.** The customer's story was "the charger was ripped out while charging, now it will not take charge", and the machine would not open at all. The tempting reading is a dead DC jack. That reading is wrong for this symptom, and the thing that settles it was already on the machine's front panel.

**The owner's reading: the power LED blinks two amber, then four white.** Dell's own table for this model (Inspiron 15 3520 Service Manual, "System-diagnostic lights") gives Amber 2 / White 4 as **Memory/RAM failure**, resolution *"Reset and swap memory modules among the slots. If the problem persists, replace the memory module."* The table contains **no charger, adapter or DC-in entry at all** - the only power-rail row is 3/5 "Power rail failure", and 2/3 and 2/5 are the neighbouring memory codes.

**The durable rule.** A blink pattern means the board HAS power and is reaching POST; it is a POST progress code, not a power-adaptor report. So: decode the blink before touching the charging path, or the bench spends the customer's money on the wrong end of the machine. And a yanked charger is a **chassis shock** - an unseated SODIMM is the classic result, which is exactly why "ripped out" and "will not POST" fit together with a memory code, with the charger as the trigger and not the cause.

**Method that actually got the table.** Fetch the vendor's service-manual PAGE for that exact model over HTTP with a browser User-Agent - a bare `Invoke-WebRequest` returns 403, and manualslib returns 403 as well; with a UA header the page came back at 252 KB. Save the HTML, then extract the table by regex (`<table.*?</table>` -> rows -> cells, tags stripped) rather than trying to read nav-heavy HTML. Community and aggregator articles agree that 2/4 is memory but name no source and often cover a different model; the service manual for the model in hand is the authority.

**Order of operations that follows.** Reseat, then move the module to the other slot, then substitute a known-good stick - and only then test charging. On this machine Dell's own configuration record for the tag says it shipped with **ONE 8 GB DDR4-3200 SODIMM**, so "swap among the slots" means moving that stick, not adding a second one; knowing the as-shipped module count before opening the machine is what makes the step unambiguous.
