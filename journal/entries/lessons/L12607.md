**L12607 · A flattened PDF is not blank: Gusto's Q3 2026 941 was filed, not missing**

LESSON ? a flattened PDF is not a blank one, and the "(1)" download is the EARLIER quarter

1. pypdf `get_fields() == 0` does NOT mean a form is blank. Gusto's Form 941 PDFs are
 generated with Prawn and flattened: zero AcroForm fields, but every value is present
 as page text. `/tmp/gusto/US_941_7757616926644421.pdf` was written off as a "blank
 template" on the field count alone; `extract_text()` shows line 1 = 1, line 2 =
 13182.69, 5a = 13182.69 x 0.124 = 1634.65, 5c = 382.30, 5e = 2016.95, line 7 = 0.01,
 lines 10/12/13 = 2016.96, line 14 blank, and a full-page "Paper Copy - Filed
 Electronically" watermark with a reporting-agent signature dated 10/13/2026.
 ALWAYS read the page text before concluding a form is empty. To settle a checkbox,
 render it (see 4) - the marks are vector paths, invisible to text extraction.

2. In /tmp/gusto the ` (1)` suffix is the EARLIER download, not a copy of the later one.
 nj_*_ (1).pdf has CreationDate 2026-08-13 and wages 6,346.15 (Q2); the plain
 nj_*.pdf has CreationDate 2026-10-19 and wages 13,182.69 (Q3). Same for the 941s:
 the (1) copy is the Q2 return (quarter 2 checked, no watermark). Distinguish paired
 downloads by CreationDate and content, never by filename.

3. accounting.db cannot reconcile a federal 941 deposit line. Gusto rows all have
 description/merchant "Gusto"; the only federal-vs-state-vs-net split is
 raw_payload_json.raw_name, which reads `GUSTO DES:TAX ...` or `GUSTO DES:NET ...` -
 it says TAX, not WHICH tax. Q3 DES:TAX debits net 2,796.23 (note the 2026-07-07
 -11.56 credit; a prior shift logged 2,807.79 by omitting it). Less NJ Q3 786.94
 leaves 2,009.29, against 2,016.96 on the return: a 7.67 gap that needs Gusto's
 per-payment tax detail or EFTPS. There is no 203.02 row in the db at all, so the
 owner's Gusto-UI screenshots cannot be corroborated from the ledger.

4. Rendering PDFs on secratary-cloud: there is NO pdftoppm / pdftocairo / gs / mutool /
 convert / qpdf. `pip install pymupdf` into /tmp/pdfvenv works and gives
 page.get_pixmap(dpi=..., clip=...) plus get_drawings() for checkbox inspection.
 `pypdf` still has no renderer.

5. Shell hazard on this route: driving ssh from Windows PowerShell mangles quoted args
 (single quotes vanish, `|` is parsed locally, CRLF puts a \r on the last argument -
 gmail-search --read then fails with "Invalid id value" %0D). Write the script to a
 file, pipe it to `cat > /tmp/x.sh`, run `sed -i 's/\r$//' /tmp/x.sh` first, then bash
 it. Python tolerates CRLF; bash and CLI args do not.

6. Consequence for the 941 pack: the premise "Gusto did not file Q3" rests on the blank-
 PDF finding and is contradicted by the primary document. Both the return and the
 owner's "Nothing to show here" screen are real; only the IRS business tax account or
 EFTPS resolves it. Branch finance/form-941-q3-2026-pack-20261021, sha aa13883da.
