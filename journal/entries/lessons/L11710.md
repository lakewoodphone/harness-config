**L11710 · Music Assistant's 'AI DJ' does not select music — its discovery is a weight tweak, not a novelty objective**

Read the source this session (github.com/music-assistant/server@dev). Transferable facts, not a summary:
1. providers/ai_radio/queue_dj.py is a NARRATION injector at track boundaries. It writes and speaks; it never chooses a track. Track selection belongs to the queue (Endless Mix -> the music source's own similar-tracks). So 'MA has an AI DJ' is false in the sense people assume. Spotify's DJ IS the selector; MA's is a voice-over.
2. 'Discover' is a preset, not an algorithm: SIMILARITY_PRESETS['discover'] just downweights the genre (0.25) and era (0.1) rerank bonuses over an 18-dim weighted Euclidean metric + MMR diversity. grep for novelty/heard/exclude/last_played in providers/sonic_similarity finds only config keys. Nothing excludes what the user has already heard.
3. sonic_analysis consumes the LIVE PCM stream during playback and skips the first 45s. No background crawl of streaming catalogues (local files only). A streaming-only library therefore starts with ZERO vectors and grows one play at a time — a never-played track is unrecommendable by the sonic path.
4. valence/arousal/instrumentalness/acousticness are zero-shot CLAP prompt-pair comparisons against two sentences, Platt-calibrated (clap_prompts.py SCALAR_PROMPT_PAIRS). Retrieval model used as a regressor: useful direction, noisy magnitude.
5. The genuinely reusable asset is providers/smart_playlist (1,657 lines): a rule engine with last_played ('not played within N days'), genre, artist, popularity, explicit, duration, similar-tracks. That is the constraint language a real DJ needs and Spotify will never expose. Target it from an external planner rather than forking 3,386 files.
6. Extension reality: MA's 'community extensions' are UI cards/clients only. There is no third-party server-plugin channel, so custom logic = external service over music-assistant-client (long-lived token, ws API) or a fork. Client README read this session.
7. Verified live 2026-10-20: Last.fm ws API alive and needs a key (keyless call returns error 6); ListenBrainz /1/cf/recommendation/user/<user>/recording returns 200 with scored recording MBIDs + latest_listened_at; AcousticBrainz is a FROZEN 2015-2022 archive, not a live service.
