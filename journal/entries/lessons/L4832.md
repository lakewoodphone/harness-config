**L4832 · Competitor/shop research: use firecrawl + jina; plain web_search found 8x less**

2026-10-15, searching for other phone shops in Lakewood NJ. The owner asked directly 'did you use your firecrawl tools, your Jina search tools?' I had not. Both keys were already configured in personal-secretary-mvp/.env (FIRECRAWL_API_KEY, JINA_API_KEY) and app/web_access.py already had _search_firecrawl and a jina provider registered.

MEASURED DIFFERENCE on the same question: plain web_search returned the same generic Yelp/Angi/iRepair4U noise over and over and never named a Lakewood store. Firecrawl search + scrape and jina (s.jina.ai search, r.jina.ai reader) produced the actual shop cluster in three calls: Lakewood Kosher Cell / Lakewood Beepers at 209 2nd St (732-886-0200), Technoman Repair 310 2nd St (732-961-6064), Kosher Cell Inc 1700 Madison Ave (848-299-4081), Chaim's Phone Repair 106 Clifton Ave (732-364-9977), plus TAG's own Lakewood store directory via r.jina.ai.

TWO TECHNIQUES worth keeping:
1. The single highest-value find was a PHONE-NUMBER JOIN, not a name search. The web installer listing for 'Chaims Computer Repair, 199 Saint Nicholas Ave' carried +1-347-598-8428 - the exact number in our Dialpad book for Chaim Ginsberger. That is how we learned a partner's shop name and address. When you know a number we already hold, search the number itself.
2. r.jina.ai/<url> reads JS-rendered pages that firecrawl scrape returns empty for. protect.tag.org/where-to-buy came back 422 bytes of nothing via firecrawl and full content via r.jina.ai. Try the Jina reader before concluding a page has no data.

TOOL HEALTH, measured the same session: in ps_action('web_search'), brave -> 302 redirect (broken), tavily -> 433 (broken), serpapi -> 429 (rate limited), jina -> read timeout, firecrawl -> worked. So firecrawl is currently the only reliable provider in that chain; do not trust a thin result from it without trying firecrawl/jina directly.

RESULT: /home/zabz/phone/lpt-hub/ops/referral-shops-lakewood.md rewritten with 10 shops across two evidence tiers (OWN RECORD = we hand the number out in our own texts; DIRECTORY = firecrawl/jina verified, no customer corroboration yet), plus exclusions with reasons.
