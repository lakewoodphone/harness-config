**L12279 · Quantising a tflite floor model: a file name is not a measurement**

Lane `floor-model` closed roadmap row A-P5-01's first two clauses in the kf repo (branch `agent/kf-floor-model`, commit b8ec76dd, ZABZ-TECH). Facts a future me cannot re-derive cheaply:

1. The kf floor NSFW model's catalogue entry *named* its file `nsfw_mobilenet_v2_int8.tflite` while pinning the upstream FLOAT bytes: release zip 100,619,093 B -> `mobilenet_v2_140_224/saved_model.tflite` 17,355,548 B, sha256 380f98f7...fab40, which is exactly the catalogue pin. A file name is not a measurement.
2. The int8 conversion (TF 2.21.0, `from_saved_model`, DEFAULT + TFLITE_BUILTINS_INT8, float32 I/O) is 5,013,840 B, sha256 490afad0...a69e0, 124/180 tensors int8 with scale, and is reproducible byte-for-byte across runs. The zip contains a full SavedModel (`saved_model.pb` + `variables/`), so no Keras/H5 wrangling is needed.
3. The kf ladder accuracy harness (`LadderRungCorpusAccuracyTest`) stubs EXPLICIT_SEXUAL to NO_ENGINE, so its rung-1 row is 0 frames and re-running it after a quantisation proves nothing. Substitution test instead: float vs int8 over 282 frames gave 269/282 top-1 (95.4%) and 278/282 at the 0.6 threshold (98.6%), with all 4 flips one-way (flagged -> clear). Quantised models drift permissive, not strict, so a threshold must not be tuned to recover them without ground truth.
4. Flipping a catalogue pin to an artefact that exists only on our own host is a field-breaking change: the fallback URL then serves bytes that fail the new digest and every phone provisions nothing. The pattern used instead: a `QuantisedVariant` published *only* while the broker holds bytes matching its pin, so an un-uploaded artefact degrades to the previous behaviour rather than to a broken manifest.
5. Tooling traps, both hit: `tf.lite.Interpreter` in TF 2.21 has no `.close()` (guard with getattr), and its tensor details carry numpy scalars that `json.dumps` refuses - cast before serialising or the script writes the artefact and then loses the measurement of it.
6. Worktree gotcha: in a `git worktree`, `.git` is a file, so `git commit -F .git/msg.txt` cannot work; put the message file outside the tree.
