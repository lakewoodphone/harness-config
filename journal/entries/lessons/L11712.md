**L11712 · Spotify's 2026 API is materially smaller than its 2024 one — and ListenBrainz Labs gives a free global similarity graph**

Verified live 2026-10-20 (mesh child on ZABZ-TECH + my own calls). Facts that decide a music build:
1. CORRECTION to my earlier claim that Spotify playlist writes were untouched: the OLD path is dead. POST /playlists/{id}/tracks -> 403 for a new app; use POST /playlists/{id}/items. Creation is POST /me/playlists. Source: developer.spotify.com Feb-2026 migration guide, fetched and read.
2. February 2026 also removed: batch GET /tracks|/albums|/artists, GET /artists/{id}/top-tracks, all /browse/*, GET /users/{id}, GET /users/{id}/playlists. Search limit max 50 -> 10 (default 20 -> 5). Save/remove/contains collapsed to PUT|DELETE|GET /me/library. 'popularity' removed from track and album objects. Surviving: GET /me/tracks, /me/top, /me/player/recently-played, POST /me/playlists.
3. Dev-mode app limits: 5 users per app, owner needs Premium, Client IDs per developer 1 -> 25 as of July 2026. Extended quota is closed to individuals since 2025-05-15 (requires an org, >=250k MAU). So personal use only, no extension path.
4. BEST FIND: ListenBrainz Labs similar-artists/similar-recordings is keyless, needs no account, and returns 100 scored neighbours (Cher -> Madonna 869, Britney 698, ABBA 671). This gives a global collaborative similarity graph WITHOUT the user's scrobbles. Also spotify-id-from-mbid. Labelled not-for-production; 1 req/s.
5. AcousticBrainz is frozen but ALIVE and queryable by recording MBID (danceability 0.954 etc., essentia 2.1-beta4); coverage stops 2022-07-06. This is the only licensed source of audio-derived traits without holding audio.
6. Preview audio (Deezer/iTunes) is technically keyless but licensed for streaming-for-promotion only; Apple forbids download/save/cache. Computing features from previews is unlicensed -> ruled out.
7. Last.fm needs a free key, non-commercial only, no published rate limit. MusicBrainz has no similarity score of its own but is the ID hub.
