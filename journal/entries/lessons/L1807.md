**L1807 · cmd /c with a quoted program plus redirection can silently do nothing**

Measured 2026-09-16: `WScript.Shell.Run("cmd /c ""C:\...\python.exe"" ""C:\...\phone-gate.py""
--listen-port 3086 ... >> ""log"" 2>> ""err""", 0, False)` produced a gate that never started,
an EMPTY stderr file and no log line. cmd's quote handling around a quoted program combined with
redirection is not something to build on. The fix was to drop cmd and redirection entirely: the
gate grew `--log-file` and writes its own record, and the VBS runs the program directly with
doubled quotes. Fewer moving parts, and a failure now leaves a file to read.
