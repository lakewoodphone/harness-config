**L1705 · Append path: no more 15,303-file walk, no more pathlib.relative_to**

Two measured fixes in one entry. (1) _rel_of now uses a precomputed string prefix instead of pathlib.relative_to: cProfile showed 15,303 calls at 7.2 s, more than half the append. (2) legacy_signature() replaces tree_signature() as the cache key for legacy_candidates, so the write path no longer stats every file in entries/ (that walk was 8.2 s and its entries_sig was never read by the only write-path consumer). tree_signature() itself is unchanged for callers that need the entries signature. Verified: _rel_of output identical to the pathlib result on a 120-path sample.
