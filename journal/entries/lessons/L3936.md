**L3936 · A fleet held a version by accident: a DNS refusal was doing the work of an update policy**

**L · A locked-down fleet held a version by accident: a DNS refusal nobody wrote down was doing the work of an update policy**

WHAT HAPPENED, measured 2026-10-14. The LPT Waze fleet sat on iOS 26.5.2 while iOS 27 had been out since 14
September 2026. The reason was not a decision. The DoH filter allowed `mesu.apple.com` and `gdmf.apple.com` — the
**catalogues**, so a device can discover an update — and refused `updates.cdn-apple.com`, the host that **delivers**
it. Fifteen refusals in 24 hours were the fleet asking for update payloads and getting NXDOMAIN. Nobody had chosen
"we do not patch"; an allowlist written for content reasons happened to make the fleet unpatchable.

Then, allowing that host so the on-device dictation model could download (the owner's instruction, 2026-10-14),
turned the other edge of the same fact into a live question: with the CDN reachable, the only brake left on
self-updating is MDM, and Meraki's own guidance says indefinitely blocking OS updates "may expose endpoints to
security vulnerabilities".

RULES:
1. **Discovery and delivery are separate hosts, and blocking only the delivery host is how a fleet ends up
 unpatchable without anyone deciding it.** `mesu`/`gdmf` = catalogues; `updates.cdn-apple.com` = bytes. Check which
 one an allowlist actually blocks before believing a device is deliberately held back a version.
2. **A version held by a network accident is a security posture nobody owns.** Either write the update policy down
 (managed delay, a named target version) or open the path. Do not let the filter decide.
3. **When opening a CDN for one asset, ask what else that CDN delivers before, not after.** Here the answer was
 every iOS payload: OS updates, restore images, Background Security Improvements and carrier bundles.
4. The upside, stated so it is not only a cost: making a device patchable is a **security gain**. The risk to manage
 is stability — a kiosk that quietly takes a new iOS is a kiosk whose lock-down nobody has retested — and that is
 what a managed update delay is for.

queries and `docker logs --since 24h waze-mdm-dns-filter-1`, 2026-10-14; Apple's enterprise host list
<https://support.apple.com/en-us/101555>.
