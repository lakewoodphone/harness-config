**L12179 · workflow's agent() runs children LOCALLY; subagent is the MESH - twelve auditors refused the wrong host and that clause is what saved them**

MEASURED 2026-10-22, orchestrating the personality-system campaign from ZABZ-YOGA.

Twelve audit agents were dispatched with `workflow` (the fan-out tool) and every one of them landed on the LOCAL node, ZABZ-YOGA, where the repository path named in their brief did not exist. All twelve correctly answered WRONG-HOST and refused to audit a different checkout — so the run cost twelve agent lifetimes and produced zero findings. Two minutes later, three plain `subagent` calls carrying the same estate landed on ZABZ-TECH via the mesh broker, with the repo present and node_modules intact.

So the rule is: `workflow`'s `agent()` runs children LOCALLY; the `subagent` family is the MESH. A brief that names another machine's path is correct for `subagent` and fatal for `workflow`. Before dispatching any fleet:

1. Decide where the child must run, then choose the tool that lands it there — do not assume the fan-out tool routes like the mesh.
2. `hostname` + the repo's `git log -1` in the brief, with the exact expected revision, is what turned twelve silent wrong-tree audits into twelve honest refusals. Keep that clause in every brief; it is the only thing that made the failure visible.
3. If the work is reading and reasoning over source (no build), it does not need a particular machine at all — pin a worktree to the production commit locally (`git worktree add <path> -b audit/x origin/main`, then a directory junction for node_modules: `cmd /c mklink /J <path>\node_modules <main>\node_modules`) and audit there. A junctioned worktree ran 57 tests in 343 ms, so it is a full test environment for no disk cost.
4. The engine's hard ceiling is 8 concurrent children, and it throws the WHOLE workflow when the ninth is requested — the first 12-agent fan-out died that way. Batch at 4-6.

Cost of learning this the hard way: one wasted fleet, about twelve minutes. Cost of not having the revision clause in the briefs: twelve confident audits of a tree that is not the one in production, which is the failure this estate has paid for before (P3164).
