**L3868 · Telephony proof: 20/20 legs pass; 10DLC 30034/30024 on a fresh number; adb re-splits SMS bodies; 'submitted' is not 'sent'**

Full telephony proof on the five bench handsets, 2026-10-19 evening, with a dedicated Twilio number (+17324667029) bought for the bench so nothing touches the production line.

RESULT: 20 legs, 20 passes.
- Outbound call (handset -> bench number): all five, 5 s completed, caller id read off Twilio.
- Inbound call (bench number -> handset): all five rang, were answered over adb via mCallState, ran 5-6 s, and produced a Twilio recording each - proof audio flowed both ways, not just that it connected.
- Inbound SMS: delivered to all five.
- Outbound SMS: received at the bench number from all five, sender = the handset's own number.

Numbers, learned by having each handset dial the bench line because none of them report their own MSISDN over adb: 615373543 +17327030043, 615963123 +19087836331, 616202539 +18482210007, 558800328253 +18483895173, 558800238329 +18483189716.

THREE LESSONS:
1. **A new Twilio number cannot text US mobiles until it is a registered A2P sender.** From=<number> alone returns 30034 "US A2P 10DLC - message from an unregistered number"; pinning an unprovisioned sender inside the service returns 30024 "numeric sender ID not provisioned on carrier". The account already had an approved brand and a Low Volume Mixed A2P service, so the fix was adding the bench number to that service's sender pool and sending with MessagingServiceSid AND From. Delivery began ~20 minutes after the pool update, not immediately - a test run inside that window looks like a broken phone and is not.
2. **adb shell re-splits arguments.** `--es sms_body LPT bench outbound SMS test` reaches the device as "LPT": everything after the first space becomes separate argv. The harness now single-quotes every extra. Five messages that read as failures were five truncated successes - the far end had them all along.
3. **"Submitted" is not "sent".** The bench APK now waits on the SMS sent-PendingIntent and reports the code (-1 = Activity.RESULT_OK = the radio handed it to the network), so the question is answered by the network rather than by the app's own optimism.

Code: lpt/condition/telephony.py (Twilio + adb legs), bench-apk SMS mode, commit 9b0dccbf. Artifacts cli/logs/telephony/*.json. Bench app uninstalled from all five and verified gone (0 packages).
