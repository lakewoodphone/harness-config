**L1831 · A managed policy file is the mechanism on a Mac that is not MDM-enrolled**

Measured 2026-09-16 on the Mac Mini: `Enrolled via DEP: No`, `MDM enrollment: No`, so the
operating system does NOT distribute preferences -- a file at
`/Library/Managed Preferences/com.google.Chrome.plist` (root:wheel 644) IS the enforcement, read
back and confirmed with `defaults read` and `plutil -lint`. It sets RestoreOnStartup=5 (the New
Tab page), BackgroundModeEnabled=0 (so quitting Chrome actually quits it) and MemorySaverModeEnabled=1.
Editing a user's own Chrome `Preferences` would NOT be durable: Chrome rewrites that file on exit.
HONEST REFUSAL, worth copying: whether this Chrome build HONOURS those keys cannot be verified
without `chrome://policy` and a human at the GUI. A headless `--dump-dom` of that page returned
101 KB of DOM containing none of the keys, because the page fills in by JavaScript after the
snapshot -- that is a refusal, not a negative result. Do not report a policy as working because it
is installed.
