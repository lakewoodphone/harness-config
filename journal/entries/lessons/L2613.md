**L2613 · Owner's Apple Wallet Digital ID is passport-backed: TSA-only in practice, physical ID still required**

Owner created a Digital ID in Apple Wallet from his US passport on his iPhone 15 Pro (reported 2026-09-27).

Facts a future session must not re-derive:
- Credential is a passport-backed mDoc (ISO/IEC 18013-5) held in the Secure Element, never in iCloud; presenting is NFC tap + Face ID, selective disclosure of only the requested fields.
- Setup verification is cryptographic, not a live State Department lookup: the ePassport chip is read and its signature validated against the issuing authority's certificate chain (US passports are signed by the State Department CA), plus a selfie + liveness check matched to the passport photo. Apple markets this as 'verified by the government issuing authority'. There is no real-time State/DHS database query and no notification to State when he presents it.
- Real acceptance today: TSA checkpoints at 250+ US airports for DOMESTIC travel only, in public beta, and TSA still requires a physical ID at the checkpoint. Also accepted for adult age confirmation on Apple Account/Apple services (from ~May 2026). Apps/sites can request it only via entitlements (Verify with Wallet / ID Verifier) - not widespread.
- NOT valid for: international travel or border crossing, in lieu of a physical passport; not a general-purpose ID at banks, traffic stops, most stores, or for I-9.
- Known defect: iOS 27 betas deactivated the Digital ID card for some users; the only fix is deleting and re-enrolling the passport. Expect to re-do setup after the iOS 27 upgrade.
- Business angle, unused: an in-person ID check at the shop (trade-in ID capture) could read a customer's Digital ID with an ID Verifier-enabled app - display-only mode needs only the Verifier API capability, no data-transfer entitlement.

Sources: apple.com/newsroom 2025-11-12, tsa.gov/digital-id and TSA ID FAQ (pub 2026-09-04), developer.apple.com/wallet/id-verifier, developer.apple.com/wallet/get-started-with-verify-with-wallet, mobileidworld 2026-08-31 (iOS 27 deactivation).
