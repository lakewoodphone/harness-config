**L1922 · A child's MESH-HOST line is a claim, not a measurement; a roster capability must name what revokes it**

A child's `MESH-HOST:` line is a CLAIM. The machine's own shell output is a MEASUREMENT. Keep both,
and never let one stand in for the other.

Measured 2026-09-17, live, three dispatches to `zabz-tech-linux` through the corrected executor row:

* dispatch A (the `subagent_remote` shape) — the child's final message was a delegation-failure
 report; no name claimed (see P… nested delegation, open pain).
* dispatch B (`mesh-run`, the hostname shape) — the child answered `MESH-HOST: zabz-yoga`, and
 `mesh-run` correctly refused it: `location disagreement: zabz-yoga not on zabz-tech-linux`. The
 child was running on `zabz-tech-linux`: `/etc/hostname` is `zabz-tech-linux`, `HOSTNAME=zabz-tech-linux`,
 and `grep -ril zabz-yoga /home/zabz/.dsh/ /home/zabz/dsh-engine/` returns NOTHING. Its own reasoning
 stream stops at "Let me run it." and never reports an output — it answered without running the tool.
* dispatch C (the framed instrument, `_scratch/102-live-child.mjs`) — the target's OWN shell captured
 `hostname` (`printf -v fanout_host "$(hostname)"`) and the child's stderr says *"The command printed
 \"zabz-tech-linux\""*. Both facts agree: exit 0, framed, `MESH-HOST: zabz-tech-linux`, 12099 ms.

RULE: a run is not verified because a model said where it was. Read the transport's own recorded host
(`transport host =` / the frame), and if a child's line disagrees with it, the run failed — that is
what the check is for. One of three children produced a plausible, specific, wrong answer; the
verifier caught it, and a human reading only the child's message would have believed it.

SECOND RULE, from the same fix: a roster capability row must name what would REVOKE it, not only what
restored it. `nodes.json`'s `zabz-tech-linux` evidence now ends "SET BACK TO false if the executor form
is replaced by an explicit interpreter pair again, or if /usr/local/bin/dsh or /etc/dsh-worker.env is
removed from the node - re-measure, do not re-argue", and `test/config.test.mjs` asserts that clause.
A row that names only its restoring condition can only ever move one way.
