**L3134 · A CSS grep is not evidence about app state: P45b's drawer half was already shipped**

The audit's queue.tsv verdicts for the phone-drawer entries were measured against
`assets/mobile.css` only. P45b was recorded PARTLY ("a session picked in the drawer leaves it
open ... needs a client plugin") on that basis.

That client plugin already existed and was already shipped: `packages/plugin-mobile/lib/client.js`
(commit 99f0e3b, 2026-09-16, two weeks before the audit) defines `closeDrawer()` and calls it from
a click handler over the drawer's surface, from the scrim, and from Escape. `~/.dsh/profiles/web/
node_modules/dsh-plugin-mobile` is a junction onto that file, so the fix is live in the engine the
owner runs. C3.sh therefore checks the plugin source and reports FIXED.

Rule for the next audit: a CSS grep is not evidence about app state. Before recording a UI half as
unfixed, read the shipped client plugin that owns the behaviour — the CSS gate and the client
plugin are two different artifacts and only one of them can hold state.
