**L1860 · Six platform traps and six of my own bugs, measured while building the node hygiene policy**

Measured on 2026-09-17 while building stream O4 (`scripts/mesh-hygiene.ps1|.sh`,
`docs/mesh/85-hygiene.md`). Each cost a wrong-looking result before it was understood.

PLATFORM TRAPS (durable facts, not my bugs)
* **`WTSINFOEX_LEVEL1.LastInputTime` and `WTSINFO.LastInputTime` are 0 for a console session on
 Windows 11 build 26200.** Raw: `sid=1 state=0 user='ZABZ-YOGA\ezabz' ws='Console' lastInput=0
 now=134340898695453374`, while `GetLastInputInfo` in the same second said 108109 ms. Consequence: a
 job running as SYSTEM (session 0) **cannot** measure the console's idleness via the WTS APIs, so it
 must decline rather than assume idle; `GetLastInputInfo` is session-scoped and only answers
 correctly from inside the console session. `quser.exe`, `query.exe` and `qwinsta.exe` do not exist
 on this build at all (Test-Path false).
* **A Windows "memory hog" that writes the same byte to every page is not a hog.** Measured:
 `New-Object byte[]` + `[Array]::Fill[byte]` touched ~2.8 MB/s (a 2 GB fill did not finish in 120 s),
 and a nominal 9.45 GB array reported `WorkingSet 126 MB`, `PrivateMemorySize 41 MB`,
 `VirtualMemorySize 2.1 TB` — most likely Windows page-combining merging identical pages (mechanism
 not proved; the measurement stands). The load that works: `Buffer.alloc` + `randomFillSync` in
 Node → `RESIDENT rss=8936 MiB` in seconds. Always measure the process's RSS, never the allocation.
* **`Start-Process -Wait` waits for the process AND its descendants on Windows**, so a test that
 spawns a 900-second hog and waits hangs until something kills it (mine was killed at 120 s and left
 a stray hog). `-PassThru` + `WaitForExit(ms)` on the intermediate only.
* **`PPID` is a bash readonly variable**, the sibling of the `uid` trap already on the record
 (`/tmp/dbg-linux.sh: line 12: PPID: readonly variable`). Use `ppid`.
* **Orphan reparenting is platform- and host-specific.** Measured on secratary: an abandoned `sh`
 reparents to pid 1. On a host with a per-user `systemd` (or any `PR_SET_CHILD_SUBREAPER`) the
 parent is a LIVE reaper, so a strict "parent pid is gone" test finds no orphans at all there.
 "Parent gone" must include "the parent is a reaper (pid 1 / systemd / launchd)".
* **The gate's `accepts.maxChildren` has no core term** (`min(budgetSlots − inUse, 12)`, budget
 floored at 4 and using `max(2 GiB, 12%)` as its reserve), while the broker's 71 §2.2 arithmetic is
 `min(memorySlots − inUse, floor(physical × 0.75))`. Measured in the same seconds: gate **12** vs
 broker **3** on the 4-core authority, **12** vs **7** on the 10-core Mac. Report both; do not let
 either be read alone.
* **Cross-checking a memory number against the local gate costs one HTTP call and catches a wrong
 definition**: Windows `avail 11226 MiB` vs gate `freeMiB 11228`; Mac `avail 7071` vs gate `7070`.

MY OWN BUGS, EACH CAUGHT BY A TEST FAILING (the reason the code is shaped as it is)
* A **cached** process table made the after-measurement equal the before-measurement
 (`179572 -> 179572` on a run that had just killed both processes). Re-read the table first.
* An **age floor checked before the pattern check** reported a human's `ping` and an unrelated
 sleeper as "matches our tooling". Pattern first, age second.
* An **etime→seconds conversion applied twice** turns every age into 0 (`etime_to_seconds("6")` has
 one field) — so no orphan ever passed the floor and the self-test said "already clean" with two
 eligible orphans in front of it.
* **Writer and reader used different row layouts** (`pid|class|exe|rss|…` written,
 `pid|class|rss|…` read): every orphan's bytes summed to 0, and the reclaim loop then did arithmetic
 on the string `sh` and died under `set -u`. One layout, written down in the file.
* **A test helper that finds processes by grepping `ps` output also matches the matcher** (awk's own
 argv carries the path), which reported two pids per hog. Let the hog write its own pid to a file.
* `bash -n` failed once on two monster lines of nested substitutions; splitting them into one value
 per line fixed it, but the individual shapes all parse in isolation — record the observation, not a
 theory about the cause.
