**L2594 · Lakewood local planning: which sources actually answer (weather, showtimes, food, events)**

Measured 2026-09-27/28 on ZABZ-YOGA. All of these are live, working paths.

WEATHER (Lakewood NJ) - authoritative and instant:
 point: https://api.weather.gov/points/40.0959,-74.2176 -> grid PHI 81,90, forecastZone NJZ020
 periods: https://api.weather.gov/gridpoints/PHI/81,90/forecast
 hourly: https://api.weather.gov/gridpoints/PHI/81,90/forecast/hourly
 alerts: https://api.weather.gov/alerts/active?zone=NJZ020 (Lakewood's own zone)
 NOTE: startTime comes back already parsed as [datetime] in pwsh - use .ToString('ddd MM-dd HH:mm'), NOT .Substring(). My first attempt threw "Method invocation failed because [System.DateTime] does not contain a method named 'Substring'" 14 times.
 Do NOT search the web for local weather. "Lakewood NJ weather tonight" returned weather.com pages in Vietnamese/Catalan/Chinese, a BBC page and weather.com.cn - none usable.

MOVIE SHOWTIMES near Lakewood:
 AMC's own site is Cloudflare-blocked to jina read_url AND to plain fetch ("Just a moment..." / "Why have I been blocked"). moviefone zip pages -> 403. bigscreenimages.com -> nav only.
 WHAT WORKS: https://www.fandango.com/<zip>_movietimes via firecrawl_scrape, proxy "stealth", formats ["query"], maxAge 0, waitFor 3000. Returns every theater in range with every post-10pm start plus ticket deep-links. Swap the zip to widen the radius (08701 Lakewood, 08901 New Brunswick, 10036 Times Sq, 11211 Brooklyn).

RESTAURANT HOURS, Lakewood:
 https://www.restaurantji.com/nj/lakewood/ via firecrawl_scrape, formats ["query"], prompt asking for hours + "open past 10pm" -> ~80 places with "(Open until 2 a.m.)" style annotations. Good enough to build a shortlist; still phone-confirm.

LOCAL COMMUNITY NEWS / EVENTS, Lakewood:
 thelakewoodscoop.com and jooish.app carry resident notices (police advisories, shul times, chol hamoed events).
 TRAP: "The Voice of Lakewood - Chol Hamoed Fun Guide" ranks #1 for chol hamoed trips. The page live on 2026-09-27 is the PESACH 2026 edition (published Mar 30 2026). Hours, prices and dates are stale for Sukkos. Read the publication date before using a seasonal guide.

DEAD LOCAL BUSINESS: Xscape Theatres Howell (Route 9, the old closest cinema to Lakewood) is abandoned and drawing trespassers - police warnings. Do not send anyone there.

JOURNAL TOOL NOTE: a first append in a session can trigger the legacy-drift scan and blow past a 120 s foreground timeout, and the --quiet writes after the killing first one then land unpredictably. Append from a BACKGROUND shell.
