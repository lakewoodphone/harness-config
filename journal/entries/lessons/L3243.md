**L3243 · Titanfall 2 works now: the clean reinstall fixed it, so the file-integrity hypothesis was right and the Repair I talked him out of would have found it**

THE NIGHT'S MYSTERY IS SOLVED, and it was the hypothesis I abandoned.

Titanfall 2 now runs and the owner calls it "way better and actually immersive". What changed:
the EA App RE-DOWNLOADED the whole 63.67 GB after I deleted the folder (my error - see L3236),
and the fresh copy WORKS.

WHY: the original install was written between 2026-10-01 00:31 and 00:50 - inside the window
when Windows was mid-26H2-upgrade, the display driver was being installed and then downgraded by
Windows Update, and dxgkrnl was failing to set display modes. The re-download was written on a
settled machine. Same version (v2.0.11.0), same 2180 files, same signature - a CLEAN INSTALL
INSTEAD OF A CHURNED ONE.

So the file-integrity hypothesis was correct: 64 GB written during a servicing storm was damaged
in a way a file count could not see, and no local tool could verify because no manifest or digest
exists in that install. THE EA APP REPAIR I RECOMMENDED HOURS EARLIER WOULD ALMOST CERTAINLY HAVE
FOUND IT. I then talked the owner out of it, on the reasoning that "the licence is fine" - which
never implied the files were. That is the costliest single judgement error of this session: it
kept a working game broken for most of a day.

LESSON, and it generalises: a game that fails at a CONSISTENT point, every single attempt, on an
install written during OS/driver churn, is a file-integrity suspect - and the launcher's own
verify/repair is the FIRST thing to run, not the last. Verify-and-repair costs one click and
answers definitively. I spent hours testing drivers, ports, refresh rates and overlays around a
question the repair would have answered in minutes.

ALSO: It Takes Two is being removed at the owner's request - 44.80 GB, judged boring ("it's a
drop boring without shooting"). Removing it via EA's own Cleanup.exe uninstall_game so the record
goes too, per L3236. Titanfall 2 must NOT be touched: 63.67 GB, working, and he plays it.

CONSEQUENCE FOR THE DOCS: play-tonight.md and pc-gaming-profile.md both recommend It Takes Two as
the first game and the reason the two controllers were bought. That is now wrong and needs a
correction block, same as the other stale claims in those files.
