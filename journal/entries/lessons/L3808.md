**L3808 · An empty hashtable has no .Keys under StrictMode, and that one line broke the window reconcile pass for three days**

`@($hashtable).Keys` is not "the keys, or none". Under `Set-StrictMode -Version Latest` — which `multi-window/dshw.ps1` sets — it THROWS:

 The property 'Keys' cannot be found on this object. Verify that the property exists.

Member enumeration needs an element to read the property FROM, and an empty collection has none. Reproduced on ZABZ-TECH with pwsh 7.6.6: `@(@{}).Keys`, `@($empty).Keys` and `@(f).Keys` where `f` returns `@{}` all throw; the same expression on a one-key hashtable works.

**What it cost.** One line — `$scanPorts = @(@(Get-WindowOriginPorts).Keys | ...)` in `Get-OriginLiveLegs` — killed the window reconcile/recovery pass every time the process scan came back empty, which is its NORMAL state: no window open, or the interactive paths (`new`, `open`, `restore`, `up`) where `SkipProcessScan` short-circuits `Get-WindowOriginPorts` to `@{}`.

Evidence read rather than reasoned: `~/.dsh/multi-window/health.log` carries `window reconcile/recovery FAILED: The property 'Keys' cannot be found` on 2026-10-11, 2026-10-13 and 2026-10-14; the `DSH Engine Vitals (5m)` task reported `LastTaskResult 3` for it; and on 2026-10-14 `dshw up -WindowsMode restore` opened the remembered windows and then died at that line, so the pass that had just done the work could not record it.

**The general lesson, which is the reason this entry exists:** a message with no line number, repeated for days, is invisible. The catch that reported it printed only `$_.Exception.Message`. It now writes `$_.ScriptStackTrace` to `health.log` as well. When you fix a fault that was only ever visible as one repeated sentence, make the reporter carry the stack — that is the difference between a bug that is known and a bug that is placeable.

**The fix shipped:** one accessor, `Get-KeyList`, which handles `IDictionary`, `ConvertFrom-Json` objects and `$null`; every `.Keys` in `dshw.ps1` now goes through it (commit f73d521d).
