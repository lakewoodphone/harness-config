**L1533 · Handy dictation can be fully provisioned over SSH: one JSON file, catalog filenames in the binary, id = repo_id/filename**

Handy (the free MIT dictation app) can be fully provisioned over SSH on macOS -- no GUI clicks at all.
These are the load-bearing facts, all verified on Handy 0.9.6 / macOS 26.5 on 2026-09-15:

1. ALL settings live in ONE file: ~/Library/Application Support/com.pais.handy/settings_store.json,
 a top-level {"settings": {...}} object. Rust field names, snake_case, every field #[serde(default)],
 plus a salvage_settings() path, so a partial or slightly wrong file cannot brick the app.
2. Onboarding is skipped automatically if `selected_model` is non-empty when it first loads
 (apply_settings_migrations: onboarding_completed = !selected_model.is_empty()). Nobody needs to click
 through the wizard.
3. A model placed at ~/Library/Application Support/com.pais.handy/models/<exact catalog filename> is
 detected as downloaded. The catalog filenames are compiled into the binary and can be read locally with
 `strings -a /Applications/Handy.app/Contents/MacOS/Handy | grep -oE '[a-z0-9._-]+\.(gguf|bin)'` -- no
 need to fetch the 127 KB catalog.json from GitHub.
4. The model registry id is "{huggingface repo_id}/{filename}", e.g.
 handy-computer/whisper-large-v3-turbo-gguf/whisper-large-v3-turbo-Q8_0.gguf. That exact string goes in
 `selected_model`; the file must be downloaded from
 https://huggingface.co/<repo_id>/resolve/main/<filename>.
5. Control without a GUI: `Handy --toggle-transcription` toggles recording in the running instance, and
 `pkill -USR2 -x handy` does the same. Log: ~/Library/Logs/com.pais.handy/handy.log (debug level by
 default, and it states the model load, the bound GPU backend, and whether input simulation is permitted).
6. Launching into her GUI session from SSH needs
 `sudo launchctl asuser <uid> sudo -u <user> /Applications/Handy.app/Contents/MacOS/Handy --debug`, or a
 LaunchAgent (which is what we ended up installing -- and `launchctl bootstrap gui/<uid> <plist>` then
 proves autostart by actually starting it).

EVIDENCE: 2026-09-15 LAKEWOOECHSMINI; model load line 842 ms / MTL0 (Apple M4); settings_store.json
written and read back; LaunchAgent `com.zabz.handy.autostart` reported by `launchctl print` as running.
