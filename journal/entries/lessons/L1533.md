**L1533 · A ratio that is stable across windows is a fact about the wiring; make it take one command or it becomes folklore**

**An aggregate with a stable value across two windows is a fact about the system, not noise -- and it
deserves a command, not an improvised query.**

Measured 2026-09-15: 85.9% self over 7 days and 85.7% over 30. Two windows, four weeks apart in
sample, agreeing to within a fifth of a percent. That stability is the useful part: it means the mix is
a structural property of how the company is wired, not a bad week, and it will still be true tomorrow
unless something changes the incentive.

Rules:
- **Make the ratio take one command.** I derived it today with an ad-hoc query; P74/P75 derived it in
 September and nobody could re-derive it without repeating that work, so it drifted into folklore. A
 measurement you cannot re-run is a memory, and memories of numbers are the least reliable thing in
 this system.
- **Print the specimens beside the statistic.** The tool prints the newest five titles for exactly this
 reason: "86% self" is an argument, "6 duplicate task clusters detected" is evidence.
- **Stability across windows is a signal about the design**, not a reason for confidence. A number that
 does not move when nothing about the system has changed is describing wiring.
