**L3515 · Grepping for a boilerplate key is a corpus dump - 250 of 296 sync records matched**

MEASURED 2026-10-11 on ZABZ-YOGA. Searching for a key that is boilerplate across a
corpus is a corpus dump, not a search.

`grep '"productionOrder"'` over lpt-hub/docs/customer-operations/sync-records/*.json
matched 250 of 296 records and spilled ~30k tokens to
~/.dsh/tmp/dsh-spill-*/grep-results.txt. The one thing I actually needed - the SHAPE of
a fully linked record - was in a single file, and naming that file would have cost ~500
tokens.

Rule: when the target is "an example of X", grep for a filename or read a known
example; grep a directory only when the match SET is the answer. The same mistake was
already recorded for whole-repo greps; this is its narrow, in-repo form.
