**L1688 · git grep without -l or a pathspec hits committed CI logs and a full ESLint JSON dump in phone-and-tech-full**

MEASURED 2026-09-16 02:0xZ on the authority, repo phone-and-tech-full.
`git grep -n "10:30\|17:30\|..." origin/test -- frontend` returned megabytes: the repo has `frontend/frontend-shard1-log.txt` and `frontend/eslint-errors.json` COMMITTED - CI logs and a full ESLint dump with embedded source - and grep matched into both. It poisoned a whole context window and the useful hits were buried under ~14 KB of JSON.

RULES. On any repo that may contain committed build/CI artifacts: (1) run `git grep -l` FIRST to see which files match before printing lines; (2) prefer explicit path filters (`-- "*.html" "*.tsx"`) over a directory; (3) add `:(exclude)*.json :(exclude)*-log.txt` pathspecs when you only want source. Same for `rg` and `grep -r` on a working tree.
