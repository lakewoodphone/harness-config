**L10303 · dsh-update fetch: a 15-minute npm ceiling declared FAILURE over a complete 0.2.1-rc.2 tree that npm finished at 19 minutes on ZABZ-YOGA**

MEASURED 2026-10-19 on ZABZ-YOGA while fetching 0.2.1-rc.2 for the second machine.

WHAT HAPPENED. `dsh-update fetch 0.2.1-rc.2` runs one `npm install` with a 900000 ms (15 min) ceiling --
`DSH_UPDATE_FETCH_TIMEOUT_MS`, README §Environment overrides. On ZABZ-YOGA, with another session's pnpm/tsc build
running on the same laptop, npm reported `added 613 packages in 19m` -- FOUR MINUTES after the pipeline had already
declared:

 fetch of 0.2.1-rc.2 FAILED: npm install timed out after 900000 ms; npm install exited null

Two distinct defects, and the second one is the dangerous one:
1. the default ceiling is below the measured time on this machine under load (19 min, 613 packages, 692.9 MB --
 versus 0.2.0-rc.2's 305 packages / 453 MB on ZABZ-TECH in 2 min). It is a per-machine number, not a constant.
2. **the pipeline reported FAILURE for a tree that is complete and usable.** Verified afterwards: the bin exists,
 `node <bin> --version` prints 0.2.1-rc.2, package.json says 0.2.1-rc.2, 63,628 files. So the honest reading is
 "npm finished after we stopped waiting", not "the fetch failed". A later step that trusts the fetch's exit code
 will refuse a candidate that is actually there -- and worse, the inverse is possible: a caller that ignores the
 exit code would install a tree nobody proved.

WHAT TO DO NEXT SESSION, in this order:
- raise `DSH_UPDATE_FETCH_TIMEOUT_MS` for a laptop under load (30 min), and
- make `fetch`, on timeout, VERIFY the prefix it was writing and report `timed out but complete` as its own result
 rather than FAILED (the verification is the same `--version` + package.json check `fetch` already does at the end).

STATE ON YOGA RIGHT NOW: candidate tree present and valid at
`harness-config\dsh-update\vendor\prefix\0.2.1-rc.2`; the live engine is STILL 0.2.0-rc.2 because updating it
requires stopping the engine that serves the running session, and that is the owner's window to give.
