**L1465 · CHR30A on a Verizon Fios install is an ACCESS POINT, not a router — verify a model number against the vendor before calling a device the gateway**

**Evidence:** 2026-09-14, recording the owner's Fios install. The router label read as `CHR30A` (confirmed
by re-reading it at 3× — the first read was right, the *inference* was wrong). I had written "Verizon
CHR30A router → ONT" as the topology. Verizon's own materials call the `CHR30A` a **Wi-Fi 7 access
point**:
[datasheet](https://www.verizon.com/business/resources/factsheets/CHR30A_datasheet.pdf),
[user guide](https://www.verizon.com/content/dam/support/pdf/CHR30A-wi-fi-access-point-user-guide.pdf).
The unit's ports (10G WAN, 10G LAN, 2×2.5G LAN, USB-C) are gateway-shaped and the `10G WAN` is the
cabled one, so it may still be doing gateway duty — but that is now a **question**, and the order
summary's waived *"Wi-Fi Access Point Fee"* is a second, independent hint that the network contains
more than one piece of equipment.

**Rule:** for any consumer/ISP hardware, a model number is a claim about the device, and the vendor's
own page settles it in one search. Do not let a plausible interpretation of a photo become a fact in a
record — the same failure mode as reporting a crisis from a stale database. Write the label as read,
the vendor's description as quoted, and the topology as **unresolved** until something on the device
answers it (`mynetworksettings.com`, the ISP's equipment list, or the LEDs).
