**L7297 · 2026-10-16 six lessons from the Waze device day: blockers expire, model the vendor's cycle, resolved rows cannot carry his words, fleets can fail silently**

**L · 2026-10-16 · Six things this day taught, each one measured rather than felt.**

**1. Verify a blocker before you build a plan on it — blockers expire faster than plans do.** A whole
workstream was written around "the deploy runner is offline, owner row 530". Hours later
`gh api .../actions/runners` read **`total_count: 0`** — the runner had been **retired** and another session
had already moved the path to GitHub-hosted runners and deployed `test` green. **A blocked deploy is not a
blocked build, and a blocker is a claim with a timestamp on it.** Re-read the blocker at the start of every
session that inherits it.

**2. When the vendor bills by the *cycle*, model the cycle.** Our documents said the Telnyx tier was *flat*,
chosen by the month's volume. The carrier's own per-record billing said 196 MB cost **14.11** where the flat
model predicted 7.65 — the rate is **progressive**: 0.078/MB until the account clears 100 MB in the month,
then 0.039. Telnyx's page says it: *"the account starts at Tier 1 for its first 100 MB."* The check that
settled it: **reproduce the vendor's own worked example** (40 SIMs / 25 GB = 347.65 — the progressive ladder
gives exactly 347.65; a flat reading gives 312.50 or 375.00). **Before predicting anything from a vendor's
rate card, find one example they published and make your model match it to the cent.**

**3. Put the model in a file that fails loudly, not in a document that agrees with you.** Every price table
this day came from a script that carries its own assertion against the vendor's number. The prose documents
were wrong for weeks because prose cannot fail.

**4. A "resolved" queue row can never afterwards carry the owner's words.** Row 255 (the price sign-off) was
`resolved` with **no answer text** — and `owner-queue.py amend` refuses on a resolved row: *"amend only
touches a question still waiting."* That is precisely how the 285 and the 299 coexisted for eleven days.
**When he answers, write it down at that moment** (journal `D4042` is what saved this one).

**5. A mesh fleet can fail completely and silently — look for the artefact before believing the failure.**
All four design children returned the same diagnostic, *"banner exchange: Connection to UNKNOWN port -1:
Connection timed out — ORPHANED"*, and no candidate directory existed. Two rules follow: **check the node for
the artefact** (a lost report is not lost work), and **when you fall back to doing it yourself, say so where
the result is consumed** — the commit message for that work states that the fleet failed and the iteration was
local, so nobody later reads four designers into it.

**6. Nested quoting costs more than it saves.** `pwsh` → `ssh` → `cmd` → PowerShell ate parentheses, `%`,
`$_`, heredocs and a `%5B` in a URL this session — each time aborting the *entire* command, including an
`scp` that silently never ran. **Write a `.ps1`/`.sh`/`.py`, copy it, run it.** It has been the same lesson
three times in one day.
