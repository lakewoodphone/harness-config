**L3113 · Twilio's SDK attribute is from_ — getattr(m,'from') returns nothing, so the catch-up path stored a blank sender on every row**

**L — Twilio's Python SDK exposes the sender as `from_`. `getattr(message, "from")` returns NOTHING, so the family-chat catch-up path stored a blank sender on every message it recovered — and nothing noticed for seven weeks.**

MEASURED (2026-09-30, secratary, live API)

```
$ .venv/bin/python -c 'm = client.messages("SM7636e3a2f5587b56cfb606871eb472b2").fetch();
 print(getattr(m, "from_", "MISSING"), getattr(m, "from", "MISSING"))'
+17326745878 MISSING
```

- `app/family_chat/twilio_client.py:243` built each record as `"from": str(getattr(page, "from", "") or "")`. The payload key is `from`, but `from` is a Python keyword, so the generated attribute is `from_` — the read could never succeed.
- Consequence on the live record: **8 inbound rows with an empty `from_number`** (2026-08-09, 08-21 x2, 09-03, 09-17, 09-24, 09-28, 09-29) out of 236 inbound rows. Every message the *catch-up* path recovered after a webhook outage — not the live webhook path, which returns early when `From` is absent (`hub.py:492`) — is senderless. The message and its SID were always stored; only the sender was lost, so the record could not answer "who sent this".
- Repaired from the carrier's own record, SID by SID: all 8 resolved to real numbers (six to members, two to +17193558139). WAL-safe backup taken first (`data/family_chat.db.bak-20260930-150123`); inbound rows still lacking a sender: **0**.
- Fix, committed on the authority (`75fb1562`) and deployed: read `from_` with a fallback, and the catch-up loop now warns on a senderless record instead of storing one silently.
- Regression test written and **falsified against the old line** (fails with `getattr(page, "from")`, passes with the fix) — a test that has never been seen to fail proves nothing.

META-LESSON, same day, same system, second instance: an instrument reading a field that does not exist returns a clean, plausible value — `""` here, `179 of 179 missing` from the watchdog — and both were silent for weeks. Two of the three defects found today in this one subsystem had the same shape: **we were reading something the source never said, and the reading was quiet.** When a value matters, call the source and print what it actually returns, in the same session, before believing the code that reads it.
