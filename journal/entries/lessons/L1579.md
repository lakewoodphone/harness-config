**L1579 · Never blind-replace a short secret value: a password that is also the username and the database name**

Evidence: the Postgres password default shipped in code was the 7-character string
`wazemdm` - which is ALSO the role name and the database name. My whole-tree scrub
replaced every occurrence, turning
 postgres://wazemdm:wazemdm@localhost:5432/wazemdm
into
 postgres://<REDACTED:dsn_password>:<REDACTED:dsn_password>@localhost:5432/<REDACTED:dsn_password>
and mangled `${DATABASE_USER:-lpt}` in two compose files. Eight files had to be restored
from backup and re-redacted.

Rule: redact by pattern anchored to context (`(postgres://[^:]+:)([^@]+)(@)` -> group 2),
never by bare value replacement, and never for a value shorter than ~16 characters. Back
up each file before rewriting, and check the replacement count afterwards.
