**L1675 · The hours a caller hears can live in an uploaded audio file that exists in no repository**

## L-new2 — The hours a caller hears can live in an uploaded audio file that exists in no repository. No grep, no test and no code change can reach it.

Measured 2026-09-15. The LPT main line's closed-hours greeting is not text. `ivr_menu_script.closed`
reads *"Thank you for calling Lakewood Phone & Tech. For lakewood-phone-tech-option-2-dropoff-hours-v2.mp3,
press 2. To leave a voicemail, press 0."* — the script is TTS, but the **hours are spoken inside the
uploaded MP3** that plays when the caller presses a key. Same for `main menu.mp3` on the open-hours route.

Neither file exists anywhere in the workspace. The local media is `lpt-ivr-open-hours.mp3`,
`lpt-ivr-closed-hours.mp3`, `lpt-ivr-dropoff-info.mp3`, `lpt-welcome-greeting.mp3`,
`lpt-voicemail-greeting.mp3` (ZABZ-TECH, 2026-07-16/17) and
`lpt-ivr-closed-{intro,special}-2026-08-03.mp3` (ZABZ-YOGA) — **not one of those names matches a live
reference.** Dialpad exposes no media-download path in our tooling, so the content of what a caller
actually hears was UNREAD this session.

The whole workspace audit for "the hours" found five mutually contradictory schedules (in-repo frontend,
Dialpad IVR + SMS, the portal's a2p template and its `business_hours` JSONB, meta `openingHoursSpecification`)
and every code-level grep was blind to the one the customer hears on the phone.

RULE: when auditing a fact that reaches customers through a third-party SaaS, enumerate the SaaS's own
configuration objects as a first-class surface, and treat any audio/image/blob the SaaS serves as a copy of
that fact. A "we fixed the hours everywhere" claim must name where the caller's copy lives and say whether
it was read or only inferred. If it can only be read by listening, say "UNREAD — must be heard", not "fine".

Cheap mitigation worth doing: keep the fact in a place a human can diff. Move the hours out of the audio
and into the spoken script text, where the API can read and write it.
