**L12191 · A removal already on main is still a mapping change: check what the read decided, not whether the name survives**

Kosher-filter worktree agent/kf-remove-agpl (A-P2-02 residual), 2026-10-22. The brief said the broker still serves nudenet at tier MID; it does not — commit 772cca8 (item 1061) removed it from server/app/model_manifest.py, the Android loaders, both platform model lists and the verify script, and that commit is an ancestor of the main this branch was cut from. Read it with `git log --oneline -3 -- server/app/model_manifest.py` and `manifest_payload()["models"]` (two entries: gantman-nsfw MIT, mediapipe-pose-lite Apache-2.0). So the remaining work was the three things 1061 did not do, and that is what this branch carries: (1) a required SPDX `licence` + `licence_note` per catalogue entry, with a test that refuses an empty/placeholder/copyleft value and any mutable ref (server/tests/test_model_catalogue_licence.py); (2) the read-by-read replacement table in docs/roadmap/items/A-P2-02.md (14 reads at 772cca8^, what each decided, what answers it now); (3) the mapping, as code: CascadeOrchestrator.FusedScoreDecision has no SAFE answer any more, because `fused < 0.2 -> SAFE` rested on three signals and one of them was the AGPL detector — the band now escalates, matching what ladder rung 1 already did with UNCERTAIN. Pinned by CascadeFusedPathDecisionTest (7 tests, includes a sweep asserting SAFE is not in the rule's range and a test proving CascadeWeights.nudenetWeight moves nothing). Two measured side-findings worth a follow-up, neither caused by the removal: ContentNotificationListener treats ESCALATE as "classified safe" (a fail-open at that site, unlike the share/a11y/MITM sites which all block it), and CascadeNsfwPrefilter.scoreJpeg returns null on every ladder household because classifyWithLadder never sets gantmanScore. Gates at merged revision: 19/19 doc checkers, 57 server tests, 171 Android ml+config tests, 0 failures. ONNX Runtime was removed from the APK — its only model was the detector and no Kotlin source imports ai.onnxruntime.
