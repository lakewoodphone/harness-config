**L6216 · L — Deploy from the host, not from git; and a deployed file's own defaults can be dead code**

**Two facts about `doh_filter.py` cost an hour on 2026-10-14, and both will recur on any deployed
file in this estate.**

**1. The repo copy is a hypothesis; the host copy is the fact.** The host file
`/opt/waze-mdm/dns/doh_filter.py` carried an Apple location-services allowlist that had never reached
git:

```
 "clientservices.googleapis.com,mtalk.google.com,"
 # Apple network-assisted location / geo services — required for iOS
 # CoreLocation WiFi/cell positioning and AGPS assistance (Waze fix 2026-08-14).
 "ls.apple.com,location.services.apple.com,gs-loc.apple.com,"
 "gsp1.apple.com,gsp10-ssl.apple.com,gsp53-ssl.apple.com"
```

Deploying the repo copy would have **silently blocked CoreLocation's network-assisted positioning** on
every managed device, with no error. This is the **fourth** drift on this one file
(`docs/lpt-shop-device-runbook.md` §3 records the others: `shop-store.mobileconfig` three times).
**Before deploying anything, `diff` the host copy against the repo copy and derive from the host.**

**2. A file's own default lists can be dead code.** `doh_filter.py` has
`DEFAULT_ALLOWED_DOMAINS` / `DEFAULT_BLOCKED_DOMAINS`, and `docker-compose.yml` passes
`ALLOWED_DOMAINS` / `BLOCKED_DOMAINS` from `/opt/waze-mdm/.env`, and the code prefers the
environment. **The live allow/block policy is in the host `.env`; editing the constants in the file
changes nothing.** Verified by reading the variables out of the running container, not by reading
the compose file. Anyone who "fixes" the allowlist in git and redeploys would change exactly nothing
and believe they had shipped a policy change.

Two smaller things from the same file: its line endings are **CRLF on the host and LF in git**, so
the shas can never match — compare with `diff <(tr -d '\r' < host_copy) repo_copy`; and a
`Settings`-style habit of "the API said ok" does not exist here, but "the file I deployed is the file
that is running" does — read it back **inside the container** with `sha256sum`.
