**L10371 · A blocker you have not tried to route around is a preference: nine keyed providers, none cheaper**

## 2026-10-20T00:13Z · ZABZ-YOGA · "it needs a key" is a claim, and claims get measured

I had been saying routing waits on a DeepInfra key. That is easy to believe and had not been checked: the estate
already has live keys for **nine** providers, and any one of them could have served the same weights cheaper.
If one had, the routing half would be live tonight with no owner action at all.

Checked, with the live keys, against the providers' own catalogs:

- **Together** - `GET /v1/models` returned **200 with 269 models**, including
 `deepseek-ai/DeepSeek-V4.1-Flash-1017` at **0.30 / 1.20**. That is the exact build DeepSeek serves, at
 exactly DeepSeek's **peak** price. A break-even pipe at peak and twice DeepSeek's off-peak input.
- Together's `DeepSeek-V4-Flash-0731` at 0.14/0.28 is cheaper but a **retired generation** - the equivalence
 rule refuses it, correctly, because cheaper-and-older is a capability change wearing a price tag.
- Google's `gemini-3.1-flash-lite` at 0.25/1.50 is **17 % cheaper than DeepSeek peak on input** and is a
 different model. Same refusal, same reason.

**Conclusion with evidence: among every provider this estate already holds a key for, not one is both
same-weights and cheaper.** DeepInfra at 0.112/0.336 flat remains the only such pipe, and it needs a key.

### Why this was worth 15 minutes

"It needs a credential" is the kind of claim that stops investigation. It is also falsifiable in one API call
per provider, and if it had been wrong the entire remaining plan changes - routing would be live tonight
instead of waiting on a person. **A blocker you have not tried to route around is a preference, not a blocker.**

### Side benefit: the pattern is corroborated

Together is a real provider, with a live key, a same-generation model id, and a flat price to compare against.
That is the same shape the DeepInfra lane uses. So when the key arrives, wiring it is a lower number in an
existing structure, not a new mechanism - which is what the last several rounds were spent building.
