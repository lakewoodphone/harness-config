**L12287 · Amazon, Walmart, Newegg and Dell data access was already paid for - and the keys were locked to Windows on every host**

The estate already paid for Amazon, Walmart, Newegg and Dell data access, and nobody knew.

Before buying any scraping or "unblocking" service, or signing up for Amazon PA-API or a Walmart partner
key, know this: the Firecrawl subscription the shop already pays for carries Alexandria providers with
typed records for those exact stores. Verified working 2026-10-22.

 walmart-com products/search, product (accepts an /ip/ URL), browse, reviews, store, suggest
 each record: name, current price with low/was, availability, seller name+id, item id,
 url, image url. ~5 credits a search page.
 amazon-com products/search, products/prices (5 ASINs per call), products/offer (buy-box, stock
 state, ZIP-aware delivery), product, photos, specifications, variants, reviews,
 bestsellers, suggestions
 newegg-com price, list price, shipping, in-stock, condition, seller, warranty
 dell-com specifications by model
 ebay-com listings/item, item_shipping, item_variations, suggest

It is reachable through MCP tools (firecrawl_scrape with an alexandria body on the v2 endpoint - v1
rejects the key outright with "Unrecognized key in body"), and now through the fetchkit CLI.

THE WIDER LESSON, which is the expensive one: the same four search keys (Firecrawl, Jina, Brave,
SerpAPI) were present in personal-secretary-mvp/.env on EVERY host - authority, ZABZ-TECH, ZABZ-YOGA -
and were still unusable off Windows, because the MCP servers that expose them are declared
`disabled: !!js process.platform !== 'win32'`. Bought, paid monthly, and locked to one platform with
nobody noticing, because no command ever asked each host what it could do. `fetchkit doctor` and
scripts/mesh/fetchkit-doctor-all.sh now ask that question, and the mesh check's own three bugs (a
whitespace-split host table, ssh eating the loop stdin so it stopped after two hosts, and nested
quoting through bash->ssh->PowerShell) are the reason to distrust a health check you have not watched
produce four rows.
