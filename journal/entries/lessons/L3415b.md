**L3415b · journal.py search is whole-phrase: search the rare token, never a sentence**

Measured 2026-10-09 while saving the oven reference: `journal.py search "oven beep Shabbos"` returned
"no match" even though three entries written minutes earlier contain all three words, while
`search "beep"` returned them and `search "JGB630"` returned exactly the three. So the search matches the
query as a phrase (plus some looser behavior), and a multi-word sentence will miss a record that exists.

Rule: before trusting a "no match", retry with the single rarest token (a model number, a part number, a
name). A compound query that fails is not evidence of absence. This is the same failure shape as the
stale-database crisis: a confident empty result read as "we never recorded that".
