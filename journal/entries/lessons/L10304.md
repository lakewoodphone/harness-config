**L10304 · A cost without a band is not an audit trail, and verification must not corrupt the record being verified**

## 2026-10-19T23:40Z · ZABZ-YOGA · a cost without a band is not an audit trail

`smart_router_decisions` had **80,414 rows** and could not answer the question it exists for: *which
provider, which model, which price, read when.* It stored `primary_cost_per_mtok` - the **output** rate -
with no hour band and no date on the price.

In a system where the same two providers answer **oppositely at 02:00Z and 20:00Z**, a decision row without
a band is not merely incomplete. It is a row that *looks* auditable, which is worse than one that obviously
is not, because nobody goes looking for what it is missing.

Fixed 23:33:08Z: three columns (`primary_cost_in_per_mtok`, `price_band`, `price_read_at`) added through the
guarded `ALTER` loop already in `_ensure_audit_table`, populated from the price book in
`log_routing_decision`, **left NULL/empty when the book declines** rather than guessed.

### Proven on a throwaway database, on purpose

Routing was quiet, so instead of waiting for a natural row I called the **real** `log_routing_decision`
against a temp sqlite file: `band offpeak`, `read_at 2026-10-19T21:38:00Z`, `in 0.15`.

The reason for the temp file is the point. Writing a synthetic decision into the production audit table
would have answered "does it work" **and** left a fake row inside the record someone later reads to ask why
a month cost what it did. **Verifying a thing must not corrupt the thing being verified** - and an audit
table is exactly where that matters most, because its whole value is that every row is real.

### And the honest limit

This change is deployed to production and is **not** in the checkout: the checkout's `log_routing_decision`
predates the W6 work and has none of `served_model`, `alerts_json` or `catalogue_listed`. Its table is 21
columns against production's 27+. Back-porting W6 is a separate job. So for this one function, the repo is
documentation and production is the source - the inverse of the usual rule, and written down so nobody
reconciles the wrong way round.
