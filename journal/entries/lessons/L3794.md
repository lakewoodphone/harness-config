**L3794 · A retailer price page is not a local-stock claim; a brand's OU symbol can differ by carton vs bottle**

Two verified ways to be wrong about a product that cost real time on 2026-10-13.

1. **A retailer's price page is not a local-stock claim — read the store id in the URL.** I told the owner
 that OWYN was "at ShopRite of Lakewood, aisle 8, shelf 6, 5.99". The URL was `/rsid/612/` — Somers
 Point, about 55 miles away — and **there has been no ShopRite in Lakewood since 21 April 2015** (that
 store closed; 1700 Madison Ave is now Gourmet Glatt North). The chain price and sale window were real;
 the location was fabricated by inference. Rule: a `/sm/planning/rsid/<N>/` or `/sm/pickup/rsid/<N>/`
 path is store-scoped, and before saying "near you" resolve what N is and confirm the branch still
 exists. Prefer the chain-level product page and state the uncertainty.

2. **A brand's kashrut symbol can differ by package format, not just by flavour.** OWYN's own FAQ:
 *"our bottles are certified OU-DE and our cartons are certified OU."* So OWYN chocolate 11.15 oz
 (Tetra carton) = **plain OU pareve**, and OWYN chocolate 12 oz (bottle) = **OU-DE**. Near-identical
 names, different symbols, and only one of the two formats matters if someone keeps cholov yisroel.
 Same class of trap as Orgain, where the plant-based shake is pareve but the dairy "Organic Nutrition
 Shake" is OU-D. **Check the format and the size, not just the flavour, and confirm on the carton.**

Method that worked, for reuse: the OU product search UI (oukosher.org/product-search) is a JS app whose
result table renders STALE rows after a search — it nearly made me report the previous query's products.
Do not scrape that table. Use the API behind it instead:
`https://productsearch-v2.oukosher.org/api/v1/product` (search) and
`https://productsearch-v2.oukosher.org/api/v1/product/<agencyUniqueId>` (one record, returns brandName,
productName, dpm = Pareve/Dairy/Dairy Equipment, symbol, company, certifiedSince). Filtering the UI by
dpm[de]=true / dpm[p]=true also returns the whole legal candidate set in one page.

Evidence: thelakewoodscoop.com, "IT'S OFFICIAL: ShopRite in Lakewood to Close its Doors Next Week",
2015-04-13; liveowyn.com/pages/frequently-asked-questions; OU API records OUV3-9PVB0AO (11.15 oz, Pareve,
OU) and OUD3-WKOLN89 (12 oz, Dairy Equipment, OU-DE); shoprite.com `/rsid/612/` page (2026-10-13).
