**L12299 · A cold load that shows the start screen with zero localStorage keys never asked the server - the only branch that produces that signature is navigator.webdriver in the library read**

## The cold-load signature, and what it proves

Measured in the worktree (libraries mocked at fetch only, nothing else stubbed):
webdriver=false -> calls ["/api/auth/session","/api/persistence"], driver postgres, 1 record,
buildResumeOptions kinds ["report"]. webdriver=true -> calls [], driver local-only, 0 records,
kinds []. So "no /api/persistence request + localStorage 0 keys + a fully drawn setup form" is
producible by exactly ONE branch: shouldUseLocalOnlyPersistence() (remote-persistence.ts:154-157,
taken at :508-510) -> buildLocalState() (:458-474) -> applySharedStateToUi (assessment.tsx:1209) ->
launchpad (:3153 vs :3180) with resumeOptions from nothing (:874).

CONSEQUENCE FOR DIAGNOSIS: when a cold-load chooser "never runs", measure navigator.webdriver in the
SAME browser that took the measurement BEFORE blaming the derivation. Every server read in
src/lib/assessment/* is gated on it (loadSharedAssessmentLibraryState :508,
readSharedAssessmentLibrarySnapshot :770), so an automated page can never ask the account.

## The fix that was allowed (commit 912a014, branch fix/cold-load-asks-the-server)

src/lib/assessment/* is off-limits, so the account's answer is asked in the component layer,
ONLY when the boot read produced no server answer: src/components/attempt/cold-load-attempts.ts.
One display-only GET, 401 = "no account", a mirror body = unanswerable, options from the same
buildResumeOptions. No adoption, no merge, no migration, no write, no revision. A page whose library
read answered is unchanged (and makes no second request) — asserted.
A finished report now shows above the setup form ("Your report is ready" / "Open my report — N
answered"); the click opens via openAccountRecordForReading, which deliberately does NOT
setCurrentSessionRecord/commit (that would orphan currentSessionId or mint a second row for one
attempt). Drafts keep today's path.

## Transferable

- A page that renders an EMPTY library from a read that never asked the server must say "checking",
 never "Start My Assessment". resolveColdLoadChooser is the single decision; the render reads it.
- One attempt reached the page twice (account record + a local copy after opening) -> dedupe by
 session.startedAt, not by record id.
- No existing test encoded this defect (the webdriver-isolation tests encode a deliberate e2e rule
 and were left alone), so the suite needed no edit: 112 files / 1318 tests.
