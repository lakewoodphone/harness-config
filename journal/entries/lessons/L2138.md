**L2138 · L2152 - run_once exceeding 600s is NOT a load problem: it timed out at load 1.4**

Correction to my own earlier attribution, measured 2026-09-20.

I recorded (P2130/P2137) that `run_once` exceeding its 600 s ceiling was a consequence of load - the
full test suite, write contention, a 9.8 GB database. Then I measured it on a quiet box:

 load average 1.42 - 1.91 (the suite was stopped, watchdog logging "ok")
 18:14:13 run starts
 18:24:46 run_once timed out after 600s â€” ABANDONING it (the thread keeps running)
 backoff 300s

**Exactly 600 s, and about 608 s of wall time between start and timeout. On an idle machine.**

So the ceiling is not being hit because the box is busy. **A `run_once` tick is intrinsically longer
than 600 s**, and it was reaching ~8 minutes when it *did* complete (17:38 -> 17:46). The load I caused
earlier made an already-too-long tick time out sooner, which is why the load story was so persuasive -
it fitted the evidence I had, and the evidence I had was taken under load.

**What this changes.** P2130 is not "fix the load so ticks fit in the budget". It is "a tick takes more
than ten minutes, which is longer than its own timeout, so ticks are abandoned rather than completed."
Either the tick gets faster, or the ceiling rises to match reality. I deliberately did NOT raise the
ceiling earlier, on the reasoning that it would hide an over-long tick - that reasoning holds, which
means the work is **making `run_once` faster**, and the first thing to do is measure which subsystem
inside it consumes the time.

**The measurement that would have caught this earlier:** compare the timeout rate at two different load
levels. One run on a quiet box was enough to falsify the load hypothesis, and I had a quiet box
available for the last hour.

**A related confirmation from the same window.** The latch fix (W2144/W2146) is doing its job: the
timeout fired, and there were **0 `previous run still active` skips** and the loop continued. Before the
fix this is exactly where the company would have gone permanently quiet.
