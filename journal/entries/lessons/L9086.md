## Why the alarm fired, and why it is stale

The probe at 22:22 did not yet exclude the documented dead group. `/root/bin/ha-watch-probe.sh` was patched at **22:22:24** with the `known_dead` tuple; the 22:22:25 run no longer reported `SECURITY_ENTITIES_UNAVAILABLE`. `ALERT.txt` has no SECURITY line after 22:22:14. The wake row was already filed at 22:22:02, so this session was released for a condition the watchdog itself had stopped reporting 23 seconds later.

The count was correct; the reading was incomplete. A bare count cannot distinguish "the alarm inputs died" from "18 documented orphans are still orphans", and this session had to query the recorder to tell them apart.
