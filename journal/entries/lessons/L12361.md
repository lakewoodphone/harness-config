**L12361 · A label with no ticket number means a device is untracked - say so out loud**

A label with no ticket number means a device is untracked, and that is the thing to say out loud.

Asked to print a label for "gartner 7326083687" — Canon Powershot ELPH 330HS, FUNC/SET button in the middle of the D-pad dead, 95 to replace. Measured before printing:

- Production (RDS `d5oq83veii4rlb`, the only store): **17 orders match canon|powershot|elph**, and NOT ONE is an ELPH 330HS. Newest order overall `WO2610250001` at 2026-10-25 17:10 UTC; no intake case or order created in the last 4 days except that one. So the camera physically in the shop had **no row anywhere**.
- The phone number, not the name, is the key. `7326083687` resolved on the first try to **customer 1396, "mrs gartenhaus"** (two CLOSED orders, WO2606020007 recorder jack, WO2605190009 cadence mic). His spoken "gartner" is not the record's spelling — third time this pattern has been measured, and a name search would have failed.
- Because there is no ticket, the label carries name + phone + device + fault + dropped date + money and **no work-order number**. That gap is the finding, not a formatting choice: the shop's own intake flow promotes every drop-off to an order (all recent intake cases are PROMOTED), so an unrowed device is a device that will not be billable and has no record at pickup.

House format reused from `_labelprinter/out/joe_fishman_secretary_740_20261014.json`, not invented: masthead, `!NAME` headline, phone, blank-line blocks, `!MONEY` headline, bare numbers with no dollar sign. Printed 31.0mm on the QL-820NWB (serial H3G354844) at 192.168.50.60 from `secratary-ts` via the newer renderer in `/home/zabz/code/lpt-ops` (the deployed `lpt-label` is a revision behind). Spooled image 11035 B, byte-identical to the dry run I looked at; printer `READY` + `29mm` before and after, so no media error. Tape itself is unproven from here — nobody has looked at the roll yet.

Rule worth keeping: when a customer names a device that is not in production, do not quietly print a ticketless tag and move on — print what was asked, then state that the device is untracked and offer to open the intake. A label that cannot be looked up is a label the secretary can only read, not act on.
