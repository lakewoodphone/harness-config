## `make_zabz_preset.py` DELETES hand-authored owner rules from the agent's own persona; running it is destructive

MEASURED AND CAUGHT 2026-09-28 (ZABZ-TECH). `scripts/make_zabz_preset.py` rewrites
`presets/zabz/agent.cordis.yml` WHOLESALE from `presets/cordis-bg/agent.cordis.yml` ("GENERATED
OUTPUT ... rewritten wholesale from this file", line 23). I ran it while making an unrelated edit
and the regeneration removed **33 lines**, including:

 - the persona rule "**8. Write money so it survives the renderer.**" (the dollar-sign/formatting rule)
 - the persona rule "**9. Do not make him think for you.**"
 - the five outbound-communication hard-stops added 2026-09-24 after the 300DDR questionnaire was
 sent without approval
 - "Ask him a question before you ask a counterparty"

Those rules exist in `presets/zabz/agent.cordis.yml` and in the LIVE installed
`~/.dsh/.agent-presets/zabz/agent.cordis.yml`, and they exist in **neither** the generator
(`scripts/make_zabz_preset.py`) nor `presets/cordis-bg/agent.cordis.yml`. So the generator's inline
persona is a STALE copy, and regeneration silently strips the newest and most expensive lessons the
owner ever taught -- from the file that defines how the agent behaves.

CAUGHT HOW: the diff was read before anything was committed (`git diff --stat` showed 18 insertions /
33 deletions when only a 2-line rename was intended). Undone with `git checkout --` and the rename
then applied by hand.

RULE: treat `presets/zabz/` as HAND-MAINTAINED until the generator is brought up to date. Do not run
`make_zabz_preset.py` without first diffing its output against the committed file and confirming
nothing is lost. `--check` correctly reports DRIFT for this file now, and that DRIFT IS EXPECTED --
it is not a to-do. Two sources of truth for a persona file is the actual defect; the fix is to
back-port the missing rules into the generator (or retire the generator), not to keep regenerating.

GENERALIZATION, and this is the third time in one session: **a "generated" file with hand edits in it
is a trap.** `git diff` before believing a generator, always.
