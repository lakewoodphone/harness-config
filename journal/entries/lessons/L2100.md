**L2100 · L2098 - a per-call unique temp filename turns every interrupted write into a permanent orphan**

Measured 2026-09-20 on the authority: **299 orphaned `agent_identities.json.<pid>.<tid>.<ns>.tmp`
files totalling 6.8 GB**, the oldest from 2026-06 and the newest from 2026-09, in `data/`.

The writer looked correct. `app/identity_store.py::_save` wrote a temp file and then
`temp_path.replace(path)` - the standard atomic-write pattern - and on the success path it was
already cleaning up. The leak was entirely on the **exceptional** path, and it was made permanent by
two things multiplying:

1. **The temp name was unique per call** (`f"{...}.{_os.getpid()}.{threading.get_ident()}."
 f"{_time.time_ns()}.tmp"`). So an interruption between `write_text` and `replace()` left an orphan
 with a name nothing would ever look for again. A *stable* name would have made the damage one
 file, reused and overwritten on the next attempt.
2. **The process was being SIGKILLed repeatedly.** systemd's default `TimeoutStopSec` is 90 s and the
 service needs minutes to shut down, so every restart cycle killed it mid-write. 299 files over
 three months is roughly that cadence.

Fix: a deterministic per-process temp name (`f"{path.name}.{os.getpid()}.tmp"`), and the whole
write+rename wrapped in `try/finally` so the temp is removed on every exit that is not a success.
Cost of a crash is now at most one bounded, self-healing file.

**The generalisable rule:** when you write a temp file, name it deterministically per process and
clean it in a `finally`. A unique name per call is only safe if nothing can ever interrupt you, and
nothing can promise that - least of all a process that a supervisor is allowed to kill.

Guarded by `tests/test_identity_store_no_temp_leak.py`, which asserts four things: success leaves no
temp, a *failed rename* leaves no temp (the case that was missing), a serialisation error leaves no
temp, and the temp name does not vary between calls. A test that only checks the happy path is
exactly why this leaked for three months.
