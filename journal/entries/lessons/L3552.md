**L3552 · git add -A swept another session's work into my commit (P13 again) - name every path**

`git add -A <dir>` swept another session's untracked files into my commit on 2026-10-08 (a case
file and several scripts written by a different session, including a customer case that had just
opened). Nothing was lost - they are now tracked - but they went in under my commit message with no
context, which is exactly what pain P13 warns about.

THE RULE, unchanged and now proven again: name every path explicitly. Never `-A`, never `.`, in a
repo that more than one session writes to. `git add <path> <path>` and check
`git status --porcelain` before committing.
