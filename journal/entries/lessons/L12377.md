**The lesson.** "Search the order" is the wrong first move for a spoken phone number in this shop.
An unlinked comms trail is a first-class record here: `ps_comms_search "<phone>"` finds the person
when `customers` and `orders` return nothing, and *comms present + zero linked rows* is the
signature of work performed off-book. Before concluding "no such customer", search comms and then
check the linkage columns — do not stop at the order table.

**Consequence, and it is owner money.** Nothing is owed *in the system* because there is no order
to owe against — that is not the same as zero dollars. Quoted on 2026-10-22: port $70, battery $40
(customer supplied the battery, so the battery line is not obviously chargeable). The bill has to be
created deliberately before any payment link can exist; `lpt-pay-notice` refuses to invent one and
`payments.prepareOweNotice` reads the balance from the order itself.

`dismiss` need `--apply`, and `send` needs the body sha256 plus the human's own words).
