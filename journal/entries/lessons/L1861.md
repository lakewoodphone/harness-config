**L1861 · The answer to today's Screen Time question was written in May, then deleted in July - search git for deleted docs before re-deriving anything**

Before re-deriving a fact about this system, run: git log --all --diff-filter=D --name-only --pretty=format:'COMMIT %H %ad' --date=short | grep -i '<subject>'. On 2026-09-17 that surfaced six May-2026 research outputs about blocking calls on a supervised Waze-only iPhone plus the 39 KB KIOSK_OPTIONS.md decision matrix - all deleted by commit 857837552 (2026-07-13) and 9f56c820f (2026-06-30), all recovered with git checkout <sha>^ -- <path> and now restored to the tree. What they already said, four months before we re-derived it: Screen Time Communication Limits cannot serve as a robust centrally managed control to block all calls; it requires a child Apple ID in a Family Sharing group; the iCloud-Contacts dependency; no Apple payload exposes the communication controls; and the decision 'do not weaken the customer profile by opening Screen Time until a data-only or voice-barred line exists'. The fleet then held three positions in twelve weeks (June: keep Screen Time shut; 2026-08-06: data-only carrier lines; 2026-09-17: open it for two practice devices) and the September work cited none of the earlier ones. A deletion is not a decision: if a doc is superseded, supersede it in place and say so.
