**L3508 · A moved authority leaves a shadow that still answers - and the split is invisible from the inside**

**WHAT.** When an authority box is replaced, the OLD box keeps answering. It has the same services, the
same jobs, the same database and a healthy `/health`; the only thing it lost is the public hostname.
Every consumer that still names it -- an ssh bridge, a cron line, a tool default, a persona sentence --
keeps working PERFECTLY and keeps returning a forked answer. Nothing errors. Nothing looks stale.

**EVIDENCE, 2026-10-11.** The company moved to `secratary-cloud` (Cloudflare CNAME
`api.abletelsolutions.com` -> tunnel `3e62916c`). The office `secratary` was still running
`secretary-api`, `dialpad-sms-ws`, `secretary-dashboard`, `phone-engine`, `phone-gate`, `mesh-broker`
and ~176 crontab lines -- including its own Dialpad harvest -- writing
`/home/zabz/personal-secretary-mvp/data/secretary.db`. That store was LIVE, not stale: newest SMS
fetched 19:51:31Z, 44 rows in 24 h, the same 38 distinct messages the authority held. Both boxes
answered `:8002`. The workstation `ps_*` bridge ran on the office box, so `ps_db_query` returned
135,455 SMS rows where the authority held 135,486, and the office's `dialpad-transcript` newest row was
17 h behind the authority's while its SMS was current -- a mixed picture that reads like health.
`ps_comms_health` reported "problems: []" and ingestion 0.3-0.4 h THE WHOLE TIME, off the wrong copy.

**THE TEST TO RUN, IN THIS ORDER.**
1. Resolve the public hostname to a TUNNEL ID via the Cloudflare API, not via DNS (a cached A record
 cannot tell you which connector owns it). `curl .../zones/<zone>/dns_records` and read the CNAME.
2. On BOTH boxes, `systemctl list-units --state=running` and `ss -lntp` -- "both answer :8002" is the
 signal.
3. Count rows in a live table on both and compare, e.g.
 `SELECT count(*) FROM dialpad_sms_cache` -- 135,455 vs 135,486 is the fork.
4. Ask the BRIDGE where it is: `ps_db_query` should be able to tell you the file it opened. If it
 cannot, that is the defect.

**RULE.** A moved authority is not "done" until the old box is stopped or explicitly frozen. Leaving it
running is not redundancy -- it is two companies, and the split is invisible from the inside.
