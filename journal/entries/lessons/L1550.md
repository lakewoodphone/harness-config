**L1550 · The whole stack kept running and said nothing: every fix must end with a number that moved**

Six defects in an Activation Lock endpoint, then five more across the system, and not one of them was visible by
reading the code. Every single one was a thing that kept running and said nothing:

- a dead endpoint that returned HTTP 200
- a health check that answered "ok" while the feature was gone
- a cron job that 401'd into a log file nobody reads, once a minute, for five days
- an alert list that grew to 152 unresolved rows until it stopped meaning anything
- a database password logged on every boot
- and a resolver I wrote to fix the alert noise that silently did nothing, because
 `resolved IN (0, FALSE)` is invalid on an INTEGER column and the exception was swallowed

That last one is the important one. I wrote a fix FOR silent failure and it failed silently. What caught it was
checking that a number moved: the resolved counts were identical before and after deploying, and every existing
`resolved_at` predated the change. A deployment that reports success with no measurable before/after is not evidence.

Rules earned:
1. Every fix ends with a reading, not a commit. Before/after, with a number that must move. "Deployed and healthy" is
 not a result.
2. A health check that cannot see a missing dependency is not a health check. If a feature needs config, the process
 must refuse to start without it - a warning is what got ignored for weeks.
3. A job whose success and whose failure look identical is worse than no job. `/fleet/sweep` says "nothing to do" when
 it works and "Invalid token" when it fails, and nobody reads the log, so both looked the same. Anything scheduled
 needs its failure to be visible somewhere a human looks.
4. An alert list that is never resolved stops being a signal. Raise AND resolve, or the list becomes history.
5. Read your own logs once in a while. Two of the five defects (the password, the 401 wall) were only visible there,
 and the 401 wall had been printing itself every minute for five days.
