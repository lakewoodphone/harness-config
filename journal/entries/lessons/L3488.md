**L3488 · The shop label printer prints from any machine, but ZABZ-YOGA was missing python-barcode and brother-ql**

WHAT I LEARNED 2026-10-08, printing the Heber callback label for the secretary.

MEASURED
- lpt-ops/lpt_ops/label_printer.py refused with: 'label printing needs: python-barcode,
 brother-ql'. PIL was already present (11.3.0). Fix: python -m pip install --user python-barcode
 brother-ql -> brother-ql 0.9.4, python-barcode 0.16.1 installed to the user site under C:\Python313.
- The printer was NOT a network problem: discovery resolved Brother QL-820NWB at 192.168.50.60 by
 mDNS (BRW4CD5775ED835.local), state READY, 29 mm roll, serial H3G354844, and the raster went out
 over tcp/9100 from this HP/Ryzen laptop on the home network. So the office printer is reachable
 from ZABZ-YOGA and no authority-side hop is needed.
- The authority is NOT the alternative: /home/zabz/personal-secretary-mvp/.venv/bin/python3 has PIL
 12.3.0 but neither barcode nor brother_ql, and there is no /home/zabz/bin/lpt-label.

THE RULE
To print a label: cd C:\Users\ezabz\Code\lpt-ops, then pipe lines to
 python -m lpt_ops.label_printer print --no-title - (add --dry-run --out x.png to preview)
--no-title suppresses the company masthead, which is what an INTERNAL label wants. did_print is
always False by construction on this model (it does not answer reads on 9100); the honest evidence is
instructions_sent true, and the tape. Do not report did_print false as a failure.

ALSO
The tape is narrow (29 mm, 306 px at 300 dpi). Long lines are size-fitted and then hard-truncated, so
ten short lines is the practical maximum; verify with --dry-run and read the PNG before spending tape.
