**L2057 · vehicle dashboard: the findings payload shape on disk is not the one in the brief**

Built app/api/vehicle_dashboard.py (PAGE_HTML) in personal-secretary-mvp 2026-09-18. The brief specified findings as {title, severity, metric, current, baseline:<number>, z, meaning, action}. app/services/vehicle_analytics.py (written concurrently by another agent) actually emits, from _finding() at line 1318: {severity, metric, kind, message, current, baseline:{mean,stdev,n}, z, sigma, n_recent, n_baseline, means, what_it_might_mean, ...}. So title=absent (use METRIC_LABELS[metric] or humanize(kind)), meaning=message, action=what_it_might_mean, baseline is an OBJECT whose .mean is the number, and sigma duplicates |z|. detect_anomalies() also returns summary (digest-equivalent), count, min_baseline_n, nothing_to_report, suppressed. baselines() returns {metrics:{name:{mean,stdev,n,min,max,median,p25,p75}}} - mean/stdev is exactly the +/-2 sigma band a chart wants. Lesson: when a brief and a concurrently-written service disagree about a payload, render BOTH shapes; the page must not assume the brief won. Evidence: two Node fixture suites, 22/22 and 18/18.
