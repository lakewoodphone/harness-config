**L3534 · Driving lpt-label: ssh to the authority, stdin JSON, and the printer status page is the only proof**

`lpt-label` prints to the shop's Brother QL-820NWB, and the way to drive it is **over ssh to
the authority** — not locally. Measured 2026-10-08.

The printer is at **192.168.50.60**, model QL-820NWB, serial H3G354844. Discovery differs by
host and that is normal, not a fault: from `secratary` it resolves through the **ARP table**
(mDNS does not resolve there), from ZABZ-YOGA over the home network mDNS works. Either way the
address is never trusted — the tool asks the device's own web interface for its model first.

**The laptop cannot print locally.** ZABZ-YOGA has pillow but not python-barcode or
brother-ql, so `python bin/lpt-label find` here fails at `_require()` with
"label printing needs: python-barcode, brother-ql" — even for a `--dry-run`, because
`render()` calls `_require()` which insists on all three. The install is on the authority at
`~/.local/bin/lpt-label` -> `/usr/local/bin/lpt-label`. Drive it as:

 echo '<json>' | ssh secratary-ts "lpt-label print - --dry-run --out /tmp/x.png"
 echo '<json>' | ssh secratary-ts "lpt-label print -"

Use the **stdin JSON path** (`print -`), not positional arguments: the command crosses
PowerShell -> ssh -> bash quoting, and JSON keys `title/heading/lines/no_title` survive it
intact. Names in this shop contain apostrophes.

**A dry run does not require a printer that can print — it does require one that can be
found.** `print_label()` calls `find()` before the `dry_run` early return, so a dry run still
fails if the printer is off. Useful: it means "dry run succeeded" already proves discovery.

**The only honest proof that tape came out** is the printer's own status page moving
READY -> PRINTING, read back with `lpt-label find`. `brother_ql`'s `did_print` is False by
construction on this model (it reads a status register over 9100 that this printer does not
answer), so it is not evidence of failure. After the job it returns to READY with the roll
still loaded. Do not claim a print from the tool's word alone.

**To omit the company masthead on an internal label, use `--no-title`** (added 2026-10-08,
commit ebdfbd1). Before that there was no way to ask: `render()` falls back to
"LAKEWOOD PHONE & TECH" when `Label.title` is empty and `main()` only assigns `args.title`
when it is truthy, so an empty `--title` silently produced the masthead.
