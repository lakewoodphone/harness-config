**L1574 · Never build a masking regex inline: I printed two live Stripe secret keys into the session transcript**

2026-09-15, ZABZ-TECH, in this seat. While enumerating which Stripe keys were in use, I piped grep through sed -E 's/^((sk|rk)_live_.*)(....)$/\\1...\\2/' intending to show only fingerprints. The groups were wrong: \\1 is the greedy whole match minus the last four characters and \\2 is the literal 'sk', so the command printed the full keys with '...sk' appended. Two live production secret keys went into the transcript - the one production uses and the one the secretary uses - exactly the class of secret the same session had spent two hours rotating out of repos.

WHAT MADE IT WORSE
- The transcript is not ephemeral. Sessions are archived as session.v3.jsonl.zstd under ~/.dsh/sessions and a scheduled task (PersonalSecretary-PushDSHSessions) ships them to the authority, so a secret printed in chat travels like a committed secret.
- It was avoidable twice: the value never needed to be printed at all (I only needed to know WHICH key was where, which a count or a last-4 comparison gives), and any masking is a thing to verify on one example before pointing it at the whole fleet.

RULES
1. Secret enumeration output is a COUNT or an explicit LAST-4 built by a helper that takes the value as an argument - never a regex written in the same breath as the command.
2. Before any command that prints a value derived from a secret, prove the mask on one line and look at the result. If the output would contain more than four characters of a secret, the command is wrong.
3. Assume anything printed in a session is stored, synced and durable. Treat a printed credential as disclosed - the same standard as a committed one - and expire it.
4. The remedy for a disclosed credential is EXPIRY, not redaction of history: that is why the two keys were expired the same evening rather than the log being edited.
Cost of the mistake: two live payment keys had to be rotated on the spot, at the owner's dashboard, outside the planned order.
