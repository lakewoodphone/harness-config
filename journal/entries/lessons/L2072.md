**L2072 · A fix applied on a machine that does not run the thing fixes nothing - the authority is the only copy that matters**

**L· 2026-09-19 · A fix applied on a machine that does not run the thing fixes nothing — and the authority is the only machine whose copy matters.**

**What happened.** On 2026-09-18 14:05 EDT the owner pulled up the HA/Shelly power-off and door-unlock logic on **ZABZ-TECH**. That session found a real defect in `check_persistent_unlock` — it decided whether the interior maglock can be held open by releasing the relay **while the owner's own re-lock automation was still enabled**, then reported the guard rail's behaviour as hardware fact ("momentary, 91 ms, cannot be held") — and fixed it. It reported the fix under the heading "The defect I fixed", named three files, and cited 51 passing tests.

**The fix never reached the machine that runs the automation.** Read on 2026-09-19: `app/services/shabbat_safety.py` on `secratary` has mtime `2026-09-15T19:56` and `check_persistent_unlock` still calls `set_interior_maglock(locked=False)` directly. The file is also **untracked** (`??`), so no `git push` from ZABZ-TECH could ever have carried it.

**The rule.** Before believing "X is fixed", resolve two things and say them out loud: **which host runs it** and **which path that host actually reads**. On this fleet the authority is `secratary`, its `personal-secretary-mvp` working tree is the live code, and the Shabbat service files are untracked there — so a fix in ZABZ-TECH's checkout, on a side branch, or in a commit is not a fix. A "fixed and tested" claim whose target is not the running host is a *proposal*, and reporting it as done is the confident-error failure this journal exists to catch.

**Corollary for handoffs.** Name the host in the CHANGED line ("changed on ZABZ-TECH, **not** on the authority"), because the next session reads CHANGED as done.

**Evidence.** 2026-09-18 final message of DSH session `9ecbfab8` (ZABZ-TECH) vs 2026-09-19 read of `~/personal-secretary-mvp/app/services/shabbat_safety.py` on `secratary` (`git status --porcelain` -> `??`; `grep -A6 'def check_persistent_unlock'` shows the unfixed body). ZABZ-TECH was unreachable from ZABZ-YOGA on `desktop-ts`, so the diff could not even be retrieved.
