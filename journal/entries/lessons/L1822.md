## A node name must be the name that resolves — `Self.HostName` is not it

Evidence, 2026-09-16 23:31Z, mesh stream S1 (`scripts/phone-gate.py`, `mesh_identity()`;
docs/mesh/71-mesh-program.md §2.1; docs/mesh/72-capacity-contract.md §2.1).

**What happened.** `GET /mesh/capacity` reported `node` from `tailscale status --json` →
`Self.HostName`, on the reasoning that it matched the ssh alias prefix and
`node-identity.json`'s `canonical_hostname`. Measured on this laptop: `Self.HostName` is
`zabz-yoga`, and the only tailnet name that resolves is `zabz-yoga-1.tail93e6e6.ts.net` —
`Resolve-DnsName zabz-yoga.tail93e6e6.ts.net` → "DNS name does not exist", `curl
https://zabz-yoga.tail93e6e6.ts.net/mesh/capacity` → curl error 6. Tailscale appends `-1` to the
*DNS* name only, and both names are for the same machine. So the route was publishing an identity
that nothing on the fleet could act on, for one of four nodes.

**The rule.** `node` is the **Tailscale DNS label** — `Self.DNSName` minus the tailnet domain —
because that is the name MagicDNS resolves and therefore the only name a broker or
`mesh-health.ps1` can place work on. `Self.HostName` is not merely different, it is unreliable:
the iPhone on this tailnet reports its HostName as `localhost`. And the ssh alias is a *route*, not
an identity — `zabz-tech-linux`'s aliases are `linux-pc`/`hp-linux`.

**What makes it stick.** The probe now enforces `node == fqdn.split(".")[0]` on every node, so the
next node whose two names disagree cannot ship quietly — a rule that lives only in prose gets
"fixed" back the first time someone finds it inconvenient.

**Consequence worth carrying forward.** Renaming the laptop's node from `zabz-yoga` to
`zabz-yoga-1` moves every consumer's mapping: the broker (S5) and `mesh-run` (S6) must resolve
`zabz-yoga-1` to the laptop's ssh route (`zabz-yoga-ts` → `zabz-yoga-1.tail93e6e6.ts.net`). A
settled interface rule is only settled once the tables downstream of it agree.

**Generalisation.** Two names for one thing is a latent outage. Where a field names an entity that
someone else must act on, the field must carry the name the *other* party can resolve, and the
checker must assert the invariant rather than the spelling.
