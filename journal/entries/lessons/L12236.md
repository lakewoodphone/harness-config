**L12236 · Live marketplace price sourcing: use the Newegg Alexandria provider, not page scrapes**

Live laptop sourcing (2026-10-21), what actually works:

1. Newegg price/stock: use the firecrawl Alexandria provider
 newegg-com / products/product with {item_number}. One compact record:
 current price, final_with_shipping, free_shipping, in_stock,
 stock_indicator, seller name + rating + review_count, condition flags,
 exact title. Never scrape the page for the number.
 products/search takes ONLY: condition, in_stock_only, page, query.
 Passing in_stock or limit returns invalid_option (cost me one round trip).

2. Return window is NOT in that provider. Scrape the same item page with
 formats=["json"] and a prompt for "seller return policy days and warranty".
 That returned "Return for refund within 30 days" plus "1 year" cleanly.

3. Back Market: the Fair/Good/Excellent price chips can point at a DIFFERENT
 seller SKU than the page you are on. On the 256GB 840 G9 page the chip read
 Fair 330 while that page's own storage picker priced 256GB at 455. Always
 trust the storage/memory picker on the same page, never the condition chip
 alone, or you will quote a price for someone else's listing.

4. Wisetek Market: product JSON said in_stock false for both ProBook 450 G9
 grades while the collection page said "Very low stock (1 unit)". Two
 sources disagreeing on stock means unavailable, not "probably fine".

5. The 280 dollar floor in a sourcing brief is real and it bites: the best
 value Newegg 840 G8 that day was 270.99, which is out on cost floor alone.
 Check the floor before falling in love with a price.
