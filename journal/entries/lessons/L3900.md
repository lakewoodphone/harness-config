**L3900 · The label body order is fixed in code, so the phone cannot be an --issue line under the name**

The label skill says to put the customer's phone number as an `--issue` line "directly under the name". The renderer cannot do that, and the reason is one line of code.

`lpt_ops/label_printer.py::work_order_label` builds the body in a fixed order:

```python
if customer: lines.append(customer)
if device: lines.append(device)
if dropped: lines.append(f"dropped {dropped}")
if issue: lines.append(issue)
```

So with `--customer`, `--device` and `--issue` all given, the order on the tape is name, device, then every issue line. The phone can never sit directly under the name — the device is always between them. And the work-order branch (`if args.ticket or args.customer or args.device`) **discards `lines` entirely**, so there is no mixing the two forms to fix it either.

**The route that works**, used on ticket 12763 (2026-10-20, Duestch Dell Latitude 5520): do **not** pass `--ticket`, and drive the whole body through the JSON stdin path with `heading` + `lines`.

```json
{"heading": "#12763",
 "lines": ["Duestch", "732-503-6369", "Latitude 5520", "ST 7TZLJL3",
 "WATER DAMAGE", "FULL BATH PLANNED", "50 MORE TO START"]}
```

`heading` is sized big by the same `_fit(..., start=64, floor=22)` that `#<ticket>` uses, so the ticket still reads as the heading, and `"#12763"` is byte-identical to what `work_order_label` would have produced. Everything after it is exactly the order given. Measured: 27.9 mm of tape, one size for the whole body, no wrapped orphan lines at 12-17 characters per line.

Two things worth keeping from the same run:
- **`--dry-run` prints the printer's own identity and the tape length before anything is sent** — `would print to 192.168.50.60 (Brother QL-820NWB, state READY, roll 29mm) - 27.9mm of tape` — and the PNG it leaves is the only way to see the wrap before spending tape. Looked at it; the print then used the same geometry.
- **The service tag belongs on the label when the board leaves the chassis.** "ST 7TZLJL3" is 10 characters and it is the only thing that pairs a bare board back to its laptop once it is on the bench. The four-item rule (ticket, name, phone, device+job) does not forbid it; it is the same fact as the device.
