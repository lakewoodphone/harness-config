**L3346 · Never tail /var/log/fleet-sweep.log on the MDM box: it is one 25 KB line**

WHAT: Never `tail` the fleet logs on the Hetzner MDM box. `/var/log/fleet-sweep.log` is appended
once a minute by `fleet-api-call.sh POST /fleet/sweep` with **no trailing newline**, so the whole
file is ONE line: `tail -5` returned ~25 KB of repeated JSON and cost a large slice of this
session's context; `tail -12 /var/log/fleet-profile-sweep.log` was the same shape (twenty
concatenated `{"detail":"Not Found"}`).

HOW TO APPLY: on that host, get the size or a count first (`wc -c`, `grep -c '"ok":true'`), and
read a bounded slice with `tail -c 400` or `cut`. Same rule as never reading a journal store end
to end: cap the read before you take it.

EVIDENCE: 2026-10-05, this session — the sweep/profile-sweep tails above; the useful fact
(`/fleet/sweep` checks 0 devices, the profile sweep 404s) came from three words of the output and
was buried in tens of KB.

SEE ALSO: the general rule for the journal (`never read the tree end to end`) and the
`chat-session-resources` spill rule in `personal-secretary-mvp/AGENTS.md`.
