**L3105 · The mesh fleet: four mechanics that cost real time, measured 2026-09-30**

## 2026-09-30 · The CFO audit fleet: four mechanics that cost real time, measured once each

### 1. The mesh provider requires the child's final message to begin with `MESH-HOST: <hostname>`, or a perfectly good run is reported as failed

Measured 2026-09-30. Eight remote children ran; seven were reported `completed` and one — WS6, the largest and
most useful report of the eight, which **did** write its 47 KB file to disk — was reported:

> `failed, error; diagnostic: the child did not begin its report with "MESH-HOST: <hostname>" — its location is
> unproven, so the run is not reported as complete`

The first probe child only passed because the probe prompt happened to ask it for its hostname first. **Every
remote brief must carry the instruction explicitly**, as its own numbered rule, or a good report is graded a
failure and the manager may discard it. The proof of location is the provider's, not a formality.

### 2. A mesh child on ZABZ-YOGA cannot reach the authority; the manager must ship the evidence to it

Measured 2026-09-30. From `ZABZ-YOGA`: `ssh secratary` resolves to the office LAN address `192.168.50.77` and
times out; `ssh secratary-ts` (tailnet) returns its output **and then hangs at session close**, which the harness
records as `[timed out after 120000ms]`. So a child that reads the authority pays ~2 minutes per read and still
gets an ambiguous result.

The working pattern, used here and worth reusing: **the manager extracts on the machine that has a fast path**
(`ZABZ-TECH` → LAN `secratary`, ~5 s per query), writes a self-contained bundle, and ships it to the fleet node.
Then children read at file-tool speed (`read` p50 0.76 ms) and never touch ssh. 4.7 MB of evidence made eight
children fully informed.

### 3. `scp` to a Windows mesh node fails with the sftp subsystem; `scp -O` works

Measured 2026-09-30. `scp -r <dir> laptop-ts:<path>` → `subsystem request failed on channel 0` /
`Connection closed`. The Windows OpenSSH server on ZABZ-YOGA has no sftp subsystem. `scp -O` (legacy protocol)
transfers the same bundle without error. Also: `ssh laptop-ts "Get-ChildItem ..."` works, so the node is
reachable — it is specifically the sftp subsystem that is missing.

### 4. A trivial child costs ~4 minutes of wall clock, so briefs must be sized for it

Measured 2026-09-30: a probe that ran five commands and wrote 200 words took **252 s** end to end, and the remote
turn cap is 1800 s. Independent children dispatch together, but each one's start-up (ssh + engine boot on the
target) is minutes, not seconds. A twelve-workstream brief would exceed the cap on the last one; eight fit.
