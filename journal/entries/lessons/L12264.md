**L12264 · Adding a test file to a repo with a docs gate costs four generated edits; and never strip Kotlin comments with one regex**

Two things a lane agent needs before it touches a repo with a docs gate.

1. A new file in a repo with generated documents costs FOUR edits nobody warns you about, and
 "docs/ is forbidden" is the wrong rule because the repo's own gate makes the generated material
 part of the change. Measured on the Kosher filter repo at a1664d2e: adding two unit-test files
 under android/app/src/test made `python scripts/docs_check.py` exit 1 with
 `FACT-STALE scripts/facts/android-test-files.py declared '156', compute() says '158'` (a
 HAND-WRITTEN number: --write does not fix it, you edit VALUE yourself) plus GEN-STALE for
 docs/FACTS.md. And a changed SOURCE file alone moves docs/REACHABILITY-CLIENTS.md: proved by
 deleting the new test files in a scratch copy and still getting GEN-STALE, 88089 -> 88070 bytes.
 The whole fix is: set VALUE from the script's own output, then one `docs_check.py --write`
 (which rewrote FACTS.md, REACHABILITY-CLIENTS.md, INDEX.md, audits/dead-citations-*.md), then
 re-run and paste the exit-0 line. Verify a claim like "my tests broke the docs" by running the
 gate on the BASE COMMIT extracted with `git archive` - it was green, so the regression was mine.

2. Stripping comments from source to assert "this call is gone" with a whole-file block-comment
 regex is unsound: `/*` inside a STRING LITERAL pairs with the next real `*/` and swallows
 hundreds of lines, so an absence assertion passes for the wrong reason and a presence assertion
 fails on a file that contains the text. Measured on PolicyApplier.kt, which holds Chrome
 blocklist patterns like "example.com/*": the regex version reported
 `BatteryExemption.apply(context)` missing from the file that contains it. Filter LINE-WISE
 instead (drop lines whose trimStart begins with /*, * or //, then substringBefore("//")), and
 never write a KDoc that contains a literal star-slash - it closes the doc and the compiler says
 "Unclosed comment" three lines later.

Reference: code that will be looked for later - ResetProtectionAnchorStore.armForSeal in the Kosher
filter repo, lane frp. Nothing here is a request for owner attention.
