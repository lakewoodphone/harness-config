## The docs system, in reading order (this is the thing that changed)
`START-HERE.md` (one screen) -> `docs/MAP.md` (29 questions, each with a REQUIRED PHRASE the answer document must
contain, machine-checked) -> `docs/STATUS.md` (what is true, dated) -> `docs/COMPLETENESS.md` (what is unfinished, with
a finish line and the line of code that says so). Then `docs/FACTS.md`, `docs/INDEX.md`, `docs/decisions/REGISTER.md`,
`docs/testing-matrix.md`, `docs/ACCEPTANCE.md` - all generated, never hand-edited.

The gate is `python scripts/docs_check.py` (17 checkers, ~100 s, `--selftest` proves each failure fires, `--write`
regenerates). There is no `make` on these hosts. Measured on main f66fddb on ZABZ-TECH 2026-10-20 with
`C:\Python313\python.exe`: **17 of 17, exit 0**.

Two decisions own the whole design: `docs/decisions/D-20261019-01-single-documentation-structure.md` (one tree under
docs/, one ID scheme ADR-NN + D-YYYYMMDD-NN + D0-D6, one generated register, six statuses, pointer docs < 20 lines) and
`D-20261019-02-facts-and-drift-detection.md` (a number stated in two places is a fact with one file in `scripts/facts/`;
`command` facts recompute, `recorded` facts need EVIDENCE+MEASURED; a dated record declares `facts-as-of:`). The reason
both exist: the repository was publishing three different "tests passed" totals and five different route counts at once,
each in a document that looked authoritative, with every link resolving.

## Two drifts that survive the green gate (found 2026-10-20, not yet fixed)
1. `docs/IMPLEMENTED-VS-DESIGNED.md:25-26` (status: live, updated 2026-10-21) still says "250 test files; 1667 passed,
 17 skipped ... on 2026-10-19" while `docs/testing-matrix.md` says 1729 passed of 1746 over 263 files, 2026-10-21.
 It is unchecked because `MATRIX-ELSEWHERE` in `scripts/check_testing_matrix.py` scans only documents whose
 front-matter is `status: generated`, plus `docs/STATUS.md` (lines 194-215). A LIVE document restating a suite result
 is invisible. The fix that matches the repo's own rule is to point at the matrix, not to restate.
2. `CONTRIBUTING.md:120` still teaches the abolished model: "`docs/README.md` | Canonical documentation index ... Update
 when: any product or engineering decision". `docs/README.md` is now a 15-line `pointer` to `docs/MAP.md` that says so
 in its own text. Nothing checks prose in CONTRIBUTING.

Generalisable: that gate proves *links, structure and registered numbers*. It does not prove a live document's prose.
Do not read "17 of 17" as "the docs are true".
