**L1697 · Dialpad: the internal web API (dialpad.com/api/*) answers what the public v2 API 403s - /licenses, /company/{id}, /changelog are the three that matter**

Internal Dialpad web API gives the account map that the public v2 API refuses.

WHY IT MATTERS: the public API 403s the company-scope paid endpoints (company/billing, /plan, /seats, /integrations return 'This API is for internal use only.'; /porting needs a 'customer_support' scope we lack). So plan/seats/billing and the whole settings tree looked unreadable. They are not.

WHAT WORKS (read-only GET, using the captured UI headers in dialpad_ui_xhr via scripts/dialpad_ivr_admin.py:_load_captured_headers / _request; the 2026-09-01 capture still authenticated on 2026-09-16):
 GET https://dialpad.com/api/licenses?company_id=5272393147203584 <- THE PLAN OBJECT. seat counts (licenses_total / licenses_in_use / line_availability), full rate card, next_charge, next_billing_date, under_contract, payment_method, calling credits, A2P state.
 GET https://dialpad.com/api/company/5272393147203584 <- 49 keys: a2p_registration, settings{}, offices[] with full office_settings, account_executive, experiments[]
 GET https://dialpad.com/api/group/{office_key} <- 105 keys: routing_options, hours, ivr_menu_script, recording, callai_settings, voicemail, parking, caller_id, spam, failover_phone
 GET https://dialpad.com/api/changelog?limit=50 <- NOT a product changelog. It is the ADMIN AUDIT LOG: 50 events with before->after details AND actor. This is the discovery tool for any Dialpad change question.
 GET https://dialpad.com/api/porting?company_id=... <- port records
 GET https://dialpad.com/api/recurringevent?target_key=Office%3A{office_id} <- holidays
 GET https://dialpad.com/api/scriptedivr?company_id=... <- IVR workflows
 GET https://dialpad.com/api/user/{user_id} <- 103-key user profile incl. personal working hours, DND, PINs, forwarding

WHAT DOES NOT EXIST (404, do not waste a sweep): every /company/{id}/<subpath> form (integrations, plan, seats, webhooks, api_keys, oauth, e911, spam, parking, ...), every /group/{key}/<subpath> form, and all of /settings, /routing, /ai, /callai, /notification, /blocker. /admin/settings|nav|sections return 500.
