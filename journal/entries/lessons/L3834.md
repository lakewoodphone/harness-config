## Method notes worth reusing

- The `dns-filter` log line format is `172.18.0.11 - - [dd/Mon/yyyy HH:MM:SS] <verdict> <name>` → the verdict is **field 6**, the name **field 7** (`awk '{print $6, $7}'`); field 3 is a dash and gives you nothing.
- DoH wire-format probes run by an agent appear in that same log as `400`s, so filter counts are device traffic *plus* your own probes. Exclude them before quoting a rate.
