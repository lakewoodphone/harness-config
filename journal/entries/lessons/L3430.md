**L3430 · One ssh per HOST, not per session: a framed batch read, and never re-inventory to resolve an id you have seen**

MEASURED 2026-10-09 on ZABZ-YOGA while making session reading reliable.

1. ONE SSH PER SESSION IS A CONNECTION STORM. With 16 concurrent `ssh host node`
 calls to one host, 103 of 107 session reads FAILED with
 `connect to host secratary.tail93e6e6.ts.net port 22: Connection timed out`.
 The same read, batched into ONE ssh per host, returned 107 of 107 in 46 s. The
 batch is a length-delimited stream: `@@SEG <i> <len> <size> <err>\n` then
 exactly `len` raw bytes. Use an explicit byte count, never a magic marker --
 compressed data contains arbitrary bytes and a marker will eventually match by
 accident.

2. ssh ACROSS TAILSCALE IS NOT CHEAP AND IS NOT STABLE. `ssh secratary-ts hostname`
 measured 1,441 / 9,224 / 11,038 ms on three consecutive attempts; `node -e 0`
 over the same link adds 1,300-2,100 ms; `ssh zabz-tech-ts hostname` 2,084 ms.
 Design consequences: (a) cache the fleet inventory in
 $DSH_HOME/session-index.json, 5-minute TTL for listings; (b) a 6-HOUR TTL for
 id->file resolution, because a mapping is stable and a miss forces a refresh --
 but `latest` always takes the short TTL; (c) classify errors: a connection
 timeout is TRANSIENT (retry, do NOT memoize), a real exit-code failure is
 deterministic (memoize, or one bad host costs one round-trip per file).

3. A WINDOWS NODE'S SSH SHELL IS POWERSHELL. `ssh zabz-tech-ts head -c 4096 <path>`
 answers "The term 'head' is not recognized as a name of a cmdlet" -- there is no
 `cat`, `head` or `grep` there. It also fails 113 of 200 candidates before you
 notice. So do remote work as a NODE PROGRAM SENT OVER STDIN: node is the one
 interpreter guaranteed on every node (DSH runs on all of them), stdin removes
 every shell-quoting problem (the remote path becomes a JSON string literal
 inside the program), and node writes raw bytes.

4. NEVER PIPE A SESSION FILE THROUGH A SHELL. PowerShell decodes a native command's
 stdout to text and can mangle binary. The fetch lives inside node's spawn with
 raw Buffer capture. This is a silent-corruption class, not a performance one.

5. A SEARCH FOR THE TOPIC YOU ARE DISCUSSING RETURNS YOURSELF. The current session
 is the newest and contains every word he said. Exclude $DSH_SESSION_ID by
 default and SAY that you did.

TOOL: scripts/sessions.mjs (fetchBatch + remoteNode + gather TTLs).
