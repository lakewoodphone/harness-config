**L1883 · An unref'd timer in a wait loop lets Node exit mid-wait**

An `unref()`d timer in a wait loop lets Node exit out of the middle of the wait. MEASURED 2026-09-17 in packages/plugin-remote-fanout/lib/placement.js (the queue wait): the child was placed at position 1, the provider logged "is QUEUED at position 1 ... it has not started", and the process then died with "Warning: Detected unsettled top-level await" at the `await Promise.all(...)` - because the only pending handle was an unref'd sleep timer. In an engine that would be a queue that waits forever with no error at all. Fixed: the sleep timer is no longer unref'd, and the comment in placement.js carries this measurement. General rule: unref a timer only when something else is certain to hold the loop open; a wait that is the last thing the process is doing must not unref.
