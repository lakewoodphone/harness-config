**L12389 · A documented mechanism can be dead on arrival: the customer-data sweep had never run once**

A script that is documented as the mechanism can be dead on arrival, and the documentation will not tell you.

`harness-config/scripts/windows/sweep-transfer-staging.ps1` is named in `docs/shop/customer-data-retention.md`
as the thing that finds and deletes customer staging folders past 30 days. On 2026-10-27 I ran it for the first
time and it exited 1 immediately:

 A parameter cannot be found that matches parameter name 'Length'.

The line was `($files | Measure-Object -Length -Sum).Sum`. `Length` is not a parameter NAME - it only binds
positionally as `-Property Length`. Writing `-Length` makes PowerShell look for a parameter called Length and
fail. So the sweep had never once produced a report, and no note anywhere recorded that. The policy document
and the script header both read as though it worked, because they were written by the session that wrote the
script, not by one that ran it.

THE RULE: before you build on an existing mechanism, or cite it as the thing that does the job, RUN IT and read
its exit code. A docstring is a claim; an exit code is evidence. This is the same defect class as a documented
script whose path does not exist (AGENTS.md §11, `build-flows-index.py`).

TWO MORE DEFECTS FOUND IN THE SAME TEN MINUTES, both created by me while fixing the first:

1. AGE FROM MONEY-FREE MTIME IS A LIE FOR A MOVED FOLDER. A customer-data folder moved with Move-Item keeps the
 phone's own file dates (2026-10-06 on the Shande job), so "newest write under the folder" - the correct rule
 for a staging folder written by a tool just now - would have called six-day-old data a month old and swept a
 live customer's library. Fixed by dating from a `_landed-on.txt` marker's first line, and by treating a
 folder with no marker as UNREAD rather than expired.
2. A `-Json` MODE MUST EMIT JSON AND NOTHING ELSE. My rewrite appended "nothing to delete." to stdout after the
 JSON, which broke `ConvertFrom-Json` at the caller. Human-facing lines are now suppressed when -Json is set.
 Same shape as any tool whose machine mode is polluted by progress text.

AND THE GENERAL ONE: an undated folder is not an expired folder. Everywhere in this estate, "we could not date
it" must surface as an item to look at, never silently fold into "past the window" or into "nothing due".
