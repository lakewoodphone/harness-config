**L10110 · A price correction is not a model decision, and a kill switch only guards the path that reads it**

## Found 2026-10-19T23:20Z (ZABZ-YOGA) while making provider routing hour-aware

### 1. A price correction is not a model decision

Enabling hour-aware candidate repricing broke a specification that was already in the repo:
`test_direct_deepseek_candidates_visible_when_flag_on`. With only DeepSeek available, a general
non-owner task stopped choosing `deepseek-v4-flash` and started choosing the **older
`deepseek-v3.2`**.

The book was right and the old table was wrong: `v4-flash` carried a stale output price of 0.28,
whereas its true off-peak output price is 0.60. Correcting the number made the better model look
twice as dear, and the cost-weighted score demoted it.

So: **fixing what a call cost and deciding which model answers it are two different changes.** They
must ship separately, and the second needs a quality floor that keeps a same-generation model ahead
of an older one regardless of price. Anything else is the company quietly getting worse at its job
while the invoice gets smaller — which is not a saving.

Rule: repricing that can reorder candidates is opt-in, off by default, and named as such
(`ROUTING_HOUR_AWARE_COSTS`).

### 2. A kill switch only guards the path that reads it

`_yield_to_cheaper_same_model` originally honoured `ROUTING_MODE` by calling
`keep_direct_preference()`. But it then called `compare()`, which answers a pure price question and
knows nothing about mode. Result: with `ROUTING_MODE=fixed` the yield still reordered candidates. A
test caught it, not review.

Rule: a kill switch must be read in the function that *acts*, not only in the function it calls. If a
helper decides "is it cheaper", it cannot also decide "are we allowed to care".

### 3. "Same model" has to be declared, not inferred

A cheaper model is not a cheaper pipe. `qwen` is cheaper than DeepSeek and swapping to it is a
capability change, not a cost optimisation. So the price book now carries an `equivalents` list —
groups of (provider, model) serving the same weights, each with a `declared_at` and its evidence — and
**validation refuses the book if any listed member cannot be priced**, because a stale equivalence
claim would silently compare two different models.

The test that matters: `same_model_alternatives("deepseek", "deepseek-v4-pro")` must return nothing,
and does.

### 4. Check a revoked credential by calling it, not by looking for the name

`OPENROUTER_API_KEY` exists in `/opt/company/.env` with a **zero-length value**; `DEEPINFRA_API_KEY`
and `FIREWORKS_API_KEY` hold revoked strings. `provider_api_keys()` counts a *present* key as an
available provider, and `provider_health` is circuit-breaker based, so a revoked key looks available
until it fails. Presence of a name is not presence of a key: check `len`, and then make one real call.
