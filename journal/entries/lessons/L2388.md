**L2388 · A worktree is only isolated if its actual branch matches the brief - verify before dispatch, and print worktree->branch first**

**Rule:** a worktree is only isolated if its ACTUAL checked-out branch matches the brief. Never re-dispatch into a worktree without reading `git branch --show-current` in it first, and never assume a sibling agent has finished because a job looked settled.

**Measured 2026-09-22, twice in one session.**
1. I dispatched the staff-console fix agent into `_fleet/waze-custui` telling it the branch was `waze/staff-fix`. It was actually on `waze/customer-completeness` and **the customer-portal agent was still running in it** - the child measured writes at 10:30:29 and 10:33:13, `WazeDevice.tsx` written at 10:32:24, and a Vitest process spawned at 10:33:52, plus a fresh agent runner at 10:33:57, and the sibling modified a file again *while the child was writing its reply*. The child correctly REFUSED: it did not `checkout -b` (which would have moved HEAD out from under the live run and captured the sibling's next commit on the wrong branch), changed **zero files**, ran **no tests** (deliberately, to avoid fighting the sibling's Vitest fleet for the same `pool: 'forks'` workers), and reported the evidence. That refusal is the behaviour to want.
2. Auditing every worktree showed the drift was systemic, not a one-off: `_fleet/waze-audit` was on `waze/billing-fix` (not the `waze/ux-audit` its name implies). A directory name and a branch name that can disagree WILL disagree.

**What to do instead:** when allocating a fleet, print `worktree -> branch -> dirty` for every target FIRST; create a fresh worktree per agent where the branch is fixed at creation; and put the verification step in the child's brief ("confirm `git branch --show-current` says X before you start; if it does not, stop and report"). Two of my last three allocation errors were this, and the cost is a wasted dispatch each time.

**Also worth knowing:** a "completed" job notification and a worktree being free are different facts. The sibling's process was still writing after I believed it had finished.
