**L3382 · Three measurement traps: parent-relative width, what max-file-lines counts, and Select-String on a minified bundle**

**A "filled, full-width control" count is the way to prove a UI ambiguity is closed — and it needs a parent-relative width, not a viewport one.**

Measuring the sale screen, `width >= 0.7 * viewport` reported 0 "final-looking" controls at 1440x900 while the defect was plainly on screen: the intake panel is a full-viewport overlay with a ~768px centred column, and at `lg` the form is a two-column grid, so a button that ends a sale is 360px wide inside a 1440px page. The honest test is `width >= 0.9 * parentElement.clientWidth` — "fills its own container" — which separated the money control (1.0) from a method button (0.33) and from half of the yes/no toggle (0.5) at every width. Measured 2026-10-08 on `lpt-staff-kiosk`: sale mode 2 brand-navy container-filling controls before, 1 after; repair mode 1 throughout.

**A rule that counts lines counts CODE lines, not comment lines — so trimming comments cannot bring a file under the ceiling.**

`backend/eslint-rules/max-file-lines.cjs` counts `sourceCode.lines` unless `skipBlankLines`/`skipComments` are set; the frontend config sets them, so the number is non-blank non-comment. Deliberately deleting 13 comment lines from `StaffIntakePage.tsx` moved 507 -> 507, which reads like the edit did not save. The only thing that moves it is removing CODE lines: a 3-line signature back to 1, an `if` wrapper folded into two existing lines, a 4-line arrow back to 1. Check what the rule counts before rewriting prose to satisfy it. Evidence: 2026-10-08, `pnpm -C frontend exec eslint src/features/staff-intake/...` repeated three times with the same 507.

**A browser bundle is one enormous line: `Select-String` can report zero matches for a string that is present.**

Grepping a 3.8MB minified bundle with `Select-String -SimpleMatch -AllMatches` returned `0` for `Create case`, `staff-sale-offline-record` and a sentence I had just written, while the in-process `grep` tool found them in the same bytes and SHA256 proved the downloaded artifact identical to the local build. A zero from that tool on a minified bundle is not evidence of absence; hash the file against the build you made, or grep with the in-process tool. Measured 2026-10-08, `index-BregBewy.js`.
