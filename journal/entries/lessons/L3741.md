comms and to "figure out what this is". This entry corrects a material reading in L3737.

## The method that matters: Dialpad's own transcript can invert the meaning

`dialpad_call_full.transcription_text` is Dialpad's ASR **plus its AI pipeline**, and where its AI features
failed it writes **placeholder tokens into the transcript as if they were speech**:
`whole_call_summary_fragment`, `action_item_v2`, `ai_csat_reboot_ineligible`, `call_purpose_category`,
`negative_sentiment`, `ner`, `action_item`, `call_purpose`. Speaker labels in it are not trustworthy either.
Reasoning off that text is how L3737 came to say the customer's phone back was "very custom".

**The fix, run and verified 2026-10-13.** On the authority:

```
cd /opt/company && SECRETARY_DB=/root/authority.db .venv/bin/python \
 scripts/dialpad-call-ops.py --log-level INFO transcribe \
 --phone 5163051457 --days 365 --limit 20 --all-downloaded --force
-> {"considered": 3, "transcribed": 2, "skipped_existing": 0,
 "skipped_quality": 0, "skipped_already_paid": 1, "failed": 0}
```

Writes `dialpad_call_retranscript` with `model='whisper-1'` plus a `deepseek-v4-flash` cleaned copy.
Cost is whisper-1 at 0.006 USD per audio-minute; these two clips are about 2 minutes total.

**Two traps, both hit for real.**

1. **A paid guard.** A second run with `--model gpt-4o-transcribe` returned
 `{"transcribed": 0, "skipped_already_paid": 3}` — the same media is never transcribed twice, so this
 path cannot give a free second ASR opinion. And `scripts/dialpad-transcript-gap.py`, the cron
 gap-filler, selects on **no `transcription_text` at all**, so it will never touch a call that already
 carries Dialpad's text — **a polluted transcript is invisible to the gap tool by design.**
2. **Status vocabulary is `success`/`failed`, not `ok`.** Filtering `status='ok'` returns 0 rows and looks
 like a total failure. Truth measured today: **1,247 `success` / 1,194 `failed`** out of 2,441 rows.

## What the clean transcripts changed — two mishearings that invert the job

| when | Dialpad heard | Whisper hears |
|---|---|---|
| 2026-10-09 voicemail, call `6488124380454912` | back of it was very **custom** things | back of it was very **scuffed** and things |
| 2026-08-20 call, call `6661639067607040` | call you if you order the new **box** | if you ordered the new **backs** |

Together they say: he **bought a black Kyocera from the shop whose back cover is scuffed**; the shop was
**ordering new backs** and told him to call when they came in; he wants his. That is a different job from
"a custom back", which is what L3737 recorded. **L3737's reading is superseded on this point.**
