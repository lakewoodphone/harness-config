**L12288 · QUEUE EMPTY means nothing is due, not nothing is open**

The owner queue's `card` command prints "QUEUE EMPTY" when nothing is DUE, not when nothing is OPEN.

Measured 2026-10-21: `card` said "QUEUE EMPTY — nothing is waiting on you", with footnotes for 3
quieter attention rows, 1 decision being briefed and 1 held row. `queue --all` on the same database
returned 24 pending rows, including #896 a critical voicemail, #890 a blocking DNS change, and two
security rows (#883 leaked GitHub token, #850 SerpAPI key). They were invisible because each carried
a future `deferred_until`: the card's working set is "due now", and a deferral is a decision made on
a previous night, silently honoured forever.

So the two sentences that must never be the same one: "nothing is waiting on you" and "nothing is
due right now". Before telling him the queue is empty, read `queue --all` and count the pending rows
with future deferrals; if any of them is security, money or a live credential, say so in the same
breath as "empty".
