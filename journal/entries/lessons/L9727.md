**L9727 · solved=True is a load-bearing assertion: ten answers were non-answers and it silenced the asker**

`solved=True` is a load-bearing assertion — ask what WRITES it before you trust anything downstream of it. Here it was written by "any answered ask exists", so "I don't know" counted as an answer.

`merchant_resolve.resolve()` returned `solved=True, confidence=0.92` for three different merchants because a reply had been recorded against their asks. The replies were "I don't know. I want you to figure this out and give me more details", "Didn't we file a few days ago? What are you talking about?", and — for a merchant called `photo` — his answer about Dave & Buster's, a different merchant entirely.

The cost is not a wrong label. **`solved=True` means DO NOT ASK**, so the charge was never categorised and the question returned weeks later — which is the "Didn't we file a few days ago?" loop he complains about.

THE RULE. When a function's boolean is consumed by something that then decides to stay silent, that boolean is a claim about the world and must be earned: a specific quote, a specific source, a confidence the rung can defend. Two sibling findings from the same pass:
- **Four category names the code emitted did not exist** in the table it filed into (`categories`, 137 rows). `category_id_for()` returns "" for an unknown name, so the rung reported success and filed nothing. Check the vocabulary against the real table; a green test proves the string, not the name.
- **A vendor entry at 0.93 was overwriting the ledger's own `auto_rule` at 0.99.** Our own AI bill was being filed as scientific supplies on every charge after 2026-10-11. Read what the writer beats before adding a rule above it.

Measurement note: `sms_log` also records one send TWICE — `_audited_send` writes an audit row and three call sites wrote a second for the same `twilio_sid` at the same second, forcing `status=sent/failed` so a relay SUPPRESSION appeared as a FAILURE (60 rows). **A per-row count of that table is not a count of texts the owner received.** Dedupe on the sid before quoting any volume.
