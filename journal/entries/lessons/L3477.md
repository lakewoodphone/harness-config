**L3477 · A rejected journalctl window reads as a true zero - I nearly reported the Shabbat watchdog as dead**

**Lesson, measured 2026-10-09 (round 7).** I nearly reported the Shabbat watchdog
as dead. It was firing every minute; my measurement was the broken thing.

## What happened

I ran:

```bash
journalctl -u secretary-api.service --since "-6 min" --no-pager | grep -cE '...Running job...'
```

It printed **0**, and "the watchdog has stopped" was the obvious reading. I very
nearly wrote that up as a finding.

`journalctl --since` does not accept a leading-minus relative time. The argument
is rejected, the command writes nothing to stdout, and `grep -c` on an empty
stream reports **0**. A rejected query is indistinguishable from a true zero.

The correct form is `--since "6 min ago"`, which showed 14 executions in 20
minutes with the newest one a minute old, all succeeding.

## The rule

**A count of 0 from a command you have not seen produce a non-zero is not
evidence of absence — it is evidence that a command ran.** Before treating a zero
as a reading, make the same command produce a non-zero: widen the window, drop the
filter, or check the command's own exit status and stderr. An empty result is a
refusal, not health, and that cuts BOTH ways: it is not evidence of health, and it
is not evidence of failure either.

Concretely, for any `--since`/`--until`: use `"N min ago"`, never `"-N min"`, and
confirm the window is real by printing the newest line it returns.

## Why this one is worth writing down

It is the fourth variant of the same error in one session — a stale deploy script,
a stale staged file, a wrong journal id, a `git stash` that did not cover the
change, and now a filter that silently matched an empty stream. Every one is the
same fault: **I reconstructed a value instead of reading it, and the failure mode
was silence rather than an error.**

The distinction that keeps getting past me is between a command that FAILED and a
command that RETURNED NOTHING. Both print nothing. Only one of them is a
measurement. Check which one you have:

```bash
out=$(journalctl ... --since "6 min ago" 2>/dev/null | grep -cE 'pattern')
echo "window produced $(journalctl ... --since '6 min ago' | wc -l) total lines"
```

If the total-line count is also 0, the window is empty for a reason — find out
whether that reason is your argument or the system.
