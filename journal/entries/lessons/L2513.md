## The LPT Dialpad messages are a deep male voice: measured median F0 110.7-115.9 Hz. `echo` is the only match in this stack.

Measured 2026-09-24 on ZABZ-TECH by decoding with ffmpeg to 16 kHz mono PCM and taking the
median autocorrelation F0 over voiced 64 ms windows (window 1024, hop 512, voiced = normalised
autocorrelation peak > 0.3):

| file | median F0 | p25 | p75 |
|---|---|---|---|
| lpt-ivr-open-hours.mp3 | 110.7 | 95.7 | 139.1 |
| lpt-ivr-dropoff-info.mp3 | 115.1 | 101.1 | 140.4 |
| lpt-voicemail-greeting.mp3 | 115.9 | 98.8 | 133.3 |
| lpt-welcome-greeting.mp3 | 111.5 | 102.2 | 146.1 |

Fresh OpenAI TTS renders of the *same* open-hours text, same measurement:

| voice | median F0 |
|---|---|
| **echo** | **113.5** |
| ash | 108.1 |
| fable | 121.2 |
| onyx | 92.2 |
| alloy | 146.8 |
| shimmer | 149.5 |
| nova | 172.0 |
| sage | 179.8 |

So the sibling files are a deep male voice and **echo** is the match; the documented default for
`scripts/dialpad-ivr-audio.py` (`nova`, "recommended for business IVR") is measurably the WRONG
voice for this shop's existing messages — it is a full 58 Hz higher. Docs that recommend a voice
are a guess about a fact that can be measured off the artifact.

TWO THINGS THAT DID NOT RESOLVE, stated so nobody re-litigates them:

1. **The encoder does not match.** All five existing files are MPEG2 Layer III, 24 kHz, mono,
 **160 kbps**, every file an exact multiple of 480-byte frames. Current OpenAI TTS mp3 is the
 same 24 kHz mono but **128 kbps / 384-byte frames**, for every model (`tts-1`, `tts-1-hd`,
 `gpt-4o-mini-tts`) and every voice. `tts-1-hd` is not the answer either. So the July 2026 files
 were not written by today's `synthesize_openai_speech` — most likely the provider's encoder
 changed, since the repo contains no other TTS provider at all (grepped for
 elevenlabs / google texttospeech / polly / azure speech: none).
2. **OpenAI TTS is not deterministic.** The same text and voice gave 687 frames on one run and
 702 on the next. Duration matching is therefore NOT a usable identity test; pitch is.

RULE: to reproduce "the same voice", measure the artifact, do not read the config or the doc.
`scripts/dialpad-message.py` now defaults to `echo` and carries this table in its docstring.
