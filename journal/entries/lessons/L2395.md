**L2395 · A branch that merges cleanly can still delete 19,296 lines: the holiday branch would have wiped the Waze surface, and only the diffstat caught it**

Measured 2026-09-23, integrating the LPT website. This is the most dangerous kind of merge and it looks
completely routine.

`origin/fix/holiday-closure-notice` is where production's live bundle came from, and it carries the closure
feature I actually needed. It was the obvious thing to merge. Diffed against the sibling branch that holds
the same fixes (`origin/project-keepalive/lpt-truthful-20260922`):

 93 files changed, 952 insertions(+), 19296 deletions(-)

Those 19,296 deletions are the **entire Waze storefront, customer portal and staff surface** - the branch
was cut from a 2026-09-17 lineage and `origin/test` has moved 69 commits since. `git merge` would not have
refused: it is an ordinary branch, and it merged toward a conflict at worst. Nothing about the git
machinery protects you here. The only thing that caught it was computing the diffstat BEFORE merging and
reading the deletion count rather than the conflict count.

TWO RULES:
1. **Before merging a branch that is older than its target, run `git diff --stat <branch> <target>` and
 read the DELETIONS.** Big unintended deletions mean: do not merge - port the specific files by blob
 (`git show <branch>:<path>`) and reconcile the overlapping ones by hand.
2. **"It merged cleanly" is not evidence of correctness.** A clean merge that deletes 19k lines is an
 ordinary git outcome, not an anomaly. The mechanical guard for any integration is
 `git diff --diff-filter=D --name-only <target> HEAD` - it must be EMPTY.

WHY THIS NEARLY HAPPENED, and the more general lesson: the project's own durable state file said
"INTEGRATE FIRST, then move on" and named the branch. A worker following that instruction literally, in
good faith, would have destroyed a product line. **An instruction to merge is a claim about the state of
the world, and it has to be measured before it is obeyed** - the same failure class as trusting a report
instead of reproducing it.
