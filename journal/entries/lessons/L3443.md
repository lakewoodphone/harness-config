**L3443 · A local checkout is an old claim about a branch - read origin/test in a detached worktree before answering anything about the repo**

MEASURED 2026-10-09, ZABZ-YOGA. Before reading the LPT website I nearly answered from
C:\Users\ezabz\code\phone-and-tech-full - the checkout that is right there, on the working machine.

It is 684 commits behind origin/test, has 15 uncommitted files, and carries a DIFFERENT
.github/workflows/ tree: about 50 files including archived/ and six grand-supervisor-* workflows,
against 6 live workflow files on origin/test. Measured the same day:
 git diff --name-only HEAD origin/test | wc -l -> 1300
 git ls-tree origin/test --name-only .github/workflows/ -> 10 entries + archived/ + config/

Had I read it I would have reported: deploy is manual for the frontend; there are nine
grand-supervisor workflows; DEPLOY_ARCHITECTURE_REALITY.md is the authority. All three would have
been wrong. The truth is one workflow (deploy-env.yml) on a self-hosted runner, documented in
docs/ci-cd/ONE-DEPLOY-PATH.md, which does not exist in that checkout.

THE RULE
For any question about a repo's present, read `origin/<the authoritative branch>`, not the working
tree. A local checkout is a claim about a branch, and it is usually an old one. The cheap and
correct move is one detached worktree at the right commit:

 git worktree add --detach <path> origin/test

and read from there for the whole session. Do this BEFORE the first file read, not after a
suspicion. Then say in the report which commit every reading came from - the doc this session
produced opens with a provenance table for exactly this reason.

HOW TO NOTICE YOU NEED IT
`git rev-list --left-right --count origin/<branch>...HEAD` before reading anything. If the left
number is not 0, your working tree is not the repo you think you are describing.

GENERALISATION
This is the same shape as the failure that once caused a phantom crisis (a stale database copy read
and believed). The fix is the same in both: name the source and its age before you report a number
from it. A reading without a commit beside it is not evidence.
