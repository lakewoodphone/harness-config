**L3809 · A listener inside the Windows dynamic port range: EACCES at boot, a zombie proxy, and a seven-minute dead GUI**

A listener must not live inside the OS dynamic/ephemeral port range. Measured on ZABZ-TECH 2026-10-14: `netsh int ipv4 show dynamicport tcp` = start 1024, 13977 ports, i.e. 1024..15000, and the multi-window origin proxy listened on 127.0.0.1:**3200-3223** — inside it.

At 08:03:56-08:11:10, immediately after boot, EVERY bind in that block was refused with **EACCES (access denied)**, not WSAEADDRINUSE: 11 consecutive proxy starts, 360 logged `LISTEN FAILED EACCES after 0 retries`. `vmcompute`, `winnat` and `WslService` were all running — Windows reserves blocks out of the dynamic range at boot for those, and `netsh int ipv4 show excludedportrange protocol=tcp` showed the same signature (9468-9567, 13091-13590, 13637-13836). The reservation lifted about seven minutes after boot and the 12th attempt bound all 24 ports. Nothing else changed.

**Two things made it an outage rather than a delay:**
1. `listenWithRetry` retried only `EADDRINUSE`, so EACCES gave up at attempt 0; the process then sat alive with ZERO ports bound, holding the lock, while `ensure` started another and another — a zombie that made the range look permanently dead.
2. The launcher's documented fallback opened windows against the engine port with a **stale token**, so the owner got an unreachable / authentication-required page instead of a GUI.

**What to do on any machine that listens on a fixed port:** read `netsh int ipv4 show dynamicport tcp` and `netsh int ipv4 show excludedportrange protocol=tcp` before choosing it; stay outside both. On these Windows boxes the safe band is 15001-49151 (verified: 19200-19223 binds 24/24 on ZABZ-TECH and ZABZ-YOGA, with no exclusion covering it). And never treat a bind refusal as permanent — EACCES means "not now", not "never".

**Fixed** commit f73d521d: base 3200 -> 19200, EACCES retried like EADDRINUSE, a proxy that bound nothing exits 2 instead of zombie-ing, and `/__dshw/stats` now reports `base` and `range` so a reader can tell a healthy proxy from one whose range never came up.
