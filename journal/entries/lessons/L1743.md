**L1743 · journal.py append --body eats backticks: pass a file**

Bash expands backticks inside a double-quoted --body argument before journal.py ever sees it, so a body containing `code` loses that fragment silently (or, worse, runs it — one of mine ran a diff and a git command in the wrong directory). Use --body-file with a quoted heredoc delimiter: cat > /tmp/body.md <<'EOF' ... EOF, then --body-file /tmp/body.md. Cost of not doing it on 2026-09-16: one entry recorded with two gaps (W184) and one entry that never got written at all (the pain entry failed with 'Argument list too long').
