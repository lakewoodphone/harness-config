**L1613 · Chumash gematria: three of eleven advertised methods were mislabelled - the corrected published definitions**

Three of the eleven gematria systems `chumash-timeline` advertises were not what they claimed.
Corrected and committed 2026-09-15: branch `agent/chumash-gematria`, commits c91c881 / 9d4aeea /
a10255a (rebased onto main 76c377b). 73 tests pass; the module header carries the citations.

Durable definitional facts — do not re-litigate these, and do not trust a number you were handed:
* mispar bone'eh (revu'a) is the CUMULATIVE RUNNING SUM of letter values: achad = 1 + (1+8) + (1+8+4)
 = 23. The shipped code computed sum-of-squares + letter count = 84.
* mispar katan = PER LETTER drop the zeros (tav 400 -> 4, kaf 20 -> 2, ק 100 -> 1) then sum.
 mispar katan mispari = sum the standard values FIRST, then reduce the total to one digit. The old
 code had these two swapped, and its `mispar ha-mispar` was the same function as katanMispari
 (0 differences over 627,439 inputs) with no published definition — it is gone.
* mispar p'rati = square each LETTER (that was the old `merubah`); mispar ha-merubah ha-klali =
 square each WORD's absolute value (the old `kellali` was a one-line alias of katan).
* mispar kidmi is the running sum over the standard values, so it is triangular only up to yod (55):
 כ = 75 (not 66), ת = 1495. Build it from the alphabet, never hand-write 1,3,6,10...
* kolel = standard value + the number of WORDS. Wikipedia's mispar musafi adds the LETTER count; the
 sources do not equate the two, so the label says kolel.
* milui (otiyot be-milui): the only source that publishes a whole list (he.wikipedia, "לפי הכתיב
 הנפוץ") spells vav ויו = 22 and tav תיו = 416, not וו = 12 / תו = 406.
* atbash is a substitution on the 22 letters: read a final as its base letter first (ך -> ל), so no
 final passes through unchanged. Sources: en.wikipedia "Gematria" §Methods of Hebrew gematria;
 he.wikipedia "גימטריה" (table ערכי האותיות במילוי). Both cite R' Moshe Cordovero's Pardes Rimmonim
 as the list's origin; the sefer itself was not consulted.

EVIDENCE: the 11x11 pair-wise difference matrix over 551,880 synthetic inputs (every 1-4 letter string
over the 27 Hebrew letters) and 75,559 live inputs (69,713 pasuk word tokens + 5,846 pesukim from
lpt-postgres) has ZERO zero-difference pairs; min non-diagonal count 25,086 (live) / 306,470
(synthetic). That test is committed as src/lib/gematria.duplicates.test.ts and reads the pasuk corpus
from $GEMATRIA_CORPUS when set.

The brief handed to me contained two wrong numbers of its own: boneh("שלום") = 1037 (the derivation is
1342 = 300+330+336+376) and "0 of 19,683 three-letter inputs agree with the old formula" (exactly 2
degenerate strings agree: אאא and באא of 19,683). Derive every reference vector yourself.
