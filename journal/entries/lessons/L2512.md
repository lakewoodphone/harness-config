**L2512 · There is no Message Creator in Dialpad, and the real TTS surfaces write to Dialpad, not to disk**

## There is no "Message Creator" in Dialpad. The owner asked for one on 2026-09-24; it does not exist as a named feature.

Searched, in this order, and all negative:
- `help.dialpad.com` full-text search for "message creator": 0 relevant hits across 560 results (all were SMS "message" articles).
- The live admin console in a logged-in Playwright session (ZABZ-TECH, saved profile
 `data/dialpad/chrome_profile/`): admin lives at `https://dialpad.com/officesettings`, not
 `/app/admin` (which silently redirects to `/app/history/new`).
- `https://dialpad.com/workflows` -> **Media** tab lists every uploaded mp3, with no
 create-from-text control. Only "Create workflow".
- `https://dialpad.com/settings` -> **Call handling and voicemail** -> "Record a greeting"
 opens a modal titled **"Record your greeting"** with `input[placeholder="Greeting name"]`
 and a record button — microphone only, no TTS.
- Workflow editor (`https://dialpad.com/workflows/workflow_<id>`) exposes only
 `aria-label="prompt menu node"`, `prompt play node`, `transfer node`, `go to node`.

WHAT DIALPAD ACTUALLY OFFERS for turning text into a voice message:
1. **Workflow step TTS** (Menu / Collect / Play -> Audio output -> "Text to speech").
 Early-Adopter-Program feature. Voice is configured office-wide at Workflows -> **Speech**
 tab. This account's live setting is `scripted_ivr_speech_settings =
 {engine: "neural", id: "Joanna", language: "en-US"}` (read from the live office group,
 2026-09-24). No Voice tab was visible in this account's Workflows UI.
2. **The recording-greeting modal** ("Record greeting"), shipped 25.10.28, with Language +
 Voice + Message fields. It writes to the call-recording announcement slot, not a
 voicemail box.

Neither one produces a file you can save locally — both write to Dialpad's servers.

RELATED, and the reason the request was still satisfiable: Dialpad's internal API surface for
greetings is `/api/customivr/<target>_GREETING | _VMUNAVAILABLE | _HOLDMUSIC | _HOLDINTRO |
_VMDROPMESSAGE` (observed live in the settings page's own network calls). `_VMUNAVAILABLE` is
the voicemail greeting slot. Replaying these from a page context with `fetch` returns
**403 forbidden** — the app's own calls carry headers a plain `credentials:'include'` fetch does
not reproduce, so reuse the captured-header replay in `scripts/dialpad_ivr_admin.py` instead.

RULE: when the owner names a third-party feature that does not exist under that name, do not
stall on the name. Enumerate the vendor's real surfaces, pick the one that produces the artifact
he asked for, produce it, and say in one line what you found instead. Naming a feature is not a
specification; the deliverable is.
