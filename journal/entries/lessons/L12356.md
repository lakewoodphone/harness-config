**L12356 · Moving files to or from ZABZ-YOGA: no sftp, base64 over ssh; use laptop-ts-ip**

MEASURED 2026-10-25 pulling the Waze Device sign renders from ZABZ-YOGA to ZABZ-TECH.

1. scp fails against ZABZ-YOGA with 'subsystem request failed on channel 0' - there is no sftp subsystem there. Do not retry scp.
2. The ssh alias 'zabz-yoga' resolves to LAN 192.168.50.244 and TIMES OUT from the office box (separate networks). Working aliases from ZABZ-TECH: laptop-ts-ip (100.72.162.5) and zabz-yoga-ts.
3. Remote default shell on ZABZ-YOGA is Windows PowerShell 5.1, so 'dir /s /b' arrives at Get-ChildItem and errors. Use 'ssh laptop-ts-ip cmd /c dir /s /b <path>'.
4. Transfer that works: ssh laptop-ts-ip certutil -encode <src> C:/Windows/Temp/x.b64 ; ssh laptop-ts-ip type C:/Windows/Temp/x.b64 | Set-Content -Encoding ASCII local.b64 ; then [IO.File]::WriteAllBytes from [Convert]::FromBase64String(joined 64-char lines).
5. Prove it: certutil -hashfile on the remote original against Get-FileHash locally. Done for both PNGs and both PDFs on 2026-10-25, all four matched.
