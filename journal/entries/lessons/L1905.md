RULE: a machine-local edit to a file that a keeper copies from HEAD is not state, it is a temporary
condition. Configure it, commit the SOURCE, then re-apply from the committed source. This is 99 §2.3's
"a hand-drop is not a keeper" with the tick MEASURED instead of predicted -- and it is why the row's
target configuration was committed (7fdbbc8) rather than only edited.
