**L3405 · Identify the platform (FCC ID -> manual -> chipset) before assessing any recovery**

**Identify the PLATFORM before reasoning about a recovery. A paper label names a brand, and the brand
names an ODM, and the ODM names the chipset - and only the chipset says whether deleted data is even a
candidate.** 2026-10-08: an "IRIS Easy Flip" came in with one deleted video and a customer who wanted to
know if the phone could be scanned for it. I read the label, wrote a confident assessment about a cheap
feature phone (small NOR flash, writes constantly, chip-off uneconomic), and filed it. Six minutes of
research then showed the handset is **Coosea's SL006 platform - Android 12 on a MediaTek MT6739WW with
8 GB eMMC**, sold as Consumer Cellular's IRIS Easy Flip and DISH/Boost's Summit FL!P (FCC ID
`2A28USL006D`, granted 2023-07-06). Every load-bearing sentence of my assessment was wrong:

 * a file received over Bluetooth on **Android** lands in the internal `Bluetooth` folder, not on the
 SD card - so the likely branch was PHONE storage, and the empty card slot in the photographs fits
 that rather than contradicting it;
 * `userdata` is **F2FS on eMMC**, and Android 10+ is **required** to use file-based encryption, so a
 chip-off dump is ciphertext - the internal branch is an ENCRYPTION problem, not an undelete problem;
 * USB exposes **MTP/PTP, not mass storage**, so a card can only be imaged in a reader.

Rule, and it costs one search: **FCC ID -> the filing -> the model's own user manual -> the chipset.**
`fccid.io/<ID>` gives internal photos, schematics status and the manual; the vendor's manual states the
storage, the file format and the save-location wording; a Geekbench or XDA result names the SoC and the
filesystem. Do that BEFORE writing an assessment, and put the platform in the first line of it. An
assessment that names the wrong platform is worse than no assessment, because it reads like work.

Second rule, same session: **when the correction arrives after the customer has already been told
something, fix the record in the same hour and say plainly that it was wrong** - the case file got an
appended correction citing its sources, the day README got one, and the counter got a second production
note. An assessment that quietly changes its mind is how a shop ends up quoting from a document that no
longer means what it says.
