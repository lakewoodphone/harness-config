**L3544 · robocopy /LOG silences the console without /TEE, and an echo containing -> is a cmd redirect - both found only by running the thing**

**Both of these were found only by running the artefact against a test tree. Neither is visible by
reading it.**

**1. `robocopy` goes silent on the console the moment you give it `/LOG`.** `/LOG:file` redirects the
whole listing into the file; the console keeps only the banner. On an hour-long copy that means a
blank window and an operator who concludes it has hung and kills it. **`/TEE` is not optional when
`/LOG` is present.** Measured 2026-10-08 on the SD-card copy tool: without `/TEE`, a captured run
produced exactly one line of copy output; with `/TEE`, the full per-file listing.

**2. `echo` followed by `->` is a redirection operator, not text.** In a launcher the line
`echo Copying %SRC% -> %DEST%` made `cmd` redirect the echo into a **file** named `%DEST%` -
the exact path `robocopy` was about to use as a **folder**. Robocopy then failed with **exit 16,
"serious error, no files copied"**, and the cause was invisible: the output looked like a robocopy
problem and the offending line had already scrolled past. **Write `to`, or escape it as `^>`. Audit
every `echo` line for `<`, `>`, `|`, `&` before shipping a `.bat`.**

**3. A scanner and the copier must be given the same exclusions.** The tool counted `NTUSER.DAT` and
`UsrClass.dat` while telling `robocopy` to skip them with `/XF`, so **every single run** reported a
false "1 file did not arrive" and ended `PARTIAL`. A verification step that cries wolf on every run
is worse than none, because the operator learns to ignore it. **Whatever you tell the copier to skip,
the thing that checks the copier must skip too.**

**The rule underneath all three:** an unattended script that will run on a customer's machine has to
be **executed against a synthetic world first**, failure paths included. The rig that found these is
recorded in the journal under the same date, and the pass/fail matrix is in
`lpt-hub/hardware-diagnostics/sd-data-copy/README.md`.

**Applies to:** any data-copy tool, any long-running unattended script, any `.bat` that reports
progress to a human who is not watching.
