**L3466 · Porting lessons 2026-10-11: empty-DB traps, merge-don't-overwrite, the OpenSSH penalty box, authority-by-hostname**

Durable rules learned 2026-10-11 (workstream 140).
1. THE APP CREATES AN EMPTY DATABASE AT A MISSING PATH AND SERVES FROM IT. Three instances in one day:
 /opt/company/data/family_chat.db (61,440 B, 1 message), the 16 KB accounting stub, and the
 1,826,816 B / 145-table decoy /opt/company/data/secretary.db that 135 sec 6.9 found. So: after ANY
 move of the app tree or its data, verify every separate SQLite file the app opens by ROW COUNT and
 max(rowid) on the destination, never by "the file is there". A missing database is not a crash; it is
 a quiet, plausible-looking emptiness.
2. A DATABASE THAT HOLDS NEWER ROWS THAN ITS SOURCE MUST BE MERGED, NOT OVERWRITTEN. The cloud
 family_chat.db holds one message written 2026-10-11 05:41:32, newer than the office copy's newest
 (02:45:22). Any "restore from the good copy" of a stub-with-one-new-row destroys real user data.
 Always compare max(created_at) on BOTH sides before replacing a file.
3. OPENSSH >= 9.8 HAS A PER-SOURCE PENALTY BOX, AND IT LOOKS LIKE A DEAD BOX. After a burst of ssh
 connections the server answers with the 26-byte banner "Not allowed at this time" and closes before
 the key exchange - which reads exactly like "the host is down / my key is wrong". Measured on
 secratary-cloud (OpenSSH_10.2p1). The default penalty max is 600 s and every retry can extend it.
 So: batch remote commands into ONE ssh call per box, never retry in a loop, and when ssh fails at
 banner exchange, test the same port with a raw TCP read to tell a refusal from an auth failure.
4. A TOOL THAT RESOLVES THE AUTHORITY BY HOSTNAME NEEDS AN ENV OVERRIDE BEFORE IT CAN BE PORTED.
 ck/sources.py compared socket.gethostname() to "secratary" and hard-coded an office path, so no
 symlink could make it honest on secratary-cloud. Any watchdog/CEO-kernel-style checker must read its
 authority identity (host name + db path) from the environment with the old values as defaults.
5. 135 sec 4.6 WAS RIGHT AND IS NOW PAID FOR: one authorized SSH key on one laptop is not an access
 path, it is a single point of failure that fires the same day you measure it.
