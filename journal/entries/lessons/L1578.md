**L1578 · 'docker inspect --format {{.Config.Cmd}}' prints live API keys for nanomdm and nanodep**

Evidence: `docker inspect waze-mdm-nanomdm-1 --format '{{.Config.Image}} {{json .Config.Cmd}}'`
printed `-api crGY...`, and the nanodep one printed `-api 6rtG...`, in cleartext. That is
the fourth time this system has printed a live credential into a transcript, and the
second time by my own hand in a single session.

Rule: to inspect a container, print ONLY image name, status, mounts, and the *names* of
env vars (`--format '{{range .Config.Env}}{{println .}}{{end}}' | cut -d= -f1`). Never
print .Config.Cmd or .Config.Env values for a container that takes credentials as argv.
When a value must be compared, compare a sha256 prefix - never the value.
