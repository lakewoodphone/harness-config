**L2382 · Intake photos are the only record of a walk-in customer — commit them, and always match the numbers on the note against production and Dialpad first**

## L2408 · 2026-09-24 · Photographed intake notes: read them, verify them, then commit them

The owner photographed three devices at the counter with handwritten notes taped to them. Each note
was the ONLY record of that customer, that number and that request: no prior case in
`lptcase.py find`, no Dialpad contact, no production customer for any of the three numbers.

WHAT WORKED, in order:
1. Crop and upscale each note (LANCZOS 3-7x + autocontrast, on the original, never the preview)
 before reading a name or a number off it. At preview size one surname was unreadable; at 7x it
 resolved to `…v-i-t-z`. A wrong digit or letter here becomes a wrong customer on the website.
2. **Match every number against production (`_customers_by_phone`, read-only) and Dialpad BEFORE
 writing anything.** That is how Devorah Goldberg's device became an iPad with a known drop-off
 ("Hi, do you fix iPads?" / "It's in my iPad. It like charging port." on call 4696325286830080,
 then the drop-off-closet call 5258751606562816) — the photo showed no device at all, only a note
 on a wall.
3. Resolve an ambiguous spelling against the shop's OWN data instead of guessing, and carry the
 losers as aliases (per CASE-FILE-STANDARD §6): production holds `mrs gewirtz` and no
 Gervitz/Gevirtz/Gavitz under any spelling, so Gewirtz is canonical and the rest are aliases.
4. Record what you CANNOT read verbatim and say so, rather than interpreting it. Ribowsky's note
 carries `(20D)` circled at the top; it is written into the case file as undeciphered, because
 guessing a price onto a work order is worse than leaving the total empty.

THE EVIDENCE TRAP THIS AVOIDED. `lpt-hub/.gitignore` excludes `*.jpg`/`*.png`, with curated
exceptions, and the repo's own comment records the April 2026 loss: 82 photos / ~240 MB gone because
they lived in a gitignored folder. `git add docs/customer-operations/case-media/2026-09-24-intake-notes/`
silently staged only the README — the three photos were NOT added. A directory "committed" with only
its README is exactly how that loss happened. Fixed with an explicit exception (3 files, ~1.9 MB) and
the reason written next to the other exceptions.

RULE. After `git add <dir>`, run `git diff --cached --name-only` and count the files. A folder of
evidence can look committed while every image in it was ignored.
