**L3730 · Lakewood build USB: autopilot Windows 11 25H2, wipes disk 0 silently, installs Home**

**The shop's Windows install USB is an autopilot stick, not plain install media.** Inspected 2026-10-08 on ZABZ-YOGA.

Identity: PNY USB 3.2.1 FD, 57.8 GB, GPT, two Basic-Data partitions. D: "Win11" (NTFS, 57.8 GB) = Windows 11 25H2 build 26200.6584, 11 editions, install.wim 6.4 GiB (too big for FAT32, hence Rufus NTFS scheme). E: "UEFI_NTFS" (FAT, 1 MB) = Rufus UEFI:NTFS shim; E:\EFI\Boot\bootx64.efi and E:\EFI\Rufus\ntfs_x64.efi are signed "Microsoft Windows UEFI Driver Publisher", so Secure Boot can stay ON. GPT means UEFI-only: it will not boot a legacy-BIOS machine.

D:\autounattend.xml (8244 B) answers Setup completely and runs before any human sees a screen:
- DiskConfiguration DiskID 0, WillWipeDisk=true, no disk-selection screen -> EFI 100 MB + MSR 16 MB + rest NTFS, labelled System/Windows.
- Installs image index 1 = **Windows 11 Home** (index 6 is Pro).
- LabConfig bypasses TPM, Secure Boot, RAM, CPU and storage checks.
- BitLocker device encryption switched off; timezone Eastern; locale en-US + he-IL.
- Creates local account Admin with a BLANK password, Administrators group, AutoLogon enabled, all OOBE screens hidden -> lands straight on the desktop.

Consequence that matters: it silently erases **disk 0** of whatever machine it boots on. No prompt, no confirmation, no chance to pick another disk. Before booting it on any PC that holds data, or that has more than one drive, either unplug the other drives or rename D:\autounattend.xml so Setup runs interactively.

D:\zzz is the shop toolkit, applied after install by D:\zzz\scripts\script1.cmd (rename PC, delete Edge desktop shortcut, all sleep/hibernate timeouts to 0, disable UCPD driver, install ChromeSetup.exe + dwagent.exe remote agent) and script2.cmd (TaskbarDa off, Word/Excel desktop shortcuts for Office 2021 from ProPlus2021Retail.img). Also present: TechloqFilterSetup.exe and four Brother/Kyocera printer installers. activate.cmd -> activate.ps1 = `irm https://get.activated.win | iex`, i.e. the MAS piracy activator, not a licensed key.

Operational gotchas proven from the layout: if Setup reports no drives on an Intel 11th-gen-or-newer machine, the BIOS storage mode is RAID/VMD/RST and must be set to AHCI; and the stick must be pulled at the first reboot, because firmware that still prefers removable media will re-enter WinPE, re-read autounattend.xml and wipe the disk it just installed to.
