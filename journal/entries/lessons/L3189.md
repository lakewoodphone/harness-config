## L — A mesh brief must carry its own bootstrap, and a node that cannot push must be collected by file

MEASURED 2026-09-30, two lessons from one fleet.

**1. The brief cannot assume the repository exists where the parent is.**
Two implementation agents were dispatched with an exclusive worktree path on the
dispatching machine (`C:\Users\ezabz\Code\_meshfix\wt\...`). The broker placed both on
`zabz-tech-linux`, where that path does not exist — and where the `harness-config` checkout
is a **two-week-old lineage** (`origin/master` f14bfde/1b921d7 vs the dispatcher's ccb7eac).
Both agents did the only sensible thing: they created their own worktree, cut their branch
from the old base, and did the work there. The work was sound and the line numbers in their
reports cited files that did not exist on the dispatcher's base — which is how the mismatch
was detected.

RULE. Every mesh brief states, in the bootstrap section: find the repo at these platform
paths, clone it from `<authority>` if absent, record `hostname` and `git log -1` in the
report, and say plainly if the base differs from the one the integrator expects. A brief that
names only one machine's absolute path is a brief that fails on the next dispatch — and
`L3184` already recorded this lesson once, which is why it is repeated here with the
mechanism rather than the warning.

**2. A node that cannot reach the authority cannot push, so collect by file.**
The Linux node's `origin` is the *office-LAN* alias `secretary:~`, and from its current
network position that host is unreachable: `ssh secratary.tail93e6e6.ts.net` times out from
it. So `git push` — the natural way to get a branch back — is not available from that node at
all. Neither `git bundle` (115 MB per branch: the whole history, because the bundles were
built against a diverging base) nor a redacted remote URL survived the round trip.

WHAT WORKED, and is the rule: export only the CHANGED FILES at the branch revision
(`git show <branch>:<path>` into a tree scoped to the package that changed), tar that
directory, and copy it back with `scp` from the parent. 30 KB instead of 115 MB, and it works
regardless of which node the broker chose or what the node can reach.

RULE. Plan the return path before spending the fleet: scope it to the package, ship it as
files, and never rely on the remote node being able to reach the authority.
