THE METHOD POINT, and it is the fourth time tonight that one more command changed the answer:
TEST FIXTURES ARE NAMED LIKE REAL DATA. A glob for "*workspaceStorage*/*.jsonl" cannot tell a
synthetic corpus built by a test from a user's chat history; only the path above the match can.
When a search returns a number that is about to become a finding, print the PATHS, not the count
-- a count of 15 looked like 15 lost conversations and was 15 lines of pytest scaffolding.
This is the same shape as `grep -i oom` matching "room" (L3758): the match was real, the meaning
was invented.
