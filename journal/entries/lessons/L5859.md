**L5859 · Finished work that was never applied is indistinguishable from work that was never done**

Measured 2026-10-16: /root/finance-fleet-20261013/history-coverage/ held a statement CSV importer (patch 19,549 B, git apply --check exit 0, sha256 88682695...), a 466-row coverage matrix, a 73-row gap statement, and recoverable-final.json naming 512 attributed recoverable rows plus 648 rows on a card with no account row. Written 2026-10-13 and never applied; three days later the ledger still began in 2024 and 70 percent of account-months could not be reconciled. The cost of a finished-but-unapplied workstream equals never starting it, plus the false confidence that it exists. Every fleet handoff must say, per artifact, either INSTALLED with the command that proved it, or NOT INSTALLED with its path - and a later session must read the fleet directories before commissioning the same work again.
