**L3780 · The NM-D471 ITL6 board: BQ24780S, no input fuse, N-channel input FETs, and where its no-power fault lives**

Written 2026-10-13 while filing the Ullman IdeaPad 3 case (WO26101312747). Applies to Lenovo IdeaPad 3 14/15/17ITL6, LCFC board HS460/HS560/HS760, board number NM-D471 Rev 2.0, assembly PNs 5B21B85082 (i3-1115G4, 4GB onboard, UMA, WIN) and 5B21B85187 (i5-1135G7).

WHAT THE SCHEMATIC ACTUALLY SAYS (the LCFC NM-D471 Rev 1.0 set was obtained and read, 110 pages; content verified by a second pass over the extracted text):
- The charger IC is a TI BQ24780S (PU5400). NOT an RT6585B. The shop's own older case note (Kreisman, WO2607290002) recorded 'RT6585B typical on this family' and that is wrong; RT6585B appears zero times in the schematic. Replacement is LCSC C2861876 (BQ24780SRUYT), about USD 3.20 at qty 1.
- There is NO discrete input fuse on this board. Zero fuse designators in 110 pages. A bench plan that says 'check the input fuse' is chasing a part that does not exist; read it as input-path continuity (jack, links, PR5425 shunt).
- The input pair is N-CHANNEL: PQ5400 = AONS32314 (DFN5x6), PQ5401 = AONR32340C. AON7407 / AO4407A / SI7149 are P-channel and are NOT substitutes. Earlier notes that assumed P-FETs would have ordered the wrong part.
- PR5425 is the 0.01 ohm ACN/ACP sense shunt. PR5436 / PR5437 (20k / 100k) are the ACDET divider.

FAULT SHAPE: 'adapter holds 19-20V, machine draws 0A' is an OPEN input path or input FETs held OFF. It is NOT a hard short - a short pulls current and folds the adapter. Expected healthy readings at the charger IC: VCC pin 28 = adapter volts; REGN pin 24 = ~6V; ACDET pin 6 = 2.6-2.8V; ACOK pin 5 asserts; ACDRV pin 4 = ~25V. ACDRV pulsing to ~2.5V then collapsing is the signature reported on this exact board.

WHAT PUBLISHED CASES SAY IS USUALLY THE REAL FAULT - check these BEFORE ordering an IC: the ACDET divider PR5436/PR5437 (an independent NM-D471 thread found exactly two blown 20k/100k resistors there), and the pin-25 BTST resistor (a drop-damage case on this family: IC had 20V in, produced nothing on the control pin). More than one published case on this board replaced the BQ24780S and nothing changed because the passive network was the fault.

NEVER leave a jumped protection FET as the repair. One published case on this exact board jumped PQ5400, the machine 'ran', and the protection was defeated.

THE HARD-SHORT CONTRAST, so the two are not confused: a documented NM-D471 no-power case had the adapter fold into short-circuit protection and input FETs at 0 ohm, from a shorted PQ1000 (CPU +VCCIN buck high-side). After removal the short cleared and standby returned to 0.01-0.03A.

IDENTITY TRAP: one PCB carries the silk screen for all three sizes (HS460 HS560 HS760) and PN 5B21B85082 is sold for BOTH 14ITL6 and 15ITL6, so the board CANNOT decide the screen size. The Kreisman file's claim 'NM-D471 = 14ITL6 (82H7)' is wrong in premise - the mapping is not one board number per size. Get the size from the base-cover MTM label or Lenovo parts lookup by serial.

BATTERY: model L20L3PF0, 11.1V, 45Wh, LG Energy Solution, ASM SB11B36276, FRU 5B11B36283 (Lenovo's own LG SDS and UN38.3 summary). The string 5B10W86937 is NOT a Lenovo battery FRU - the 5B10W869xx block belongs to the L19L3PFx IdeaPad 5 family; it was a misread off the label and it reached production before the research caught it.
