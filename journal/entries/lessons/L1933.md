**L1933 · An EMC number must come from a source that MAPS EMC to model - a supplier page title will lie to you, and the serial format would have caught it**

WHAT HAPPENED. The owner dictated "model 2338, EMC 3578" for a MacBook. A2338 is shared by the 13" M1 (2020) AND
the 13" M2 (2022), so the EMC is the ONLY thing that separates them. I wrote the case up as the M2 2022 because
I read a laptopscreen.com page titled "Screen for Apple MACBOOK PRO 13 M2 A2338 (2022)" and let its TITLE settle
the year. The supplier had filed an M1-and-M2-shared part under an M2 label; the label says nothing about this
machine. An independent research pass caught it and was right.
THE FACTS (verified 2026-09-17, mine and the subagent's, independently): EMC 3578 = MacBook Pro (13-inch, M1, 2020),
MacBookPro17,1, order numbers MYD83/MYD92/MYDA2/MYDC2. EMC 8162 = the M2 2022, Mac14,7, MNEH3/MNEJ3/MNEP3/MNEQ3.
Apple's own "Identify your MacBook Pro model" page prints model identifiers and order numbers and NO EMC numbers,
so the mapping rests on repair-community and vendor consensus and the ground truth is the machine itself
(About This Mac -> Chip; System Information -> model identifier).
THE CHECK I SHOULD HAVE RUN AND DID NOT: the serial. FVFG6T6VQ05D is 12 characters - Apple legacy format - and
Apple moved to randomised 10-character serials announced March 2021, which is anomalous for a machine released
mid-2022. That is a 60-second structural check on a field I had ALREADY collected, and it would have caught the
error before the first byte was written.
RULE: when two models share a model number, resolve the variant from a source that MAPS the distinguishing field
to the model, and cross-check with any structural fact already in hand (serial length/format, order number, chip).
A supplier page title, a marketplace listing, or a search snippet is a FILING LABEL, not a mapping.
COST: file and sync record renamed and rewritten the same day; and the year moved the machine value from
"materially more" to about USD 400, which flipped the repair from fine to upside-down money.
