**L1770 · Region test kits: buy by label, verify by the Region Code item specific, and never test DVD region 2 with a PAL disc**

**The point of a test kit.** Proving a region-free modification means proving that a *region-locked* disc behaves
differently depending on the region the player is set to. A disc marked `A/B/C`, "All Regions" or "Region Free" proves
nothing at all, and **4K UHD has no region coding by spec**, so UHD discs are unusable for this in any form.

**Sourcing them — what actually worked, measured 2026-09-16.** eBay returns **403** to an automated browser *and* to plain
`curl` (a 1832-byte error page), and Jina's reader gets eBay's own "Something went wrong" page. **Firecrawl works.** Go
through its search against the search index to find listings whose title states the region, then scrape the **item page**
and read the **`Region Code` row of the Item specifics table** — that is the authoritative field, e.g.
`Blu-ray: A (Americas, Southeast Asia…)`, `B`, `DVD: 1 (US, Canada…)`, `DVD: 2 (Europe, Japan, Middle East…)`.
Never trust the title alone: an eBay search for `arrow video blu ray` returned thirteen **remote controls**.

**Do not use eBay's own search-results page as the source.** It renders nonsense to a datacenter IP — `criterion blu ray`
came back as "0 results", which is impossible — and returns unrelated junk under "results matching fewer words". Item pages
are reliable; the SRP is not.

**The trap that would have wasted the whole exercise: never test DVD region 2 with a UK disc.** UK discs are **PAL**, and a
US player will not output PAL video — so the disc can fail *with the modification working perfectly*, producing a false
negative that sends you hunting a bug that does not exist. **Japan is region 2 and NTSC**, which isolates the region test
cleanly. Buy the Japanese release.

**Rule.** For a region test kit: buy by **label/edition** (US boutique labels lock to A; UK editions lock to B), verify by
the **`Region Code` item specific**, and match the **video standard** as well as the region on the DVD side.
