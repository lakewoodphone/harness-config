**L9790 · Suppression is loss: the internal-prose guard was deleting 9 of 34 real reminders, and a reminder that is refused is never resent**

A guard that stops a message is a message LOST when the sender does not resend. Check, per class, whether suppression means "not sent" or "never sent".

The owner-text internal-prose guard went live and correctly refused bodies that read like agent instructions. The next day I counted the cost: of **34 distinct reminder-class texts ever delivered, 9 would now be refused** - the Weinberg cash settlement, the Fisher SD-card search, the Weitman bench job, the Yaakov refund. A refused reminder is a reminder he never receives.

The guard's judgement was right and its consequence was wrong. Those reminders ARE written as instructions to an agent ("EXECUTE: Pay X. Record date+amount in lpt-hub/docs/..."). The gate cannot fix the sender, but it must not turn "this is badly written" into "he will not be told".

THE RULE. For each class a guard can suppress, ask: **does anything resend it?** A periodic cron re-fires, so dropping a duplicate costs nothing. A one-shot reminder from a task does not re-fire, so dropping it deletes an obligation. Those classes need a REPAIR path, not a refuse path: strip the internal scaffolding (paths, branch names, `.md`, work-order ids, "Record ... in", "append ... to"), cap at a sentence boundary, and send the readable remainder. If nothing readable survives, refuse - deliberately, and say so in the attempt row.

Implemented as `_rescue_reminder()` in `owner_text_relay.py`, before the guards, owner-directed reminder-class bodies only. Result: **9 rewritten and kept, 1 still refused** - and the one refused is an instruction addressed to a coding session, which should never have reached his phone.

TWO TRAPS:
- **A probe that measures AROUND the gate reports the defect it was written to find.** My first `reminders-at-risk.py` called `internal_prose()` directly and said 9 lost, when the gate refuses none. Measure through the pipeline you shipped.
- **Rewriting must be scoped by an explicit marker.** Only bodies carrying the reminder marker are rescued; the same words without it are a different message and are still refused. Otherwise the rescue quietly becomes "everything gets sent".
