**L7614 · NJ ZIP Phase 3: the $7,000 electric van is a voucher-net price, Class 3 not Class 2b**

Researched 2026-10-18: the "$7,000 electric van" in Lakewood is a **net-after-NJ-ZIP-voucher** price, not a product price. Do not re-research this from scratch.

VERIFIED FACTS (read 2026-10-18):
- Program is NJ ZIP Phase 3 (NJEDA), RGGI-funded, $75M in 2 rounds of $37.5M each.
 Source: NJEDA purchaser webinar slides Oct 2025 (njeda.gov/wp-content/uploads/2025/10/NJ-ZIP-Phase-3-NJ-ZEV-Purchaser-Webinar-Slides-October-2025-1.pdf);
 NJEDA press release 2025-11-25; programs.njeda.com/en-US/njzippurchaser3-list/
- Base voucher BY CLASS: 2b $15,000 | 3 $50,000 | 4 $65,000 | 5 $75,000 | 6 $90,000 | 7 $135,000 | 8 $175,000
- Bonuses: small business +25% of base; WMBE +4% per certification (max 3); school bus +25%; scrappage $3,000/vehicle
- Voucher capped at 100% of vehicle cost. $3M per EIN per round. $500 app fee.
- Round 1 purchaser applications CLOSED and OVERSUSCRIBED (portal text, read 2026-10-18); waitlist only.
- Round 2 launches "at least one year after round 1's launch" = not before 2026-11-25.
- VENDOR application window closed 2026-05-08 (Friday) per the same portal page -> vendor pool is frozen.
- Eligibility: NJ commercial/industrial/institutional, NJ Tax Clearance Certificate, NEW ZEV Class 2b-8 (>=8,501 lb GVWR),
 registered COMMERCIAL (personal registration explicitly excluded), 75%+ of VMT in NJ for 3 CONTINUOUS years
 after delivery, Geotab Go9 telematics installed by vendor, subject to NJEDA audit.
- Federal 45W commercial clean vehicle credit is DEAD: not available for vehicles acquired after 2025-09-30 (IRS page, reviewed 2026-07-13).
 30D and 25E also terminated 2025-09-30. So NO federal money is part of this.
- NJEDA's own TCO flyer assumes a $60,000 electric Class 2b van vs $47,000 gas, with a $15,000 voucher.
- Ford E-Transit cargo: GVWR 9,500 lb -> Class 2b (not Class 3). ~159 mi range, 89 kWh.

THE $7,000 ARITHMETIC (why the number is real):
Class 3 base $50,000 x 1.25 (small business) = $62,500 -> $62,500 + $7,000 = $69,500 vehicle
Class 3 base $50,000 x 1.37 (small biz + 3 WMBE) = $68,500 -> $75,500 vehicle
So a ~$69.5k-75.5k Class 3 electric truck/van lands at exactly ~$7,000 out of pocket. That is the whole story.
Class 2b only yields $18,750, so it CANNOT produce a $7,000 van on any real (~$50k+) Class 2b product.

LESSON: when a client quotes a suspiciously good subsidy number, reconstruct it as (base x multiplier) and solve for the
vehicle price. The number was exact, which is what proved the mechanism.

non-browser clients; ArcGIS services at mapsdep.nj.gov returned only SampleWorldCities). Moot anyway: the OBC set-aside
expires 6 months after each round's application launch, so it has already lapsed for round 1.
