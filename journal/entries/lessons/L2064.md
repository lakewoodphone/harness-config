**L2064 · Granular voice-changer DSP: measured traps (voice-engine.js)**

Built /home/zabz/phone/live-voice-dialer/public/voice-engine.js (AudioWorklet voice changer, 10 presets, 16/16 tests pass). Four things cost real time and are worth not rediscovering:

1. LINEAR INTERPOLATION ON A FRACTIONAL DELAY-LINE READ COSTS 1.76 dB. Measured: a 4-tap Hann granular pitch shifter lost a flat -6.0 dB on white noise at EVERY ratio != 1.0. Decomposition: -4.26 dB is the unavoidable Hann power sum ((2/TAPS)^2 * sum(w^2) = 0.375), and -1.76 dB was pure interpolation droop (a 2-tap average has mean power (1-f)^2+f^2 averaged = 2/3). Cubic Catmull-Rom costs 2 extra reads + ~12 flops per tap and removes it. Only 0 dB at ratio exactly 1.0 is achievable with coherent normalisation.

2. A NARROW BANDPASS BANK IS NOT A FORMANT CONTROL, IT IS A LEVEL SINK. A 3-resonator (Q 6.5-9) bandpass formant bank measured -8 to -10 dB on broadband voice and left one preset 19.5 dB quieter than the input, because a narrow bank discards everything outside its peaks. Replacing it with 3 peaking boosts (Q 1.4, +8 dB) at F_scaled, crossfaded by |scale-1|, keeps every preset within 3 dB of the input AND stays measurably effective (band-shape distance 0.1467 for formant 0.5 vs 2.0 on noise). Also: formant=1 is then an EXACT bypass (fw=0), which the bandpass version could not be.

3. A ONE-POLE SMOOTHER NEVER REACHES ITS TARGET, so 'mix = 0 is a bit-exact dry path' is unachievable with one. Fixed-rate slewing (full-scale move in 50 ms) lands exactly on the target, is the same CPU, and is also the literal 'crossfade preset changes over ~50ms' the spec asked for. Same bug kept a formant warp running at formant=1 forever.

4. A SINGLE TONE OR TWO-TONE PROBE IS THE WORST-CASE INPUT FOR ANY GRANULAR SHIFTER AND MEASURES THE WRONG THING. Taps at fixed relative offsets cancel coherently for a periodic input (a 1 kHz tone at ratio 1.58 measures -7.5 dB while the same shifter on a voice-like harmonic stack measures -3 dB), and a two-tone probe smears so badly that NO 2 Hz-wide Goertzel bin sees the carriers - I briefly misread that as 'the formant knob does nothing'. Use BAND energies (6 Goertzel probes summed per band over 10 bands, not single probes: a 2 Hz bin misses +/-58 Hz ring-mod sidebands entirely) and a voice-like harmonic stack / phone-band (300-3400 Hz) noise for level, never full-band white noise for a band-limited preset.

Design consequence recorded: granular, non-phase-locked shifting is not level preserving and the loss is content-dependent (2-8 dB on voice). Compensated with a per-preset measured outGain (all 10 now within 0.3 dB of each other on voice-like input); deliberately NOT with an AGC, which pumps on speech.
