**L13536 · A silent lossy mechanism makes an agent superstitious, not careful: give it the reading, then the rule**

## The lesson

A lossy, silent, unobservable mechanism does not make an agent cautious. It makes an agent guess, and the
guess fills the vacuum with the most available story — here, "my context is nearly gone" — which is
indistinguishable to the agent from knowledge.

THE MECHANISM, named precisely. The agent had no context number because none was exposed to it. The retry
rule was a prose warning ("write down what you will still need") with a false factual premise attached
("it does not tell you when either happened"). An instruction that overstates a hazard does not produce
vigilance; it produces superstition, and superstition is not correctable by evidence because there is no
evidence channel to correct it with. Give the senses first, then the rule.

HOW TO RECOGNISE IT ELSEWHERE. Whenever an agent's behaviour is "irrational" about a resource — time, disk,
context, remaining turns, budget — check whether it can READ that resource. If it cannot, the behaviour is
not a discipline problem and no amount of "be careful not to overreact" will fix it. Add the reading, state
the real threshold, and name the recovery path. Three surfaces did it here: a tool for on demand, a notice
at the boundary, and a recovery path in the text.

THE SECOND LESSON, about surfaces. The same persona rule lived in four committed files: the generator, the
generated preset, the profile patch, and the staged copy. Fixing one left a false statement in three, and
two of them are what a session actually loads. `scripts/mirror-persona-block.py` exists because "I fixed
it" meant "I fixed one of four", and `scripts/preset-drift.py` already existed to say so and was not run.
Before declaring a text change done: grep the sentence, not the file.

THE THIRD, about deployment. `harness-sync` links and NAMES any package in `packages/` that declares
`dsh.bundle.patch`; with `patchReload: live` a new bundle row took effect in the running process without a
restart. That is why the notice appeared in the same session that wrote the plugin — measured, not hoped.
