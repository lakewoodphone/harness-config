**L5858 · id IS NULL on a legacy-imported TEXT primary key is a test for broken, not for missing**

Measured 2026-10-16: accounting.db transaction_categories.id (TEXT PRIMARY KEY) holds 871 NULL primary keys (lpt 639, personal 232). A query filtering tc.id IS NULL matched 607 rows where only about 200 lack a resolvable category name, overstating unexplained money by 56,863.48 USD on one report. Those rows are not missing a category; their identifier was never written. Before filtering on IS NULL, ask what WRITES that field and whether a legacy importer could have written the row without it. The correct predicate here is categories.name IS NULL.
