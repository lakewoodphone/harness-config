**The Voice of Lakewood's live Chol Hamoed guide — and how to search a 580-page issue instead of squinting at it**

Measured 2026-09-28. Every seasonal "Chol Hamoed guide" search keeps landing on a stale year; this is what is
actually live and how to read it.

**The live issue (Sukkos 5787):** Voice of Lakewood **09.24.26**, "THE ULTIMATE CHOL HAMOED TRIP GUIDE":
`https://issues.thevoiceoflakewood.com/3dissue/092426/` — HTTP 200, verified.

**The trick that makes it usable:** the flip-book's text layer is served as JSON, one file per page:

 https://issues.thevoiceoflakewood.com/3dissue/092426/files/pages/words/<n>.json

which means the whole 580-page issue can be fetched and searched as text rather than read as images. The
"FOR BACHURIM" attraction page is 412/414, the carnival is 384, Riverwood is 386, the cruises are 398.

 revision 1 of the trip record and it does not exist; `betweencarpools.com` itself is Cloudflare-blocked (403).

The test before using any seasonal guide: read its own publication date, and if it names a weekday that does
not match this year's calendar, stop.
