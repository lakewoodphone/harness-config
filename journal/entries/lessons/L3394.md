**L3394 · Haiku 5.5 vs DeepSeek V4.1 Flash: Haiku wins intelligence, DeepSeek wins long cache-heavy loops**

Measured 2026-10-08, day after Claude Haiku 5.5 launched (2026-10-07). Sources: anthropic.com/claude-haiku-5-5,
platform.claude.com/docs/en/models/haiku-5-5/overview, api-docs.deepseek.com/news/news260910 +
quick_start/pricing, and the only head-to-head on a shared harness —
artificialanalysis.ai/models/comparisons/claude-haiku-5-5-vs-deepseek-v4-1-flash.

Artificial Analysis Intelligence Index v4.3.2, both at max effort, same 10 evals:
 Haiku 5.5 43 (#2/182) vs DeepSeek V4.1 Flash 39 (#7/117). Haiku leads 8 of the 11
 published rows. DeepSeek's one decisive win is AutomationBench-AA 69% vs 35% (2x).
 AA-Omniscience: Haiku 11, DeepSeek MINUS 5 — DeepSeek answers confidently wrong more
 than it abstains. For this estate, which has been burned by confident wrong numbers,
 that is the single most important row in the table.

Cost, USD per 1M tokens:
 Haiku 5.5 <=100k prompt: in 0.10, out 0.50, cache read 0.01, 5m cache write 0.125.
 Haiku 5.5 >100k prompt : in 0.50, out 2.50, cache read 0.05, 5m cache write 0.625.
 DeepSeek V4.1 Flash off-peak: cache hit 0.003, cache miss 0.15, out 0.60.
 DeepSeek V4.1 Flash peak : cache hit 0.006, cache miss 0.30, out 1.20.
 AA measured cost per Intelligence Index task: Haiku 0.21, DeepSeek 0.27 at PEAK prices.
 Every DeepSeek rate halves off-peak, so its per-task cost off-peak is ~0.135 — cheaper
 than Haiku 5.5 despite scoring lower. Peak/off-peak (01:00-04:00 and 06:00-10:00 UTC
 weekdays; everything else is off-peak) is a bigger lever than the model choice.

Where the cost story flips, and this is the part to remember:
 1. The 100k prompt cliff. Above 100k tokens Haiku 5.5's rates go x5 (in 0.50, out 2.50).
 Our agent loops are exactly that shape. Against DeepSeek off-peak that is 3.3x on
 input and 4.2x on output in DeepSeek's favour.
 2. Cached input. Haiku cache read is 0.01 (0.05 over 100k); DeepSeek is 0.003-0.006.
 On a mostly-cache-hit loop DeepSeek is 8-17x cheaper on the dominant token class.
 So: Haiku 5.5 wins short-prompt high-volume work (classification, extraction, routing,
 live chat) and wins on reliability; DeepSeek V4.1 Flash wins long cache-heavy agent
 loops and wins outright off-peak.

Caveats that must travel with these numbers:
 - Haiku 5.5 uses the newer tokenizer; the same text is ~30% more tokens than Haiku 4.5.
 A prompt tuned to sit just under 100k on 4.5 crosses the cliff on 5.5. Per-token
 prices across the two providers are measured in different tokenizers.
 - Anthropic's launch table is self-reported at max effort, five trials; DeepSeek's
 benchmark table is self-reported and arrives as PNG images on the news page (no text
 in the DOM — download and read_image them). Only the AA rows are cross-provider.
 - AA reports Haiku TTFT 415.30s vs DeepSeek 1.12s at max effort: adaptive thinking at
 max emits ~7 minutes of reasoning before the first answer token. Anthropic's default
 effort is medium, not max, so that is a worst case — but do not cite Haiku as "low
 latency" without naming the effort level.
 - DeepSeek's own table lists Terminal-Bench 4.0 31.2 and HLE 36.8(39.1*) vs AA's 27 and
 39 for the same model. Self-reported and third-party do not agree; treat a single
 source as directional only.

Fleet relevance: harness-config/settings/base.yaml agent-default-model is
deepseek-official/deepseek-flash, and DeepSeek's news page states `deepseek-flash` IS
DeepSeek-V4.1-Flash (V4-Flash retired, legacy names routed to it). So this fleet already
runs one half of this comparison. Note the literal id `deepseek-v4.1-flash` is REJECTED
by the API — the supported names are `deepseek-flash` and `deepseek-v4-pro`, and since
2026-09-14 v4-pro also routes to V4.1-Flash. Probe the catalogue, never hardcode.
