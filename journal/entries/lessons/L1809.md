**L1809 · journal.py --root was accepted and silently ignored (argparse subparser clobber)**

Found by the verification pass on 2026-09-16, with a measured cost: a timing probe run as
`journal.py --root <temp> append ...` wrote 26 throwaway entries (L1778-L1803) into the LIVE
journal and printed `+ L1791 -> ...` as if all were well. Cause: both the top-level parser and
every subcommand declare `--root` (the subcommands take parents=[common]), and argparse lets
the subcommand's own default None overwrite the value the top-level parser already stored -- so
`--root` written BEFORE the subcommand was discarded. Fixed by reading the flag off the raw
argv (`_root_from_argv`) and by printing `journal: writing to <path>` on stderr for any
mutating command given an explicit root.
RULE: a safety flag that is accepted and ignored produces exactly the outcome it was used to
prevent. If a flag can be ignored in one position, either honour it or refuse loudly.
