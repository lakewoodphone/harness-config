**L2126 · L2129 - one rate limit for every tool is a limit that punishes reading and cannot stop a runaway by itself**

Measured 2026-09-20 on the authority, 7-day window: of 836 blocked tool calls, **146 - the largest
single fixable class - were the per-step rate limit firing**, almost entirely on `repo_search`:

 repo_search: Rate limit: repo_search called 7x this tick (limit 6). 35x
 repo_search: called 8x ... 17x | 9x ... 6x | 10x ... 3x | 11x ... 3x

One constant, `_PER_TICK_ACTION_LIMIT = 6`, applied to every tool. But the tools are not alike:

 - a MUTATING tool (`create_task`, `send_sms`, `repo_run_command`, `update_task`) called 11 times
 in one step is a runaway loop, and refusing it is exactly right;
 - a READ-ONLY lookup (`repo_search`, `repo_read_file`, `list_tasks`) called 11 times in one step is
 an agent reading a codebase.

So a single number was simultaneously too strict for reading and no protection at all for the case
it existed to catch - a runaway *write* loop would still get 6 attempts before being stopped, which
is already too many, while a researcher was cut off at 6 searches.

**The refusal message was the proof it was wrong.** It said "Spread remaining calls across future
ticks" - advice the agent cannot act on, because the *step* is what it has run out of. When an error
message instructs the recipient to do something impossible, the message is describing the bug.

**Fix:** two ceilings. `_PER_TICK_ACTION_LIMIT = 6` unchanged for mutating tools;
`_PER_TICK_LOOKUP_ACTION_LIMIT = 18` for members of the existing `_LOOKUP_TOOLS_ALWAYS_ALLOWED`
set ("Read-only / lookup tools that are always allowed through the REQUIRED TOOL gate"). That set
already existed for exactly this classification, so it is reused rather than duplicated - a second
hand-written list of read-only tools would drift from the first.

Guarded by `tests/test_rate_limit_read_only_tools.py`, which asserts the higher limit exists, that it
is *higher*, that the mutating limit is **unchanged**, that reading tools are in the set and mutating
tools are not, and that the impossible advice is gone.
