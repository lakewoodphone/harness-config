**L11006 · A model literal is three defects, and the fix is per-provider, not per-file (A6 literals)**

A model literal is not one defect but three, and the fix is per-provider, not per-file.

The A6 literals workstream (ws/literals, commit 39e82da17) converted the last 37 selection literals in
personal-secretary-mvp. What is transferable:

1. `deepseek-flash` cannot be the default for a vision, audio or Copilot lane. The brief said "text
 models default to deepseek-flash" AND "do not invent a default that does not exist at the provider";
 those only reconcile if a lane is keyed by provider. So `model_ids.lane_setting(lane, *keys)` reads
 `LLM_MODEL_<LANE>` (one provider) or `LLM_MODEL_<LANE>_JSON` (a per-provider table), and returns ""
 for "this arm is not configured" — call sites use `model_for_lane()` only where borrowing the fast
 tier is safe. Renaming `model="whisper-1"` to a text id would have turned the test green and broken
 the feature.

2. The guard file's BASELINE was the real deliverable. It went 39 -> 2, and the two survivors are data
 (an inert registry row whose collector filters tier=="ceo", and mem0's DeepInfra id with no
 verifiable live replacement). Two additions made the list self-policing: a stale entry fails, and an
 excuse under 40 characters fails. Two of the 39 had ALREADY outlived their fix (agent_worker.py,
 main.py) and nothing noticed — a tolerance nobody re-checks re-permits the thing silently.

3. Do not convert a literal you cannot verify. mem0's extractor is the case: every DeepInfra spelling
 of that model is retired upstream, a config DEFAULT may not name a retired id (an existing test
 enforces it), so any conversion either sends a DeepSeek id to DeepInfra or switches the extractor to
 an unverified pipe. It was reverted to the literal and the baseline entry now says exactly that, with
 the one-operator-step fix. The other DeepInfra/Fireworks legs (deep_research, chaos_judge,
 code_self_edit) WERE converted because they sit in fallback ladders that degrade to the next backend.

4. A hand-kept mirror of a hardcode is the same hardcode. code_self_edit._attempted_model listed the
 ids the call sites used, and a test asserted the two lists matched. Deriving both from the resolver
 deleted the copy and the test's reason for existing.

PRE-EXISTING RED, not caused by this work: tests/test_config_contract.py (3) fails because .env.example
is missing 63 Settings keys — 51 before this change — and tests/test_d015_model_registry.py (13) fails
because the registry seed now holds 56 models where the tests expect 2. Both modules and .env.example
were untouched by the commit; config.py's diff was +69/-0, and model_registry.py reads only model_ids
functions that were not changed. Owner: whoever holds .env.example and the registry seed.
