**L3627 · Hardware spec comparison: use PassMark CPU Mark + G3D, then price the soldered-vs-SO-DIMM difference**

Method that worked for a two-machine 'which is better' question (2026-10-12, Dell Latitude 5491 i5-8400H vs Lenovo Ryzen 3 7320U box).

1. Resolve the exact CPU/GPU ids from the screenshots first, then read cpubenchmark.net singleCompare and videocardbenchmark.net gpu.php. Fetched values that day: i5-8400H CPU Mark 7482 / ST 2332 / 45W; Ryzen 3 7320U 8401 / 2287 / 15W; MX130 G3D 1793; Radeon 610M 1270. notebookcheck.net, cpu-monkey and nanoreview all return 403 to a plain fetch - do not burn calls on them.
2. Report CPU as two numbers (single-thread and mixed/multi), never one. Single-thread was a 2 percent tie while mixed was 12 percent the other way; a single 'faster CPU' claim would have been wrong either way.
3. Weight the non-benchmark facts that decide a machine in year 8: soldered LPDDR5 vs two SO-DIMM slots, MX130 variant (GDDR5 vs DDR3 spread is real - individual baselines ranged 1077-1944), battery age, Wi-Fi generation, serviceable chassis class.
4. State what the photos do not show (screen panel, battery health) instead of inferring it.
