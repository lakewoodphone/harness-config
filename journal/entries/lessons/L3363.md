**L3363 · A probe without a User-Agent is evidence of nothing: Cloudflare 403s Python-urllib, and I recorded the artifact as a finding**

GOAL ROUND 9, and a correction to my own record from round 4. In round 4 I ran the DNS failover against the live zone, saw the verification step report HTTP 403 for the company's public surface, and wrote into annex M: 'With the hostnames pointed at a tunnel that has no connector, Cloudflare does not answer 530 - it answers 403, a different failure.' THAT WAS WRONG. The 403 was my own HTTP client: Cloudflare's edge rejects Python's default User-Agent. MEASURED TONIGHT WITH A CONTROL HOSTNAME I had never touched - printer.abletelsolutions.com, which points at a tunnel dead since August 2025 - and by changing ONLY the header: curl default UA -> 530; User-Agent Python-urllib/3.12 -> 403; and on the company's own surface, urllib with no UA -> 403 vs urllib with 'company-promote/1.0' -> 530. So both verification scripts (company-dns-failover.py and the new company-promote.py) were reporting 403 for every failure they ever saw, and I had turned that artifact into a documented finding about Cloudflare's behaviour. WHAT SURVIVED: the conclusion (the DNS switch alone is never the fix, because a connector-less tunnel serves nothing and the write looks successful either way) - that is still true, and it is now enforced as a pre-flight refusal that I verified against the live standby tunnel: '[FAIL] target has an active connector: 0 connector(s)' -> REFUSED, nothing changed. WHAT DIED: the evidence I had cited for it. RULES: (a) a probe that cannot distinguish 'the target is down' from 'my client was filtered' is not a probe - set a User-Agent, and verify a NEGATIVE control (here: an unrelated hostname already in the failing state) before believing a status code about your own production surface; (b) when a tool reports a surprising code about infrastructure I control, suspect the tool first; (c) an artifact written into a durable document becomes a fact to whoever reads it next, which is how a wrong lesson outlives the session that invented it - the correction now lives in the same annex, above the original claim.
