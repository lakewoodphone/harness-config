**L3057 · The NJ state park site blocks scraping but r.jina.ai reads it - and that unlocked the whole state fee and hours layer**

Measured 2026-09-29, primary-source hiking research for the owner's Chol Hamoed day out.

THE BLOCK: dep.nj.gov/parksandforests and nj.gov/dep/parksandforests return HTTP 200 with an EMPTY BODY (a title at most) to web_fetch. Every state PDF returns unsupported content type. This is the documented Incapsula/JS block.

THE UNLOCK, and it is a one-liner: curl -s -H 'User-Agent: Mozilla/5.0' 'https://r.jina.ai/https://dep.nj.gov/parksandforests/<path>/' returns the state's OWN page text, including the blocks that matter. This gave, verbatim and authoritative:
 - Round Valley's own Hours block: 'Gate: 8 a.m. - 8 p.m., daily' and its Fees block: fees Memorial Day Weekend through Labor Day, then 'After Labor Day to Memorial Day Weekend: Free'.
 - Worthington's trail brochure: 'Hours: Visitors are welcome on the trails from dawn to dusk. Trail use is not permitted after sunset.'
 - Stokes' 2026 trail map PDF: 'Tillman Ravine Trail - White - 1.5 miles - Hiking only - Moderate'.
 - Wharton's Batsto sentence: 'The grounds are open every day, dawn to dusk, for self-guided tours.'
It also read npshistory.com PDFs (NPS 'Guide to the Gap') this way.

WHAT IT STILL COULD NOT READ: pages that build their body in JavaScript after load - the High Point Monument page, the state fee-schedule page (503 placeholder), DEP news pages. And OUTDATED SLUGS matter: state-park/brendan-byrne-state-forest is a 404; the live slug is state-park/brendan-t-byrne-state-forest. Probe slugs rather than assuming.

COROLLARY WORTH KEEPING: an HTTP 200 is not a successful read. This tool returns 200 with zero bytes for a blocked page AND for a genuinely empty one. Always check the byte count and the title before believing a fetch.
