**L1967 · The harness-config convention for a diverged machine is a branch named diverged-<HOST>-<DATE>, not a merge**

DISCOVERED 2026-09-17 by listing the bare repo on secratary after finding this machine's harness-config diverged (4 local vs 5 remote commits).

The server already carried, from other sessions: diverged-ZABZ-TECH-20260917, diverged-ZABZ-YOGA-20260915, diverged-ZABZ-YOGA-20260916, diverged-ZABZ-YOGA-20260917, diverged-secratary-20260917 - plus reconcile/secratary-20260917 and preserve/secratary-worktree-20260917. That IS the convention: each machine parks its diverged state on its own dated branch, and a reconcile effort merges them later. Nothing is force-pushed and nobody resolves another machine's conflicts in the moment.
