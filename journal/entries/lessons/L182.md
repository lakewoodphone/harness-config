**L182 · A size difference between machines is an alarm, not a diagnosis - measure which copy is behind**

*Learned:* the same journal existed as three documents. On 2026-09-14 `HANDOFF.md` was 273,065 bytes on
ZABZ-YOGA, 262,948 on ZABZ-TECH and 259,703 on `secratary`; `PAIN.md` differed three ways as well. The
instinct is to call that a three-way fork. Measuring the git state showed something narrower and more useful:
all three were on the same line of history, two were simply **6 and 1 commits behind**, working trees clean.
*Rule:* when two copies of the same document differ, establish **which copy is behind and which is forked**
before naming the problem — `git rev-list --left-right --count origin/master...master` answers it in one
command. And the corollary that made the difference: a *size* difference between machines is an alarm, not a
diagnosis. Report the measurement, not the inference.
