**L3494 · Which data-recovery lab we use is a BUSINESS SECRET - it appeared in a customer README, and the generator now refuses to write if it does**

**Owner, 2026-10-09, on a README that named the lab:** *"did you include a readme that actually included the labs name? thats a business secret where we send to."*

**The rule: which data-recovery lab we use is a business secret. It never appears in anything a customer can see.** It appeared in four places in the first Kogel README — the lab's name twice and its ticket number twice — and in the case file's own prose.

## What "customer-visible" covers
- A README or any file placed on the customer's media.
- A printed label.
- An outbound message, text or email.
- The **folder and file names** we hand over. `73459` is the lab's ticket number; a raw folder called that, and `73459-File-Listing.html`, travel with the numbers on them even when the name is absent. **The customer gets the organised set only — the raw recovery, the lab's file listing and the lab's leaflet stay on our drive.**
- Photos of the bench or the paperwork, if any ever get sent.

## Enforced, not remembered
`lpt-hub/scripts/customer-operations/make_stick_readme.py` holds a `FORBIDDEN` list (`300 Data Recovery`, `300DDR`, `300 Dollar`, `dollardatarecovery`, `repairshopr`, `slack-files`, the ticket number, *"the lab"*, *"chip-off"*, `R-Studio`, `PC-3000`, …) and it **exits non-zero and writes nothing** if any of them appears in the generated text. A warning would have been ignored; a refusal cannot be.

**Generalise it:** any fact that must not reach a customer should be enforced by a check that refuses to produce the artefact, because a rule that only lives in a document is a rule that eventually loses to a deadline.

## The same mistake in the case file, and it cost more than the README
I also wrote, from a single unverified packing-plan line (*"we are NOT providing a transfer drive"*), three wrong conclusions: a possible unbilled medium charge, a medium that was not ours, and a return obligation to the lab. The drive was **ours** and was sitting on the bench with the ticket number on its label the whole time.

**Both failures are the same shape: a claim about the physical world, derived from a document, never checked against the thing itself.** The lab's name was in my own draft; the drive's ownership was on its own volume label. Neither got read before it was written down.
