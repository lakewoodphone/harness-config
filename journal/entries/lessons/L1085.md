**L1085 · The harvest's 'transcripts: found 0' is honest, not broken - do not rebuild it**

## The harvest's `transcripts: found 0` is honest, not broken — do not "fix" it

The 30-minute Dialpad harvest logs `"transcripts": {"requested": 100, "found": 0, "errors": 0}`
on every pass, and has for months. It reads like a dead leg and it is not. Probed directly on
2026-09-14 with the live token:

* `GET /api/v2/transcripts/<call_id>` for a call that HAS a transcript returns
 `{"call_id": ..., "lines": [...]}` — the endpoint works, the token is scoped correctly, and the
 harvest's parser reads the right field.
* The same call, asked through `GET /api/v2/calls/<id>`, returns **404** — so `calls/{id}` is not a
 valid path and nothing should be built on it.
* For a call that has no transcript, the endpoint honestly returns `{"call_id": ...}` with no
 `lines`. `found: 0` means Dialpad has no transcript for the calls being asked about — which is
 exactly the set the selector chooses (most recent calls with empty `transcription_text`).

So the leg is correct and the *data* is absent. The gap is Dialpad's, not the code's, and it is why
the Whisper backfill (`scripts/dialpad-transcript-gap.py`) is the right fix rather than an API
investigation. Two things worth knowing anyway:

* Those calls have no transcript because Dialpad never produced one (its AI transcription is not
 enabled for every call), so no API call will ever fill them.
* The selector has no negative cache: the same ~200 calls are re-requested every 30 min forever
 (~9,600 API calls a day) and always answer "none". Cheap, but it hides the real signal and it
 makes a healthy no-op look like a fault — the third time today that "the number looked like a
 fault and was a fact".

**Structural bonus.** The API marks each line with a `type`: real dialogue is
`"type": "transcript"`, and every analytics label is `"type": "moment"`. That is independent
confirmation that the artifact vocabulary stripped in **L1082** is metadata rather than speech —
the API says so, the corpus measurement says so, and both agree.
