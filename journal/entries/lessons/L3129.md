That is too strong: the branch IS pushed to origin (git branch -r --contains d7cdf9a lists origin/hk/20260928-journal-utf8-complete), so another machine can fetch it; what it cannot do is see it in a checkout of master. Integrating it is a real merge, and the journal index files were regenerated on both sides, so the index must be regenerated once after the merge rather than taken from either side. Filed as ledger item 161, priority 1, with that discipline in its definition of done.
