**L1477 · Rows whose state is outside every filter become invisible to all cleanup and all metrics**

Rows whose state value is outside the set every query filters on become invisible to all cleanup and all metrics

Three instances in one night on the authority, all the same shape. In each case the row
existed, was counted nowhere, and nothing would ever have revisited it:

 1. work_sessions.status held 39 shifted-column values ('5', '4.81'). Every sweep and
 every count filters on a known status, so those rows counted as neither completed
 nor failed for three months. Fixed by declaring the closed set at the writer.
 2. email_drafts carried expires_at since it was created and nothing ever READ it, so
 64 drafts from June were still pending_review in September, waiting for a review
 surface that was never offered. Fixed by enforcing the column in the lifecycle sweep.
 3. job_queue held 9 rows 'running' for 41 to 90 days. requeue_stale_running_jobs
 filters WHERE agent_id = ? and the work loop passes its own agent id, so a job
 claimed by any other agent was never examined again; it also required
 picked_up_at IS NOT NULL, which the oldest rows predate. So
 `count(*) where status='running'` read 10 when 1 was true.

THE GENERAL RULE: a column used as a state machine is only as honest as the weakest
reader. If a value can enter it that no query matches, the row leaves the system's view
while remaining in its database -- no error, no alert, and no metric moves. Two habits
that prevent it:
 * declare the closed set at the WRITE path and refuse anything else loudly (which is
 what update_work_session now does), rather than trusting callers;
 * for every state column, ask which query is responsible for eventually leaving that
 state, and check that it can actually see every row in it. An expiry column nothing
 reads, or a cleanup scoped to one actor, is not a policy -- it is a comment.

The cheap detector, when something feels unaccountably unmonitored: count the rows by
state, then count the rows each maintenance path can see, and subtract.
