**L1766 · Corrected: the RattleByte Panasonic Initial flash auto-starts from the Home Screen - the update menu is for later updates only**

*(Re-appended 2026-09-16 after an id collision. This record was first written under id `L1744` on a checkout that was nine commits behind `origin/master`, so that id already meant a different entry written on another machine. `journal.py` allocated a fresh id rather than let one id mean two things; the content below is unchanged apart from this note.)*

**The RattleByte Panasonic Initial flash does not go through the player's update menu.** I published the menu path
(Setup -> Player Settings -> System -> Firmware Update -> Update Now) as the answer to the owner's question 3, and it was
wrong - that path is what the vendor documents for **later** updates once the mod is already installed.

**The actual procedure (RattleByte Solderless Fitting Instructions, Panasonic all models, p.3):** unpack the archive to an
**empty FAT32 stick**; insert it into the **front USB slot while the player is on the Home Screen**; the update **starts
automatically**; **remove the stick as soon as the player reboots** so it does not reinstall. Then the board pairs on first
boot (~3 min, LED flashing red, brief green flash at the end, never power off during it).

**Why this was worth checking:** the generic manufacturer procedure and the vendor's procedure are different for the same
file name (`PANA_DVD.FRM`). I generalised from Panasonic's public support page - a plausible-looking, authoritative source -
instead of reading the mod vendor's own sheet, which was one download away and is the only document that describes *this*
install. On vendor-hardware work the vendor's sheet outranks the OEM's generic page; get it before giving steps.

**Also:** "This USB device is incompatible" is the same message for a wrong-model file and a bad stick, so it cannot rank
the causes - the file's model is the cheap thing to check first (L1743).
