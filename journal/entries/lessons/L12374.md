**L12374 · Phone charging ports: use ebay_api.py, not shop_sourcing.py**

2026-10-26, LG Exalt VN220 port. shop_sourcing.py maps 'charging port' -> laptop 'dc jack' in part_names.py and drops the brand token, so 'charging port for an LG Exalt VN220' searched 'vn220 dc jack' and returned Sony VAIO VGN-*220 laptop jacks. Exit 1 was a real negative about the wrong query. For a phone part go to scripts/sourcing/ebay_api.py: 'search' for the population, 'item <id>' for the facts that decide a bench job - price, estimatedAvailableQuantity, itemLocation (state), returnTerms.returnsAccepted, and shippingOptions with min/maxEstimatedDeliveryDate (free USPS First Class vs +5 FedEx 2Day is often the whole decision). Also: the price ledger's 'vn220' model key now holds 13 Sony VGN-*220 jack observations; a model key that collides with a laptop suffix is poisoned and needs the brand token kept. And the fan-out's backmarket/newegg sources return ERROR no FIRECRAWL_API_KEY - a refusal, not an empty result.
