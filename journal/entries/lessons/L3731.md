**L3731 · session/agent-busy means the prompt was rejected and the reason was hidden - read details.reason, not the message**

## session/agent-busy is a WRAPPER, not a state

dsh-api-session-controller/lib/index.js wraps ANY unexpected throw during prompt admission:

 catch (error) {
 if (remoteErrorOf(error) !== undefined) throw error;
 if (error instanceof AttachmentError) throw new RemoteError('session/attachment-invalid', ...);
 throw new RemoteError('session/agent-busy', 'prompt rejected', { reason: String(error) });
 }

So the code does not mean \"an agent is running\". On 2026-10-12 it meant
\"file-upload: operation requires the Agent's own scope\" and cost the owner every send
on four devices. The real text travels in result.error.details.reason, which no UI shows.

HOW TO GET IT: capture the response body, not the rendered message.
 page.on('response', ...) in a Playwright session against the gate, or
 curl the engine's /api/session/prompt with the cookie from the engine's token line.

Two later sites also emit agent-busy and are DIFFERENT faults (subagent-owned session;
subagent delivery required) - so the code alone never names the cause.
