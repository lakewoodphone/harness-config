**L3667 · update_order refuses a bare dict for deviceInfo - jsonb fields must go through the module's own psycopg2_json() helper**

**Measured 2026-10-11, WO26101112743 (Fisher SD card).** Correcting an order's `deviceInfo` through the
sanctioned writer fails on the first attempt, with a message that does not name the fix:

```
website_db: update order failed: can't adapt type 'dict'
{"ok": false, "error": "Update failed: can't adapt type 'dict'"}
```

`deviceInfo` **is** in `website_db.ORDER_WRITABLE_FIELDS`, so `_validate_write` accepts it and the failure
comes later, from psycopg2, which has no adapter for a bare dict against a jsonb column.

**The fix is a helper in the same module:** `website_db.psycopg2_json(value)` returns
`psycopg2.extras.Json(value)`. Pass the dict through it and the same call succeeds:

```python
from app.services.website_db import psycopg2_json, update_order
update_order(pg_url=..., secretary_db_url=..., order_id=3037,
 updates={"deviceInfo": psycopg2_json({...}), "description": "..."},
 confidence=0.95, source="...")
```

The module also knows how to *read* such a value back — `_json_safe` unwraps anything whose type name is
`Json` and recurses into `.adapted` — which is the tell that JSON wrappers are the expected shape.

**Also measured the same day, and worth copying:** `title` is writable too (added to the whitelist
2026-10-06, per the code comment, precisely because duplicate detection reads it and a wrongly-titled
order was otherwise permanently wrong). `update_order` refuses a status *regression* unless the caller
passes `allow_status_regression=True`, and its `reason=` argument is stored verbatim in
`order_status_history.reason` — the way to tell a deliberate human correction apart from an automated
re-read. Use it when correcting a record by hand.

**Why this matters beyond the mechanical fix:** the two fields every staff member reads first — the work
order's title and its device line — were both asserting facts nobody had established (a 64 GB SanDisk
Ultra Plus that "was formatted"). A note that corrects them sits under them; the header does not. Fix the
header.
