**L2351 · L — The Family Chat speaks in exactly ONE sendable voice (Chip), through hub._send_to_member; and the owner cannot answer the ask_user_question widget from his phone**

**Evidence: 2026-09-23, SECRATARY, a requested Chip broadcast.**

1. THE SEND DOOR. The family chat forwards whatever a *member* texts to the hub, so an agent can never "text as ETZ" honestly. The only voice the system can add is Chip (the family-computer persona) - `personality._send_chip_reply(text)` for the automated path, or a loop over `db.list_members()` filtered to `active and not muted` calling `hub._send_to_member(member, sender_name="Chip", body=..., media_urls=[], status_callback=...)`. That second form is what I used because it returns a per-recipient result; it writes the ledger row itself, so no separate INSERT is needed (and per L1570 a hand-rolled send that skips this door is the bug).

2. BOOKKEEPING THAT MUST RIDE ALONG. After a send: `personality._record_reply(estimate_group_cost(text))` (increments chip_replies_<date> and chip_monthly_spend - measured 0.2739 for 3 SMS x 11 members, $0.0249 each) and `db.chip_add_memory(...)` for facts Chip should know later. Budget is $5/month, so a broadcast is ~5% of it.

3. GROUP SIZE IS NOT THE ROSTER SIZE. 13 members, 11 targets: Bracha (id 9) is active=0 and Yosef Dov (id 8) is muted=1. Always read the target list before quoting a cost.

4. THE OWNER CANNOT USE THE ASK-USER-QUESTION WIDGET FROM HIS PHONE. He answered a rendered question with "I can't see the question when you use the answer a question tour on the phone". Ask in plain chat text, one question, with the options spelled out in prose; the widget is for a desktop GUI session only. Rule 2 still holds - one question, one recommendation.

5. WHAT HE MEANT BY "WEIRD AND CUTE AND SHARP". First draft (headline + bullet-list tone, "MAZEL TOV x2") was rejected as not sharp/weird/creepy enough; the accepted register was the *surveillance log* voice - the baby is a file, the machine knows which closet shelf Zaidy's rok is on, illness is reported as "his phone went quiet and I noticed", and the closer is "Sleep well - I don't." Deliver the persona, not a greeting card.
