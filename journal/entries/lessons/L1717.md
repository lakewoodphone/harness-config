**L1717 · A keeper that only runs when someone remembers is a procedure - install-client-plugins.ps1 existed and nothing called it, so sync.py calls it now**

## The rule this is an instance of
**A keeper that only runs when someone remembers is a procedure, not a keeper.** If a component
can silently disappear, the thing that keeps it alive must itself be invoked by something that
cannot be skipped.

## The instance (2026-09-16, harness-config)
`scripts/install-client-plugins.ps1` exists, is well documented, and its own header states the
invariant it protects: *every name in the profile's bundle list must resolve*. Its header also
cites DECISIONS D38 — "a component that can silently disappear needs a keeper, not a procedure" —
and records the 2026-09-11 engine refusing to boot with:

 Error: dsh: cannot resolve profile bundle "dsh-plugin-cost"
 from the dsh installation or C:\Users\ezabz\.dsh\profiles\web

…and plugin-windows having to be copied into the profile by hand, twice, once leaving a stale
3636-byte client.js behind.

**And nothing called it.** `scripts/sync.py` copies settings, presets and the profile patch into
`~/.dsh` on every sync — but not plugin packages, because the bundle list lives in the
machine-local `~/.dsh/profiles/web/package.json` and the packages are junctioned into
`profiles/node_modules`. So the one script that guarantees the invariant ran only when a session
happened to remember, which is exactly the failure mode its own header describes.

## The fix
`sync.py` now calls `install-client-plugins.ps1 -RequireAll` as the last step of every sync:
- Windows-only (`os.name != "nt"` returns early) — the installer is PowerShell;
- `--dry-run` announces what it *would* run and still writes nothing;
- a non-zero result returns **1 (attention)**, not 2, and prints the last three output lines, so a
 bundle that cannot resolve is loud and attributable rather than a silent missing tool.

Verified on ZABZ-YOGA: dry run printed `client plugins: would run install-client-plugins.ps1
-RequireAll`; the real run printed `client plugins: every bundle name resolves` and exited 0.
