**L1989 · A memoised probe inside its own wait loop: 60 reads of the first wrong answer**

MEASURED 2026-09-18. Test-OriginsProxy memoises its answer in $script:OriginsAlive so a 16-slot status call makes one HTTP round trip instead of sixteen. Start-OriginsProxy then polled Test-OriginsProxy in a 25 s wait loop - and read its own FIRST, FAILING answer back every 400 ms for 25 s, then declared "origins proxy never answered" and threw, while the proxy was up and serving all 24 ports. The launcher then started a SECOND instance, which split the port range (3200-3215 vs 3216-3223) - healthy from any single port, broken as a whole.

RULE: a memo used to save round trips must never be read by the loop that is waiting for the thing to change. The wait loop now passes -Fresh to clear it before each check.
