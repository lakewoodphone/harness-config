**L6655 · The persona points agents at journal/README.md as the journal map - it is a byte-identical copy of the repo README (cmp -s)**

**The persona points agents at a file that is not the journal's map.**

The standing instruction to every session reads: *"The full mechanics — the five entry kinds, every read
command and its flags, the state tier, the append-only rule, `check` and the repair commands — are in
`journal/README.md`. Read it once; it is the map."*

Measured 2026-10-16 on `secratary-cloud`:

```
$ wc -lc journal/README.md README.md
 276 14613 journal/README.md
 276 14613 README.md
$ cmp -s journal/README.md README.md && echo IDENTICAL
IDENTICAL
```

`journal/README.md` is a byte-for-byte copy of the repository's top-level README. Its first heading is
*"Harness configuration — single source of truth"* and its sections are `Layout`, `The agent fleet
(scripts/agent-fleet.ps1)`, `The window fleet (multi-window/)`, `Profile patches`, `Plugin packages`,
`Applying it`. **An agent that follows the instruction reads about presets, profiles and the window
fleet, and learns nothing about the journal.** It does not name the canonical tree, it does not mention
convergence, and the only occurrence of the word "canonical" in it is `presets/ # canonical agent
presets`.

It is **not** one of the journal's legacy inputs — `FLAT_FILES = (("HANDOFF","handoff"),
("LESSONS","lessons"), ("PAIN","pain"), ("DECISIONS","decisions"), ("WINS","wins"))` — so nothing
parses it as journal content, and it can be replaced. The defect is the pointer, not the file.

**This is the estate's own §6.3 defect applied to the instruction surface:** *"a rule in one surface is
not a rule — check the surface the caller actually reads."* The journal's mechanics were documented by
the tool's `--help`, by `SPEC-v2.md`, by `AUDIT.md` and by the tests, and were pointed at from nowhere
an agent is told to look.

**WHAT I DID INSTEAD OF EDITING IT.** The journal's map now exists as `journal/CONVERGENCE.md` —
where the record is, how to read it from another machine, how an entry reaches it, which instrument
answers which question, and the traps this work paid for. Verified not to disturb `check` (0 errors, and
no warning names it).

**NOT DONE, and it needs a build:** correcting the sentence itself. The persona is generated by
`scripts/make_zabz_preset.py` and the surface reaches three machines, so changing where it points is the
`deliver-persona.py` path — a deliberate, verified, three-machine change, not a line edit made in
passing. Until then the new file is reachable by name but not by instruction.
