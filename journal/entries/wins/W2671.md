**W2671 · 2026-10-08 · LPT wave-two: diagnosing the false positive, clean-worktree deploy, live-box verification.**

WHAT MEASURABLY WORKED.

1. DIAGNOSING THE FALSE POSITIVE INSTEAD OF ACTING ON IT. deploy-backend.sh exited 3 and printed a
 rollback command naming lpt-lpt-backend:8c99290be12b. Rolling back would have reverted a healthy
 production backend to an older commit for no reason. Running /opt/lpt/guard-check.sh instead gave
 POSTURE INTACT rc=0 on the same box, and reading the script's own source showed `open_q` calling
 `q()` (a GET) against two tRPC mutations. The mechanism was found, not guessed, and it became
 PR #308. LESSON: when a check's failure and its subject disagree, suspect the check.

2. A CLEAN WORKTREE MADE THE WHOLE PROMOTION POSSIBLE WITHOUT TOUCHING A DIRTY CHECKOUT.
 `git worktree add -b deploy/w2-prod-20261008 <path> <merge-commit>` gave a tree with no tracked
 changes, so the deploy script's dirty-tree gate passed honestly AND the frontend's `git archive`
 exported exactly the promoted commit. No `--force`, no stashing, no `git reset --hard`.

3. THE COMMITTED PROBE HARNESS GAVE REAL BROWSER EVIDENCE FOR SCREENS THAT NEED A SESSION.
 Production staff sign-in fails, so the authenticated counter screens are unreachable on
 production. `frontend/src/features/staff-intake/__probe__/*` and
 `frontend/src/components/layout/__probe__/*` render the REAL component trees with only
 `src/lib/trpc` stubbed, driving real Chromium at four viewports. That is how checks 3-9 were
 measured on the promoted commit rather than asserted.

4. VERIFYING A FIX ON THE LIVE BOX RATHER THAN IN A LOG. The corrected guard probe was scp'd to
 lpt-apps and run against the real production backend: POSTURE INTACT, exit 0, where the shipped
 probe gave POSTURE BROKEN, exit 3. A fix that only passes a syntax check proves nothing.

5. MEASURING THE DEPLOYED ARTIFACT BY HASH. The live bundle's SHA256 equals the local build's
 byte for byte (9D96F90F...D92D3, 3,809,964 bytes), which is stronger than "the filename changed".
