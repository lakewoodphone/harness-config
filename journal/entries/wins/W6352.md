**W6352 · 2026-10-13 · sync.py now verifies what it deployed -- the last check nobody ran.**

THE LAST CHECK NOBODY RAN. Now it runs on every machine, on a job that already exists.

WHAT WAS WRONG, and it is the same defect this program kept finding in other people's work: two drift
checkers were written (`preset-drift.py` for the instruction surface, `deployed-drift.py` for the
scripts), both correct, **neither scheduled.** A check that a session has to remember is a check that
does not happen -- which is precisely why the corrected instructions sat in git for two days while
every machine loaded the old ones.

THE FIX: `sync.py` now ends by asking **what the machine LOADS**, not what it did.
`verify_loaded_surface()` runs `preset-drift.py` and reports the answer:

 MATCH -> "loaded surface matches the repo (compared 15 match=15 drift=0 missing=0)"
 DRIFT / MISSING -> printed, AND filed to the journal once per distinct drift
 repo disagrees with itself -> reported, deliberately NOT alarmed
 tool missing -> "UNVERIFIED", never clean

The distinction between the middle two matters: a repo disagreeing with itself is tidiness in the
repository, not a failure to deploy, and alarming on it would train the reader to ignore the alarm.

AND IT RIDES ON `PersonalSecretary-HarnessSync`, which already runs on every Windows machine. No new
timer, no new thing to remember.

VERIFIED IN A THROWAWAY REPO with its own journal tree, driven through a stub so every branch is
exercised without touching a live surface: MATCH -> True and files nothing; DRIFT -> False, files
once, and the entry names `sync.py` and warns that **the repo is not automatically right** (two
scripts were recovered FROM the deployed side this week, so that warning is earned); the same drift
again -> no duplicate; a dry run -> no alarm; a missing tool -> False. The real journal is asserted
unchanged at 3,826 entries before and after.

WHY THIS IS THE RIGHT PLACE FOR IT: the other four "correct in the repo, absent where it runs"
failures this week were all found by a human asking the question. This one is asked by the job.
