Round 2 of the LPT-website session (2026-10-20 late), all measured on the carrier branch
`integrate/website-20261020` and verified on ZABZ-TECH. GitHub Actions still refuses to start any job

MEASURED WINS, each with the command that produced it:

1. The phone probe exists and has run (F0-4, PR #513). `frontend/scripts/measure-phone.mjs`,
 393x852, 4x CPU throttle, cold cache. Carrier build: `/` LCP 652 ms, 340.3 kB transferred,
 12 requests, entry 163.9 kB gzip, CLS 0.0000. The deployed pre-cut build on the same routes:
 LCP 1,020 ms, 927.5 kB, entry 894.6 kB, CLS 0.0804. Scoreboard rows 5, 7 and 8 went from
 "NOT MEASURED" to numbers. Caveat recorded in the doc: the local run has no network latency, so
 the gap is consistent with the chunk cut and is not proof of it.

2. One hours source (F1-3, PR #514). `features/settings/shopHours.ts:getShopHoursLines()` is now the
 only place the customer week is written, rendered by a shared component on the footer, the
 homepage, /contact and the FAQ, with a contract test that fails if any surface types its own
 sentence. The four surfaces now print identical lines.

3. The shared shell covers the last two public routes (F1-4/F1-5): /kosher-waze and
 /find-a-computer, and /kosher-waze is now a footer and homepage destination. The shell contract
 parses every literal route out of App.tsx and MVPRouter.tsx and fails if one is neither shelled
 nor listed as an exception.

4. `/computer-finder` no longer canonicals to the homepage. It renders the same page as
 /find-a-computer and had no row in the route table, so a no-JS fetch advertised `/`. The table
 gained `canonicalPath`, the generator now emits its document (14 documents, 13 sitemap entries)
 with `noindex, follow` and `canonical -> /find-a-computer`, and an alias is allowed while an
 accidental duplicate still fails the build.

FOUR THINGS THAT WERE WRONG AND ARE NOW RECORDED AS SUCH:

 hand-typed `SCREEN_REPAIR_PRICES` array whose provenance is a comment. Typing six more arrays would
 be the anti-pattern the roadmap forbids, so the item is now "build the feed", not "add six tables".
- F0-1's "prerender" is the HEAD half only. `dist/screen-repair/index.html` is bodyBytes=76,
 visibleTextChars=0 - the body is still the app mount point. Split into F0-9 rather than ticking
 F0-1 as a bigger win than it is.
- The FAQ claimed "Fridays until 1.5 hours before sunset"; `backend/src/lib/business-hours.ts:69`
 makes Friday drop-off-only and no sunset rule exists anywhere. Owner queue #863 asks which is true;
 the hours item stays unticked until it is answered.
- My own patch was a silent no-op: I asserted the function NAME existed and then replaced a body that
 did not match, so nothing was written and the test kept failing. The corrected script asserts the
 body it edits. A patch that cannot find what it edits must fail loudly.
