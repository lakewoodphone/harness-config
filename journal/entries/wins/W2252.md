## Why it counts

* The CRITICAL was false on its own terms: the boundary condition is now written
 down (every channel dead), so the check can go green without anyone waiving it.
 An alarm nobody can clear is an alarm nobody reads (L5).
* The real fault -- questions filed into a channel that can never send them -- was
 invisible to the old check by construction, because it read `MAX(sent_at)` across
 every reason and the daily briefing kept that number fresh. It now has its own
 measurement (`reason='ask_owner'`), and the live check printed the finding with a
 five-month-old date in it (newest question ever sent 2026-04-16T12:00Z).
