**W2741 · The test environment had been undeployed for three days because a deploy ran out of disk, and the fix was 30 GB of superseded images**

MEASURED 2026-10-12, `lpt-apps-01` (the Hetzner box that runs both `lpt-backend` and
`lpt-test-backend`).

`test` had not moved since **2026-10-09 17:38** while the branch had. The deploy run
`37964094831` had failed with

```
ERROR: failed to extract layer sha256:933795ab…: write
/var/lib/containerd/.../snapshots/6086/fs/app/node_modules/.pnpm/aws-sdk@2.1693.0/…/appsync.d.ts:
no space left on device
FATAL: docker build failed (exit 2)
```

The disk, read before the fix:

```
/dev/sda1 75G 68G 4.0G 95% / <- 4 GB free
docker system df: Images 23 total, 43.52GB, RECLAIMABLE 30.51GB (70%)
 7 x lpt-test-lpt-test-backend: 4.44GB each (only ONE was running)
 2 x lpt-lpt-backend: 4.44GB each (only ONE was running)
```

Removing the superseded images — keeping, per app, the running image and ONE
rollback image — took it to **25 GB free (67%)** in about a minute, and the deploy
that was in flight then completed:

```
Untagged/Deleted: 7 x lpt-test-lpt-test-backend + 1 x lpt-lpt-backend
BEFORE /dev/sda1 75G 68G 4.0G 95%
AFTER /dev/sda1 75G 48G 25G 67%
```

THE SHAPE OF THIS DEFECT, because it has now cost two deploys (production on
2026-10-08, test on 2026-10-09): **every deploy keeps a 4.44 GB image and nothing
removes the previous one.** Roughly nine deploys fill the disk, the tenth fails at
the export step, and the environment silently stops moving while `git` says the
branch is fine. The failure names `aws-sdk` and `containerd`, so it reads like a
build problem rather than an arithmetic one.

THE FIX, AND WHAT IS STILL MISSING. Doing it by hand worked. What does not exist is
anything scheduled, and the deploy script (`scripts/deploy-backend.sh:293`) builds
without first asking the target how much room it has — so the next failure is
identical and equally silent. The smallest useful change is a step before the
build: read `df` on the target, and if the build cannot fit, reclaim superseded
images and re-measure before `die`-ing with the numbers.
