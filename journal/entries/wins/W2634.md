**W2634 · 2026-10-05 · W: One queue replaced four channels, and it refuses to answer from a stale input.**

MEASURED AND VERIFIED 2026-10-05, rounds 1-5 of the contact-queue goal.

WHAT WORKS NOW
A single command on secratary produces the whole customer-contact picture:
 cd ~/_scratch/dialpad && python3 refresh_all.py
Three stages in the only correct order - refresh_case_phones.py, build_contact_queue.py,
build_worklist.py - and stage 2 REFUSES TO RUN if stage 1 output predates the case index.

WHY IT MATTERS
The old queue read unanswered SMS only. Dialpad''s badge counts missed calls, voicemail and
SMS together, so my number looked defensible and was blind to about 90% of what the shop was
flagging. The merged queue reports, verified at 2026-10-05T20:0xZ:
 still_open 184 / open_with_sms 88 / open_with_voicemail 17
 open_with_ring 129 -> credible 91, unverified 38
 a_person_actually_spoke_or_wrote 100

THE GUARD, AND ITS OWN FIRST FAILURE
build_contact_queue.py compares the case index mtime against the stamp written by
refresh_case_phones.py and exits 2 with an explanation if the stamp is older. Its FIRST
version did not fire, and the reason is worth keeping: the stamp lines are padded
("index mtime : ..."), so splitting on ":" left trailing spaces in the keys and every
lookup silently missed. A guard that looks correct and never fires is worse than no guard.
It is now tested by test_stale_guard.py, which fakes an old stamp, asserts exit code 2, and
restores the stamp - PASS recorded.

THREE CORRECTIONS THIS WORK MADE, ALL THE SAME SHAPE
Every one was a one-channel reading reported as the whole answer:
 1. the "answered" test looked only for a later SMS; the shop returns voicemails with an
 OUTBOUND CALL. Adding that took open items 255 -> 183 and fixed 7 of 25 voicemail
 verdicts, one of which had been answered with a 6m30s call.
 2. "38 unanswered voicemails" was wrong for the same reason; the answerable figure is 17.
 3. a stale case-phones snapshot made the work list report "56 needing a case file" AFTER
 the files were written.
The lesson is L3336 and L3338.
