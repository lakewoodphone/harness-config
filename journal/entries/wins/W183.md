**W183 · 2026-09-16 · Read the owner's live insurance policy out of the insurer's portal, unattended, including email MFA.**

What worked: launched Chrome via Playwright with a persistent profile (~/accounting-data/browser-auth/plymouthrock/profile), completed Plymouth Rock eService MFA by choosing 'Use email instead' and reading the 6-digit code out of the owner's own Gmail through app.services.gmail_service, then read the authenticated SPA.

Result: policy status, period, coverage schedule, premium, pay plan, payment history, and the declarations page and NJ insurance ID card as PDFs — all first-hand, no guessing, no call, no owner involvement. That is what turned 'I don't know if I'm insured' into a settled fact plus one decision.

Two things made it work: keeping the profile persistent so the session survives between runs, and reading the code fast (codes expire; internal_ts is milliseconds; submit within a minute).
