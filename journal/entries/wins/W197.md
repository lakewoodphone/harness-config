**W197 · 2026-09-17 · The drift line showed the slide before it happened, and one run undid it (placeable 12 -> 0 -> 12).**

The drift half of the node-hygiene policy paid for itself the first time it was pointed at a loaded
machine, and the number that did it is one line.

On 2026-09-17 ZABZ-YOGA was deliberately loaded with a named 10.2 GiB Node hog (resident 10,369 MB)
plus three small processes. The report run at 03:56:36Z printed, without being asked anything:

 placeable=0 (memSlots=-3 coreSlots=12) gate_free=3995MiB gate_maxchildren=2
 drift prev_d=-8611 MiB in 262 s rate=-33031 MiB/h over 0.22 h placeable_d=-12
 zero_children_in_h=0 trend=shrinking

That is the whole point of the stream: the capacity contract would have said "free memory is low",
and the broker (reading it honestly) would simply have stopped choosing the node — which is the
failure that cost the Mac mini 32 hours of being quietly unusable (74-mac-mini.md §4, §8). The drift
line instead says **when** it happened (`prev_d=-8611 MiB in 262 s`), **how fast** (-33 GiB/h), that
the placeable count moved by exactly the twelve children it lost, and that the time to zero children
has already arrived. A human reading one line knows which node to fix.

And one run of the shipped policy undid it: at 03:57:36Z,
`reclaimed 1 process(es) [node.exe/17688]: 9412 MiB resident let go; reclaimable_rss_kb 9637912 -> 0`,
and one second later the gate read `freeMiB 14477, swapUsedPct 0.0, budgetSlots 24, maxChildren 12`
with the report at `placeable=12 … placeable_d=12 trend=growing`.

Two properties made it trustworthy enough to believe: the after-number was a **re-measurement** of the
process table (the first version of that code printed `179572 -> 179572` on a run that had just killed
both processes, which is exactly the kind of number that looks fine and is not), and the sparing case
ran in the same pass — the unlisted hog and the same `cmd.exe` binary outside the listed prefix both
survived, so "it reclaimed 9.4 GB" and "it took only what it was told to" are one measurement, not two
claims.
