finished, session failed anyway". That mode now counts zero.

it shows the branch fires and decides correctly, which is what was in doubt. It is not yet evidence
about the long-run failure percentage, because the company's traffic has been suppressed by the wedged
autopilot (P2129) for most of the window. **Every percentage I quote from this period is bounded by
that.** The correct claim is: the fix routes correctly on every post-fix session observed; the effect
on the overall rate is unmeasurable until the loop has run healthy for a day.
