**W38 · 2026-09-14 · The DRN fleet is manageable from the portal, and four of its numbers are now measured.**

The staff Waze page can now do the three things the owner said the DRN fleet needs, and
four of the numbers on it are now ones I measured rather than assumed.

Working and verified:
- The DRN staff table has per-row Open, and the new MDM panel shows device facts, last
 check-in, installed profiles with the age of the observation, lockdown apply/lift, and
 Lost Mode. Backend deployed to the test stack and its four new procedures probed live.
- The confirm gates actually gate: empty, lowercase and near-miss tokens all leave both
 destructive buttons disabled; only exact SERVICE WINDOW / LOST MODE enable them. Verified
 6 input states in the browser against the live API, and nothing was clicked, so no MDM
 command reached any phone.
- "Could not determine" renders as itself with the server's reason, and says in words that
 it is not the same as "no profiles". This is the defect the whole change grows out of:
 a check that reported MISSING for profiles that were installed.

 53, with the 9 retired phones named as excluded. Match with the monitor's own exemption.
- Every timestamp the fleet-api emits is now ISO-8601 UTC with a Z, so no consumer
 computes a wrong age by reading a timezone-free string as local time.
- The unbounded database connect that I had just put on a request path is bounded, with a
 test that fails on an unbounded connect.

The honest limits, stated rather than smoothed over:

 visibility is genuinely unknown, not empty. The panel says exactly that.
- The frontend is verified but NOT published: Netlify refuses deploys on exhausted
 account credits (queue row #16). test.lakewoodphoneandtech.com still serves the previous
 bundle. The verification ran against a locally served build with a different API base,
 and that is named wherever the result is reported.
- A deferral that is now closed: the owner named "push a profile" as a DRN need, past-me
 deferred it in a commit message, and it is now built and verified.
