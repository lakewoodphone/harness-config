## 2026-10-07 · VERIFIED: the WhatsApp injection technique works on iOS 27.0, not just 26.x

WHY THIS MATTERED: everything in the playbook was proven on iOS 26.5 (iPad) and 26.2. Sara Kramer's
destination phone arrived as an **iPhone 16 (iPhone17,3) on iOS 27.0, build 24A437** - two major versions
past anything we had touched. If Apple had changed the backup manifest, the whole landing route would have
needed re-deriving.

MEASURED ON THAT DEVICE (2026-10-07, ~11:54 local):
- **`pymobiledevice3` 9.7.2 DOES back up an iOS 27.0 device.** Result: 7,521 indexed files, 125 MB,
 clean (0 AppleDouble junk). So the old library is not blocked by iOS 27.
- **The manifest format is UNCHANGED**: same `Files(fileID, domain, relativePath, flags, file)` schema,
 same MBFile keys (Birth, Flags, GroupID, InodeNumber, LastModified, LastStatusChange, Mode,
 ProtectionClass, RelativePath, Size, UserID), and **still NO content digest**.
- `RequiresEncryption: 0` on this device, and the unencrypted manifest carries **no EncryptionKey** -
 so the simple path (and the synthesised-record path for media) applies exactly as documented.

CONCLUSION: the iOS-backup injection technique in `sops/IPHONE-WHATSAPP-INJECTION-PLAYBOOK.md` is not
version-specific in the way that mattered. Verified across 26.2 / 26.5 / 27.0.

OPERATIONAL NOTE WORTH KEEPING - "Device locked" (MBErrorDomain/208) and how it was actually beaten
A one-shot backup command CANNOT be synchronised with an operator unlocking a phone by hand: the screen
re-locks and the command fails with 208. New tool `scripts/ios-whatsapp/backup-until-unlocked.sh` retries
in a loop, cleaning the target each attempt, and succeeds on the first attempt that catches an unlocked
device (it caught it on attempt 2). Also: a full backup needs the device to STAY unlocked for its whole
duration - set Display & Brightness -> Auto-Lock -> Never first. Pairing/trust was never the problem -
`idevicepair validate` returned SUCCESS throughout.

STATE: the phone is CLEAN - 256 apps, all system, **no WhatsApp at all**. Nothing can be injected until
WhatsApp Business is installed and registered with 732-998-0915, because the container rows the injector
replaces are created by that install. Gate: WhatsApp's verification code for her number.
