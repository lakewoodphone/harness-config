**W127 · 2026-09-15 · Profile coverage went from 1 of 65 to 34: the fleet now answers 'is the kiosk installed?'.**

The fleet now answers the question support actually asks: is this phone locked?

BEFORE
Exactly 1 of 65 devices had ever answered a ProfileList - the record was lost with the
pre-2026-08-14 history - so the portal showed "Could not determine the installed profiles"
for 64 of them, including every phone we manage. "Is the kiosk installed on this phone?"
was unanswerable.

CHANGE
`POST /fleet/heartbeat?profiles=true` sends ProfileList instead of DeviceInformation. It
is the same mechanism, still read-only (no profile, no setting, no lock), one bad device
still cannot stop the sweep, and a ProfileList reply doubles as a liveness signal because
it updates `last_seen`. Scheduled daily at 06:15 UTC with stale_hours=0; the 6-hourly
DeviceInformation heartbeat stays as the cheap one.

RESULT, FIRST SWEEP
55 devices asked, 0 enqueue failures. **34 devices now report their real profiles, up from
1.** DRN 1, which read "Could not determine" an hour earlier, reports:

 DRN Device 1 - Sponsored by Lakewood Phone & Tech [com.abletel.waze.layeredkiosk.drn1]
 Waze Web Trap Proxy [com.abletel.waze.webtrap]
 Waze Siri Result Filter DNS [com.abletel.waze.sirifilterdns]
 Waze MDM Enrollment [com.abletelsolutions.waze-mdm]

WHY THAT MATTERS BEYOND THE UI
- It is the device's own testimony that it is fully locked, which independently
 corroborates the July provisioning and is the evidence I did not have when I wrongly
 claimed the fleet had never been set up.
- Support can now verify a phone is locked BEFORE and AFTER a service window instead of
 assuming it, and lockdown can be confirmed rather than hoped for.
- The kiosk identifier is the per-DRN variant (`layeredkiosk.drn1`), which is exactly the
 trap the deployment docs warn about - visible per device now.
- DRN 26 still reads "unavailable", correctly: it is the one phone genuinely not answering.

KEEP THIS
The portal's "Installed profiles" is only as good as the last sweep. It shows the age of
the observation for that reason, and it must keep doing so - a profile list from a week ago
is not a statement about now.
