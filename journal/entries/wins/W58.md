**Addendum to W57: the loop-closure code exists, is in the running build, and its tests pass — so the 72 unapplied need a different explanation**

W57 fixed two reasons the evolution engine inflated its own unapplied count (the stall reset clearing the
exact-duplicate guard, and vendor trees not being excluded). It also flagged that commit `cd25a430`
("fix(evolution): make the self-improvement loop able to close at all") was on `origin/ops-evolution-loop`
and **not** on `origin/master`. Checked, and the flag resolves better than expected:

- `cd25a430` **IS an ancestor of the running code** on the authority (`git merge-base --is-ancestor cd25a430
 HEAD` -> yes; HEAD `a080c228`). It is not on `origin/master`, so other machines and the eventual
 reconciliation lack it, but the live engine has it.
- It changed `app/autopilot.py` (+54), `app/evolution.py` (+38),
 `app/services/evolution_verifier.py` (+31) and added `tests/test_evolution_loop_closes.py` (142 lines).
- **`tests/test_evolution_loop_closes.py` passes 5/5 on the authority's own tree.**

So the mechanism P4 says is missing is *present in production and tested*. That retires the simplest reading
of P4 ("nobody built the closure") and leaves a sharper question: **with the closure code live and green,
why are 72 proposals still unapplied?** The candidates, none yet measured:

1. proposals that *cannot* be applied — which is what my vendor exclusion addresses (18 offers aimed at a
 file npm overwrites);
2. proposals that apply but fail verification, and the verifier reverting them by design;
3. the apply path not being *reached* on the engine's schedule, as opposed to failing when reached.

Distinguishing those is the next measurement, and it is cheap: the engine writes `evolution_log` with an
`applied` flag and `evolution_verification` exists as its own table, so the split is a query rather than an
investigation. **The honest state of P4 is now "the closure exists, the closure is tested, and the residue
is unexplained" — which is a better place to be than "unbuilt", and a worse one to guess from.**
