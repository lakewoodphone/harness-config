The four files still failing are the same four that fail on the pristine branch,

WHY THIS IS A WIN AND NOT A COINCIDENCE. Without the baseline, "4 failing files"
reads as a broken branch and stalls a deploy; with it, it reads as **30 tests
fixed and none added**, which is a number you can put in a PR and act on. The
baseline cost one extra suite run (~12 minutes, in the background) and it is the
reason the remaining redness is a known quantity rather than an argument.

THE RULE IT CONFIRMS (L3386): a suite verdict is evidence only about a DELTA
against the same machine's pristine base. Absolute counts are not.
