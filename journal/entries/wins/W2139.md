**W2139 · 2026-09-20 · W2155 - the instrument works and the number is decisive: a run takes 648.4s against a 300s interval.**

The timing instrument (W2138) produced its first real reading 2026-09-20 18:45:26Z:

 WARNING app.autopilot: run_once took 648.4s, longer than its 300s interval - a run cannot fit
 its own schedule at this cadence (recent: [648.374])

**This settles the autopilot question with a measurement instead of an inference**, and it settles it
against what I expected:

 - **648.4 s, not ~480 s.** An earlier estimate of ~480 s came from the gap between two `last_run_at`
 values (17:38 -> 17:46) - but `last_run_at` is written at the END of a run, so that gap measured
 run-to-run spacing, not run duration. The instrument measures the thing itself.
 - **600 s timeout and 648 s duration are consistent**: the loop abandoned the run at its ceiling and
 the run, unable to be killed, carried on and finished 48 s later. That is the latch fix's whole
 point - an abandoned run no longer blocks the next one (`skips=0`).
 - **It exceeded 300 s on an idle box** (load 0.45-0.72), confirming L2139: this is not a load problem.

**So the arithmetic is now exact rather than approximate:** a run takes 648 s and the interval is 300 s,
so **every single run both overruns its schedule and is abandoned at its timeout**. There is no cadence
at which this loop completes normally, and D2093's recommendation (raise the interval to 900) is
confirmed as the right first step - 900 s is the smallest round number above the measured 648 s.

**The instrument's own design is validated by the same reading.** It recorded the duration of a run that
was ABANDONED. A `return`-side instrument would have recorded nothing, because an abandoned run never
returns - which is the case that matters and the only one I could not previously see. The `finally` was
the right place.

**A note on the estimate I published earlier.** I recorded "~480 s" in L2139 and D2093 as though it were
a measurement. It was a difference between two timestamps of a metric written at a different moment than I
assumed. The instrument took one round to build and immediately corrected a figure I had already acted
on. **Cheap instruments beat careful reasoning about what a timestamp means.**
