**W35 · 2026-09-14 · The journal costs 6.6 KB to consult instead of 590 KB, and the read path is bounded by design.**

The journal now costs a bounded read to consult. Measured on 2026-09-14:

| Question | Before | Now |
|---|---|---|
| "Where do I stand?" | six files, 590 KB, ~150k tokens | `journal.py status` — **6,590 characters**, and it fails loudly past 12,000 |
| "What happened last?" | read 273 KB to find the newest entry at the top | `newest handoff 1` — **4 KB** |
| "Have I hit this before?" | grep six files, then read around every hit | `search` — matching lines with the entry heading beside them |
| "Is the record intact?" | nothing could answer | `check` — 0 errors, and it exits non-zero on a real one |
| "What is open?" | read `PAIN.md` (1,067 lines) and infer status from prose | `state/open-pain.md`, generated |

*Measurement:* `journal.py status` = 6,590 chars; `journal.py check` = 0 errors / 4 warnings; `journal.py
kinds` = handoff 68, lessons 164, pain 57, decisions 69, wins 42. The one unbounded read is now impossible
rather than merely discouraged, because the index carries line ranges and every read is a slice.
