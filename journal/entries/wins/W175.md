**W175 · 2026-09-15 · Chumash Timeline: seven parallel workstreams, a live app audited, rebuilt and deployed in one night.**

## W — One job, seven parallel workstreams, a live app rebuilt and deployed in a night

**The job.** "Pull up the whole chumash tracking and gematria app and program we are making, it needs
to be audited and fixed and engineered and brought to the next level… use the multiagent flow to
orchestrate and delegate the job to many subagents and get to work seriously."

**The shape that worked.** Seven *read-only* audits partitioned by exclusive file scope (search/API,
data/DB, gematria engine, live UX, auth/security, build-deploy-docs) plus an eighth whose only job was
to **disprove** the other seven. That produced ~90 findings including 9 criticals. Then seven
*workstreams*, each in its own git worktree and branch, each with a written contract (repo path,
branch, read-first list, exclusive file scope, forbidden paths, gates, definition of done, report
format, and the honesty clause), managed rather than built.

**What made the difference, in order of value.**

1. **The adversary.** A dedicated disprover refuted or narrowed nine claims, six of them mine —
 including "there are no backups" (there are: 20 restic snapshots nightly), "the container runs as
 root" (it does not), and "`gematria=26` wrongly returns 0" (0 is correct; no pasuk totals under
 229). Two of those would have sent work in a wrong direction. **Run one agent whose only job is to
 falsify the others, and make it publish a corrigenda list.**

2. **Freezing interfaces in the middle of the fleet.** Once two workers needed the same names — the
 persisted gematria columns, `searchPesukimByGematria({value,system,limit,offset}) → {rows,total}`,
 the 11 gematria system ids, the per-method era shape — I broadcast a frozen contract to all seven.
 Integration then had exactly **one** cross-worker break, and it was a *test's* stale name mapping,
 not a design conflict. One of my broadcasts ("land `agent/chumash-data` first") also saved a worker
 from a failing `tsc` by authorising an adapter it had already reasoned its way to.

3. **Partitioning by file, not by topic.** Zero file conflicts across seven concurrent branches. The
 only shared-file collisions were ones I created myself (`.env.local.example`, touched by me and the
 deploy worker) and I resolved them by hand.

4. **My own re-verification of every headline claim.** The cross-worker check that mattered most: W1's
 *persisted* gematria columns against W2's *independently rewritten* engine against *my own*
 from-scratch implementation — **0 mismatches of 17** sampled pesukim across five columns. Two
 independent implementations agreeing is the strongest evidence available here.

5. **Migrate-then-start as a written rule.** Discovered by making the mistake on a scratch database:
 the new code queries columns the migration adds, so starting it first 500s every gematria request.
 Written into `DEPLOYMENT.md` as a hard constraint with the exact commands — and followed on the
 real deploy.

**What went wrong, recorded so it is not repeated.** I "verified" a build fix by testing the *wrong
configuration* (I had already copied a corrected config into the worktree), and two subagents caught
me. I compounded it: my first kill-command swept up my own shell's process tree. And I chased a
trigram-index optimisation that turned out to be built on a `\uXXXX` escape PostgreSQL does not
interpret — the index did nothing, and I reverted it rather than ship a no-op that looks like
progress. All three are written up as lessons (L1618, L1630) rather than smoothed over.

**The result.** `main` went from 36 tests to **301**, typecheck 0, eslint 0 warnings, build 0, and is
deployed and verified live: the Hebrew corpus is clean (was contaminated on 1,082 rows), gematria is
correct (was wrong on 716), Method D's label and verse agree for today's year (they did not), the JPS
1917 translation and the parsha map are live for all 5,846 pesukim, era events no longer cross methods,
sign-in works for the first time, the Gregorian year is no longer 7,520 years wrong, Hebrew reads
right-to-left, and no secret is baked into the image. **19/19 live acceptance checks pass.**

**Honest gaps.** Method D can reach only 860 of Devarim's 956 pesukim — arithmetically forced, since a
century is 100 years and six units are longer than that; the alternative is moving the 1840/1940
anchors, which is the owner's call. Free-text search still costs 130–413 ms. A real end-to-end Google
login is unverified because it needs a human.
