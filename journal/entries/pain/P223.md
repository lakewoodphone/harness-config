## P223 — A paid supplier order has no delivery check: $167.96 sat unshipped for 148 days and the task about it was closed done

**Symptom.** Nothing in this company connects *a paid supplier order* to *a delivery*. On 2026-09-14 the owner had to remember that Global Direct Parts order **#161898** — 4x LG Exalt LTE VN220 Upper PCB, **USD 167.96**, paid by PayPal on **2026-04-19** — had never arrived. It never had: no carrier email, no PayPal "on its way" notice, no refund, for **148 days**. Every other order from the same merchant (#161657, #161899, #162234) carries a tracking record; this one carries none.

**Cause, three layers, each verified.**
1. `purchases` (2,678 rows) is populated only from eBay and Amazon order mail. A direct supplier order paid through PayPal never enters any ledger, so nothing downstream can count it. The row for #161898 was added on 2026-09-14 by hand — it had never existed.
2. Task **#1777** "Review new parts orders from Global Direct Parts (#161898, #161899) and update inventory" was closed **done on 2026-04-26**, two days after payment and while nothing had shipped. The same closed-while-unfixed pattern is already owner question #8 for the four broken syncs.
3. The merchant does send tracking — through PayPal's "your order is on its way" mail, which nothing reads. The signal existed and was ignored, not missing.

**Cost.** 167.96 USD of unaccounted spend, and it recovers only because a 180-day PayPal window happens to still be open (expires **2026-10-16**). A second instance would land the same way. This is the same class as the two earlier customer-data losses: the record existed and no process read it.

**Fix.** A delivery watchdog over `purchases` (once supplier orders are actually written there): for every order older than its expected ship window with no tracking record, raise a task and age it. Immediate: #161898 documented in `lpt-hub/docs/procurement/2026-09-14-global-direct-parts-order-161898-exalt-upper-pcb-unshipped.md`, task **25106** due 2026-10-12.

**Related.** The same session found the second half of the pair: Device Parts order #62415 sits at DHL with a ~USD 70 import-duty demand and a 5-day return clock, notified only by SMS to a Google Voice number (task **25105**).
