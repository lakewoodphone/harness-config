## P196 — The shared journal hub is a junk drawer: 42 branches, thirty from one day

**P-new — the shared journal hub is a junk drawer: 42 branches, ~30 from a single day.**

`git ls-remote --heads` on `/home/zabz/harness-config.git` lists **42 branches**, of which thirty are
`zabz-audit-20260914-rN` from one day's session, plus four `diverged-*`, two `preserve*`, and mine from
today. Each one exists because someone preserved work that had nowhere else to go -- which is the right
instinct and the wrong long-term shape: the hub now makes it hard to see *which* ref is the real lineage,
and the fork question (P134) is embedded in that noise.

The commits themselves must NOT be deleted blindly: for some of those branches the ref is the only thing
keeping the commits reachable. So the fix is a rule, not a purge: **preservation branches carry a date
and an owner** (`preserved-<host>-<YYYYMMDD>`), and a prune may remove a branch only when its tip is an
ancestor of another preserved ref or of master -- verified with `git merge-base --is-ancestor` per branch,
never by pattern. Until that exists, the count is recorded here so the next session does not have to
rediscover it.
