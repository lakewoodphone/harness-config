## P2128 — P2133 - one unusable tool costs 51 blocked calls a week and repeats forever because a work order orders the agent to use it

Measured 2026-09-20 on the authority, 7-day and 14-day windows.

 alibaba_onetalk_automation blocked : 51 (48-51 across the window)
 alibaba_onetalk_automation executed: 0 in 14 days
 share of ALL blocked tool calls : 5.8 % (51 of 879)

The mechanism is in L2133: the tool's Python signature requires `onetalk_url` and `api_key`; the
schema the model receives exposes neither and sets `additionalProperties: False`; neither value
exists anywhere in config or `.env`; and `work_orders.py` declares the tool REQUIRED in the
`seed_alibaba_procurement_cycle` steps, so `agent_worker`'s gate forces the call every 12 hours.

**Why this one deserves attention beyond its 51 calls.** It does not merely waste calls - it
*manufactures* follow-on work. The work order's own step text says: *"If sync_error is returned
(auth-required or sync-failed), log it and create_task with title='Alibaba auth required: re-login
needed' priority='high'."* So a permanently impossible tool produces a recurring high-priority task
asking the owner to re-login to something that was never configured. That is a loop that generates
owner-facing noise from a defect, and it is exactly the category the owner named as his biggest pain.

**Two honest dispositions, and the choice is the owner's because it is a business integration, not
code.** Either (a) supply `ALIBABA_ONETALK_URL` and an API key, and add both to the schema the model
sees plus to `config.py`; or (b) retire the Alibaba procurement cycle - disable the standing work
order and drop the tool from the department tool list.

**What I did not do, and why.** I did not invent a URL, and I did not silently disable the work
order. Disabling it is a business decision (it is a live procurement integration that may be wanted),
and guessing a credential would be worse than leaving it blocked. The mechanical cause is fully
identified, so whichever way the owner decides, the implementation is small.
