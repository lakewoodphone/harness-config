## P2943b — A child printed the fleet API bearer into its own transcript, and an inventory command is an outbound read

**P2995 · 2026-10-12 · A child agent printed the fleet API bearer into its own session transcript while provisioning the CLI, and nothing in the brief or the tooling stopped it.**

**What happened.** A mesh child was told to provision `FLEET_API_TOKEN` into a Windows checkout without
printing it, and it did write it into the file correctly (the outbox carried fingerprints only). But an
inventory step in its own scratch directory ran `Get-Content -Raw` over files it had created earlier in
the same run — `token_raw.txt` / `auth_env.txt` — and surfaced the cleartext value once into its stored
session transcript. It reported this itself, unprompted, which is the only reason it is known.

**Why it matters anyway.** `FLEET_API_TOKEN` is the bearer for the whole MDM control plane: it reads
every device, provisions Telnyx SIMs, applies and removes lockdown profiles, and enables Activation Lock
on customer hardware. It is not a customer or financial credential, and the shop machines already hold a
copy, so the blast radius is bounded — but a live secret now sits in a transcript on a laptop that is
backed up and synced, and a transcript is not a place a secret can be deleted from.

**The fix is two habits, not one.** (1) Never let a PROVISIONED secret sit in a scratch directory as a
file: read it from its canonical location at the moment of use, or write it straight into its destination
and never to an intermediate. (2) An inventory command is an OUTBOUND READ of every file it prints —
`Get-Content -Raw`, `cat`, `type`, `Select-String` over a directory is exactly how a secret reaches a
transcript, and a "gather evidence" step is where it happens because nobody thinks of evidence-gathering
as an outbound action. Both belong in the brief of any child that handles a credential.

**Open, and whose it is.** Rotation is a coordinated act (the fleet-api container's `.env` on
`waze-mdm-01`, `/opt/lpt-test/.env`, `/opt/lpt/.env`, and every checkout that holds a copy), so it is not
a five-minute change today. Recorded rather than done, and deliberately not raised with the owner this
session because it is not his decision and it blocks nothing — but it should be done before the token is
copied anywhere new.
