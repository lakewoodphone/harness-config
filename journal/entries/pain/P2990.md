## P2990 — the website's Print Label button still cannot print anything - it posts to localhost:8080

The website's Print Label button still cannot print. The tool that CAN print now exists
(`lpt-label`, proven 2026-10-08), but nothing connects the two.

What is broken: `backend/src/services/print.service.ts` posts to `PRINT_SERVICE_URL`, which is
documented as `http://localhost:8080` - the Heroku dyno itself. There is no print service there,
and none reachable from there.

What would fix it: run the print service on the authority (which is on the printer's LAN and
already proven to print) and point `PRINT_SERVICE_URL` at it through the existing Cloudflare
tunnel, replacing the Home Assistant add-on that never worked. This is engineering, not an owner
decision - the only thing that touches the owner is that a shop-LAN device becomes reachable from
the internet, and that the endpoint must be API-key gated.

Until then: print labels with `ssh secratary-ts 'lpt-label ...'`, which works now.
