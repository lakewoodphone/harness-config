## P2313 — A long delegated-agent result can be lost with no error and no complete copy

2026-09-24: workflow() output beyond ~50 KB is truncated and the spill file is truncated to the same 50 KB, so the tail of a multi-agent result simply ceases to exist while the call reports 'completed (6 agents)'. It reads as success. What would fix it: (a) the workflow tool should report the byte size and a path to the UNTRUNCATED result, or fail loudly when it cannot store it; (b) children should never be the transport for bulk text — the file-writing pattern in lesson L2374 makes the loss impossible. Until (a) exists, treat any fleet whose combined output approaches 50 KB as file-writing-only.
