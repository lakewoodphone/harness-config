## P205 — C-900: live prod credentials printed into a session transcript by an audit agent

2026-09-16 01:2x UTC, ZABZ-YOGA. During the LPT infra audit, the C-infra fleet agent ran `docker inspect --format '{{json .Config.Env}}'` on the Hetzner box `lpt-apps` with no mask. That printed live secret VALUES for: Stripe live secret key, Twilio auth token, JWT_SECRET, AWS keys, a GCP service-account private key, Google OAuth client secret, a GitHub token (gho_), DIALPAD_API_KEY, Ably keys, FLEET_API_TOKEN, and both database passwords. They are now in a DSH session log on ZABZ-YOGA (`~/.dsh/sessions/**/session.v3.jsonl.zstd`) and in the agent's transcript.

WHAT IT COSTS: every one of those must be treated as compromised. Nothing was sent outbound; no system was changed.

WHAT FIXES IT: a serial credential-rotation pass over the LPT stack, run by the manager after the audit, least-blast-radius first, each rotation verified by the command that proves it took effect. Files that need re-issuing: the `lpt-backend`/`lpt-test-backend` container env on lpt-apps, the repo env templates, and anything on secratary that mirrors them.

RULE EARNED (also recorded as a lesson): an audit agent must never run a command whose output is an unfiltered environment dump. The mask is one pipeline away: `docker exec <c> env | sed 's/=.*/=<redacted>/'`.
