## P10059 — rollback hint in deploy-production.sh is broken, and work.py --left is not --left_over

Two papercuts from the 2026-10-21 personality-test deploy.

1. deploy-production.sh prints a rollback command that cannot work. It sets PREV from the running container image ("personality-test:e7ab460a90df...") and then advises `sh deploy-production.sh $PREV`, but the script passes its first argument to `git checkout`, which cannot resolve an image name. The working rollback is to pass the sha (e7ab460a90dfda618752ea419579c113f35f2d7c) or to run `IMAGE_TAG=<sha> docker compose up -d --no-build`. Anyone following the printed hint during an incident loses minutes to a git error.

2. work.py attempt takes --left, not --left_over, despite the brief and the ledger field being called left_over. A long attempt is rejected with "unrecognized arguments" after the whole command has been typed.
