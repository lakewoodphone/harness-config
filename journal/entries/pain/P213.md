## P213 — The LPT intake funnel failed silently at five points, and its worst failure mode was a quiet fallback

**Recorded 2026-09-16. Ranked by cost to the business, from the LPT website-redo audit.**

**1. The intake funnel silently dropped its own leads.** The website computer-finder is dead at five independent
points, and the Google Form that used to feed sourcing has been repointed away - so sourcing requests are being
submitted to a form nothing reads. Nothing reported it because each failure returns a soft result: the webhook
returns `status:'skipped'` with no error when its env vars are absent, the form's save failure shows a generic
"try again", and no staff view reads the table. **Fix: make every one of those five steps fail loudly, and give
staff a view of submissions.** A funnel whose failure mode is a quiet fallback is a funnel that is already broken.

**2. The live site published a fabricated address for at least a day.** "123 Main Street ... Highway 99 ... blue
storefront" rendered on the homepage next to the real address. Cause: a tRPC query called with no argument, whose
catch returns `getMockFaqs()`. **Fix: a catch block that substitutes invented content must never be the default
path in production. Either the query is correct or the page shows nothing.** Suggested concrete rule for this
codebase: mock/fallback data must be dev-only or carry a visible marker.

**3. Seven SEO pages have never been indexable.** Client-side-only metadata plus an sitemap listing three URLs.
The cost is invisible - no error, just traffic that never arrives. **Fix: prerender at build time.**

**4. Production's backend cannot be rebuilt from the repository, and its security posture lives in a hand-patched
image layer.** This already bit once: a routine `docker compose up -d` reverted six guards and exposed an
endpoint that minted live Stripe Terminal tokens, and nothing alarmed. **Fix: reconcile the build context against
a named commit and rebuild.** Until then every deploy is a coin flip on whether the guards survive.

**5. The promotion has never been run - 102 commits, zero PRs to main.** The gate explicitly permits it. **Fix:
one promotion, after the `systemLog` guard is in source.** This is a process hole, not a technical one, and it is
the cheapest of the five.
