## P2551 — I reported a 59-test copy guard as 'a rule, not a promise' - it was running ZERO tests, and a green suite containing no tests is the most dangerous green there is

A test file that runs no tests reports success, so it passed every gate I ran and I reported it as working.

**VERIFIED BY ME AFTER THE FIX: `Test Files 1 passed (1) · Tests 67 passed (67)`.** Before: 0 tests. **A green suite that contains no tests is the most dangerous kind of green there is, and I reported it as a strength - twice.**
