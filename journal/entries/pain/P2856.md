## P2856 — Owner profiles: the code, the runbook and the registry notes disagree about lockdown, so a reconcile would lock the owner's phones

WHAT HURTS: The owner's two profiles do not match what the registry, the RUNBOOK and the code all
say about them, so any future session that tries to "reconcile desired vs actual" will lock the
owner's own phones.

- `app/services/nanomdm_service.py::make_owner_personal_phone_profile` documents itself as
 "Light-touch personal phone profile ... without any kiosk lockdown. All apps remain visible and
 usable." It then sets `allow_ui_app_installation=False` (no App Store),
 `allow_safari=False`, `allow_app_removal=False`, and `allowed_bundle_ids` = 21 specific apps.
 The June runbook row agrees with the code ("Locked-down profile — only 21 allowed apps, no App
 Store, no Safari"); the registry metadata for GMG9TQ6R56 and the class description agree with
 the docstring ("Fully open profile — MDM for Find My/remote wipe/location only"). Three sources,
 two stories.
- The owner's standing instruction for his spare SE is "device fully allowed"
 (`mdm_fleet_devices.metadata_json`, 2026-06-09). A `desired_profile` of `owner_mobility` or
 `owner_personal_phone` with a `profile_state` that reads as drift is a loaded gun pointed at a
 phone that must not be restricted without him asking.

WHAT WOULD FIX IT: one source of truth per profile. Decide what each owner class means — the
likely answer is "MDM management only: remote wipe, lock, activation-lock bypass, Find My; no app
restriction" — then either (a) change `make_owner_personal_phone_profile` to emit no restriction
payload and add a separate, explicitly named `owner_car_phone` profile for the Waze/Spotify/Maps
set, or (b) accept the lockdown and correct every doc, docstring and registry note that says
"fully open". Until then, **do not auto-install an owner profile**; install only on the owner's
request. Both owner phones are currently unrestricted (no profile installed, verified 2026-10-05),
so nothing needs undoing.

EVIDENCE: `nanomdm_service.py:2102-2133`; `mdm_fleet_devices.metadata_json` for FFMD39W5PLJM and
GMG9TQ6R56, read on both registry stores 2026-10-05; archive runbook
`deploy/waze-mdm/archive/2026-06-29-old-runbook.md:102`.
