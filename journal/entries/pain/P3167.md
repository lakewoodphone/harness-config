## P — The shop devices dialled a machine that had been frozen two days earlier, and only the owner's eyes caught it

**When:** found 2026-10-13, ~14:30Z. **What it was:** the LPT shop counter devices (DRN 2001/2002/2003)
wore a managed profile naming `secratary.tail93e6e6.ts.net` as the DSH web clip and as the only permitted
web-filter URL. That box has been the FROZEN rollback anchor since the 2026-10-11 05:43:36Z cutover, with
no phone stack on it. The clip could not load, so iOS drew a grey square. **The owner found it, not a
check** — and he found it as a cosmetic complaint ("the shortcuts have no icon"), which is what a dead
endpoint looks like from the outside.

**Why nothing caught it.** The migration's six governing documents cover hosts, service state and the
phone path; this file is configuration on a *third* host, inside another product's MDM
(`/opt/waze-mdm/profiles/`), owned by a different runbook. No check in the estate reads "what address do
the devices dial". A repo-wide grep for the old name returns 40 hits and not one of them is this file —
because the file is not in that repo.

**What it cost.** Two days of a shop device whose primary shortcut was dead; one grey-icon report; the
owner's attention on a thing a check should have named. Not customer data, and the fix was small — the
cost is that it was invisible until it was ugly.

**What would fix it.** A **cutover inventory**, written into the migration brief and run on the first hour
after any host change: enumerate *every stored absolute that names the old side* by asking the systems that
dial them — each device's own profile list (`ProfileList` via the MDM), each gate's allow file, the
clipboard of saved shortcuts — and record the answers next to the ones the documents already name. The
cheap version, and the one that would have caught this: after the cutover, pull the MDM's `ProfileList` for
every device in the `lpt` and `waze` fleets and grep the returned plists for the retired hostname. The
machinery already exists (runbook §6, `diagnose <DRN>`); nobody pointed it at this question.

**Related:** L (a managed web clip reads only the payload's `Icon`), L (a cutover leaves the configuration
that names the old host), D (the MDM repoint), runbook §12, `docs/mesh/146` (same class of miss, one
surface over).
