## P267 — Built-in web_search returns HTTP 402 for every session (DeepSeek balance empty)

Every session's `web_search` call fails with HTTP 402 Insufficient Balance from the DeepSeek endpoint, so the built-in search is silently useless until someone pays. Two separate things have to happen and only the owner can do the first: (1) top up the DeepSeek balance, or repoint the search endpoint in Settings > Plugins > Plugin configuration > Web search to a funded Anthropic-compatible Messages API; (2) nothing — the Jina/Firecrawl MCP tools already cover search, read and PDF, so no work is actually blocked. What makes it hurt: the failure only surfaces when a session happens to need a search, and the error text ("Search endpoint configuration is separate from chat") reads like a config problem rather than an empty wallet, so a future session may burn time re-diagnosing it. Fix that costs nothing: default to the MCP search tools and treat `web_search` as unavailable until the balance is restored.
