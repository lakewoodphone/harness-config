## P3004 — Nothing outside the authority reads the new estate-monitor's own liveness file - a whole-box death stays invisible

WHAT HURTS. The authority's silent-failure monitor is now the best instrument on that box, and **nothing
outside the box reads it.** `/root/.estate-monitor/last-run` is written on every run and
`monitor_run_gap_s` plus the per-metric `max_age` staleness pass turn everything `CRIT` — *"reading
stopped arriving"* — after two missed runs. But if the **whole box** dies, the thing that would report it
is dead too, and the file simply stops advancing with no one watching.

MEASURED. Installed and proven 2026-10-11 06:34–06:40Z: `estate-monitor.timer` `OnCalendar=*:0/2`,
`Persistent=true`; five runs in the journal, the 06:36:02 and 06:40:02 ones on the schedule. Nothing else
in the estate reads `/root/.estate-monitor/` (grep of the fleet: the only consumers are this monitor's
own `--json` and a human).

WHY IT MATTERS. This is `135` §6.7's own finding, one layer up: *"every heartbeat this system keeps is
read by something on the authority, so if the authority dies, its own health checks die with it and the
owner learns nothing."* The dead-man switch (`authority-deadman.timer`, healthchecks.io) covers the
box-death case from outside, and the monitor now reads that switch **from both sides** — which is exactly
the right detector for the detector. What is still missing is the inversion: an **external absence
check** on this monitor's own liveness file.

WHAT WOULD FIX IT, cheapest first.
 1. Add `/root/.estate-monitor/last-run` to the dead-man switch's context body (one line in
 `authority-deadman.py`'s `body_now()`), so an alert that does arrive carries the monitor's own age.
 2. Better, and the real fix: make the check that runs **outside** the authority — the vault's own
 heartbeat on `lpt-apps-01`, which already probes `https://ai.abletelsolutions.com/health` every 2
 minutes and writes `/var/lib/company-heartbeat/state.json` — also alarm when that file's age exceeds
 one interval. It is already the right machine in the right place with the right reachability; it is
 simply not told to look.
 3. Do not solve this by putting the reader on the authority. A reporter that lives on the thing it
 reports on is not a reporter — that is the whole of §6.7.
