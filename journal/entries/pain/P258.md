## P258 — harness-config is diverged (ahead 1, behind 5) and the journal's entries never reach origin

**Measured 2026-09-17 ~19:30Z on ZABZ-YOGA.** `~/code/harness-config` reads `## master...origin/master [ahead 1, behind 5]`. The journal — the organ that makes me continuous across sessions — is committed locally and **not reaching origin**, and dozens of entry files sit **untracked** in the working tree (H467–H470, D252–D2085, and more), written by sessions on this and other machines that never committed them.

**Why this is worse than untidiness.** A future session can only read what this one learned if the entry reaches the machine that session runs on. With origin 5 behind, a `git push` is rejected non-fast-forward, so a session that believes it has recorded a lesson has recorded it **for one clone**. **The failure is silent:** the entry exists, `journal.py check` exits 0, `journal.py show <id>` works, and no other machine ever sees it.

**Contrast, and it matters.** The four entries written this session (L1954, P257, W206, H526) are committed (`a89b361`), so they are durable **here** — but durability in one clone is not continuity.

**Not fixed in this session, deliberately.** The working tree holds other sessions' untracked entries and modified `scripts/owner-attention-digest.sh`, and the 5 unpulled commits may touch `journal/tools/journal.py` itself — the tool every live session is running right now. Reconciling a shared clone out from under running sessions is the wrong trade for a session that cannot see both sides.

**What would fix it.** (1) Reconcile `master` against origin — a small gap, behind 5 / ahead 1 — reviewing `journal/tools/journal.py` first, then push. (2) The derived `journal/index/*` and `journal/state/*` churn is safe to leave alone (the index rebuilds itself when stale), **but untracked `entries/**` files are absorbed by nothing** — no sweep commits them. A scheduled `git add journal/entries && git commit && git push`, or one designated writer host, closes it. (3) The same root cause produced **P257** in `lpt-hub` (ahead 27, behind 9). **Unpushed work in a diverged clone is this fleet's recurring silent failure, and it is silent in exactly the place meant to defeat silence.**
