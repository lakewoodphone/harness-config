## P4633 — A verdict produced on a schedule and consumed by nobody is still a silent system

Measured 2026-10-16: /usr/local/bin/finance-reconcile.sh runs weekly, builds /root/.cfo/balances-live.json and /root/.cfo/reconciliation-worklist.md, and raises no flag. grep -rln for those two paths across /root/bin /usr/local/bin /root/ceo-kernel/scripts /opt/company/scripts returns only the script itself. Its own docstring calls reconciliation the CFO program second completion condition, and it had been reporting 68 disagreeing account-months and 667 unjudgeable ones into a file nothing reads. The fix is not a better report, it is a consumer: wire the verdict into the existing /root/bin/sources/_flag.py wake convention so a disagreement is work. Until then finance-freshness logs quiet while 70 percent of account-months cannot be judged.
