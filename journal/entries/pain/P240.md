## P240 — The spend guard's ceiling is per-engine: two engines on one host share one state file

FOUND 2026-09-17 while building the guard (docs/mesh/101 section 8.2).

packages/plugin-cost/src/guard.mjs keeps its day in <DSH_HOME>/spend-guard/day.json. Two DSH engines on one machine share that path and each overwrites the other's total, so each sees roughly one engine's spend. Bounded, but not additive, and it is not visible from the code.

WHAT WOULD FIX IT: a per-engine state file (suffix the path with the engine pid or a profile name) PLUS a fleet roll-up that posts each host's hourly total into the authority, so a single ceiling can bind across engines and machines. The roll-up is doc 65 section 3.6 / P209's own recorded fix and is still not implemented.

SEVERITY: medium. A machine running two engines is unusual today; the cross-MACHINE gap (ZABZ-TECH was 56.5 pct of the worst day) is the bigger half of the same hole.
