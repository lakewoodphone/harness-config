## P2870 — The GitHub mirror of harness-config diverges and rejects push

**The GitHub mirror of harness-config diverges and rejects push, so the offsite backup is stale.**

`origin` on ZABZ-YOGA has **two push URLs** - `secretary-ts:/home/zabz/harness-config.git` (the
authority, source of truth) and `https://github.com/lakewoodphone/harness-config.git` (offsite).
A push goes to both. On 2026-10-08 a commit (`e4b5bdeb`) reached the authority ("Everything
up-to-date" on that URL, confirmed by `git ls-remote origin refs/heads/main`) and was **rejected by
GitHub with non-fast-forward**, while the local remote-tracking ref showed zero commits behind.
GitHub's `main` has moved independently.

Not forced - that is not mine to rewrite unasked. The consequence is real: if the authority is lost,
the offsite copy is missing whatever diverged. It needs a reconciliation (fetch GitHub into a
separate remote, compare, merge deliberately), not a `--force`.

Fix would be: add GitHub as its own remote (it already exists as `offsite`), stop pushing to two URLs
blindly, and reconcile the divergence explicitly with a record of what each side holds.
