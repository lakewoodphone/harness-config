## P3178 — P — What runs and what is in git are two artifacts, and the difference is silent

**What hurts.** In this estate, **the thing that runs and the thing in git are two different
artifacts, and the difference is silent.** Measured instances, all on the Waze/MDM stack alone:

| What runs | Where | What git has | Consequence of deploying from git |
|---|---|---|---|
| `fleet_api.py`, 7024 lines | `waze-mdm-fleet-api-1:/srv/` | 6761 lines (`7ed6dbcf`) | loses an entire store-device wallpaper feature (§10.1 of the runbook, still open) |
| `doh_filter.py` + Apple location allowlist | `waze-mdm-01:/opt/waze-mdm/dns/` | no `ls.apple.com` allow at all | CoreLocation network-assisted positioning blocked on every device, no error |
| `shop-store.mobileconfig` | `waze-mdm-01:/opt/waze-mdm/profiles/` | pre-filter copy | web-content filter silently reverted (three separate times) |
| `DEFAULT_ALLOWED_DOMAINS` / `DEFAULT_BLOCKED_DOMAINS` in `doh_filter.py` | they are **dead code** | they look like the policy | editing them changes nothing in production — the host `.env` wins |

**So the whole family has one shape: a file that looks authoritative, is editable, is deployed, and
is not what runs.** Every retelling of the lesson ("derive from production", "diff both copies") has
been written down before, in `docs/lpt-shop-device-runbook.md` §3 and §10 — and *the next session
still had to catch it by hand*, which means the discipline is documentation, not mechanism.

**What would fix it, in order of value:**
1. **A drift check that runs and shouts.** One scheduled job that, for each deployed artifact,
 compares a declared host path against its declared git path and reports a mismatch with both
 shas. It would have caught all four rows above without anyone remembering anything.
 `doh_filter.py` alone is a two-line `diff <(tr -d '\r' < host) repo`.
2. **A deploy script per artifact that refuses to run without a drift check and a backup**, so
 "deploy" stops being "copy a file I believe is right".
3. **Read the running service back**: `sha256sum` inside the container, then one real query. Cheap,
 and it is the difference between "I deployed" and "it is deployed".
4. Stop planting defaults in a file whose environment always overrides them: either the file is the
 policy or the env is, and the code should fail loudly if both exist and disagree.

**How this was found today:** only because the deploy was being done carefully, by hand, one file at
a time. The next one will not be.
