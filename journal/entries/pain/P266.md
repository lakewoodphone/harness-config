## P266 — Android worktrees fail Gradle with 'SDK location not found' because local.properties is gitignored

Every fresh git worktree of the Android repo starts without android/local.properties (it is gitignored), so :app:testDebugUnitTest dies in ~2 min with 'Could not determine the dependencies of task :app:testDebugUnitTest > SDK location not found'. Cost: one wasted 2-minute Gradle run per fleet agent on this repo. Fix (cheap): cho sdk.dir=C:/Android > android/local.properties before the first Gradle call on ZABZ-YOGA (SDK lives at C:\\Android; the main checkout at ~/code/kosher-filter-ai/android/local.properties says exactly that), or export ANDROID_HOME. Durable fix would be for the fleet bootstrap script to copy local.properties (or set ANDROID_HOME) into every worktree it creates.
