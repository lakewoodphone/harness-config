## P-new · `ps_search` was committed on whatever branch the production checkout happened to be on

**State, 2026-10-08 03:0xZ.** The secretary MCP server lives at `/home/zabz/personal-secretary-mvp/scripts/ps_mcp_server.py`
— the authority's production checkout, which is on branch `fix/557-posted-refresh-canonical-hash`.
`ps_search` (tool 20, committed as `b596336a`, one file, 39 insertions) is therefore **on a feature
branch**, and the same file on the laptop (`C:\Users\ezabz\code\personal-secretary-mvp`) does not contain
it at all.

**Why this matters.** This file *is* the agent tool list. A deploy or checkout from any other line that
does not carry that branch silently removes the search tool from every agent on the authority — the same
class of loss as the skill that no catalog could see, and silent for the same reason: nothing asserts
that the tool list contains the tools we expect.

**Fix, in order:** (a) carry `b596336a` to the trunk that deploys this file; (b) mirror the change into
the laptop's copy so no deploy can regress it; (c) add an assertion — the MCP tool list must contain
`ps_search`, and a check that fails loudly when a tool we depend on is missing from it.
