## P2938 — Curl 403 on Cloudflare-fronted academic PDFs (philpapers, philsci-archive) blocks primary-source quotes

2026-10-12, cluster H dossier. philpapers.org/archive/FEFGIT.pdf and philsci-archive.pitt.edu both return 403 to curl and to web_fetch (Cloudflare 'Just a moment'). Workarounds that worked: author-hosted copies (math.stanford.edu/~feferman/papers/penrose.pdf), author slide decks (indico.cern.ch), ar5iv.labs.arxiv.org for arXiv HTML, and the Stack Exchange API for SE content. Where only a paywalled/blocked source has the wording, the dossier marks the characterisation UNVERIFIED rather than quoting from memory — one subagent caught itself drafting a Crelle citation from memory and replaced it with UNVERIFIED, which is the correct behaviour. What would fix it: register a general note that Feferman/Koellner/Franzen primary text sits behind 403s and route to the author-hosted mirror first.
