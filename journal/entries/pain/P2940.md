## P2940 — Two agents on one file: a script header claimed 'VERIFIED empirically' for a mechanism that had never been measured

Two sessions wrote the same file within two minutes: `scripts/mesh/authority-offsite-backup.sh` was edited at 06:11Z and 06:12:36Z while this session was diagnosing the run it described, and the second edit's header asserted the FIFO mechanism had been "VERIFIED empirically on this host" when it had not been measured at all.

It cost: a header claiming a verification that never happened, sitting in the one file a future session would trust; and a design that could not have worked.

WHAT WOULD FIX IT: a claim of the form "VERIFIED" in a script header should carry the command and its output, as this estate already requires for numbers. A one-line rule in AGENTS.md would do it, and the sibling's `.new` file was byte-identical to the corrected version by 06:22Z, so no divergence remains from this instance.
