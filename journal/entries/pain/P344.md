**11 of 14 were world-readable** (`-rw-r--r--` or `-rw-rw-r--`), each a complete snapshot of every
API key, token and webhook secret the company holds, sitting inside the git working tree since
30 August. This is the fourth instance of the same class in this system's history: an AWS key killed,
a Twilio token rotated, and on 2026-09-20 a mesh child printed `DIALPAD_API_KEY` in full plus two
webhook JWTs into a session transcript.

Two of them are already stale in the good sense - `-striperoll-` and `-twilirot-` mark rotations
that happened on 2026-09-15, so their Stripe/Twilio values are dead. The rest are not known to be
dead, and `/home/zabz` is an allow-all-tailnet host.

**Fixed immediately and reversibly: `chmod 600 .env.bak*`** - all 13 now `-rw-------`, zero
world-readable, no file deleted and no key rotated. That removes the exposure without breaking a
single consumer.

**Left open deliberately: key rotation.** That is the owner's decision, not mine - rotating the
DeepSeek, Cloudflare and Google keys breaks every consumer until each is updated. See D334.
