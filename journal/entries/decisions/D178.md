**D178 · 2026-09-15 · Chumash Timeline: the 11 gematria systems are redefined to published, non-duplicate methods.**

## D — the 11 gematria systems are redefined to published, non-duplicate methods

**Decision.** The Chumash Timeline gematria engine exposes exactly these 11 systems, each a
distinct formula under an exact published name:

| id | published name | definition |
|---|---|---|
| `hechrechi` | mispar hechrechi (absolute value) | sum of standard letter values 1..400 |
| `gadol` | mispar gadol | five finals valued 500..900 |
| `siduri` | mispar siduri (ordinal) | 22 letters 1..22, finals continuing 23..27 |
| `katan` | mispar katan (mispar me'ugal) | per letter, truncate the zeros, then sum |
| `katanMispari` | mispar katan mispari | sum standard values, then reduce the total to one digit |
| `prati` | mispar p'rati (ha-merubah ha-prati) | square each letter's value, then sum |
| `merubahKlali` | mispar ha-merubah ha-klali | per word, square the word's standard value |
| `boneh` | mispar bone'eh (revu'a) | cumulative running sum of letter values |
| `kolel` | kolel / mispar musafi | standard total plus the word count |
| `milui` | otiyot be-milui (mispar shemi) | each letter valued by its spelled-out name |
| `kidmi` | mispar kidmi (mispar meshulash) | each letter valued as the sum of preceding values |

**Dropped:** `mispar ha-mispar` (no published definition exists; its behaviour was a duplicate),
`kellali` (was a literal one-line alias of `katan`), `merubah` (renamed `prati`, because per-letter
squares are the published *p'rati*, not *ha-merubah* — the latter is `merubahKlali`).

**Why it was needed.** Three of the previously advertised eleven were mislabelled and four formed
two identical pairs, proved by zero differences across 75,571 inputs on four corpora: `kellali` was
`return gematriaKatan(hebrew)`, and `katanMispari` was byte-identical in output to `mispar`.
Additionally `katan` and `katanMispari` were **swapped** relative to their published definitions, and
`boneh` used `Σ(letter²) + letterCount` where the published *bone'eh* is the cumulative running sum
(`אחד` = 1 + 9 + 13 = 23; the code returned 84).

**Source.** The "Methods of Hebrew gematria" section of the English Wikipedia *Gematria* article,
which the audit cross-checked against he.wikipedia. Chosen deliberately over inventing definitions:
where no published definition could be found, the method was dropped rather than guessed.

**Consequence, stated plainly:** if a user later asks for a different reading of a contested system
(e.g. `siduri` with finals equal to their base letters rather than 23–27), that is a one-line change
plus a test-vector update — not a redesign. `siduri`'s UI label must disclose its finals convention,
because it changes the result for 92% of pesukim.
