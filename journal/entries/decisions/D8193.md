## 2026-10-19T22:30Z · ZABZ-YOGA · the scheduler's prize measured by replay: 16.1 %, no key needed

### The number

`scripts/cost/schedule_backtest.py` replays the real `model_usage` rows through the **deployed** price
book - the same code the service runs - and prices the same tokens at the cheap band. Read-only; no
model call, no write. 14,783 calls over 7 days:

| scenario | actual | projected | saving | % | peak share | calls moved |
|---|---|---|---|---|---|---|
| `dept_*` only | 99.20 | 83.18 | 16.02 | 16.1 | 26.79 → 6.20 | 2,836 |
| all but orchestrator | 99.20 | 80.80 | 18.40 | 18.6 | 26.79 → 3.16 | 3,235 |

≈68.7/month conservative. **With no key, no provider and no purchase** — so the scheduler is not gated
on the owner at all, unlike routing. That is the important asymmetry and it changes the plan: the
scheduler is the lever that can be finished tonight.

### It also re-sizes the target

Peak is 20.8 % of the week, so the handoff's `SCHEDULE_CHEAP_SHARE_TARGET=0.8` (an 80 % cheap share) was
already met by the *baseline*. The reachable figure is a peak share near **6 %**. A target copied from a
brief rather than measured from the window is a target that cannot fail, which makes it worthless.
Set it from this replay.

### The residual 6.2 % is the design, not a shortfall

What stays in peak after the conservative scenario is the orchestrator and the non-department lanes -
exactly the exempt set. A policy whose exemption list is empty would score better and be wrong.

### The wiring point, identified and deliberately not used yet

`app/workforce.py::company_tick` walks the agent tree and ticks every active agent - the one place a
deferral can be applied. But the tick is where an agent reflects, claims tasks and reviews reports, so
skipping it is not free: a blanket skip could stall a department's task claiming for four hours, and
"no observable work" reads like health.

So before enabling: the skip must appear in `tick_telemetry` as a distinct state, not an absence, and
open tasks must remain claimable while parked. Then ship it inert by default, as with the router and the
pricing book.

### One bug found in my own instrument

SQLite's `datetime('now', '-7 days')` returns `YYYY-MM-DD HH:MM:SS` with a **space**, and the column
stores `YYYY-MM-DDTHH:MM:SS+00:00` with a **T**. `T` (0x54) sorts after space (0x20), so every row on
the boundary date passed regardless of its time - a silently over-inclusive window, not an error. Fixed
by building the boundary in the column's own format. Numbers from a boundary you did not check are not
numbers.
