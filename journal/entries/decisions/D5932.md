**D5932 · 2026-10-13 · Owner set the Schreiber prices: 50 further diagnosis, 75 plus the customer's USB for the data - and a stated price is not on the record until it is in production.**

**Owner-stated, 2026-10-13, on WO26100812737 (Schreiber, Dell Inspiron 15 3520), verbatim:** *"okay print a label saying the board may be bad, if they want further diagnosis it's 50 dollar diagnostic fee, and if they want we can get the data for 75 plus the cost of a usb"*.

**The two figures, and what they are for.** **50** is further diagnostic work on the machine - the shop's diagnostic fee, which the standing shop rule credits toward a repair. **75 plus the customer's cost of a USB drive** is recovering the data when the board is bad and no repair is done: the drive is bought at cost, the 75 is labour. Nothing has been offered to the customer yet; which one is collected depends on the path she chooses.

**What I did with it, and why the price gate forced the issue.** The order carried **total NULL**, which under the shop's own price gate (`lpt-ops` N9) means an open work order that can never be charged and can never be released. With a number in hand from the owner for the further-diagnosis path - and with the shop's own history showing every order carrying exactly 50 as a terminal no-repair case (UNFIXABLE / CANCELLED / ready-for-pickup-only) - I set **total = 50** (write ledger seq 380, `updatedAt` 2026-10-13T15:49:04Z) and recorded the reasoning in production note **3164** (BILLING). If the customer takes the other path the total becomes 75 plus the drive; if they walk away it becomes 0 with a reason. Each is a one-command change, and the case file says so.

**The generalisation, which is the transferable part:** a price the owner states in conversation is not a price on the record until someone writes it where the shop actually reads money. Setting it here took one command and closed a gate finding that had been open since 2026-10-08; leaving it in the transcript would have left the order unchargeable for as long as the machine sat on the shelf. Statement of the number -> the order's `total` -> the work-order note -> the case file -> the sync record's `pricing` block, in that order, in one session.
