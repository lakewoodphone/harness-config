**D88 · 2026-09-14 · D: scheduled tasks run through a hidden wscript launcher.**

DECIDED 2026-09-14 (ZABZ-YOGA).

- Mechanism: per-task generated .vbs + a wscript action (SW_HIDE at creation, wait, propagate exit
 code). Rejected: `-WindowStyle Hidden` (hides only after the window exists, so it still pops);
 moving tasks to a non-interactive LogonType/S4U or session 0 (the DSH watchdog must start an engine
 and the launcher opens Edge windows IN the interactive session, so the session must not change, and
 session 0 would need stored credentials).
- Scope: EVERY interactive scheduled task that launches a console host, not just DSH. The detector
 covers .exe hosts (pwsh/powershell/python/cmd/node/conhost), extensionless names (`cmd`, `python`)
 and .cmd/.bat scripts — the desktop had five such tasks the first pass missed.
- Durability: fix the registration sites (dshw.ps1 autostart + watchdog, Install-Autosync.ps1,
 install-node-agent.ps1, install-vscode-chat-sync-task.ps1) AND keep a daily self-heal in dshw.ps1,
 so a later regression from ANY installer is hidden without the owner reporting it a second time.
- Reversible: every conversion also writes <task>.json holding the original action, and
 `Set-TaskHidden.ps1 -Restore` puts the task back exactly as it was.
