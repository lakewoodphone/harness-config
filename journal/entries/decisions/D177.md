## D - personality-system: models resolved at runtime from the gateway, never hardcoded

**Decided 2026-09-15** (owner instruction, plus a measured production outage as the forcing evidence).

Context: the AI layer of `personality-system` failed on 100% of recorded live calls because
`secretary-provider.ts` hardcoded `deepseek-v4-flash` / `deepseek-v4-pro` and those names stopped
resolving. The change is not "use the right name" - that reproduces the bug at the next rename.

Rules decided:
1. Application code never contains a concrete model name. Selection is resolved at runtime.
2. The gateway (`SECRETARY_API_BASE`) is the source of truth via `GET /v1/models`.
3. **Route aliases are preferred over concrete ids** - `secretary-auto`, `secretary-fast`,
 `secretary-smart`. They are slots the gateway fills with whatever model is currently appropriate,
 so provider churn never reaches the app. `secretary-genius` is excluded (measured 502).
4. Operators override per tier through a comma-separated env chain (`AI_MODEL_FAST=...,secretary-auto`),
 so a model swap is an env edit + container restart - no code change, no redeploy of code.
5. A configured id is **validated against the catalog and DROPPED if absent**, and the drop is
 recorded. If the catalog is unreachable the value is accepted but marked `unvalidated`, never
 `known good`.
6. Catalog fetch is cached (minutes) with single-flight, and fails **soft** - a catalog outage must
 never break the user flow.
7. Provenance is published: per tier, the effective chain and where each entry came from. An
 operator must never have to read code to learn which model served a request.
8. An AI outage must never be **silent**. Failing soft to deterministic fallback is correct;
 failing invisibly is not. This is the specific failure that hid for over a week.

Also decided in the same pass, same reasoning: the deployment must expose which commit is running
(OCI labels from a build arg), and there must be a healthcheck - because "is production healthy?"
was unanswerable.

Applies to every app on `ai.abletelsolutions.com` and to the secretary router. Encoded into the
zabz persona (`presets/zabz/agent.cordis.yml`, committed d154b62, synced to every machine).

Evidence: journal H301; lessons L1606; `_scratch/gateway-models.sh`, `_scratch/gateway-alias-test.sh`.
