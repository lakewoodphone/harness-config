**D9307 · 2026-10-21 · D-35 the parent's visibility is a dial, and nothing is the red option.**

D-20261021-35 records the owner's answer to Q35 on 2026-10-21 ("The parent can set it up and
customize it."): what a parent sees is a setting, not a policy - nothing, blocks only, blocks plus a
weekly attempt count, or a weekly summary alone. "Nothing" is the red option: marked, explained,
argued against, and still his to choose. The default is the middle - every block with time, category
and rule, plus attempts as a weekly COUNT rather than a list. The child sees the setting including
when it is nothing (D-24). The chaver's window is a separate dial (D-09).

Requirements the decision creates, and which the code now owes: nothing about what was ALLOWED is
shown at any setting; a change of the dial is delayed (D-15) except widening, which must never be
instant; the summary is generated from the same rows the app enforces; support explains the dial in
one sentence and does not recommend a setting beyond the red marking.

Contradictions named in the file: a parent unable to see blocks because a default was chosen for
him; any view listing allowed activity; a visibility change the child's app does not show.
