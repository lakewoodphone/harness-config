**D73 · 2026-09-14 · Enum types in backend services are derived from the generated model, never imported by name.**

`Prisma.$Enums` does not exist in Prisma 6, and the previous hand-maintained import list (`DeviceType`, `BudgetTier`, … from `@prisma/client`) silently drifts when `schema.prisma` changes. `laptop-preference.service.ts` now derives each via `NonNullable<LaptopPreference[K]>`, so adding or renaming an enum value cannot leave the service stale.
*Cost of learning it:* one failed typecheck pass and one wrong guess (`$Enums`) written before checking what the installed Prisma actually exports.
