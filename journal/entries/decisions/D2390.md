**D2390 · 2026-09-23 · D — When someone speaks to Chip, he answers: direct address outranks the randomizer; the rails that survive it.**

**Decision (owner instruction, 2026-09-23).** Direct address outranks the randomizer. When a message is addressed to Chip, he answers. The rule and the rails around it, so this is not relitigated:

1. **Detection is content, not keywords.** `classify_address()` sends the recent turns plus the new message to the model and gets back CHIP or OTHER. The owner was explicit: it is about understanding the text, e.g. a brother replying "what about me" to Chip's message, which contains no keyword at all.
2. **Bypassed for an address:** dormancy wake roll, burst roll, guaranteed post-burst silence, dormant cooldown, burst cooldown, the 3/day unsolicited cap.
3. **Never bypassed:** `chip_enabled` (his kill switch) and the monthly budget. A budget block is loud - log + admin notice - because a silent block on someone talking to Chip is the failure this replaced.
4. **Its own allowance:** `chip_direct_max`, env `FAMILY_CHAT_AI_DIRECT_MAX`, 25/day, reason `direct flood`. Addressed replies do not consume the unsolicited cap (they get `chip_received_<date>`-style accounting of their own, key `chip_direct_<date>`) but they DO spend the monthly budget.
5. **Quiet hours:** answered by default; `chip_direct_quiet = "respect"` restores them. Rationale: the person texting is awake, and their own message already reached every phone.
6. **In flight:** an addressed message waits (bounded 150 s) rather than being dropped. The old unconditional stand-down was measured to lose the message entirely.
7. **Refusal:** if the model answers NONE twice, or the model is unavailable, an addressed message gets one honest in-voice line. Never a mood canned line.
8. **The classifier's reasoning stays ON.** Measured: with `thinking` off the same prompt scored 6/10 and missed every implicit address; on, 10/10. The token ceiling must cover thinking plus the word (a 128-token ceiling on a reasoning call returns empty content).

Companion decisions taken in the same pass (engineering, mine, recorded so they are not "found" again):

- `_keyword_hit` is word-boundary now. The live trigger list contained `ai`, which matched "said", "wait", "email", "Lchaim", "Raitzik", "Shaina", "details" - 15 of 24 keyword-matched turns were ordinary names and words. Keywords remain only as the fallback when the classifier is unreachable.
- Model ids are resolved against the provider's live catalogue at runtime with a configurable comma chain, and the id that served a call is recorded in `chip_model_last`. The previous default (`deepseek-v4-flash`) is not in the catalogue - it happens to be accepted as an alias, which is exactly the kind of luck that made personality-system fail silently for a week.

**Left to the owner (money and family, not engineering):** the monthly budget is $5 and one group reply costs about $0.18 across 11 phones, so the budget binds after roughly 27 replies. `chip_direct_max` is therefore not the real limit - the budget is. Raising it is his call; raised in the queue with a recommendation.
