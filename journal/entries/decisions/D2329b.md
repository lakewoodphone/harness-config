**A REAL BUG I INTRODUCED AND CAUGHT IN THE LIVE RESPONSE.** Changing the included allowance from `1` to `0.25` produced **`includedGb: 0`** from the API - because `WAZE_PLAN_INCLUDED_GB` used `.transform(val => parseInt(val, 10)).pipe(z.number().int()...)`. **`parseInt('0.25')` is `0`.** So the price card would have said "includes 250 MB" while the offer said **zero** - a silent contradiction between what the customer reads and what the system believes, and exactly the class of lie this project keeps finding. Fixed to `parseFloat` + `z.number().nonnegative()`, with the reason written into the comment. Verified live: `includedGb: 0.25`.
