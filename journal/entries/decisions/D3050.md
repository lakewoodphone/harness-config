**D3050 · 2026-10-11 · The mesh broker moves to the authority, and the authority is listed in every node gate allow-list.**

DECIDED 2026-10-12 ~03:20Z (ZABZ-YOGA). Context: the post-cutover mesh audit the owner asked for.

WHAT WAS DECIDED
1. `mesh-broker` runs on `secratary-cloud`, the authority — enabled and started 03:18Z. Its roster
 was replaced with the repo's (the staged copy did NOT exclude the frozen office box, so starting
 it as found would have spent leases on the rollback anchor).
2. The dispatcher defaults name the authority in BOTH paths: `profiles/web/cordis.patch.yml` (already
 retargeted in d143fb7a) and `bin/mesh-run.mjs` (still `secratary-ts` until this session).
3. `secratary-cloud` (`100.73.176.126`) is listed in `scripts/phone-gate-allow.txt` on every node the
 broker reads, because WITHOUT it the broker could read nothing (5/5 nodes HTTP 403) and answered
 every placement blind.

WHY THE THIRD ONE WAS NECESSARY AND NOT OPTIONAL
Measured from the cloud before the change: every node, every route, `HTTP/2 403 "Not signed in"`;
`GET /nodes?fresh=1` -> 5/5 unreachable `reason: HTTP 403`; `POST /place` -> `zabz-tech position 1
blockedBy ["unreachable","no-free-slots"]`. A blind broker still answers, so a dispatcher pointed at
it would queue every child and pile them onto one machine while four sat idle — strictly worse than
not moving at all.

WHAT IT COSTS, RECORDED IN THE FILE TOO
A listed device can be signed in automatically, so a compromise of the authority now also buys a
session on every machine listed above it, on top of the company database and API keys it already
holds. The narrow reason is the broker's READ path, not "the authority is trusted".

REVERTS (both one line)
- delete the `100.73.176.126` line to refuse the cloud again;
- stop `mesh-broker` on the cloud and put the broker back where it was to undo the move.

STILL THE OWNER'S: the office box's `mesh-broker` is still active/enabled and must eventually be
stopped to leave one broker for one mesh. That is a state change on a FROZEN host
(`settings/machines/host-posture.tsv`, guard exit 2) and is asked as one question.
