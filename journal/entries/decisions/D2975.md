**D2975 · 2026-10-08 · Card-lane build gate: production cannot build without a pk_live_ value, and a pk_test_ is refused by name.**

DECIDED 2026-10-08 in scripts/lib/frontend-deploy-config.mjs. The frontend could ship with NO publishable key and nothing said so; Stripe minted the intent and the page had nothing to confirm it with. Now publishableKeyRefusal() refuses a production build that takes real payments (VITE_MOCK_PAYMENTS !== true) unless VITE_STRIPE_PUBLISHABLE_KEY begins pk_live_. A pk_test_ value is refused by NAME because production secret key is live and a test key cannot confirm a live intent. Implemented as a REFUSAL (plan.refusals) not a throw, so --dry-run prints the plan and then the refusal instead of a stack trace. Shape: production map carries VITE_STRIPE_PUBLISHABLE_KEY: '' (empty is the refusable state, and an override still works because the key exists in the map). Both refusals name the Dashboard path and the live account. Consequence accepted: the frontend cannot deploy at all until the key is set - deliberate, because a deploy without it changes nothing about cards and would be recorded as progress. Tests: node scripts/test-deploy-metadata.mjs -> 39 passed 0 failed.
