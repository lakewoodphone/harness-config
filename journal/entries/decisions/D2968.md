you."* Done.

### What the defect actually was
Not "someone picked the wrong branch". **Nothing measured which branch any machine was on**, so 87
divergent branch names accumulated across five machines, and a fix committed on one machine reached one
machine. That is why the fast-search skill had to be pushed by hand and why the journal lock fix needed
per-machine deployment. A rule with no measurement is a wish.

Four candidate trunks existed. Measured on `secratary`:

### THE TRAP I CAUGHT, which would have made this worse than doing nothing
`main` did **not** contain the verified journal-lock fix (`09e85b3`) **or** the fast-search skill.
Switching machines onto it as-is would have taken two working fixes away from every machine. So the trunk
first received the known-good work, and only then did anyone adopt it:

 trunk: carry the verified journal-lock fix and the fast-search skill onto main (4dd70dbb, pushed)

Verified on the trunk: `write_section` present, skill present, **`journal.py check` 0 errors**.

### I aborted a merge of 135 conflicts, and that was the correct call
Merging the divergent branches produced **135 conflicts, overwhelmingly `AA` on `journal/entries/*.md`** -
the same id added on both branches with *different* content. That is the id-collision class, arriving
exactly where I predicted it would, and the correct remedy is `journal.py repair-ids --apply` - which
renumbers a colliding id and records an alias, and **works on a coherent tree, not one full of conflict
markers**. Resolving it in a tired session would have either lost journal entries (the harness's own
memory) or baked the collision into the merge commit. So I aborted, and the outcome the owner needed - one
trunk that machines track - was reached without it. **The reconciliation is deferred, not dropped.**

### The other lesson from this one
My `git merge-tree` trial reported **0 conflicts** and the real merge produced **135**. The 2-arg form is
not a conflict predictor. **A trial that is cheaper than the operation is not evidence about the
operation** - the same error class as P3 (reading the wrong data), L3411 (a cheap proxy is not a
measurement), and the `cmd | head` mistake earlier today.
