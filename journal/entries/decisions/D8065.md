## 2026-10-19T22:20Z · ZABZ-YOGA · cheap-hour scheduling and provider routing, rounds 1–3

**Owner's instruction, 2026-10-19:** have the company prioritise work during cheap time; during
expensive time route to DeepInfra / Fireworks / others when they are significantly cheaper than
DeepSeek direct, "even though usually we prefer deep seek direct".

Development decisions below are mine, recorded rather than asked. The only owner action outstanding is
a DeepInfra key.

### Decided

1. **Router before scheduler.** Routing to DeepInfra Flex is a 41.4 % cut with nothing delayed;
 scheduling is 21.7 % and requires delaying work. The handoff ordered them scheduler-first; the
 measurement reverses that. The scheduler is retained as the availability hedge — it is what saves
 money when the second provider is unavailable or its promotional price ends, which is the estate's
 exact state tonight.
2. **Prices are data at `docs/cost/prices.json`, never a literal in Python.** Hour bands, per-model
 rates, source URL and `read_at` per provider. `app/services/price_book.py` loads and validates it;
 `app/pricing.py::estimate_cost` consults it and now takes `at_utc` and `cached_tokens`.
3. **`PRICING_MODE=legacy` is the kill switch** and must reproduce pre-2026-10-19 behaviour exactly,
 bands ignored. Tested.
4. **Anti-fallback rule:** no tier or model is ever resolved by dict ordering. Validation refuses a
 tier set with no explicit `default_tier`. The first version of this file did exactly that and a test
 caught it.
5. **A residue window must be declared `catch_all`.** See lesson; without it Saturday morning is
 unpriced while every naive coverage check passes.
6. **Fireworks gets no key.** Its Standard rate is exactly DeepSeek peak.

### Deliberately not done

- No change to which model the company calls. The book prices; it does not yet route.
- No restart of `company-api`. The new code is inert until `estimate_cost` is called with a book
 available and a restart picks it up; measured, not assumed, before any restart.
- `deepseek-v4-pro` rows price implausibly (6.29 M tokens for 0.84 USD) — logged, not fixed, because it
 is 1.2 % of volume and unrelated to the hour question.
