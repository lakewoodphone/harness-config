**D241 · 2026-09-16 · Shlock's canonical design sources and recovery archaeology are now committed to git (lpt-hub/research/miscellaneous/shlcok-source, commit 9a8815799).**

**Decision.** The Shlock project's **canonical design sources and the archaeology that recovered them are now
committed to git**, reversing the earlier decision to keep them gitignored in `_scratch/`.

**Where.** `lpt-hub/research/miscellaneous/shlcok-source/` — 40 files, 18 MB, commit `9a8815799`, pushed to
`origin/main`. Contents: the canonical design (`2026-08-14-CANONICAL-DESIGN.md`), the v3 fabrication spec, the
entire drawing generator and its iteration trail (`build-drawings*.py`, `render-v7pages.py`, `make-pdf.py`,
`shlock-minimax-review.py`, `crop-parts.py`), the only surviving site photography (5 JPEGs + the beam overlay —
deleted from git in `9f56c820`, recovered from dangling objects), the Q4-2025 ancestor plan
(`Project Pla1.docx`), the two recovered record files (`000-shlock-current-start-here.md`, `SHLOCK-FILE-INVENTORY`),
and the nine 2026-09-17 recovery digests, with a README explaining why the files are there.

**Why.** The canonical design was deleted on 2026-08-08 (exit 0) and survived only by accident; recovering it
took six parallel searches across two machines, sixteen git repos, a 7.27 GB database, four mail accounts and the
mesh nodes. The earlier "gitignored, local to this laptop" decision was reasonable for byproducts and wrong for
the authority the whole project derives from. Evidence and the general rule: **`journal.py show L1832`**.

**Also decided.** The two derived documents that constitute the project's return-to point —
`2026-09-17-shlock-master-index.md` and `2026-09-17-shlock-status-and-next-actions.md` — live in the same repo
tree as the sources, so a future session that clones `lpt-hub` gets the design, the sources and the state in one
clone. Nothing about Shlock is now reachable only through a machine-local scratch folder.

**Consequence for other projects.** Any document that is *the* authority for a project should be checked with
`git check-ignore -v <path>` and recovered from a clone before it is trusted. The same audit should be run on the
other personal projects that keep a "sources of truth (gitignored, local to this laptop)" section — the pattern is
not unique to Shlock.
