## Decision 2026-10-21 · The product promise, in the owner's words (Q1)

Owner's answer to Q1 — "what is the sentence a customer repeats to a friend":

> "It is mine — every last thing is something I set for myself. It is very fast and doesn't block any
> usage I want, and only blocks things I don't want. It is fully my own guidelines, and it works very
> fast and well."

Recorded consequences, because the sentence is now the standard everything is judged against:

1. **Ownership is the promise, not accountability.** The shop's absence from every setting is what the
 customer is buying (D0 gains this as its customer-facing half). A shop override is not a support
 convenience; it is a breach of the sentence.
2. **It is also an accuracy promise.** "Only blocks things I don't want" makes a false block a broken
 promise rather than a tuning question — so over-blocking has to be measured and reported per rule,
 which nothing in the estate does today (filed as a ledger item on 2026-10-21).
3. **It is also a speed promise.** No latency has ever been measured on a device; every number in the
 tree is a code comment. The promise is currently unverifiable.
4. **"Mine" is hardest for a child's phone**, where the person holding it did not choose the settings.
 Q3 (whose filter is it when a parent sets it up) decides how the sentence is kept there.
5. Rejected by this answer: the "my kid cannot get around it and I see everything" framing, and the
 "nobody at the shop can see or change it" framing on its own. The promise is stated from the
 customer's side, in the first person, not from ours.
