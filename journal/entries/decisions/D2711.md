**D2711 · 2026-09-28 · sync policy: origin wins only where the local side is a measured regression; preserve to three places before moving; never auto-resolve a divergence.**

Sync policy used 2026-09-28 for the three-machine git convergence, so it is not re-litigated.

FOR harness-config (the harness's source of truth):
1. Take ORIGIN's version when two sides differ and the local side is a REGRESSION - measured, not assumed.
 On secratary, local commit c469c1b (a journal-commit autocommit of 69 paths) carried stale metadata shas
 and double-encoded headings against origin's repaired text; origin's tree checked out with 0 journal
 errors and the local one with 34. Bodies were otherwise identical, and no path existed locally that did
 not exist upstream (69 M, 0 A, 0 D).
2. PRESERVE BEFORE MOVING ANYTHING, in three places: the commit pushed to refs/heads/diverged-<host>-<date>
 on origin (verified by exact-sha ls-remote BEFORE the local branch moved), every dirty file copied byte
 for byte to a dated backup dir, and the commit exported as a patch.
3. Never reset, rebase, clean, stash or force - "no history was rewritten on any node" is a property this
 repository has maintained since 2026-09-14 and it held today as well.
4. Clear only what is PROVABLY not work: modified tracked files under journal/index/ or journal/state/
 (generated), and untracked files byte-identical to the incoming blob. Everything else is kept and named.
5. A pull refused for ANY other reason is reported as a real finding and the exact paths are named in the
 status - never a generic "needs a human".

FOR the other repos: fetch, fast-forward only when purely behind AND the tracked tree is clean, push only
when purely ahead, and report divergences untouched. Divergence (ahead AND behind) is never auto-resolved,
because that is where a merge needs a reader.

FOR the two real forks found (personal-secretary-mvp, ha-config): they are merge projects and were left
alone deliberately. Preservation refs were created so no tip exists in only one place.
