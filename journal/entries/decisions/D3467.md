**D3467 · 2026-10-14 · make_zabz_preset.py is the persona's source of truth again - every hand edit moved inward into it.**

**Context.** `scripts/make_zabz_preset.py` generates `presets/zabz/agent.cordis.yml`, and its `--check` had reported DRIFT since at least 2026-09-28. The committed output carried a comment saying the file "MUST NOT BE REGENERATED", because the generator would delete owner rules 8 and 9, the outbound hard-stops and the counterparty rule.

**Measured before the decision.** Running the generator produced 50,127 bytes against the committed 53,189, and what it would have deleted was worse than that comment claimed: `enableRunInBackground: true` on both mesh rows, seven documented incident comments, and — the serious one — **the company MCP rows still pointed at the FROZEN office box** (`secretary-ts`, `/home/zabz/personal-secretary-mvp/...`) instead of the authority (`secratary-cloud`, `/opt/company/...`). Regenerating would have re-created the 2026-10-11 migration defect that the company moved to the cloud to end.

**Decision: the generator is the source of truth, and the reconciliation goes INWARD — every hand edit moves into the generator, not the generator out of the way.** Rejected alternative: retire the generator and maintain the preset by hand. That leaves two sources and no guard, and this file has already proved it accumulates drift nobody notices.

**Done.** The persona round-tripped byte-exactly (a one-off script reversed the generator's own rendering, and the generator's `--check` — a byte comparison — is what verified it). The mesh rows, the MCP rows and the comments moved in. One now-false comment ("must not be regenerated") was dropped deliberately; one measured finding the committed file was missing (`skill-filesystem` registers nothing on 0.1.7) came back by regeneration. `--check` exits 0 and a further regeneration is byte-neutral (`7 insertions / 9 deletions` before it, `0` after).

**Rule this establishes: when a generated file must be hand-edited, the edit is not finished until the generator produces it.** A hand edit living only in the output is a change the next green regeneration silently deletes — and the deletion is invisible because `--check` will then pass.
