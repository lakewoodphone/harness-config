**D2839 · 2026-09-30 · The gateway resolves a short model id and the catalogue lists it; an unknown id is served loudly, never silently.**

THE OWNER SAID, 2026-09-15: ai models change very often, can never be hardcoded and get changed
and updated all the time, so we need robust easy flows for that. The standing rule that fell out
of it is: read the gateway own catalog, validate every configured id against it, prefer route
aliases, and never let an AI outage be silent.

THAT RULE WAS UNSAFE AS WRITTEN, and the reason is measured. GET /v1/models returned 38 ids and
none of them was `deepseek-v4-flash`, while POST /v1/chat/completions accepted it and answered
200. A caller obeying the rule literally would have dropped configuration that works.

DECISIONS TAKEN, 2026-09-30, all recorded in
`harness-config/docs/owner-text-and-one-brain-2026-09-30.md`:

1. The CATALOGUE changes, not the caller. A short id the endpoint accepts is listed as
 `kind: legacy_alias` with its canonical id, so the two agree. 38 -> 42 ids.
2. A short id is RESOLVED to its canonical id before pinning, so `deepseek-v4-pro` serves
 DeepSeek-V4-Pro-0813 rather than the cheapest capable model.
3. An id that is neither a canonical id nor a route alias is served on the SETTINGS OWN DEFAULT
 ROUTE and logged at WARNING. Not a hard error (the endpoint stays compatible) and not silent
 (the log and `model_usage` carry the truth).
4. One concept, one number: the autonomous owner-SMS ceiling is read from
 `OWNER_SMS_DAILY_QUOTA`. 0 blocks every autonomous send, -1 lifts the daily ceiling, an
 unreadable value warns and falls back to the documented 20.
5. A duplicate-send check is scoped to the last 24 hours. A check that stays red for a week
 after the fix is a check nobody reads.

WHY IT MATTERS BEYOND THIS BUG: the app three model tiers have never been three models. Every
component that named a bare id got DeepSeek V4 Flash. That is the mechanism behind the owner
complaint that the systems are not holistic enough to be the same brain -- they were not even
different models.
