**D7681 · 2026-10-19 · A reply to the owner's own text is a direct request, not floor traffic.**

**2026-10-19 · A reply to the owner's own text is a DIRECT REQUEST; the 20-minute floor is for unsolicited traffic**

Evidence: `sms_log` 4303 "That screenshot settles it…" (refused, "we texted him 10 minute(s) ago"),
4313 "Understood - mom's card, not mom's car…" and 4319 "You're right, and I'm sorry. Fuel = gas…"
(both "1 minute(s) ago"). Each has a paired `failed` row (4304/4314/4320) and nothing re-sent it —
the "queued for a retry" in the reason was never a queue this path drained. The channel went mute in
the middle of a conversation.

Root cause, two halves: (1) `app/direct_request.py` documents the marker as the one thing the
autonomous path cannot forge, and both `sms_service` and `owner_text.gate` read it — but NOTHING in
the API process ever set it; (2) `gate()`'s M1 rate floor ignored `direct_request` anyway.

Fix (`22eaa66d2`, live after the 14:54:25 restart):
- `app/main.py::_execute_sms_actions_background` runs `execute_actions` inside
 `owner_direct_request("owner_sms")` when `is_owner`. It is set *inside* the worker because the
 actions run on a `threading.Thread` and a ContextVar does not cross a thread boundary.
- `app/owner_text.py::gate` exempts `direct_request` from the floor. Every autonomous producer
 (briefings, CFO asks, triage) still meets the floor; the runaway guard for direct requests is the
 pre-existing burst ceiling (`OWNER_SMS_DIRECT_BURST_LIMIT`, 10 per 60 min).
- Pinned by `tests/test_owner_text_direct_request_floor.py` (3) and
 `tests/test_sms_actions_direct_request.py` (3).

OPEN, found while doing it: `tests/test_owner_text_no_question.py::test_the_gate_reopens_once_the_acknowledgement_is_stale`
already failed on HEAD before this change (verified by running the test against `git show
HEAD:app/owner_text.py`): at +5 minutes the floor (M1, which precedes turn-taking) returns
`rate_floor`, so the test never reaches the `awaiting_reply` it asserts. Not fixed — it needs whoever
owns the open-turn ordering to decide which answer is correct.
