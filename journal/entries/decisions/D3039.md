**D3039 · 2026-10-10 · Survey the estate before designing anything - the register, an auto-discovered skill, and AGENTS.md section 0.**

## D — The estate must be surveyed before anything is designed; the register and a skill make that automatic

DECIDED 2026-10-10 after two identical failures in 48 hours, both "an agent proposed to build
something the estate already had":
 1. A Hetzner Storage Box was recommended when Cloudflare R2 already held the offsite DB backup.
 2. A hand-rolled Cloudflare DNS cutover was designed and started - the owner spent $51.59/month
 and hours of work - before discovering company-promote.py had done exactly that promotion
 since 2026-10-06, with five pre-flight refusals including the two-writer hazard the agent had
 "independently derived".
Owner's words: "It didn't even plan out properly what you were even doing. This was just in the
wind."

THE RULE: before the first design sentence, spend ten minutes proving the thing does not already
exist - read the register, grep the repos, read ~/bin and /opt/company/deploy/hosting-migration/
scripts, run journal.py search, and check what is RUNNING on the hosts (much of this estate's
machinery is deployed rather than committed). If it exists, USE IT. If it exists but is broken,
FIX IT. Never build a parallel one.

WIRED INTO THREE PLACES so a future session cannot miss it:
 1. docs/mesh/000-SYSTEMS-REGISTER.md - machines and roles, every system and where it lives, what
 is authoritative for what, and eight traps that have already cost this estate.
 2. presets/zabz/skills/estate-systems/SKILL.md - an AUTO-DISCOVERED skill whose description fires
 on "set up / build / migrate / replace / new server / we should / I want to move", so the
 survey is offered at the moment it is needed.
 3. AGENTS.md section 0 - a standing rule with both failures named, read by every session under
 harness-config.

THE ARCHITECTURE DECISION THIS SETTLED (mine, not the owner's): secratary-cloud is the PRIMARY and
lpt-survivor-01 stays the standby. It is the faster box and the whole point is to stop depending on
office power. Asking the owner that question was transferring my own thinking back to him.
