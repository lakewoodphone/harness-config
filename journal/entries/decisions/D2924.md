## Decision: a malformed tool call is repaired in the adapter, never silently executed, and never allowed to end the turn

Decided 2026-10-05, ZABZ-YOGA, after the owner reported the same fatal error repeatedly and said to fix it
fully. This is a development decision, not a boss question (rule 3), recorded so it is not relitigated.

**The rule.** When a provider streams tool-call arguments that are not valid JSON:

1. **Strict parse first.** Unchanged behaviour for the 99.9 % of calls that are fine.
2. **Repair only by ADDING syntax.** A repair may insert quote, backslash, comma or bracket characters. Every
 byte of the model's original text must survive into the repair, in order — enforced by a comparison, not by
 intent. If satisfying the parser would need content deleted, truncated, reordered or invented, **the repair
 is refused**.
3. **Refusal is not fatal.** An unrepairable call proceeds with `{}`; the tool layer answers
 `invalid arguments: ...`, the model reads it and corrects itself inside the same turn.
4. **Never guess content.** 52 of the 86 real cases are values cut off mid-string (one was 21,675 characters
 of a message). A repair that closed the string would have invented text and — for `send_message` and
 `write` — silently done the wrong thing. This seat has already sent one outbound message the owner never
 approved; the same class of accident in an automated repair is not acceptable.
5. **Second layer, not first.** `MALFORMED_RESPONSE` also joins `llm-deepseek.retryPolicy.retryableCodes`, so
 an unrecovered case costs one retry rather than the turn. The adapter repair is the primary fix because it
 keeps the turn's work.

**Where it lives:** `scripts/patch-dsh-malformed-tool-input.py` (idempotent, anchored, drift-fails), with the
regression test `dsh-update/tests/tool-input-repair.test.mjs` running the installed patched `translate()` over
the captured corpus. Same convention as `patch-dsh-settlement-crash.py`.

**Rejected alternatives.** (a) Remove the validation — it would accept unparseable input and surface a much
later, more confusing failure. (b) Close truncated strings — invents content. (c) Retry only — leaves a known
recoverable failure to chance and burns a full request per occurrence. (d) Fix it upstream — `0.2.1-alpha.1`
is byte-identical to the installed `0.2.0-rc.2`, so there is nothing to upgrade to; a local patch plus this
record is the honest option, and the patcher is written to fail loudly rather than silently stop matching
when the runtime moves.
