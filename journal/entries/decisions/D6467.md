# D: Part-quality tier for phone repairs — higher-tier refurbished, not aftermarket and not new OEM

**Owner, 2026-10-18:** *"in general Phones we use the higher tier refurbished."*

**The rule, stated so a future session can act on it without asking:**

> **Phone repairs use the HIGHER-TIER REFURBISHED part** — the refurbished / Grade-A used-OEM-pull
> band. **Not** the cheap aftermarket incell LCD, and **not** new genuine OEM.

**Why this had to be written down.** It was already the owner's policy and it reached him as an
owner-queue question anyway (`#537`), because the rule existed only in his head. Every new model
would have re-raised it. The question looked like pricing judgement and was actually a missing record.

**What the tier is worth, measured at MobileSentrix 2026-10-18** — the spread is why the rule matters:

| part | price |
|---|---|
| iPhone 17 — aftermarket LCD (AQ7/Incell) | 25.43 |
| iPhone 17 — aftermarket Plus soft OLED | 45.98 |
| iPhone 17 Pro — aftermarket LCD | 29.25 |
| iPhone 17 Pro Max — aftermarket LCD | 29.93 |
| **iPhone 17 Pro Max — refurbished LCD** | **296.27** |
| **iPhone 17 Pro Max — Grade-A used OEM pull** | **311.73** |
| iPhone 17 Pro — genuine OEM OLED (new) | 342.83 |
| iPhone 17 Pro Max — genuine OEM OLED (new) | 395.61 |

**Tenfold on the same repair.** Quoting the aftermarket tier loses money or gets a redo; quoting new
OEM prices the shop out against everyone. The policy picks the middle band, and it is the band that
feels like a phone screen without new-OEM cost.

**The corollary for price seeds:** a repair price must be derived from a supplier's **actual price for
the selected tier**, with the supplier line and the date read recorded beside it — never "copied from
the previous model's row". Measured on 2026-10-18: no purchase record existed for any iPhone 17 part,
so the TEST prices were anchored estimates with an unstated assumption. Filed as its own work item.

**The generalisation worth keeping: when a question reaches the owner twice, the first instance was a
missing document, not a decision.** Ask what standing rule would have answered it, write that rule
down where the work happens, and the second instance never occurs.
