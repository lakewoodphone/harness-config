## The defect that was still real: a stale budget failed LOOSE

`wake-budget-env.sh` **abandoned** a budget older than 3 hours rather than discounting it -
`read_budget()` returned `None` and the wrapper printed *"STALE ... ceilings left UNSET"*. Measured
consequence at the live balance:

| | before | after |
|---|---|---|
| `WAKE_MAX_USD_PER_DAY` | unset -> `wake.DEFAULT_MAX_USD_PER_DAY` **25.0** | **1.6599** (4h) / 1.1923 (24h) / 0.0 (72h) |
| `WAKE_MAX_PER_DAY` | unset -> `wake.DEFAULT_MAX_PER_DAY` **500** | **25** / 18 / 0 |
| cadence | reverts to target 3 / max 8 | stays 1 / 2 |

That is defect 3 recurring through a different door - a ceiling larger than the balance, which cannot
bind - and it opens **exactly when the guard has stopped running**, which is the ENOSPC at
`wake-balance.py:250` that started this workstream. A spend ceiling must fail tight, never loose.

## The fix (deployed)

`wake_budget.effective_cap()` decays a stale reading linearly instead of discarding it:

 effective = stored_cap x (1 - (age - grace) / (runway_days x 86400)), floored at 0 under min_daily

so the ceiling sheds its whole self over one runway of silence from a 3h grace: 1.6833 at the grace
-> 1.1222 after a day -> 0.5611 after two -> 0.0 after three. The invariant holds at every age
because the linear term never exceeds 1. `effective_max_per_day()` derives the release count from
the **decayed** cap, so the count and the dollars cannot disagree. **An absent file still falls back**
- a host that has never measured a balance must not be starved.

`WAKE_MAX_USD_PER_DAY` is now **always exported when a budget file exists**, stale or not: leaving it
unset is precisely what let 25.00 govern a 4.48 balance.

**Single-sourced, third copy removed.** `wake_budget.budget_env_lines()` renders the shell contract,
and `wake-budget-env.sh` only `eval`s it - the wrapper no longer re-implements the arithmetic. So the
ceiling now lives in **one** place (`wake_budget.py`), read by `wake-balance.py:162`,
`wake-value.py:38` and the crontab's `wake-budget-env.sh` call. Verified: `wake-fanout` crontab line
carries **0** ceiling literals.
