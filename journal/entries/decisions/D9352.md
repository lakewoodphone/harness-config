## Waze dictionary blocking: Apple's own successor to allowDefinitionLookup exists in a declarative config, so the entitled Network Extension is not the only route

Read 2026-10-22 15:15-15:25 UTC on ZABZ-TECH. The investigation it corrects is `personal-secretary-mvp/deploy/waze-mdm/docs/2026-10-22-dictionary-redownload-investigation.md` at origin/master commit `fc1950f6c` (blob 9514 B), plus handoffs `H12227` / `H12244` and lesson `L12196` on ZABZ-YOGA. That doc closes with "the only MDM-deployable control left is a Network Extension content filter". That closing line is now superseded — not the networking finding, only the options ranking.

**The finding.** Apple's Restrictions page, read this session, on `allowDefinitionLookup`: "Deprecated: use the declarative management `com.apple.configuration.keyboard.settings` configuration. Available: iOS 8.1.3+ ... Deprecated: iOS 26.4+". Apple's schema for that declaration (`apple/device-management`, `release`, `declarative/declarations/configurations/keyboard.settings.yaml`) carries `AllowDefinitionLookup`: boolean, default true, presence optional, `combinetype: boolean-and`, iOS 26.4+, supervised, scope system. So the restriction was not removed — it moved from the legacy `com.apple.applicationaccess` payload to declarative management.

**What that changes.** Definition-card harm can be attacked without an Apple entitlement and without a signed app. The cost moves from "weeks of entitlement approval + a money decision" to "stand up a DDM server": NanoMDM does **not** serve declarations itself — `jessepeterson/kmfddm` is the companion DDM server, and our deployed NanoMDM (`ghcr.io/micromdm/nanomdm:latest`, label version `0.9.0`, built 2025-12-25, revision `54b9eaf`) answers `/declaration/<id>` with the plain-text health string "Waze MDM is online" (18 B, HTTP 200, `content-type: text/plain`), i.e. no declaration route. Stand up KMFDDM, enrol it beside nanomdm, ship one `keyboard.settings` declaration with `AllowDefinitionLookup=false`, test on DRN 2007.

**What it does not change.** A declaration kills the lookup UI; it does not stop the MobileAsset download that `L12196` proved invisible to resolver and PAC. If the requirement is "no dictionary file on the device", only the socket-level Network Extension can do it. Whether the requirement is the cards or the file is the owner's call and has not been asked.
