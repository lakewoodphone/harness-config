**D2906 · 2026-09-30 · Security program: allow-by-identity, per-process containment, keys never in context.**

## 2026-09-30 · The security program's decisions

**D1 — Security is allow-by-identity, and denial lives only at the edge.** The owner's constraint is
absolute: *"never ever blocks us when we're doing stuff"*. So enforcement never sits in the path of a
known identity (tailnet, known SSH key, loopback, known agent). Public-internet reachability is the
only place that is deny-by-default, because a mistake there costs us and a delay there costs nobody.

**D2 — Containment is per-process, never per-node.** The only automatic action any component may take
is terminating one process's outbound connection. No whole-machine quarantine, because taking a shop
node offline is a business outage, and an un-quarantine path that nobody has tested is not a control.

**D3 — Credentials must never be readable by an agent.** Keys are injected into a child process by a
runner (`msx-secret run`), recognised by a hash-only scrubber, and eventually held by a broker so the
value never exists in the requesting process. Rationale is two recorded losses, not theory: `P13b`
(a live API key in a session transcript) and `P2815` (a probe that echoed a provider's key out of an
HTTP body). Anything an agent can read has already reached a model provider.

**D4 — The sensing layer is read-only; the acting layer is separate and ships disabled.**
`collect` observes; `sentinel` acts and ships with `enforcement.enabled = false` plus an empty
`auto_contain` list, because an unproven blocker is worse than none.

**D5 — One repository, `mesh-security`, on the authority.** The mesh spans machines; harness
configuration is a different thing. `harness-config` keeps DSH configuration, `mesh-security` owns
the security program, and the bare remote lives at `/home/zabz/mesh-security.git` so every node can
clone it.

**D6 — Change detection outranks point-in-time configuration.** A snapshot that says "port 8128 is
open" is worthless a week later; a diff that says "a listener appeared on all interfaces since
yesterday" is the alarm. Everything the program builds must be diffable and timestamped.

**D7 — Read-only first on every host, including ours.** A security program that mutates the estate
while measuring it cannot be trusted to report honestly. The only host changed this session was the
public box, and only with a scheduled rollback.
