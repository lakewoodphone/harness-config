# ADB helper contract in lpt-flip-phone: `$AdbArgs` is `[string[]]`, and one space-joined element is unwrapped

Decided 2026-10-08 while fixing a repo-wide defect. Every PowerShell helper that shells out to adb
in this repo now follows one shape:

 function Invoke-Adb {
 param([Parameter(Mandatory = $true)][string[]]$AdbArgs, [switch]$AllowFail)
 # Callers pass either an argv array (@('shell','pm','path',$pkg)) or one space-joined
 # command line ("getprop ro.product.model"). Unwrap the second; a typed
 # [string] parameter splats a string one character per argv entry.
 $argv = if ($AdbArgs.Count -eq 1 -and $AdbArgs[0] -match '\s') {
 @($AdbArgs[0] -split '\s+' | Where-Object { $_ -ne '' })
 }
 else { @($AdbArgs) }
 $out = (& adb -s $Serial @argv 2>&1 | Out-String).Trim()
 ...
 }

Three rules, each with a measured reason:

1. **The parameter is never named `$Args`.** `$Args` is automatic and a `param()` for it binds
 nothing, so `@Args` splats nothing and adb runs bare (returns its help text). This silently
 broke `ready-e4610.ps1` — the phone-leak gate — until 2026-10-08.
2. **It is `[string[]]`, not `[string]`.** With `[string]`, an array call site either coerces
 ("a b", wrong) or throws under `Mandatory`, and `@AdbArgs` splats a command line **one argv
 entry per character** (measured: `ARGV(32)` for `"shell getprop ro.product.model"`).
3. **One element containing whitespace is a command line, two-or-more elements are literal argv.**
 This keeps `@('pull', $remote, 'C:\Users\me\App Data\run\b.png')` intact (spaces in a local path
 must not be split) while still accepting legacy `-AdbArgs "settings get global mobile_data"`
 call sites. Verified with a shadowed `adb` function that prints its argv.

Verification harness (works with no handset attached): redefine `adb` as a function returning
`"ARGV($($args.Count)): $($args -join '|')"`, AST-extract the helper from the shipped file,
`Invoke-Expression` it **in the calling scope** (defining it inside a helper function makes it
vanish on return), then call it once per call-site shape and diff the argv.

Applied across 13 files / 75 call sites and pushed as `195d759f` (plus `ready-e4610.ps1` as
`f0117a82`). Evidence: `scripts/utilities/verify-mms-helpers`-style harness runs 2026-10-08, serial
616462586 for the live proofs, `journal` lesson L3446/L3447 and pain P2993/P2994.
