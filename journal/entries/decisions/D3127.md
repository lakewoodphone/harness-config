**D3127 · 2026-10-12 · Do not price an undiagnosed work order: the 50 diagnostic fee is a terminal state in this shop's data, not an intake default.**

**Decision, 2026-10-12, on WO26100812737 (Schreiber, Dell Inspiron 15 3520).** The order was open and `AWAITING_DIAGNOSIS` with **total NULL**, and `bin/lpt-price` (lpt-ops N9) treats an open order with no price as one that can never be charged and can never be released. The temptation was to set the shop's stated 50 diagnostic fee and make the gate green.

**Measured before deciding, production (operational store) read 2026-10-12:** every order in the database carrying exactly **50** is a **terminal** case - `UNFIXABLE`, `CANCELLED`, or `READY_FOR_PICKUP` with nothing further owed. That is the "kept the diagnostic fee" pattern the 2026-10-05 pivot file describes as undocumented practice. Open `AWAITING_DIAGNOSIS` orders instead carry **job** quotes: 55, 75, 100, 150, 165 - and some are NULL.

**Decision: on an unopened machine the honest state is total NULL.** Setting 50 would record a decision nobody has made - that this job is a keep-the-fee no-repair - and a wrong price on an order is customer-visible while a NULL is a known, self-reporting gate finding. The quote is set when the bench answers, by the owner-stated rule **(part cost + shipping) x 1.4 + 65**, rounded to what the customer should be told.

**Reference points for this job, all from the shop's own record.** 8 GB DDR4-3200 SODIMM: 15-25 landed. Dell 3511/3520-class DC-in cable (Dell 0231X7 / DC301017H00): 6-12; the shop's last two DC-jack jobs were quoted **70** and **75** - and its own formula on a 6-dollar cable gives `(6) x 1.4 + 65 = 73.4 -> 75`, which is how you know the rule reproduces history rather than inventing a number. A memory-module job lands near **95**.

**Transferable habit:** when a number has to be set, ask the data what the shop actually does (one query on `orders.total` answered this in seconds) before inventing a convention. The difference between 50 and "no price yet" was one SELECT.
