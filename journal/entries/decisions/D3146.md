**D3146 · 2026-10-13 · The phone gate serves /apple-touch-icon.png and injects the link.**

**Decided and done 2026-10-13, ZABZ-YOGA.** The phone gate now serves the harness's Home Screen icon:
`assets/apple-touch-icon.png` (180x180, 5580 B) is delivered at `/apple-touch-icon.png` **and**
`/apple-touch-icon-precomposed.png`, and `<link rel="apple-touch-icon" sizes="180x180">` is injected into
every document the gate rewrites. Kill switch `PHONE_TOUCH_ICON=0`.

**Why now.** The managed shop clips are fixed in the MDM payload (separate decision), but a clip added by
hand from Safari reads `apple-touch-icon` from the page — and the served document had none, so iOS used a
screenshot. `docs/mesh/67` had said this in writing since September: *"no apple-touch-icon ... iOS rejects
an SVG for that rel and this repo's only PNGs are app screenshots — the real fix is a PNG upstream."* This
is that PNG, and it removes the reason for the omission.

**Measured, same hour, over the tailnet** (not loopback): `GET /apple-touch-icon.png` -> `200`, `image/png`,
`5580` bytes, body byte-identical to the asset; `-precomposed` -> `200 image/png 5580`; the served document
carries exactly one link tag; `/dsh-phone-mobile.css` still `200 / 28167`; title still `DeepSeek Harness`.
`scripts/verify-phone-icon.py` **23/23** in-process — including the two absence paths, because an empty
result must not read as health: with the asset missing the route answers **404** and injects **no** link
while the CSS layer still injects; with the kill switch on, the same, plus the report naming
`apple-touch-icon.png=missing`. Deployed to `/usr/local/bin/phone-gate.py` + `/usr/local/assets/` on the
authority (backup `phone-gate.py.bak-20261013T144459Z-pre-icon`) and the gate restarted under
`phone-gate.service`; the laptop's own gate was restarted the same way and answers the icon at
`https://zabz-yoga-1.tail93e6e6.ts.net/apple-touch-icon.png`.

**Also corrected in the same pass** (one fact, every surface that states it — AGENTS.md §6.3):
`scripts/probe-phone.py` defaulted its authority to the frozen office box; it now resolves this node's own
tailnet name at run time, with the cloud name only as a last resort. `scripts/phone-gate-allow.txt`'s
comment named the old clip URL. `docs/mesh/67` §5.1 and §9.1 and `docs/mesh/146` now say what is true.
