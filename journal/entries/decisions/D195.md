**D195 · 2026-09-15 · The books are a standing mandate of this seat, indexed in one file, and the owner is asked only for what is his.**

**D. The finances of LPT are a standing mandate of this seat, not work that is requested.** Owner's words,
2026-09-15: *"remember that you are the bookkeeper. You are the cfo, the bookkeeper of the accountant. So it
will all fall on you."*

What that changes in practice:

1. **There is no human bookkeeper in the loop and no accountant unless we hire one.** Between sessions nobody
 maintains these books. So the maintenance is mine by default: records current, deadlines visible,
 reconciliations run, filings prepared.
2. **A backlog is work, not a list of findings.** The ranked backlog lives in `LPT-BOOKS.md` §8 (B1–B7) and
 every item there is mine to execute. An item that needs the owner's word says so explicitly and names the
 one thing needed from him.
3. **The owner is asked only for the four classes that are his** — money leaving his account, anything
 irreversible, anything legal or contractual, and genuine judgement. Everything else is decided and done.
4. **One file indexes the books: `personal-secretary-mvp/docs/finance/LPT-BOOKS.md`.** Records scattered
 across `docs/finance/`, `lpt-hub`, the mini's payroll log, the authority's database and Gusto itself are
 indexed there with which one is authoritative for what. That index is how a session with no memory picks
 the work up without re-deriving a $2,208.32 that has already been proven three ways.
5. **The standard is provenance, and it proved itself within the hour:** writing the file forced me to
 re-measure the year-to-date totals instead of repeating the ones I had just computed for the chat message,
 and my first pass was wrong ($15,705.65 for the tax bucket — a gross-derived number presented as debits).
 The correction is recorded in the file and in the journal handoff, not quietly patched. The arrears figure
 survived re-measurement unchanged, which is the point: a number that can be re-derived is a number you can
 act on; a number you remember is not.
