**D3991 · 2026-10-20 · LPT: work orders untouched for more than 50 days are auto-closed.**

Owner rule, stated 2026-10-20 verbatim: 'any work order that hasn't been touched in over 50 days i wnat you to fully auto close now with a note saying why'.

Implemented as lpt-ops/bin/lpt-close-stale (commit b73bab4, docs/close-stale.md). 'Touched' = the latest of five signals: orders.updatedAt, a note on the order, an order_status_history row, a payment row, a communication linked to the order. orders.updatedAt ALONE is not a touch signal - loop jobs write it (measured: 2026-08-13 03:00:29-58 carries 2-4 READY_FOR_PICKUP rows per second).

Consequence the owner must know: an agent note resets an order's clock, so the 163 READY_FOR_PICKUP orders (157 with a note inside 50 days) will NEVER auto-close. They are worked by hand, one device at a time.

First run 2026-10-20: 72 orders closed and verified, all UNFIXABLE, 53-300 days stale, 0 candidates remaining on the next dry run, ledger verified 313 lines. Reversible per order: lpt-write status set --order WO... --status UNFIXABLE --apply.

Decision recorded in lpt-ops/docs/close-stale.md.
