**D2334 · 2026-09-23 · Circuit-breaker runaway_loop is argument-aware; an agent fault never texts the owner.**

DECIDED 2026-09-23 (ZABZ-YOGA -> secratary; deployed, service restarted, 57/57 tests pass).

1. `runaway_loop` is now argument-aware, not name-aware.
 `cost_circuit_breaker.check_duplicate_tools` and
 `anomaly_detector._check_runaway_loop` accept `StepResult.tool_call_details`
 (name + args + executed). A trip now requires the SAME call repeated
 (> `DUPLICATE_TOOL_LIMIT` = 6, arguments compared). A read-only lookup repeated
 with *different* arguments is caught only by `LOOKUP_NAME_STORM_LIMIT` = 25,
 above the agent worker's own `_PER_TICK_LOOKUP_ACTION_LIMIT` = 18. The worker's
 lookup set is resolved from `agent_worker._LOOKUP_TOOLS_ALWAYS_ALLOWED` (with a
 fallback copy plus a test asserting the two sets are equal), so the two layers
 cannot drift apart again. Callers passing bare names keep the old flat rule; only
 the live caller changed.

2. An agent fault never texts the owner.
 `trip_agent` no longer calls `sms_service.send_message`. It records the event and
 calls the new `queue_agent_fault_notice`, which enqueues into
 `owner_message_queue` at urgency "low". The owner set
 `owner_sms_min_urgency = "urgent"` on 2026-05-04 plus a 3/day cap counted from
 `sms_log`; the direct send bypassed the urgency gate entirely and spent the quota
 that real questions need. `anomaly_detector._send_alert` did the same thing and
 was changed the same way. P0/security alerts keep their own
 `bypass_owner_kill_switch` path — this decision does not touch it.

3. Every circuit check now receives `db_url` from the caller, so a trip is
 persisted. It never was: `check_duplicate_tools(agent_id, result.tools_executed)`
 passed no db_url, so both `_log_event` and `_persist_state` returned immediately
 and `circuit_breaker_events` held no runaway_loop row for any of the 14 trips.

WHY: 14 trips in 4 days (2026-09-20 -> 09-23), each opening an agent's circuit for
30 minutes and sending the owner a text; all 14 were false positives. The texts are
what he asked about, verbatim: "⚠️ Agent dept_engineering circuit-broken:
runaway_loop: repo_search called 9x (limit 6) ($0.0000). Cooldown 1800s."
