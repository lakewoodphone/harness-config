**D2653 · 2026-09-27 · Owner text gate is code in the send path, not a settings flag.**

Decision (2026-09-28): the owner's text channel is governed by `app/owner_text.py`, a gate
every owner-bound message must pass, rather than by settings flags or per-caller restraint.

Chosen, and why:
 1. ENFORCE IN CODE, NOT CONFIG. `owner_briefings_enabled=true` sat in `settings_overrides`
 since 2026-05-04 and overrode `.env`'s `false` at every startup, which is how a
 1,736-character briefing reached his phone 25 times in eleven minutes. Config is a
 thing a forgotten process can change; the send path is not.
 2. ONE GATE, THREE CHOKE POINTS. `owner_text.gate()` is called from
 `tool_factory.send_owner_update` (the autonomous choke point, 9 callers),
 `autopilot._maybe_flush_owner_message_queue`, and `sms_service.send_message` as a
 backstop for callers nobody wired up. A refused message is HELD, never dropped, so it
 stays visible in the queue and can be sent deliberately.
 3. BRIEFINGS ARE NEVER TEXTED. `_send_owner_briefing` still builds the briefing (the
 dashboard reads it) but enqueues it `held`. It also marks the day sent
 UNCONDITIONALLY -- marking it only on success is what made one permanent Twilio 400
 into a 25-attempt retry loop.
 4. THE WINDOW IS 12 HOURS, and `urgent`/`critical` may interrupt an open turn. A question
 asked in the evening must still be the only open question in the morning, and being
 silent about a door left open is worse than being second.
 5. A BLANKET STOP HAS ONE CARVE-OUT. "I don't want these" suppresses everything except a
 genuine emergency; a topic he NAMES blocks absolutely, including "urgent" sends --
 because "urgent" is the sender's opinion, and the 2026-09-27 urgent email was a glob.
 6. `is_owner_direct_request()` (a `contextvars` marker in `app/direct_request.py`) is the
 only bypass, and only for turn-taking, never for shape. It is not an action parameter,
 so a model cannot forge it.

Reversible: `remove_suppression(id)`, and the gate's limits come from
`OWNER_TEXT_MAX_CHARS` / `OWNER_TEXT_REPLY_WINDOW_HOURS`.
